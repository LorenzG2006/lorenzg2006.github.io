Aufgabenstellung

void printPattern(int lineLength, int patternLength) gibt auf der Konsole eine oder mehrere Zeilen der Länge lineLength aus. Jede Zeile enthält patternLength mal das Zeichen '?' direkt hintereinander. In der ersten Zeile stehen diese am Beginn der Zeile, in jeder weiteren Zeile wandern sie um jeweils patternLength viele Zeichen nach rechts. Die Zeilen werden rechts der '?' mit dem Buchstaben 'y' aufgefüllt, und ab der zweiten Zeile links der '?' mit dem Buchstaben 'x'. Es gibt genau so viele Zeilen, dass sich auch in der letzten Zeile noch alle patternLength viele Zeichen '?' ausgehen. Annahme(n): 0 < patternLength <= lineLength.

Überblick

Jede Zeile besteht aus drei Bereichen: x von Spalte 0 bis start - 1, ? von start bis start + patternLength - 1, y bis zum Zeilenende. Dabei ist start die Startspalte der ?, die in der ersten Zeile 0 ist und pro Zeile um patternLength wächst. Eine Zeile gibt es, solange die ? noch ganz hineinpassen: start + patternLength <= lineLength. Die äußere Schleife läuft über start, die innere über die Spalten j.

Code

public static void printPattern(int lineLength, int patternLength) {
    for (int start = 0; start + patternLength <= lineLength; start += patternLength) {
        for (int j = 0; j < lineLength; j++) {
            if (j < start) {
                System.out.print('x');
            } else if (j < start + patternLength) {
                System.out.print('?');
            } else {
                System.out.print('y');
            }
        }
        System.out.println();
    }
}

Schritt für Schritt

  1. Äußere Schleife: start = 0, patternLength, 2·patternLength, …, solange start + patternLength <= lineLength. Damit ist die Zeilenanzahl ⌊lineLength/patternLength⌋\lfloor \text{lineLength} / \text{patternLength} \rfloor⌊lineLength/patternLength⌋ – wegen der Annahme mindestens 1.
  2. Innere Schleife: genau lineLength Zeichen pro Zeile.
  3. Bereichswahl per if / else if / else: links x, Mitte ?, rechts y. In der ersten Zeile ist start = 0, die Bedingung j < 0 nie wahr – also kein x, wie verlangt.
  4. Zeilenende mit System.out.println().

Ergebnis

Äußere Schleife über die Startspalte start = 0, p, 2p, … solange start + p <= lineLength; innere Schleife über alle Spalten mit x für j < start, ? für j < start + p, sonst y; Zeile mit println() beenden (Code oben, p = patternLength).

Hilfreiches

Muster ausgeben

Für jede Zeile überlegen: Welche Spaltenbereiche gibt es, und wie hängen ihre Grenzen von der Zeilennummer ab? Dann eine innere Schleife über alle Spalten mit einer if-Kette für die Bereiche. Das ist robuster als drei getrennte Schleifen mit berechneten Längen.

Typische Fehler
  • Abbruchbedingung start < lineLength – dann entsteht eine letzte Zeile mit abgeschnittenen ? (z. B. xxxxxx? bei (7, 3)).
  • start um 1 statt um patternLength erhöhen.
  • x auch in der ersten Zeile oder y links der ? ausgeben.
  • System.out.print("x") ist erlaubt, aber 'x' + '?' in einem print ergibt eine Zahl.
