Angabe Originalseite

Einstufungstest K2, WS2024 (Beispieltest 3), main – (4 Punkte)

Implementieren Sie folgende Punkte in main:

  • Deklarieren Sie eine short-Variable result und eine String-Variable test mit dem Inhalt "all: hallo hall".
  • result soll das Ergebnis des Aufrufs sumUp(4, 9, 320_300) ohne Compiler-Fehler zugewiesen werden.

Testen Sie alle Methoden in main mit zumindest folgenden Aufrufen, und erzeugen Sie mit deren Hilfe die gezeigten Ausgaben. Außer printPattern darf keine der implementierten Methoden eine Ausgabe erzeugen. Alle anderen Ausgaben müssen in main erfolgen.

(Aufrufe und Ausgaben: siehe Tabellen in K2-2024c.1 bis K2-2024c.4.)

Bewertung: Deklarationen 1, korrekte Zuweisung (result) 1, korrekte Aufrufe 1, Ausgaben in der Konsole 1.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Aufbau wie in den anderen K2-Tests. Zwei Details: 320_300 ist ein ganz normales int-Literal (Unterstriche zwischen Ziffern sind seit Java 7 erlaubt und dienen nur der Lesbarkeit). Und sumUp liefert ein int, das wir mit (short) in die short-Variable zwingen müssen – „ohne Compiler-Fehler“ heißt genau das. Interessant: Der Wert ist hier so groß, dass der Cast tatsächlich überläuft.

Code (vollständige Klasse)

public class Aufgabe {

    // sumUp, addMark, digitsToDistance, printPattern wie in K2-2024c.1 bis K2-2024c.4

    public static void main(String[] args) {
        short result;
        String test = "all: hallo hall";
        result = (short) sumUp(4, 9, 320_300);

        System.out.println(sumUp(2, 5, 11));
        System.out.println(sumUp(8, 8, 40));
        System.out.println(sumUp(5, 1, 2000));
        System.out.println(addMark(test, "allo", 6));
        System.out.println(addMark(test, "all", 3));
        System.out.println(addMark(test, "hall", 3));
        System.out.println(addMark(test, "@all", 3));
        System.out.println(digitsToDistance("12oder34"));
        System.out.println(digitsToDistance("Ich bin 1 Berliner!11"));
        System.out.println(digitsToDistance("Heute ist der 4.März 2022"));
        System.out.println(digitsToDistance("Vier*mal*vier_=_0"));
        printPattern(6, 2);
        printPattern(7, 3);
        printPattern(1, 1);
        printPattern(8, 5);
    }
}

Schritt für Schritt

  1. Deklarationen: short result; und String test = "all: hallo hall";.
  2. Zuweisung: result = (short) sumUp(4, 9, 320_300);. Ohne Cast: incompatible types: possible lossy conversion from int to short.
  3. Wert: sumUp(4, 9, 320_300) ergibt 800728007280072 (mit Java und unabhängig mit Python nachgerechnet). Das passt nicht in ein short (max. 327673276732767). Der Cast behält die unteren 16 Bit: 80072−65536=1453680072 - 65536 = 1453680072−65536=14536, also result = 14536. Die Angabe verlangt nur die fehlerfreie Zuweisung, nicht die Ausgabe von result – der Überlauf ist aber eine gute Kontrollfrage.
  4. Aufrufe: sumUp, addMark, digitsToDistance in System.out.println, printPattern (void) direkt.

Hilfreiches

Überlauf beim Cast

(short) x behält die unteren 16 Bit von x und interpretiert sie im Zweierkomplement. Für x=80072=65536+14536x = 80072 = 65536 + 14536x=80072=65536+14536 bleibt 145361453614536; Werte über 327673276732767 können dabei auch negativ werden.

Unterstriche in Zahlenliteralen

320_300 ist dasselbe wie 320300. Unterstriche dürfen nur zwischen Ziffern stehen (_320300 oder 320300_ sind Fehler).

Typische Fehler
  • Cast vergessen → Compilerfehler → 0 Punkte für den ganzen Test.
  • result als int deklarieren, um den Cast zu umgehen – verlangt ist ausdrücklich short.
  • "all: hallo hall" falsch abtippen (Leerzeichen, Doppelpunkt) – dann stimmen die addMark-Ausgaben nicht.
  • Umlaut in "4.März": Quelldatei als UTF-8 speichern, sonst erscheint MÃ¤rz oder M?rz.
