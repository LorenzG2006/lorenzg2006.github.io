Aufgabenstellung

int countDivisors(int x, int y) liefert die Anzahl der Zahlen im Intervall [x,y] zurück, die durch 4 teilbar sind, aber nicht durch 6. Annahme(n): x > 0, y > 0, x <= y.

Aufruf Ausgabe in main auf der Konsole
countDivisors(1, 28) 5
countDivisors(101, 2001) 317
countDivisors(8, 8) 1

Bewertung: korrekte Schleife 2, korrekte Berechnung 2, korrekte Rückgabe 1.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Wir gehen mit einer for-Schleife jede ganze Zahl i von x bis einschließlich y durch und prüfen mit dem Rest-Operator %, ob sie durch 4 teilbar ist (i % 4 == 0) und nicht durch 6 (i % 6 != 0). Trifft beides zu, erhöhen wir einen Zähler. Am Ende geben wir den Zähler zurück. Die Methode gibt selbst nichts aus – die Ausgabe passiert in main.

Code

public static int countDivisors(int x, int y) {
    int count = 0;
    for (int i = x; i <= y; i++) {
        if (i % 4 == 0 && i % 6 != 0) {
            count++;
        }
    }
    return count;
}

Schritt für Schritt

  1. Zähler anlegen: int count = 0; – vor der Schleife, sonst würde er bei jedem Durchlauf neu auf 0 gesetzt.
  2. Schleife über das geschlossene Intervall: Start bei i = x, Bedingung i <= y (nicht <!), denn auch y selbst gehört zu [x,y].
  3. Teilbarkeit: a % b ist der Rest der Ganzzahldivision. a ist genau dann durch b teilbar, wenn der Rest 0 ist. Beide Bedingungen werden mit && verknüpft.
  4. Rückgabe: return count; nach der Schleife.

Ergebnis

Eine for-Schleife von x bis einschließlich y, Bedingung i % 4 == 0 && i % 6 != 0, Zähler erhöhen, nach der Schleife return count; (Code oben).

Hilfreiches

Modulo-Operator

a % b liefert den Rest der Ganzzahldivision a / b (für positive Zahlen zwischen 0 und b - 1). „a durch b teilbar“ ⇔ a % b == 0.

Typische Fehler
  • i < y statt i <= y – dann fehlt y (Off-by-one; countDivisors(8, 8) liefert dann 0).
  • i % 6 == 0 statt != 0 (Logik umgedreht) oder || statt &&.
  • return in der Schleife – die Methode bricht nach dem ersten Treffer ab.
  • System.out.println in der Methode statt return – laut Angabe darf nur printPattern ausgeben.
  • Fehlende Klammer oder fehlendes return → Compilerfehler → 0 Punkte für den ganzen Test. Vor der Abgabe immer kompilieren.

Verwandte Beispiele: K2-2024.2 (findDoubles), K2-2024.5 (main), K2-2024b.1 (getIntegerRoot).
