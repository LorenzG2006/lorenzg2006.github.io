Angabe Originalseite

Einstufungstest K2, WS2024 (Beispieltest 3), Methode 2 von 4 – (6 Punkte)

Einschränkungen

  • Sie dürfen keine zusätzlichen eigenen Hilfsmethoden oder Klassenvariablen verwenden.
  • Die vorgegebenen Methodenköpfe dürfen nicht erweitert oder geändert werden.
  • Sie dürfen Strings nicht per Referenz vergleichen.
  • Sie dürfen nicht die Klassen StringBuffer bzw. StringBuilder verwenden.
  • Sie dürfen keine Lambdas, Streams oder Methodenreferenzen verwenden.
  • Sie dürfen nur folgende Methode(n) aus der Klasse String verwenden: charAt, equals, length, substring.
  • Sie dürfen nur folgende Methode(n) aus der Klasse Character verwenden: isDigit.
  • Aus der Klasse Math dürfen alle Methoden verwendet werden. Sonst darf keine weitere Klasse verwendet werden.

Aufgabenstellung

String addMark(String a, String pattern, int pos) überprüft, ob die Zeichenkette in pattern an bestimmten Stellen in a auftritt, und gibt davon abhängig einen neuen String zurück:

  • Ist pattern ein Teilstring von a an Index pos, wird der Inhalt von a ab inklusive Index pos zurückgegeben.
  • Ist dies nicht der Fall, aber beginnt a mit pattern, so enthält der Rückgabe-String "--" gefolgt von a.
  • Ist auch dies nicht der Fall, aber endet a mit pattern, so enthält der Rückgabe-String a gefolgt von "--".
  • Sonst ist der Rückgabestring "--".

Annahme(n): a != null, pos ≥\geq≥ 0, pattern.length() >>> 0, pos + pattern.length() ≤\leq≤ a.length().

Aufruf Ausgabe in main auf der Konsole
addMark(test, "allo", 6) allo hall
addMark(test, "all", 3) --all: hallo hall
addMark(test, "hall", 3) all: hallo hall--
addMark(test, "@all", 3) --

(test = "all: hallo hall".)

Bewertung: Substrings an richtigen Stellen gesucht 2, korrekte Suche 2, korrekte Rückgabe 2.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

startsWith, endsWith und indexOf sind verboten – wir bauen sie mit substring und equals nach. Wir schneiden aus a jeweils ein Stück der Länge len = pattern.length() heraus (an Index pos, am Anfang, am Ende) und vergleichen es mit pattern. Die vier Fälle stehen in einer Prioritätsreihenfolge („ist dies nicht der Fall, aber …“), also prüfen wir sie genau in dieser Reihenfolge mit return in jedem Zweig.

Code

public static String addMark(String a, String pattern, int pos) {
    int len = pattern.length();
    if (a.substring(pos, pos + len).equals(pattern)) {
        return a.substring(pos);
    }
    if (a.substring(0, len).equals(pattern)) {
        return "--" + a;
    }
    if (a.substring(a.length() - len).equals(pattern)) {
        return a + "--";
    }
    return "--";
}

Schritt für Schritt

  1. An Position pos: a.substring(pos, pos + len) liefert die len Zeichen ab Index pos (Endindex exklusiv). Wegen der Annahme pos + len <= a.length() ist der Aufruf immer gültig. Treffer → a.substring(pos) = Rest ab pos.
  2. Am Anfang: a.substring(0, len) – gültig, weil aus der Annahme len≤pos+len≤len \le pos + len \lelen≤pos+len≤ a.length() folgt.
  3. Am Ende: a.substring(a.length() - len) – die letzten len Zeichen; der Startindex ist ≥0\geq 0≥0 aus demselben Grund.
  4. Sonst "--".

Trace mit a = "all: hallo hall" (Länge 15)

Indizes: a0 l1 l2 :3 4 h5 a6 l7 l8 o9 10 h11 a12 l13 l14.

Ausgabe der Beispielaufrufe (identisch mit der Angabe):

allo hall

Eigene Randfälle:

addMark("abc", "abc", 0)   = abc       (pattern = ganzer String, Fall 1 hat Vorrang)
addMark("abcab", "ab", 3)  = ab        (Treffer genau am Ende über pos)
addMark("abcab", "ab", 1)  = --abcab   (nicht an pos, aber am Anfang)
addMark("xbcab", "ab", 0)  = xbcab--   (nur am Ende)
Ergebnis

Mit len = pattern.length(): (1) a.substring(pos, pos + len).equals(pattern) → a.substring(pos); (2) a.substring(0, len).equals(pattern) → "--" + a; (3) a.substring(a.length() - len).equals(pattern) → a + "--"; (4) sonst "--" (Code oben).

Hilfreiches

substring

s.substring(von, bis) liefert die Zeichen mit Index von bis bis - 1 (Länge bis - von). s.substring(von) liefert alles ab von bis zum Ende. Ungültige Indizes werfen eine StringIndexOutOfBoundsException.

Typische Fehler
  • startsWith/endsWith/indexOf/contains verwenden – nicht erlaubt.
  • substring(pos, len) statt substring(pos, pos + len) – der zweite Parameter ist ein Endindex, keine Länge.
  • Reihenfolge der Fälle vertauschen (z. B. Anfang vor Position prüfen): addMark("abc", "abc", 0) muss abc liefern, nicht --abc.
  • Strings mit == vergleichen.

Verwandte Beispiele: K2-2024c.1 (sumUp), K2-2024c.3 (digitsToDistance), K2-2024b.2 (getThird).
