Einschränkungen

  • Sie dürfen keine zusätzlichen eigenen Hilfsmethoden oder Klassenvariablen verwenden.
  • Die vorgegebenen Methodenköpfe dürfen nicht erweitert oder geändert werden.
  • Sie dürfen Strings nicht per Referenz vergleichen.
  • Sie dürfen nicht die Klassen StringBuffer bzw. StringBuilder verwenden.
  • Sie dürfen keine Lambdas, Streams oder Methodenreferenzen verwenden.
  • Sie dürfen nur folgende Methode(n) aus der Klasse String verwenden: charAt, equals, length, substring.
  • Aus der Klasse Math dürfen alle Methoden verwendet werden. Sonst darf keine weitere Klasse verwendet werden.

Aufgabenstellung

int findDoubles(String text) zählt, wie oft der Buchstabe 'a' innerhalb des Strings text zweimal direkt hintereinander vorkommt, und liefert diesen Wert zurück. Annahme(n): text.length() > 0.

Aufruf Ausgabe in main auf der Konsole
findDoubles(test) 0
findDoubles("Haarspangenaal") 2
findDoubles("The Black Beast of Aaaaargh!") 3
findDoubles("Schokoladenkuchen") 0

(test ist in main der String "Teststring_Einstufungstest".)

Bewertung: korrekte Schleife 2, korrekte Verzweigung 1, korrekte Rückgabe 1.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Wir betrachten jedes Paar benachbarter Zeichen text.charAt(i) und text.charAt(i + 1) und zählen die Paare, in denen beide gleich 'a' sind. Aus dem Beispiel "Aaaaargh" → 3 lesen wir zwei Dinge ab: Paare dürfen sich überlappen (aaaa enthält die Paare an den Stellen 0–1, 1–2, 2–3, also 3), und die Groß-/Kleinschreibung zählt (das große 'A' gehört nicht dazu).

Code

public static int findDoubles(String text) {
    int count = 0;
    for (int i = 0; i < text.length() - 1; i++) {
        if (text.charAt(i) == 'a' && text.charAt(i + 1) == 'a') {
            count++;
        }
    }
    return count;
}

Schritt für Schritt

  1. Schleifengrenze: Weil wir auf i + 1 zugreifen, darf i höchstens text.length() - 2 sein, also Bedingung i < text.length() - 1. Mit i < text.length() würde beim letzten Durchlauf charAt(text.length()) eine StringIndexOutOfBoundsException werfen.
  2. Vergleich von char: Einzelne Zeichen sind primitive char-Werte und werden mit == verglichen (das ist kein Referenzvergleich von Strings). Zeichenliterale stehen in einfachen Hochkommas: 'a'.
  3. Zählen und zurückgeben: wie üblich Zähler vor der Schleife, return danach.

Ergebnis

Schleife for (int i = 0; i < text.length() - 1; i++), Bedingung text.charAt(i) == 'a' && text.charAt(i + 1) == 'a', Zähler zurückgeben (Code oben). Überlappende Paare werden mitgezählt, genau wie die Beispiele es verlangen.

Hilfreiches

charAt und length

s.length() ist die Anzahl der Zeichen; gültige Indizes sind 0 bis s.length() - 1. s.charAt(i) liefert das Zeichen an Index i als char.

Typische Fehler
  • i < text.length() mit Zugriff auf i + 1 → Laufzeitfehler (StringIndexOutOfBoundsException).
  • Nach einem Treffer i zusätzlich erhöhen (i++ im if) – dann zählt "Aaaaargh" nur 2 statt 3.
  • "a" (String) statt 'a' (char) – text.charAt(i) == "a" ist ein Compilerfehler.
  • Groß- und Kleinschreibung vermischen: 'A' ist ein anderes Zeichen als 'a'.
