Angabe Originalseite

Einstufungstest K2, WS2024 (Beispieltest 2), main – (4 Punkte)

Implementieren Sie folgende Punkte in main:

  • Deklarieren Sie eine short-Variable result und eine String-Variable test mit dem Inhalt "Blaukraut".
  • result soll das Ergebnis des Aufrufs getIntegerRoot(25) ohne Compiler-Fehler zugewiesen werden.

Testen Sie alle Methoden in main mit zumindest folgenden Aufrufen, und erzeugen Sie mit deren Hilfe die gezeigten Ausgaben. Außer printBars darf keine der implementierten Methoden eine Ausgabe erzeugen. Alle anderen Ausgaben müssen in main erfolgen.

(Aufrufe und Ausgaben: siehe Tabellen in K2-2024b.1 bis K2-2024b.4.)

Bewertung: Deklarationen 1, korrekte Zuweisung (result) 1, korrekte Aufrufe 1, Ausgaben in der Konsole 1.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Wie in jedem K2-Test: zwei Variablen deklarieren, result den Rückgabewert zuweisen und alle Beispielaufrufe ausführen. getIntegerRoot liefert ein int; die Zuweisung an die short-Variable result braucht einen expliziten Cast (short), sonst kompiliert das Programm nicht.

Code (vollständige Klasse)

public class Aufgabe {

    // getIntegerRoot, getThird, replaceA, printBars wie in K2-2024b.1 bis K2-2024b.4

    public static void main(String[] args) {
        short result;
        String test = "Blaukraut";
        result = (short) getIntegerRoot(25);

        System.out.println(getIntegerRoot(144));
        System.out.println(getIntegerRoot(13));
        System.out.println(getIntegerRoot(1));
        System.out.println(getThird("toss", "a", "coin"));
        System.out.println(getThird("Blaukraut", "bleibt", test));
        System.out.println(getThird("badger", "badger", "badger"));
        System.out.println(replaceA("TU Wien"));
        System.out.println(replaceA("Hubba bubba!"));
        System.out.println(replaceA("aaaa"));
        printBars(2);
        printBars(19);
        printBars(20);
        printBars(21);
    }
}

Schritt für Schritt

  1. Deklarationen: short result; und String test = "Blaukraut";.
  2. Zuweisung: result = (short) getIntegerRoot(25); – Wert 555, denn 5⋅5=255 \cdot 5 = 255⋅5=25. Ohne Cast: incompatible types: possible lossy conversion from int to short.
  3. Aufrufe: getIntegerRoot, getThird, replaceA liefern Werte → in System.out.println(...). printBars ist void und gibt selbst aus → direkter Aufruf.
  4. Im Aufruf getThird("Blaukraut", "bleibt", test) wird die Variable test übergeben; sie hat denselben Inhalt wie das erste Argument, daher ist "bleibt" der „Dritte“.

Ergebnis

Hilfreiches

Rückgabewert vs. Ausgabe

Eine Methode mit Rückgabetyp (int, String, …) liefert einen Wert an den Aufrufer; ausgegeben wird er erst, wenn der Aufrufer ihn an System.out.println übergibt. Eine void-Methode liefert nichts und kann nicht in println stehen.

Typische Fehler
  • Cast (short) vergessen → Compilerfehler → 0 Punkte.
  • String test = Blaukraut; ohne Anführungszeichen → Compilerfehler.
  • System.out.println(printBars(2)); → Compilerfehler (void kann nicht ausgegeben werden).
  • Zusätzliche Ausgaben in getThird usw. – nur printBars darf ausgeben.
