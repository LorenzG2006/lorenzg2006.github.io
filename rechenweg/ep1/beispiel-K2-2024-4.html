Aufgabenstellung

void printPattern(int n, char character) gibt auf der Konsole n Zeilen aus. Ist die aktuelle Zeilennummer gerade, wird 2·n-mal das Zeichen character ausgegeben. Ist die aktuelle Zeilennummer ungerade, wird n-mal zuerst das Zeichen character gefolgt von einem Punkt '.' ausgegeben. Am Ende jeder Zeile wird die Zeilennummer ausgegeben. Die Zählung der Zeilennummern beginnt mit 1. Annahme(n): n > 0.

Aufruf Ausgabe in main auf der Konsole
printPattern(4, '!') !.!.!.!.1
!!!!!!!!2
!.!.!.!.3
!!!!!!!!4
printPattern(5, '*') *.*.*.*.*.1
**********2
*.*.*.*.*.3
**********4
*.*.*.*.*.5

Bewertung: richtige Anzahl an Zeilen 2, richtige Anzahl an Zeichen pro Zeile 2, korrekte Zeilennummern 2.

Überblick

Eine äußere Schleife zählt die Zeilennummer line von 1 bis n. In jeder Zeile entscheidet line % 2 == 0, welche Variante gedruckt wird; eine innere Schleife gibt die Zeichen aus. Beide Varianten sind gleich lang (2n2n2n Zeichen). Mit System.out.println(line) wird am Zeilenende die Nummer ausgegeben und gleichzeitig die Zeile beendet. Diese Methode ist die einzige, die selbst ausgeben darf.

Code

public static void printPattern(int n, char character) {
    for (int line = 1; line <= n; line++) {
        if (line % 2 == 0) {
            for (int j = 0; j < 2 * n; j++) {
                System.out.print(character);
            }
        } else {
            for (int j = 0; j < n; j++) {
                System.out.print(character);
                System.out.print('.');
            }
        }
        System.out.println(line);
    }
}

Schritt für Schritt

  1. Zeilen: line von 1 bis einschließlich n → genau n Zeilen, Nummerierung ab 1 wie verlangt.
  2. Gerade Zeile: innere Schleife 2 * n Mal, jeweils character.
  3. Ungerade Zeile: innere Schleife n Mal, jeweils character und '.' – zwei getrennte print-Aufrufe, damit nicht character + '.' als Zahl addiert wird.
  4. Zeilenende: System.out.println(line) druckt die Nummer und den Zeilenumbruch.

Ergebnis

Äußere Schleife line = 1 … n; bei geradem line 2n-mal character, sonst n-mal character und '.'; danach System.out.println(line) (Code oben).

Hilfreiches

print vs. println

System.out.print(x) gibt x ohne Zeilenumbruch aus, System.out.println(x) gibt x aus und beendet die Zeile. System.out.println() beendet nur die Zeile.

Typische Fehler
  • Zeilenzählung bei 0 beginnen – dann ist die erste Zeile „gerade“ und die Nummern sind um 1 verschoben.
  • System.out.print(character + '.') – char + char ist eine int-Addition, ausgegeben wird z. B. 79 statt !..
  • In der geraden Zeile nur n statt 2 * n Zeichen ausgeben.
  • println innerhalb der inneren Schleife – dann steht jedes Zeichen in einer eigenen Zeile.
