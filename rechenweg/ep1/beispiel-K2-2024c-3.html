Einschränkungen

  • Sie dürfen keine zusätzlichen eigenen Hilfsmethoden oder Klassenvariablen verwenden.
  • Die vorgegebenen Methodenköpfe dürfen nicht erweitert oder geändert werden.
  • Sie dürfen Strings nicht per Referenz vergleichen.
  • Sie dürfen nicht die Klassen StringBuffer bzw. StringBuilder verwenden.
  • Sie dürfen keine Lambdas, Streams oder Methodenreferenzen verwenden.
  • Sie dürfen nur folgende Methode(n) aus der Klasse String verwenden: charAt, equals, length, substring.
  • Sie dürfen nur folgende Methode(n) aus der Klasse Character verwenden: isDigit.
  • Aus der Klasse Math dürfen alle Methoden verwendet werden. Sonst darf keine weitere Klasse verwendet werden.

Aufgabenstellung

String digitsToDistance(String text) gibt eine Kopie von text zurück, in der jede Ziffer durch die Anzahl jener Zeichen ersetzt wird, welche in text zwischen der Ziffer und der vorangehenden Ziffer in text stehen. Die erste Ziffer wird durch die Anzahl aller Zeichen, welche vor ihr in text vorkommen, ersetzt. Hinweis: Ziffern können durch mehrstellige Zahlen ersetzt werden. Annahme(n): text != null.

Aufruf Ausgabe in main auf der Konsole
digitsToDistance("12oder34") 00oder40
digitsToDistance("Ich bin 1 Berliner!11") Ich bin 8 Berliner!100
digitsToDistance("Heute ist der 4.März 2022") Heute ist der 14.März 6000
digitsToDistance("Vier*mal*vier_=_0") Vier*mal*vier_=_16

Bewertung: Schleife(n) und korrekter Test auf Ziffern 2, Ersetzungen richtig berechnet, eingefügt, zurückgegeben 2.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Steht eine Ziffer an Index i und die vorangehende Ziffer an Index last, so liegen dazwischen genau i - last - 1 Zeichen. Für die erste Ziffer stehen vor ihr i Zeichen – das passt in dieselbe Formel, wenn wir last mit -1 beginnen lassen: i - (-1) - 1 = i. Wir laufen also einmal durch text, merken uns den Index der letzten Ziffer und bauen das Ergebnis Zeichen für Zeichen auf. Wichtig: Die Abstände beziehen sich auf den Original-text, nicht auf das (durch mehrstellige Zahlen längere) Ergebnis.

Code

public static String digitsToDistance(String text) {
    String result = "";
    int last = -1;
    for (int i = 0; i < text.length(); i++) {
        char c = text.charAt(i);
        if (Character.isDigit(c)) {
            result += i - last - 1;
            last = i;
        } else {
            result += c;
        }
    }
    return result;
}

Schritt für Schritt

  1. last = -1 bedeutet „bisher keine Ziffer“ (ein Index, der vor dem String liegt).
  2. Für jedes Zeichen: Character.isDigit(c) prüft, ob es eine Ziffer ist (erlaubt laut Einschränkungen).
  3. Ziffer: Abstand i - last - 1 anhängen (als Zahl, also ggf. mehrstellig), dann last = i – nach dem Berechnen, sonst wäre der Abstand immer −1-1−1.
  4. Keine Ziffer: Zeichen unverändert anhängen.

Achtung bei result += i - last - 1;: Der Ausdruck rechts wird zuerst als int ausgerechnet (+= hat die niedrigste Priorität), dann als Text angehängt. Schreibt man stattdessen result = result + i - last - 1;, wird von links nach rechts gerechnet: erst result + i (String!), dann - last → Compilerfehler.

Trace für "Ich bin 1 Berliner!11"

Ziffer an Index i last vorher Abstand i - last - 1 angehängt
8 −1 8−(−1)−1=88 - (-1) - 1 = 88−(−1)−1=8 8
19 8 19−8−1=1019 - 8 - 1 = 1019−8−1=10 10
20 19 20−19−1=020 - 19 - 1 = 020−19−1=0 0

Ergebnis Ich bin 8 Berliner!100 ✓ (zwischen Index 8 und 19 stehen die 10 Zeichen Berliner!).

Weitere Kontrolle "Heute ist der 4.März 2022": 4 an Index 14 → 14; 2 an Index 21 → 21−14−1=621 - 14 - 1 = 621−14−1=6; 0, 2, 2 direkt dahinter → je 0. Ergebnis Heute ist der 14.März 6000 ✓.

Kompiliert und getestet (javac/java, JDK 21)

Ausgabe der Beispielaufrufe (identisch mit der Angabe, Datei UTF-8, Ausgabe mit -Dstdout.encoding=UTF-8 wegen „ä“):

Ich bin 8 Berliner!100
Heute ist der 14.März 6000

Eigene Randfälle:

digitsToDistance("")              = ""
digitsToDistance("abc")           = abc             (keine Ziffer)
digitsToDistance("7")             = 0
digitsToDistance("abcdefghijkl9") = abcdefghijkl12  (zweistelliger Ersatz)
Ergebnis

Einmal durch text laufen, last = -1; bei einer Ziffer i - last - 1 anhängen und last = i setzen, sonst das Zeichen anhängen; Ergebnis zurückgeben (Code oben).

Hilfreiches

Character.isDigit

Character.isDigit(c) liefert true, wenn c eine Ziffer ist ('0' bis '9'). Gleichwertig ohne die Klasse Character: c >= '0' && c <= '9'.

Typische Fehler
  • last mit 0 initialisieren – dann ist der Abstand der ersten Ziffer um 1 zu klein ("12oder34" würde mit -1 beginnen).
  • last = i vor der Berechnung setzen.
  • Abstände im Ergebnis-String statt im Original messen (mehrstellige Ersetzungen verschieben die Indizes).
  • result = result + i - last - 1; → Compilerfehler (String minus int).
  • Die Ziffer selbst zusätzlich anhängen.

Verwandte Beispiele: K2-2024c.2 (addMark), K2-2024c.4 (printPattern), K2-2024b.3 (replaceA).
