Angabe Originalseite

Einstufungstest K2, WS2024 (Beispieltest 1), main – (4 Punkte)

Implementieren Sie folgende Punkte in main:

  • Deklarieren Sie eine short-Variable result und eine String-Variable test mit dem Inhalt "Teststring_Einstufungstest".
  • result soll das Ergebnis des Aufrufs countDivisors(299, 305) ohne Compiler-Fehler zugewiesen werden.

Testen Sie alle Methoden in main mit zumindest folgenden Aufrufen, und erzeugen Sie mit deren Hilfe die gezeigten Ausgaben. Außer printPattern darf keine der implementierten Methoden eine Ausgabe erzeugen. Alle anderen Ausgaben müssen in main erfolgen.

(Aufrufe und Ausgaben: siehe Tabellen in K2-2024.1 bis K2-2024.4.)

Bewertung: Deklarationen 1, korrekte Zuweisung (result) 1, korrekte Aufrufe 1, Ausgaben in der Konsole 1.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

main hat drei Aufgaben: die zwei Variablen deklarieren, result den Rückgabewert von countDivisors(299, 305) zuweisen und alle Beispielaufrufe ausführen. Der Knackpunkt ist die Zuweisung: countDivisors liefert ein int, result ist aber ein short. Java erlaubt die einengende Umwandlung int → short nur mit einem expliziten Cast (short), sonst gibt es einen Compilerfehler – und ein Compilerfehler bedeutet beim K2-Test 0 Punkte.

Code (vollständige Klasse)

public class Aufgabe {

    // countDivisors, findDoubles, reverseInsert, printPattern wie in K2-2024.1 bis K2-2024.4

    public static void main(String[] args) {
        short result;
        String test = "Teststring_Einstufungstest";
        result = (short) countDivisors(299, 305);

        System.out.println(countDivisors(1, 28));
        System.out.println(countDivisors(101, 2001));
        System.out.println(countDivisors(8, 8));
        System.out.println(findDoubles(test));
        System.out.println(findDoubles("Haarspangenaal"));
        System.out.println(findDoubles("The Black Beast of Aaaaargh!"));
        System.out.println(findDoubles("Schokoladenkuchen"));
        System.out.println(reverseInsert(test, '.'));
        System.out.println(reverseInsert("qwerty", '-'));
        System.out.println(reverseInsert("Pinkie Pie", '!'));
        printPattern(4, '!');
        printPattern(5, '*');
    }
}

Schritt für Schritt

  1. Deklarationen: short result; und String test = "Teststring_Einstufungstest"; (Variablenname und Inhalt exakt wie verlangt).
  2. Zuweisung mit Cast: result = (short) countDivisors(299, 305);. Ohne (short) meldet javac: incompatible types: possible lossy conversion from int to short. Der Wert ist hier 111 (von 299 bis 305 ist nur 304 durch 4, aber nicht durch 6 teilbar; 300 ist durch 12 teilbar), passt also problemlos in ein short.
  3. Aufrufe und Ausgaben: Die Methoden mit Rückgabewert werden in System.out.println(...) aufgerufen, weil sie selbst nichts ausgeben dürfen. printPattern gibt selbst aus und hat void als Rückgabetyp – sie wird ohne println aufgerufen (System.out.println(printPattern(4, '!')) wäre ein Compilerfehler).
  4. Die Variable test wird bei den Aufrufen findDoubles(test) und reverseInsert(test, '.') verwendet.

Ergebnis

short result; String test = "Teststring_Einstufungstest"; result = (short) countDivisors(299, 305); und anschließend alle Beispielaufrufe – die Methoden mit Rückgabewert in System.out.println, printPattern direkt (Code oben).

Hilfreiches

Einengende Typumwandlung (Narrowing)

Von einem größeren in einen kleineren Ganzzahltyp (long → int → short → byte) muss explizit gecastet werden: (short) ausdruck. Ist der Wert zu groß, werden die oberen Bits abgeschnitten (der Wert „läuft über“). short umfasst −32768-32768−32768 bis 327673276732767.

Typische Fehler
  • short result = countDivisors(299, 305); ohne Cast → Compilerfehler → 0 Punkte.
  • short(countDivisors(299, 305)) schreiben – das ist keine Java-Syntax; richtig ist (short) countDivisors(299, 305).
  • Ausgaben in den Methoden statt in main (außer printPattern).
  • void-Methode in println aufrufen → Compilerfehler.
  • Den String test falsch abtippen (Großschreibung, Unterstrich) – dann stimmen die Ausgaben nicht.

Verwandte Beispiele: K2-2024.1 (countDivisors), K2-2024b.5 (main, Test 2), K2-2024c.5 (main, Test 3).
