Einschränkungen

  • Sie dürfen keine zusätzlichen eigenen Hilfsmethoden oder Klassenvariablen verwenden.
  • Die vorgegebenen Methodenköpfe dürfen nicht erweitert oder geändert werden.
  • Sie dürfen Strings nicht per Referenz vergleichen.
  • Sie dürfen nicht die Klassen StringBuffer bzw. StringBuilder verwenden.
  • Sie dürfen keine Lambdas, Streams oder Methodenreferenzen verwenden.
  • Sie dürfen nur folgende Methode(n) aus der Klasse String verwenden: charAt, equals, length, substring.
  • Aus der Klasse Math dürfen alle Methoden verwendet werden. Sonst darf keine weitere Klasse verwendet werden.

Aufgabenstellung

String reverseInsert(String text, char character) fügt zwischen je zwei Zeichen von text den Buchstaben character ein und gibt diesen String in umgekehrter Reihenfolge zurück. Annahme(n): text.length() > 1.

Aufruf Ausgabe in main auf der Konsole
reverseInsert(test, '.') t.s.e.t.s.g.n.u.f.u.t.s.n.i.E._.g.n.i.r.t.s.t.s.e.T
reverseInsert("qwerty", '-') y-t-r-e-w-q
reverseInsert("Pinkie Pie", '!') e!i!P! !e!i!k!n!i!P

(test = "Teststring_Einstufungstest".)

Bewertung: korrekte Schleife(n) 2, korrekte Verzweigung 2, Randfälle (Position text.length()) korrekt behandelt 1, korrekte Rückgabe 1.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Einfügen und Umdrehen lassen sich in einem Durchlauf erledigen: Wir laufen von hinten nach vorne durch text und hängen jedes Zeichen an einen Ergebnis-String an. Nach jedem Zeichen außer dem letzten angehängten (das ist text.charAt(0)) hängen wir zusätzlich character an. So steht character genau zwischen je zwei Zeichen, aber weder am Anfang noch am Ende. Da StringBuilder verboten ist, verketten wir mit +=.

Code

public static String reverseInsert(String text, char character) {
    String result = "";
    for (int i = text.length() - 1; i >= 0; i--) {
        result += text.charAt(i);
        if (i > 0) {
            result += character;
        }
    }
    return result;
}

Schritt für Schritt

  1. Start mit leerem String "". Hängt man an einen String ein char mit += an, entsteht ein neuer String mit diesem Zeichen am Ende.
  2. Rückwärts-Schleife: i beginnt beim letzten gültigen Index text.length() - 1 (nicht bei text.length()!) und läuft bis einschließlich 0.
  3. Verzweigung für den Rand: Nach dem Zeichen mit Index 0 ist der String fertig – dort darf kein Trennzeichen mehr folgen, daher if (i > 0).
  4. Rückgabe des fertigen Strings.

Rückgabe y-t-r-e-w-q ✓. Bei einem String der Länge nnn entstehen nnn Zeichen plus n−1n - 1n−1 Trennzeichen, also 2n−12n - 12n−1 Zeichen (hier 111111).

Alternative

Man kann auch vorwärts laufen und vorne anfügen: result = text.charAt(i) + result; – dann muss man aber aufpassen, dass char + String korrekt ein String wird (das klappt, weil result ein String ist) und das Trennzeichen vor allen Zeichen außer dem ersten einfügen. Die Rückwärts-Schleife ist übersichtlicher.

Kompiliert und getestet (javac/java, JDK 21)

Eigene Randfälle:

reverseInsert("ab", '+')  = b+a     (kürzester erlaubter Text)
reverseInsert("xyz", 'x') = zxyxx   (Trennzeichen kommt auch im Text vor)
Ergebnis

Rückwärts von text.length() - 1 bis 0 laufen, jedes Zeichen anhängen und – außer nach Index 0 – character anhängen; Ergebnis-String zurückgeben (Code oben).

Hilfreiches

String-Verkettung

s + c bzw. s += c hängt ein Zeichen (oder eine Zahl, einen String) an den String s an und erzeugt einen neuen String. Strings sind unveränderlich; result zeigt danach auf den neuen String.

Typische Fehler
  • Start bei i = text.length() → StringIndexOutOfBoundsException (der in der Bewertung genannte Randfall).
  • Trennzeichen auch nach dem letzten Zeichen anhängen (y-t-r-e-w-q-).
  • result += character + text.charAt(i); – zwei char werden dabei zuerst als Zahlen addiert (z. B. '-' + 'y' = 166) und erst dann angehängt.
  • Nur umdrehen oder nur einfügen und das andere vergessen.

Verwandte Beispiele: K2-2024.2 (findDoubles), K2-2024.4 (printPattern), K2-2024c.3 (digitsToDistance).
