Angabe Originalseite

Einstufungstest K2, WS2024 (Beispieltest 2), Methode 3 von 4 – (5 Punkte)

Einschränkungen

  • Sie dürfen keine zusätzlichen eigenen Hilfsmethoden oder Klassenvariablen verwenden.
  • Die vorgegebenen Methodenköpfe dürfen nicht erweitert oder geändert werden.
  • Sie dürfen Strings nicht per Referenz vergleichen.
  • Sie dürfen nicht die Klassen StringBuffer bzw. StringBuilder verwenden.
  • Sie dürfen keine Lambdas, Streams oder Methodenreferenzen verwenden.
  • Sie dürfen nur folgende Methode(n) aus der Klasse String verwenden: charAt, equals, length, substring.
  • Sonst darf keine weitere Klasse verwendet werden.

Aufgabenstellung

String replaceA(String s) gibt eine Kopie von s zurück, bei der das erste Vorkommen des Zeichens 'a' durch die Zahl 1, das zweite Vorkommen von 'a' durch die Zahl 2 usw. ersetzt wird. Annahme(n): s != null.

Aufruf Ausgabe in main auf der Konsole
replaceA("TU Wien") TU Wien
replaceA("Hubba bubba!") Hubb1 bubb2!
replaceA("aaaa") 1234

Bewertung: korrekte Schleife 2, korrekte Verzweigung 2, korrekte Rückgabe 1.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Wir bauen einen neuen String Zeichen für Zeichen auf (Strings sind unveränderlich, replace ist ohnehin verboten). Ein Zähler merkt sich, das wievielte 'a' gerade gefunden wurde. Ist das aktuelle Zeichen ein 'a', hängen wir die Zahl des Zählers an, sonst das Zeichen selbst.

Code

public static String replaceA(String s) {
    String result = "";
    int count = 0;
    for (int i = 0; i < s.length(); i++) {
        if (s.charAt(i) == 'a') {
            count++;
            result += count;
        } else {
            result += s.charAt(i);
        }
    }
    return result;
}

Schritt für Schritt

  1. Ergebnis und Zähler vor der Schleife anlegen: result = "", count = 0.
  2. Jedes Zeichen von Index 0 bis s.length() - 1 betrachten.
  3. Treffer: zuerst count++ (das erste 'a' bekommt 1, nicht 0), dann result += count;. Weil result ein String ist, wird die Zahl als Text angehängt – ab dem zehnten 'a' also auch mehrstellig (10, 11, …).
  4. Kein Treffer: Zeichen unverändert anhängen.
  5. return result;

Eigene Randfälle:

Ergebnis

Zeichenweise kopieren; bei 'a' den Zähler erhöhen und den Zähler anhängen, sonst das Zeichen; Ergebnis zurückgeben (Code oben).

Hilfreiches

String + Zahl

"Hubb" + 1 ergibt den String "Hubb1": Ist ein Operand von + ein String, wird der andere in Text umgewandelt und angehängt.

Typische Fehler
  • count++ erst nach dem Anhängen – dann beginnt die Nummerierung bei 0.
  • result += (char) count; oder result += '0' + count; – das hängt ein Zeichen mit dem Code count bzw. eine int-Summe an, nicht die Ziffer.
  • Den Zähler in der Schleife deklarieren – dann wird er bei jedem Zeichen auf 0 zurückgesetzt.
  • s selbst „verändern“ wollen (z. B. s.charAt(i) = '1') → Compilerfehler.
