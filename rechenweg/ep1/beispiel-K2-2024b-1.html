Einstufungstest K2, WS2024 (Beispieltest 2), Methode 1 von 4 – (5 Punkte)

Einschränkungen

  • Sie dürfen keine zusätzlichen eigenen Hilfsmethoden oder Klassenvariablen verwenden.
  • Die vorgegebenen Methodenköpfe dürfen nicht erweitert oder geändert werden.
  • Sie dürfen Strings nicht per Referenz vergleichen.
  • Sie dürfen nicht die Klassen StringBuffer bzw. StringBuilder verwenden.
  • Sie dürfen keine Lambdas, Streams oder Methodenreferenzen verwenden.
  • Sie dürfen nur folgende Methode(n) aus der Klasse String verwenden: charAt, equals, length, substring.
  • Sonst darf keine weitere Klasse verwendet werden.

Aufgabenstellung

int getIntegerRoot(int k) bestimmt, ob k das Quadrat einer natürlichen Zahl ist – d. h. ob eine natürliche Zahl i existiert, sodass i · i = k ist. Ist dies der Fall, wird i zurückgegeben, ansonsten wird -1 zurückgegeben. Annahme(n): k > 0. Hinweis: Die Berechnung muss nicht effizient implementiert werden. Bedenken Sie, dass für i nur Zahlen im Intervall [1,k] in Frage kommen. Beachten Sie auch, dass Sie gemäß den Einschränkungen keine Methoden der Klasse Math verwenden dürfen.

Aufruf Ausgabe in main auf der Konsole
getIntegerRoot(144) 12
getIntegerRoot(13) -1
getIntegerRoot(1) 1

Bewertung: korrekte Schleife 2, korrekte Berechnung 2, korrekte Rückgabe 1.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Math.sqrt ist verboten, also suchen wir die Wurzel: Wir probieren i = 1, 2, 3, … und prüfen jeweils i * i == k. Sobald es passt, geben wir i sofort zurück. Wird die Schleife ohne Treffer verlassen, ist k keine Quadratzahl → -1. Da i * i mit wachsendem i streng wächst, können wir aufhören, sobald i * i größer als k ist.

Code

public static int getIntegerRoot(int k) {
    for (int i = 1; i <= k / i; i++) {
        if (i * i == k) {
            return i;
        }
    }
    return -1;
}

Schritt für Schritt

  1. Kandidaten: i beginnt bei 1 (die Angabe nennt das Intervall [1,k]).
  2. Abbruchbedingung i <= k / i: Für positive ganze Zahlen gilt i <= k / i (Ganzzahldivision) genau dann, wenn i⋅i≤ki \cdot i \le ki⋅i≤k. Sobald i2>ki^2 > ki2>k ist, kann kein größeres i mehr passen. Wir schreiben die Bedingung als Division statt als i * i <= k, weil i * i für große k (nahe Integer.MAX_VALUE) über den int-Bereich hinauslaufen könnte.
  3. Treffer: if (i * i == k) return i; – das return beendet die Methode sofort.
  4. Kein Treffer: Nach der Schleife return -1;. Dieses return ist Pflicht, sonst meldet der Compiler missing return statement.

Einfachste erlaubte Variante

Laut Hinweis muss es nicht effizient sein: for (int i = 1; i <= k; i++) { if (i * i == k) return i; } ist für die Beispielaufrufe ebenfalls richtig. Für sehr große k (über 46340246340^2463402) kann i * i dabei allerdings überlaufen; die Variante mit i <= k / i vermeidet das und ist zusätzlich viel schneller.

Ergebnis

Kandidaten i = 1, 2, … durchprobieren, solange i <= k / i; bei i * i == k sofort return i;, nach der Schleife return -1; (Code oben).

Hilfreiches

Frühes return

Ein return innerhalb einer Schleife beendet sofort die ganze Methode. Damit lässt sich eine Suche elegant formulieren: Treffer → return, nach der Schleife der „nicht gefunden“-Wert.

Typische Fehler
  • Math.sqrt(k) verwenden – laut Einschränkungen verboten (diesmal ist Math nicht erlaubt).
  • return -1; im else-Zweig innerhalb der Schleife – dann wird schon bei i = 1 abgebrochen (getIntegerRoot(144) liefert -1).
  • Fehlendes return nach der Schleife → Compilerfehler → 0 Punkte.
  • Schleife bei 0 beginnen ist harmlos für i * i, aber k / i wäre dann eine Division durch 0.

Verwandte Beispiele: K2-2024b.2 (getThird), K2-2024b.5 (main), K2-2024.1 (countDivisors).
