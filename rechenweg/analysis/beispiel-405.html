Angabe Originalseite

Man bestimme die relativen Extrema der Funktion f(x,y)=4(x−2)(y2+10y)+3x3f(x,y) = 4(x-2)(y^2+10y) + 3x^3f(x,y)=4(x−2)(y2+10y)+3x3.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

fff ist ein Polynom, also auf ganz R2\R^2R2 beliebig oft differenzierbar. Relative Extrema können nur in stationären Punkten (∇f=0\nabla f = 0∇f=0) liegen. Diese bestimmen wir und entscheiden mit der Hessematrix, ob Maximum, Minimum oder Sattelpunkt vorliegt.

Schritt 1: Gradient

fx=4(y2+10y)+9x2,(Ableitung von 4(x−2) ist 4)fy=4(x−2)(2y+10)=8(x−2)(y+5).\begin{aligned} f_x &= 4(y^2 + 10y) + 9x^2, && (\text{Ableitung von } 4(x-2) \text{ ist } 4)\\ f_y &= 4(x-2)(2y + 10) = 8(x-2)(y+5). && \end{aligned}fx​fy​​=4(y2+10y)+9x2,=4(x−2)(2y+10)=8(x−2)(y+5).​​(Ableitung von 4(x−2) ist 4)​

Hilfreiches

Notwendige Bedingung

Hat die differenzierbare Funktion fff in einem inneren Punkt ppp ein lokales Extremum, so gilt ∇f(p)=0\nabla f(p) = 0∇f(p)=0.

Hinreichende Bedingung (2 Variablen)

Sei ∇f(p)=0\nabla f(p) = 0∇f(p)=0 und D=fxxfyy−fxy2D = f_{xx}f_{yy} - f_{xy}^2D=fxx​fyy​−fxy2​ in ppp. D>0,fxx>0D > 0, f_{xx} > 0D>0,fxx​>0: lokales Minimum; D>0,fxx<0D > 0, f_{xx} < 0D>0,fxx​<0: lokales Maximum; D<0D < 0D<0: Sattelpunkt; D=0D = 0D=0: keine Aussage.

Typische Fehler
  • Beim Faktorisieren von fyf_yfy​ einen Fall vergessen (Produkt null   ⟺  \iff⟺ ein Faktor null).
  • x=−103x = -\frac{10}{3}x=−310​ übersehen (Wurzel hat zwei Vorzeichen).
  • Ein lokales Maximum mit größerem Wert als das lokale Minimum für „global“ halten – fff ist unbeschränkt.
