Überblick

Zählergrad = Nennergrad = 333: zuerst Polynomdivision. Den Nenner faktorisieren wir durch Erraten einer Nullstelle; er hat eine doppelte Nullstelle bei x=1x = 1x=1. Der echt gebrochene Rest wird in Partialbrüche zerlegt.

Da beide Polynome Leitkoeffizient 111 haben, ist der ganzrationale Anteil 111:

Hilfreiches

Nullstellen erraten

Hat ein normiertes Polynom mit ganzzahligen Koeffizienten eine ganzzahlige Nullstelle, so teilt diese den konstanten Term (hier 222: Kandidaten ±1,±2\pm1, \pm2±1,±2).

Partialbruchzerlegung

Mehrfacher Linearfaktor (x−a)k(x - a)^k(x−a)k → Teilbrüche A1x−a+⋯+Ak(x−a)k\frac{A_1}{x - a} + \dots + \frac{A_k}{(x - a)^k}x−aA1​​+⋯+(x−a)kAk​​; AkA_kAk​ über Einsetzen von x=ax = ax=a, den Rest über Koeffizientenvergleich.

Typische Fehler
  • Ohne Polynomdivision Partialbrüche ansetzen (Zählergrad = Nennergrad!).
  • Vorzeichen beim Rest −x2+3x-x^2 + 3x−x2+3x (es wird −3x-3x−3x subtrahiert, also +3x+3x+3x).
  • ∫dx(x−1)2\int\frac{\mathrm dx}{(x - 1)^2}∫(x−1)2dx​ als Logarithmus integrieren.
