Angabe Originalseite

415–420) Man bestimme die allgemeine Lösung der Differentialgleichung bzw. die Lösung der Anfangswertaufgabe:

xy′=yln⁡yxxy' = y\ln\frac{y}{x}xy′=ylnxy​

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Nach Division durch xxx steht y′=yxln⁡yxy' = \frac{y}{x}\ln\frac{y}{x}y′=xy​lnxy​ – die rechte Seite hängt nur von u=yxu = \frac{y}{x}u=xy​ ab (homogene Differentialgleichung). Mit der Substitution y=uxy = uxy=ux entsteht eine separable Gleichung für uuu. Wegen des Logarithmus muss yx>0\frac{y}{x} > 0xy​>0 sein.

Schritt 1: Substitution

Sei u(x)=y(x)xu(x) = \frac{y(x)}{x}u(x)=xy(x)​, also y=uxy = uxy=ux und y′=u+xu′y' = u + xu'y′=u+xu′ (Produktregel). Einsetzen in y′=uln⁡uy' = u\ln uy′=ulnu:

u+xu′=uln⁡u  ⟺  xu′=u(ln⁡u−1).u + xu' = u\ln u \iff xu' = u(\ln u - 1).u+xu′=ulnu⟺xu′=u(lnu−1).

Definitionsbereich: u>0u > 0u>0 (Logarithmus), x≠0x \ne 0x=0.

Schritt 2: Konstante Lösung

u(ln⁡u−1)=0u(\ln u - 1) = 0u(lnu−1)=0 mit u>0u > 0u>0   ⟺  ln⁡u=1  ⟺  u=e\iff \ln u = 1 \iff u = e⟺lnu=1⟺u=e. Also ist u≡eu \equiv eu≡e, d. h. y=exy = exy=ex, eine Lösung.

Schritt 4: Rücksubstitution

y=ux=x e1+Cx.y = ux = x\,e^{1 + Cx}.y=ux=xe1+Cx.

Wegen e1+Cx>0e^{1+Cx} > 0e1+Cx>0 hat yyy dasselbe Vorzeichen wie xxx, also ist yx>0\frac{y}{x} > 0xy​>0 automatisch erfüllt. Die Lösungen sind auf x>0x > 0x>0 (dann y>0y > 0y>0) bzw. x<0x < 0x<0 (dann y<0y < 0y<0) erklärt.

Hilfreiches

Homogene DGL (im Sinne von Euler)

y′=g(yx)y' = g\bigl(\frac{y}{x}\bigr)y′=g(xy​). Substitution u=yxu = \frac{y}{x}u=xy​ führt auf die separable Gleichung xu′=g(u)−uxu' = g(u) - uxu′=g(u)−u.

Logarithmische Integration

∫f′(u)f(u) du=ln⁡∣f(u)∣+c,hier f(u)=ln⁡u−1, f′(u)=1u.\int \frac{f'(u)}{f(u)}\,du = \ln|f(u)| + c, \quad \text{hier } f(u) = \ln u - 1, \ f'(u) = \tfrac1u.∫f(u)f′(u)​du=ln∣f(u)∣+c,hier f(u)=lnu−1, f′(u)=u1​.

Typische Fehler
  • y′=u′y' = u'y′=u′ statt y′=u+xu′y' = u + xu'y′=u+xu′ setzen.
  • Die konstante Lösung u=eu = eu=e (also y=exy = exy=ex) beim Teilen verlieren – sie steckt im Ergebnis bei C=0C = 0C=0.
  • Den Definitionsbereich yx>0\frac{y}{x} > 0xy​>0 ignorieren.
