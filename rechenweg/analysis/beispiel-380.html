Angabe Originalseite

380–382) Die folgenden Aufgaben sollen mit implizitem Differenzieren gelöst werden.

In welchen Punkten der Kurve x2+4xy+16y2=27x^2 + 4xy + 16y^2 = 27x2+4xy+16y2=27 sind die Tangenten horizontal, in welchen vertikal?

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Mit F(x,y)=x2+4xy+16y2−27F(x,y) = x^2 + 4xy + 16y^2 - 27F(x,y)=x2+4xy+16y2−27 ist die Tangentensteigung y′=−Fx/Fyy' = -F_x/F_yy′=−Fx​/Fy​.

  • Horizontal (y′=0y' = 0y′=0): Fx=0F_x = 0Fx​=0 und Fy≠0F_y \ne 0Fy​=0.
  • Vertikal (Tangente parallel zur yyy-Achse): Fy=0F_y = 0Fy​=0 und Fx≠0F_x \ne 0Fx​=0 – dann ist xxx lokal Funktion von yyy mit x′=−Fy/Fx=0x' = -F_y/F_x = 0x′=−Fy​/Fx​=0.

Jeweils eine lineare Bedingung mit der Kurvengleichung kombinieren.

Schritt 1: Implizit ableiten

2x+4y+4xy′+32yy′=0⟹y′=−2x+4y4x+32y=−x+2y2x+16y.2x + 4y + 4xy' + 32yy' = 0 \quad\Longrightarrow\quad y' = -\frac{2x + 4y}{4x + 32y} = -\frac{x + 2y}{2x + 16y}.2x+4y+4xy′+32yy′=0⟹y′=−4x+32y2x+4y​=−2x+16yx+2y​.

Also Fx=2x+4yF_x = 2x + 4yFx​=2x+4y, Fy=4x+32yF_y = 4x + 32yFy​=4x+32y.

Schritt 2: Horizontale Tangenten

Fx=0  ⟺  x=−2yF_x = 0 \iff x = -2yFx​=0⟺x=−2y. Eingesetzt in die Kurvengleichung:

4y2−8y2+16y2=12y2=27⟹y2=94,y=±32,x=∓3.4y^2 - 8y^2 + 16y^2 = 12y^2 = 27 \quad\Longrightarrow\quad y^2 = \frac{9}{4},\quad y = \pm\frac32,\quad x = \mp 3.4y2−8y2+16y2=12y2=27⟹y2=49​,y=±23​,x=∓3.

Kontrolle Fy≠0F_y \ne 0Fy​=0: in (−3,32)(-3, \frac32)(−3,23​) ist Fy=−12+48=36≠0F_y = -12 + 48 = 36 \ne 0Fy​=−12+48=36=0; in (3,−32)(3, -\frac32)(3,−23​) ist Fy=−36≠0F_y = -36 \ne 0Fy​=−36=0 ✓.

Schritt 3: Vertikale Tangenten

Fy=0  ⟺  x=−8yF_y = 0 \iff x = -8yFy​=0⟺x=−8y. Eingesetzt:

64y2−32y2+16y2=48y2=27⟹y2=916,y=±34,x=∓6.64y^2 - 32y^2 + 16y^2 = 48y^2 = 27 \quad\Longrightarrow\quad y^2 = \frac{9}{16},\quad y = \pm\frac34,\quad x = \mp 6.64y2−32y2+16y2=48y2=27⟹y2=169​,y=±43​,x=∓6.

Kontrolle Fx≠0F_x \ne 0Fx​=0: in (−6,34)(-6, \frac34)(−6,43​) ist Fx=−12+3=−9≠0F_x = -12 + 3 = -9 \ne 0Fx​=−12+3=−9=0; in (6,−34)(6, -\frac34)(6,−43​) ist Fx=9≠0F_x = 9 \ne 0Fx​=9=0 ✓.

Ergebnis
  • Horizontale Tangenten in (−3,32)\bigl(-3, \tfrac32\bigr)(−3,23​) und (3,−32)\bigl(3, -\tfrac32\bigr)(3,−23​) (Tangenten y=±32y = \pm\frac32y=±23​).
  • Vertikale Tangenten in (−6,34)\bigl(-6, \tfrac34\bigr)(−6,43​) und (6,−34)\bigl(6, -\tfrac34\bigr)(6,−43​) (Tangenten x=∓6x = \mp 6x=∓6).
Probe
  • Alle vier Punkte erfüllen die Kurvengleichung, z. B. (−6)2+4(−6)34+16⋅916=36−18+9=27(-6)^2 + 4(-6)\frac34 + 16\cdot\frac{9}{16} = 36 - 18 + 9 = 27(−6)2+4(−6)43​+16⋅169​=36−18+9=27 ✓.
  • Plausibilität: Die quadratische Form x2+4xy+16y2x^2 + 4xy + 16y^2x2+4xy+16y2 hat die Matrix (12216)\begin{pmatrix}1&2\\2&16\end{pmatrix}(12​216​) mit Determinante 12>012 > 012>0 – die Kurve ist eine Ellipse, und eine Ellipse hat genau zwei horizontale und zwei vertikale Tangenten, jeweils punktsymmetrisch zum Mittelpunkt ✓.
  • Die vertikalen Tangenten liegen beim größten bzw. kleinsten xxx-Wert: Aus 16y2+4xy+x2−27=016y^2 + 4xy + x^2 - 27 = 016y2+4xy+x2−27=0 (quadratisch in yyy) folgt Diskriminante 16x2−64(x2−27)≥0  ⟺  x2≤3616x^2 - 64(x^2 - 27) \ge 0 \iff x^2 \le 3616x2−64(x2−27)≥0⟺x2≤36, also ∣x∣≤6|x| \le 6∣x∣≤6 ✓.

Hilfreiches

Tangenten implizit gegebener Kurven

Für F(x,y)=0F(x,y) = 0F(x,y)=0 ist (Fx,Fy)(F_x, F_y)(Fx​,Fy​) ein Normalenvektor der Kurve. Horizontale Tangente: Fx=0F_x = 0Fx​=0, Fy≠0F_y \ne 0Fy​=0. Vertikale Tangente: Fy=0F_y = 0Fy​=0, Fx≠0F_x \ne 0Fx​=0.

Typische Fehler
  • Beim Ableiten von 4xy4xy4xy die Produktregel vergessen (4y+4xy′4y + 4xy'4y+4xy′).
  • „Vertikal“ mit y′=∞y' = \inftyy′=∞ begründen, ohne Fx≠0F_x \ne 0Fx​=0 zu prüfen (bei Fx=Fy=0F_x = F_y = 0Fx​=Fy​=0 wäre der Punkt singulär).
