Hilfreiches

Monotone Funktionen erhalten Ungleichungen

Ist ggg streng monoton wachsend, so gilt x<y  ⟺  g(x)<g(y)x < y \iff g(x) < g(y)x<y⟺g(x)<g(y). Hier mit g=⋅3g = \sqrt[3]{\cdot}g=3⋅​ und g(t)=t3g(t) = t^3g(t)=t3.

Invariantes Intervall zwischen Fixpunkten

Liegt der Start zwischen zwei Fixpunkten r1<r2r_1 < r_2r1​<r2​ einer wachsenden Funktion fff, so bleibt die Folge in (r1,r2)(r_1, r_2)(r1​,r2​); das Vorzeichen von f(x)−xf(x) - xf(x)−x auf diesem Intervall entscheidet über die Monotonie.

Typische Fehler

  • r2≈0,618r_2 \approx 0{,}618r2​≈0,618 als Grenzwert angeben: Die Folge fällt aber schon nach einem Schritt auf 0<r20 < r_20<r2​.
  • Bei negativen Radikanden „nicht definiert“ schließen.
