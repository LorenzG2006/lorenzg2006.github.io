Angabe Originalseite

Sei an≥0a_n \ge 0an​≥0 für alle n≥0n \ge 0n≥0 und die Reihe ∑n≥0an\sum_{n\ge0} a_n∑n≥0​an​ konvergent. Man zeige, dass dann auch die Reihe ∑n≥0an2\sum_{n\ge0} a_n^2∑n≥0​an2​ konvergiert.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Aus der Konvergenz von ∑an\sum a_n∑an​ folgt an→0a_n \to 0an​→0. Ab einem Index sind die Glieder daher ≤1\le 1≤1, und für 0≤t≤10 \le t \le 10≤t≤1 gilt t2≤tt^2 \le tt2≤t. Also ist ∑an\sum a_n∑an​ selbst (bis auf endlich viele Glieder) eine Majorante für ∑an2\sum a_n^2∑an2​.

Schritt 1: Die Glieder bilden eine Nullfolge

Da ∑n≥0an\sum_{n\ge0} a_n∑n≥0​an​ konvergiert, ist (an)(a_n)(an​) nach dem notwendigen Kriterium eine Nullfolge. (Begründung: Mit sN=∑n=0Nan→ss_N = \sum_{n=0}^N a_n \to ssN​=∑n=0N​an​→s gilt aN=sN−sN−1→s−s=0a_N = s_N - s_{N-1} \to s - s = 0aN​=sN​−sN−1​→s−s=0.)

Schritt 2: Ab einem Index ist an≤1a_n \le 1an​≤1

Wir wenden die Definition der Konvergenz an→0a_n \to 0an​→0 mit ε=1\eps = 1ε=1 an: Es gibt ein N∈NN \in \NN∈N mit

∣an−0∣<1fu¨r alle n≥N,also0≤an<1(n≥N).\vert a_n - 0\vert < 1 \quad\text{für alle } n \ge N, \qquad\text{also}\quad 0 \le a_n < 1 \quad (n \ge N).∣an​−0∣<1fu¨r alle n≥N,also0≤an​<1(n≥N).

Schritt 3: Abschätzung der Quadrate

Für 0≤t≤10 \le t \le 10≤t≤1 gilt t2=t⋅t≤1⋅t=tt^2 = t\cdot t \le 1\cdot t = tt2=t⋅t≤1⋅t=t. Mit t=ant = a_nt=an​:

0≤an2≤anfu¨r alle n≥N.0 \le a_n^2 \le a_n \qquad\text{für alle } n \ge N .0≤an2​≤an​fu¨r alle n≥N.

∑n≥Nan\sum_{n\ge N} a_n∑n≥N​an​ konvergiert (Endstück einer konvergenten Reihe), und für n≥Nn \ge Nn≥N gilt 0≤an2≤an0 \le a_n^2 \le a_n0≤an2​≤an​. Nach dem Majorantenkriterium konvergiert ∑n≥Nan2\sum_{n\ge N} a_n^2∑n≥N​an2​. Hinzufügen der endlich vielen Glieder a02,…,aN−12a_0^2, \dots, a_{N-1}^2a02​,…,aN−12​ ändert die Konvergenz nicht. ■\blacksquare■

Explizit sind die Partialsummen beschränkt: ∑n=0Man2≤∑n=0N−1an2+∑n=N∞an<∞(M≥N),\sum_{n=0}^{M} a_n^2 \le \sum_{n=0}^{N-1} a_n^2 + \sum_{n=N}^{\infty} a_n < \infty \qquad (M \ge N),n=0∑M​an2​≤n=0∑N−1​an2​+n=N∑∞​an​<∞(M≥N), und da sie wegen an2≥0a_n^2 \ge 0an2​≥0 monoton wachsen, konvergieren sie (Monotoniekriterium).

Ergebnis

Ist an≥0a_n \ge 0an​≥0 und ∑an\sum a_n∑an​ konvergent, so ist auch ∑an2\sum a_n^2∑an2​ konvergent: Ab einem NNN gilt 0≤an<10 \le a_n < 10≤an​<1 und damit an2≤ana_n^2 \le a_nan2​≤an​; ∑an\sum a_n∑an​ ist eine konvergente Majorante.

Probe

Beispiel an=1(n+1)2a_n = \frac{1}{(n+1)^2}an​=(n+1)21​: ∑an=π26\sum a_n = \frac{\pi^2}{6}∑an​=6π2​, ∑an2=∑1(n+1)4=π490≈1,082≤π26≈1,645\sum a_n^2 = \sum\frac{1}{(n+1)^4} = \frac{\pi^4}{90} \approx 1{,}082 \le \frac{\pi^2}{6} \approx 1{,}645∑an2​=∑(n+1)41​=90π4​≈1,082≤6π2​≈1,645 ✓ (hier ist sogar N=0N = 0N=0, denn alle an≤1a_n \le 1an​≤1).

Die Umkehrung gilt nicht

an=1n+1a_n = \frac{1}{n+1}an​=n+11​: ∑an2=∑1(n+1)2\sum a_n^2 = \sum\frac{1}{(n+1)^2}∑an2​=∑(n+1)21​ konvergiert, ∑an\sum a_n∑an​ aber nicht.

Hilfreiches

Notwendiges Kriterium

Konvergiert ∑an\sum a_n∑an​, so gilt an→0a_n \to 0an​→0.

Majorantenkriterium

Gilt 0≤bn≤an0 \le b_n \le a_n0≤bn​≤an​ für fast alle nnn und konvergiert ∑an\sum a_n∑an​, so konvergiert ∑bn\sum b_n∑bn​.

Typische Fehler
  • an2≤ana_n^2 \le a_nan2​≤an​ für alle nnn behaupten – das stimmt nur für an≤1a_n \le 1an​≤1 (z. B. a0=5a_0 = 5a0​=5 ist erlaubt).
  • Die Voraussetzung an≥0a_n \ge 0an​≥0 nicht verwenden: Sie wird für an2≤ana_n^2 \le a_nan2​≤an​ und das Majorantenkriterium gebraucht (vgl. Bsp. 89).

Verwandte Beispiele: Bsp. 89, Bsp. 90, Bsp. 95.
