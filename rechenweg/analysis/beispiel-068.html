Angabe Originalseite

63–68) Man bestimme die Partialsummenfolge und ermittle dann gegebenenfalls den Grenzwert der Reihe. (Hinweis: Man stelle die Summanden als Differenz bzw. Summe passender Ausdrücke dar.)

∑n=1∞(−1)n2n+5(n+2)(n+3)\sum_{n=1}^{\infty} (-1)^n \frac{2n+5}{(n+2)(n+3)}n=1∑∞​(−1)n(n+2)(n+3)2n+5​

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Partialbruchzerlegung ergibt eine Summe 1n+2+1n+3\frac{1}{n+2} + \frac{1}{n+3}n+21​+n+31​. Das wechselnde Vorzeichen macht daraus eine Differenz aufeinanderfolgender Glieder der Folge cn=(−1)nn+2c_n = \frac{(-1)^n}{n+2}cn​=n+2(−1)n​. Die Partialsumme teleskopiert dann zu „erstes minus letztes Glied“.

Schritt 1: Partialbruchzerlegung

Ansatz 2n+5(n+2)(n+3)=An+2+Bn+3\frac{2n+5}{(n+2)(n+3)} = \frac{A}{n+2} + \frac{B}{n+3}(n+2)(n+3)2n+5​=n+2A​+n+3B​, also 2n+5=A(n+3)+B(n+2)2n + 5 = A(n+3) + B(n+2)2n+5=A(n+3)+B(n+2).

  • n=−2n = -2n=−2: 1=A1 = A1=A.
  • n=−3n = -3n=−3: −1=−B⇒B=1-1 = -B \Rightarrow B = 1−1=−B⇒B=1.

2n+5(n+2)(n+3)=1n+2+1n+3(Kontrolle: (n+3)+(n+2)(n+2)(n+3) ✓).\frac{2n+5}{(n+2)(n+3)} = \frac{1}{n+2} + \frac{1}{n+3} \qquad \Bigl(\text{Kontrolle: } \tfrac{(n+3) + (n+2)}{(n+2)(n+3)} \ \checkmark\Bigr) .(n+2)(n+3)2n+5​=n+21​+n+31​(Kontrolle: (n+2)(n+3)(n+3)+(n+2)​ ✓).

Schritt 2: Differenzform

(−1)n2n+5(n+2)(n+3)=(−1)nn+2+(−1)nn+3(Schritt 1)=(−1)nn+2−(−1)n+1(n+1)+2((−1)n=−(−1)n+1, n+3=(n+1)+2)=cn−cn+1,cn:=(−1)nn+2.\begin{aligned} (-1)^n \frac{2n+5}{(n+2)(n+3)} &= \frac{(-1)^n}{n+2} + \frac{(-1)^n}{n+3} && \text{(Schritt 1)}\\ &= \frac{(-1)^n}{n+2} - \frac{(-1)^{n+1}}{(n+1)+2} && ((-1)^n = -(-1)^{n+1},\ n+3 = (n+1)+2)\\ &= c_n - c_{n+1}, \qquad c_n := \frac{(-1)^n}{n+2} . \end{aligned}(−1)n(n+2)(n+3)2n+5​​=n+2(−1)n​+n+3(−1)n​=n+2(−1)n​−(n+1)+2(−1)n+1​=cn​−cn+1​,cn​:=n+2(−1)n​.​​(Schritt 1)((−1)n=−(−1)n+1, n+3=(n+1)+2)​

Schritt 3: Partialsummen

SN=∑n=1N(cn−cn+1)=c1−cN+1(Teleskopsumme)=−13−(−1)N+1N+3=−13+(−1)NN+3.\begin{aligned} S_N &= \sum_{n=1}^N (c_n - c_{n+1}) = c_1 - c_{N+1} && \text{(Teleskopsumme)}\\ &= \frac{-1}{3} - \frac{(-1)^{N+1}}{N+3} = -\frac13 + \frac{(-1)^N}{N+3} . \end{aligned}SN​​=n=1∑N​(cn​−cn+1​)=c1​−cN+1​=3−1​−N+3(−1)N+1​=−31​+N+3(−1)N​.​​(Teleskopsumme)​

Ausgeschrieben: SN=(−13−14)+(14+15)+(−15−16)+…S_N = \bigl(-\frac13 - \frac14\bigr) + \bigl(\frac14 + \frac15\bigr) + \bigl(-\frac15 - \frac16\bigr) + \dotsSN​=(−31​−41​)+(41​+51​)+(−51​−61​)+… – alles ab 14\frac1441​ hebt sich weg bis auf den letzten Term.

Schritt 4: Grenzwert

Wegen ∣(−1)NN+3∣=1N+3→0\left|\frac{(-1)^N}{N+3}\right| = \frac{1}{N+3} \to 0​N+3(−1)N​​=N+31​→0:

∑n=1∞(−1)n2n+5(n+2)(n+3)=−13.\sum_{n=1}^{\infty} (-1)^n \frac{2n+5}{(n+2)(n+3)} = -\frac13 .n=1∑∞​(−1)n(n+2)(n+3)2n+5​=−31​.

Ergebnis

Partialsummen SN=−13+(−1)NN+3S_N = -\dfrac13 + \dfrac{(-1)^N}{N+3}SN​=−31​+N+3(−1)N​; die Reihe konvergiert, und ∑n=1∞(−1)n2n+5(n+2)(n+3)=−13.\sum_{n=1}^{\infty} (-1)^n \frac{2n+5}{(n+2)(n+3)} = -\frac13 .n=1∑∞​(−1)n(n+2)(n+3)2n+5​=−31​.

Hilfreiches

Teleskopsumme

∑n=1N(cn−cn+1)=c1−cN+1\sum_{n=1}^N (c_n - c_{n+1}) = c_1 - c_{N+1}∑n=1N​(cn​−cn+1​)=c1​−cN+1​.

Alternierende Summe zweier Brüche

(−1)n(f(n)+f(n+1))=(−1)nf(n)−(−1)n+1f(n+1)(-1)^n\bigl(f(n) + f(n+1)\bigr) = (-1)^n f(n) - (-1)^{n+1} f(n+1)(−1)n(f(n)+f(n+1))=(−1)nf(n)−(−1)n+1f(n+1) – eine Teleskopdifferenz mit cn=(−1)nf(n)c_n = (-1)^n f(n)cn​=(−1)nf(n).

Typische Fehler
  • c1c_1c1​ falsch berechnen: c1=(−1)11+2=−13c_1 = \frac{(-1)^1}{1+2} = -\frac13c1​=1+2(−1)1​=−31​.
  • Die Summe 1n+2+1n+3\frac{1}{n+2} + \frac{1}{n+3}n+21​+n+31​ ohne Vorzeichen teleskopieren wollen – ohne (−1)n(-1)^n(−1)n würde nichts wegfallen (die Reihe der Beträge divergiert).
