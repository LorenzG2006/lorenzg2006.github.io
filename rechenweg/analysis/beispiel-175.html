Hilfreiches

Monotoniekriterium

f′>0f' > 0f′>0 auf einem Intervall ⇒\Rightarrow⇒ fff streng wachsend. Die Umkehrung ist falsch (dieses Beispiel); richtig ist nur: fff wachsend ⇒\Rightarrow⇒ f′≥0f' \ge 0f′≥0 (Bsp. 174).

Kubische Differenz

v3−u3=(v−u)(v2+uv+u2),v2+uv+u2=(v+u2)2+34u2≥0.v^3 - u^3 = (v - u)(v^2 + uv + u^2), \qquad v^2 + uv + u^2 = \Bigl(v + \frac u2\Bigr)^2 + \frac34u^2 \ge 0 .v3−u3=(v−u)(v2+uv+u2),v2+uv+u2=(v+2u​)2+43​u2≥0.

Typische Fehler
  • Strenge Monotonie von x3x^3x3 mit „f′=3x2≥0f' = 3x^2 \ge 0f′=3x2≥0“ begründen – das zeigt nur schwache Monotonie.
  • Glauben, eine waagrechte Tangente bedeute immer ein Extremum: Bei x3x^3x3 ist es ein Sattelpunkt.
  • Als Gegenbeispiel eine nicht differenzierbare Funktion wählen – die Voraussetzung „differenzierbar“ muss erfüllt sein.
