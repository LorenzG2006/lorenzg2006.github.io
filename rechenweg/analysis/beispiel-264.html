Man berechne:

∫(x2+1)e−2x dx\int(x^2 + 1)e^{-2x}\,\mathrm dx∫(x2+1)e−2xdx

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Polynom mal Exponentialfunktion: Das Polynom wird bei jeder partiellen Integration abgeleitet (Grad sinkt), die Exponentialfunktion integriert (bleibt bis auf Faktoren gleich). Nach zwei Schritten ist nur noch ∫e−2x\int e^{-2x}∫e−2x übrig. Zur Kontrolle rechnen wir zusätzlich mit einem Ansatz.

Grundintegral: ∫e−2x dx=−12e−2x\int e^{-2x}\,\mathrm dx = -\frac12e^{-2x}∫e−2xdx=−21​e−2x.

Schritt 1: Erste partielle Integration

u′=e−2x,u=−12e−2x,v=x2+1,v′=2x.u' = e^{-2x},\quad u = -\tfrac12e^{-2x}, \qquad v = x^2 + 1,\quad v' = 2x .u′=e−2x,u=−21​e−2x,v=x2+1,v′=2x.

∫(x2+1)e−2x dx=−12(x2+1)e−2x+∫x e−2x dx.\int(x^2 + 1)e^{-2x}\,\mathrm dx = -\frac12(x^2 + 1)e^{-2x} + \int x\,e^{-2x}\,\mathrm dx .∫(x2+1)e−2xdx=−21​(x2+1)e−2x+∫xe−2xdx.

Schritt 2: Zweite partielle Integration

u′=e−2x,u=−12e−2x,v=x,v′=1.u' = e^{-2x},\quad u = -\tfrac12e^{-2x}, \qquad v = x,\quad v' = 1 .u′=e−2x,u=−21​e−2x,v=x,v′=1.

∫x e−2x dx=−x2e−2x+12∫e−2x dx=−x2e−2x−14e−2x.\int x\,e^{-2x}\,\mathrm dx = -\frac x2e^{-2x} + \frac12\int e^{-2x}\,\mathrm dx = -\frac x2e^{-2x} - \frac14e^{-2x} .∫xe−2xdx=−2x​e−2x+21​∫e−2xdx=−2x​e−2x−41​e−2x.

Schritt 3: Zusammensetzen

∫(x2+1)e−2x dx=−12(x2+1)e−2x−x2e−2x−14e−2x+C=−e−2x4(2x2+2+2x+1)+C=−2x2+2x+34 e−2x+C.\begin{aligned} \int(x^2 + 1)e^{-2x}\,\mathrm dx &= -\frac12(x^2 + 1)e^{-2x} - \frac x2e^{-2x} - \frac14e^{-2x} + C\\ &= -\frac{e^{-2x}}{4}\bigl(2x^2 + 2 + 2x + 1\bigr) + C = -\frac{2x^2 + 2x + 3}{4}\,e^{-2x} + C . \end{aligned}∫(x2+1)e−2xdx​=−21​(x2+1)e−2x−2x​e−2x−41​e−2x+C=−4e−2x​(2x2+2+2x+1)+C=−42x2+2x+3​e−2x+C.​

Alternative: Ansatz

Wir setzen F(x)=(ax2+bx+c)e−2xF(x) = (ax^2 + bx + c)e^{-2x}F(x)=(ax2+bx+c)e−2x an. Dann

F′(x)=(2ax+b)e−2x−2(ax2+bx+c)e−2x=(−2ax2+(2a−2b)x+(b−2c))e−2x.F'(x) = (2ax + b)e^{-2x} - 2(ax^2 + bx + c)e^{-2x} = \bigl(-2a x^2 + (2a - 2b)x + (b - 2c)\bigr)e^{-2x} .F′(x)=(2ax+b)e−2x−2(ax2+bx+c)e−2x=(−2ax2+(2a−2b)x+(b−2c))e−2x.

Koeffizientenvergleich mit x2+1x^2 + 1x2+1: −2a=1-2a = 1−2a=1, 2a−2b=02a - 2b = 02a−2b=0, b−2c=1b - 2c = 1b−2c=1, also a=b=−12a = b = -\frac12a=b=−21​, c=−34c = -\frac34c=−43​ – dasselbe Ergebnis.

Ergebnis

∫(x2+1)e−2x dx=−2x2+2x+34 e−2x+C.\int(x^2 + 1)e^{-2x}\,\mathrm dx = -\frac{2x^2 + 2x + 3}{4}\,e^{-2x} + C .∫(x2+1)e−2xdx=−42x2+2x+3​e−2x+C.

Probe

(−2x2+2x+34e−2x)′=−4x+24e−2x+2x2+2x+32e−2x=−2x−1+2x2+2x+32e−2x=(x2+1)e−2x\Bigl(-\frac{2x^2 + 2x + 3}{4}e^{-2x}\Bigr)' = -\frac{4x + 2}{4}e^{-2x} + \frac{2x^2 + 2x + 3}{2}e^{-2x} = \frac{-2x - 1 + 2x^2 + 2x + 3}{2}e^{-2x} = (x^2 + 1)e^{-2x}(−42x2+2x+3​e−2x)′=−44x+2​e−2x+22x2+2x+3​e−2x=2−2x−1+2x2+2x+3​e−2x=(x2+1)e−2x ✓.

∫u′(x) v(x) dx=u(x) v(x)−∫u(x) v′(x) dx.\int u'(x)\,v(x)\,\mathrm dx = u(x)\,v(x) - \int u(x)\,v'(x)\,\mathrm dx .∫u′(x)v(x)dx=u(x)v(x)−∫u(x)v′(x)dx.
