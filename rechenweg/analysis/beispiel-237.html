Berechnen Sie

lim⁡n→∞1n3∑k=1nk(n−k)\lim_{n\to\infty}\frac{1}{n^3}\sum_{k=1}^n k(n - k)n→∞lim​n31​k=1∑n​k(n−k)

durch Interpretation als Grenzwert Riemannscher Zwischensummen.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Wir schreiben die Summe in der Form 1n∑f(kn)\frac1n\sum f\bigl(\frac kn\bigr)n1​∑f(nk​): Das ist eine Riemannsche Zwischensumme von fff auf [0,1][0, 1][0,1] zur äquidistanten Zerlegung mit rechten Randpunkten. Für stetiges fff konvergiert sie gegen ∫01f(x) dx\int_0^1 f(x)\,dx∫01​f(x)dx.

Schritt 1: Umformen

Wir verteilen n3=n⋅n⋅nn^3 = n\cdot n\cdot nn3=n⋅n⋅n auf die Faktoren:

1n3∑k=1nk(n−k)=∑k=1nkn⋅n−kn⋅1n=1n∑k=1nkn(1−kn).\frac{1}{n^3}\sum_{k=1}^n k(n - k) = \sum_{k=1}^n \frac kn\cdot\frac{n - k}{n}\cdot\frac1n = \frac1n\sum_{k=1}^n \frac kn\Bigl(1 - \frac kn\Bigr) .n31​k=1∑n​k(n−k)=k=1∑n​nk​⋅nn−k​⋅n1​=n1​k=1∑n​nk​(1−nk​).

Schritt 2: Riemann-Summe erkennen

Mit f(x)=x(1−x)f(x) = x(1 - x)f(x)=x(1−x), der Zerlegung xk=knx_k = \frac knxk​=nk​ (k=0,…,nk = 0, \dots, nk=0,…,n) von [0,1][0, 1][0,1], Δxk=1n\Delta x_k = \frac1nΔxk​=n1​ und den Zwischenpunkten ξk=xk=kn\xi_k = x_k = \frac knξk​=xk​=nk​ ist

1n∑k=1nkn(1−kn)=∑k=1nf(ξk) Δxk.\frac1n\sum_{k=1}^n \frac kn\Bigl(1 - \frac kn\Bigr) = \sum_{k=1}^n f(\xi_k)\,\Delta x_k .n1​k=1∑n​nk​(1−nk​)=k=1∑n​f(ξk​)Δxk​.

Schritt 3: Grenzwert

fff ist ein Polynom, also stetig und damit auf [0,1][0, 1][0,1] integrierbar. Die Feinheit 1n\frac1nn1​ geht gegen 000, also konvergieren die Zwischensummen gegen das Integral:

lim⁡n→∞1n3∑k=1nk(n−k)=∫01x(1−x) dx.\lim_{n\to\infty}\frac{1}{n^3}\sum_{k=1}^n k(n - k) = \int_0^1 x(1 - x)\,dx .n→∞lim​n31​k=1∑n​k(n−k)=∫01​x(1−x)dx.

Schritt 4: Integral berechnen

∫01x(1−x) dx=∫01(x−x2) dx(ausmultiplizieren)=[x22−x33]01(Hauptsatz)=12−13=16.\begin{aligned} \int_0^1 x(1 - x)\,dx &= \int_0^1 (x - x^2)\,dx && \text{(ausmultiplizieren)}\\ &= \Bigl[\frac{x^2}{2} - \frac{x^3}{3}\Bigr]_0^1 && \text{(Hauptsatz)}\\ &= \frac12 - \frac13 = \frac16 . && \end{aligned}∫01​x(1−x)dx​=∫01​(x−x2)dx=[2x2​−3x3​]01​=21​−31​=61​.​​(ausmultiplizieren)(Hauptsatz)​

Ergebnis

lim⁡n→∞1n3∑k=1nk(n−k)=∫01x(1−x) dx=16.\lim_{n\to\infty}\frac{1}{n^3}\sum_{k=1}^n k(n - k) = \int_0^1 x(1 - x)\,dx = \frac16 .n→∞lim​n31​k=1∑n​k(n−k)=∫01​x(1−x)dx=61​.

Probe

Hier lässt sich die Summe auch direkt ausrechnen (Summenformeln): ∑k=1nk(n−k)=n⋅n(n+1)2−n(n+1)(2n+1)6=n(n+1)(3n−(2n+1))6=(n−1)n(n+1)6,\sum_{k=1}^n k(n - k) = n\cdot\frac{n(n+1)}{2} - \frac{n(n+1)(2n+1)}{6} = \frac{n(n+1)\bigl(3n - (2n+1)\bigr)}{6} = \frac{(n-1)n(n+1)}{6},k=1∑n​k(n−k)=n⋅2n(n+1)​−6n(n+1)(2n+1)​=6n(n+1)(3n−(2n+1))​=6(n−1)n(n+1)​, also 1n3⋅(n−1)n(n+1)6=n2−16n2→16\frac{1}{n^3}\cdot\frac{(n-1)n(n+1)}{6} = \frac{n^2 - 1}{6n^2} \to \frac16n31​⋅6(n−1)n(n+1)​=6n2n2−1​→61​ ✓.

Hilfreiches

Grenzwert Riemannscher Summen

Ist fff auf [0,1][0, 1][0,1] stetig, so gilt lim⁡n→∞1n∑k=1nf(kn)=∫01f(x) dx.\lim_{n\to\infty}\frac1n\sum_{k=1}^n f\Bigl(\frac kn\Bigr) = \int_0^1 f(x)\,dx .n→∞lim​n1​k=1∑n​f(nk​)=∫01​f(x)dx.

Rezept
  1. Den Faktor 1n\frac1nn1​ herausziehen.
  2. Den Rest nur durch kn\frac knnk​ ausdrücken (Potenzen von nnn passend verteilen) – das ergibt f(kn)f\bigl(\frac kn\bigr)f(nk​).
  3. Intervall aus dem Bereich von kn\frac knnk​ ablesen, Stetigkeit von fff prüfen, integrieren.
Typische Fehler
  • Den Faktor nnn in n−kn - kn−k übersehen: n−kn=1−kn\frac{n - k}{n} = 1 - \frac knnn−k​=1−nk​, nicht n−knn - \frac knn−nk​.
  • Ein falsches Intervall wählen, etwa [0,n][0, n][0,n].
