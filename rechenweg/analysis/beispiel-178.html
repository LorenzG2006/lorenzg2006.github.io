Angabe Originalseite

Man berechne die ersten 4 Ableitungen der Funktion f(x)=exsin⁡xf(x) = e^x\sin xf(x)=exsinx. Können Sie allgemein einen Ausdruck für die nnn-te Ableitung angeben (Fallunterscheidung nach Restklasse von n mod 4n \bmod 4nmod4)?

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Wir leiten viermal mit der Produktregel ab. Dabei fällt auf, dass f(4)=−4ff^{(4)} = -4ff(4)=−4f ist: Nach vier Ableitungen ist man wieder bei der Ausgangsfunktion, nur mit Faktor −4-4−4. Daraus ergibt sich die Fallunterscheidung nach n mod 4n \bmod 4nmod4: Schreibt man n=4k+rn = 4k + rn=4k+r mit r∈{0,1,2,3}r \in \{0, 1, 2, 3\}r∈{0,1,2,3}, so ist f(n)=(−4)kf(r)f^{(n)} = (-4)^k f^{(r)}f(n)=(−4)kf(r).

Schritt 1: Die ersten vier Ableitungen

Produktregel mit (ex)′=ex(e^x)' = e^x(ex)′=ex, (sin⁡x)′=cos⁡x(\sin x)' = \cos x(sinx)′=cosx, (cos⁡x)′=−sin⁡x(\cos x)' = -\sin x(cosx)′=−sinx:

f′(x)=exsin⁡x+excos⁡x=ex(sin⁡x+cos⁡x),f′′(x)=ex(sin⁡x+cos⁡x)+ex(cos⁡x−sin⁡x)=2excos⁡x,f′′′(x)=2excos⁡x+2ex(−sin⁡x)=2ex(cos⁡x−sin⁡x),f(4)(x)=2ex(cos⁡x−sin⁡x)+2ex(−sin⁡x−cos⁡x)=−4exsin⁡x.\begin{aligned} f'(x) &= e^x\sin x + e^x\cos x = e^x(\sin x + \cos x),\\ f''(x) &= e^x(\sin x + \cos x) + e^x(\cos x - \sin x) = 2e^x\cos x,\\ f'''(x) &= 2e^x\cos x + 2e^x(-\sin x) = 2e^x(\cos x - \sin x),\\ f^{(4)}(x) &= 2e^x(\cos x - \sin x) + 2e^x(-\sin x - \cos x) = -4e^x\sin x . \end{aligned}f′(x)f′′(x)f′′′(x)f(4)(x)​=exsinx+excosx=ex(sinx+cosx),=ex(sinx+cosx)+ex(cosx−sinx)=2excosx,=2excosx+2ex(−sinx)=2ex(cosx−sinx),=2ex(cosx−sinx)+2ex(−sinx−cosx)=−4exsinx.​

Also

f(4)(x)=−4 f(x).f^{(4)}(x) = -4\,f(x) .f(4)(x)=−4f(x).

Schritt 2: Allgemeine Formel

Behauptung: Für alle k∈Nk \in \Nk∈N und r∈{0,1,2,3}r \in \{0, 1, 2, 3\}r∈{0,1,2,3} gilt f(4k+r)=(−4)kf(r)f^{(4k + r)} = (-4)^k f^{(r)}f(4k+r)=(−4)kf(r).

Beweis durch Induktion nach kkk:

  • Anfang k=0k = 0k=0: f(r)=(−4)0f(r)f^{(r)} = (-4)^0 f^{(r)}f(r)=(−4)0f(r) ✓.
  • IV: Für ein kkk gelte f(4k+r)=(−4)kf(r)f^{(4k + r)} = (-4)^k f^{(r)}f(4k+r)=(−4)kf(r) (für alle rrr).
  • Schritt k→k+1k \to k + 1k→k+1: f(4(k+1)+r)=(f(4k+r))(4)=IV(−4)k(f(r))(4)(4 weitere Ableitungen, Faktor bleibt)=(−4)k(f(4))(r)=(−4)k(−4f)(r)(Reihenfolge egal, Schritt 1)=(−4)k+1f(r).■\begin{aligned} f^{(4(k+1) + r)} &= \bigl(f^{(4k + r)}\bigr)^{(4)} \overset{\text{IV}}{=} (-4)^k\bigl(f^{(r)}\bigr)^{(4)} && \text{(4 weitere Ableitungen, Faktor bleibt)}\\ &= (-4)^k\bigl(f^{(4)}\bigr)^{(r)} = (-4)^k(-4f)^{(r)} && \text{(Reihenfolge egal, Schritt 1)}\\ &= (-4)^{k+1} f^{(r)} . && \blacksquare \end{aligned}f(4(k+1)+r)​=(f(4k+r))(4)=IV(−4)k(f(r))(4)=(−4)k(f(4))(r)=(−4)k(−4f)(r)=(−4)k+1f(r).​​(4 weitere Ableitungen, Faktor bleibt)(Reihenfolge egal, Schritt 1)■​
