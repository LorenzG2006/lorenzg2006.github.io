Hilfreiches

AM-GM-Ungleichung

Für a,b≥0a, b \ge 0a,b≥0: ab≤a+b2\sqrt{ab} \le \frac{a + b}{2}ab​≤2a+b​, denn a+b−2ab=(a−b)2≥0a + b - 2\sqrt{ab} = (\sqrt a - \sqrt b)^2 \ge 0a+b−2ab​=(a​−b​)2≥0.

Einschließungskriterium (mehrdimensional)

Gilt ∣f(x⃗)−L∣≤g(x⃗)|f(\vec x) - L| \le g(\vec x)∣f(x)−L∣≤g(x) in einer punktierten Umgebung von a⃗\vec aa und g(x⃗)→0g(\vec x) \to 0g(x)→0, so ist lim⁡x⃗→a⃗f(x⃗)=L\lim_{\vec x \to \vec a} f(\vec x) = Llimx→a​f(x)=L.

Typische Fehler
  • Stetigkeit nur entlang von Geraden prüfen – das beweist keine Stetigkeit; man braucht eine Abschätzung, die für alle Annäherungen gilt.
  • Den Fall xy=0xy = 0xy=0 übersehen, wenn man durch ∣xy∣\sqrt{|xy|}∣xy∣​ teilt.
  • Die Beträge vergessen: Der Hinweis gilt nur für a,b≥0a, b \ge 0a,b≥0.
