Angabe Originalseite

421–430) Lösen Sie die folgenden Differentialgleichungen:

y′=y+xy+1y' = y + xy + 1y′=y+xy+1

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

y′=(1+x)y+1y' = (1 + x)y + 1y′=(1+x)y+1 ist linear mit a(x)=−(1+x)a(x) = -(1 + x)a(x)=−(1+x), b(x)=1b(x) = 1b(x)=1. Homogene Lösung Cex+x2/2Ce^{x + x^2/2}Cex+x2/2. Die partikuläre Lösung benötigt ∫e−x−x2/2dx\int e^{-x - x^2/2}dx∫e−x−x2/2dx, also nach quadratischer Ergänzung das Gaußsche Fehlerintegral – nicht elementar. Wir geben sie mit einem bestimmten Integral bzw. mit erf⁡\operatorname{erf}erf an.

Schritt 1: Homogene Lösung

y′=(1+x)yy' = (1 + x)yy′=(1+x)y ⇒\Rightarrow⇒ ln⁡∣y∣=x+x22+c\ln|y| = x + \frac{x^2}{2} + cln∣y∣=x+2x2​+c ⇒\Rightarrow⇒ yh=C ex+x2/2.y_h = C\,e^{x + x^2/2}.yh​=Cex+x2/2.

Quadratische Ergänzung: x+x22=(x+1)22−12x + \frac{x^2}{2} = \frac{(x+1)^2}{2} - \frac12x+2x2​=2(x+1)2​−21​.

Schritt 2: Variation der Konstanten

Ansatz y=C(x) ex+x2/2y = C(x)\,e^{x + x^2/2}y=C(x)ex+x2/2: C′ex+x2/2+C(1+x)ex+x2/2=(1+x)Cex+x2/2+1  ⟺  C′(x)=e−x−x2/2.C'e^{x + x^2/2} + C(1 + x)e^{x + x^2/2} = (1 + x)Ce^{x + x^2/2} + 1 \iff C'(x) = e^{-x - x^2/2}.C′ex+x2/2+C(1+x)ex+x2/2=(1+x)Cex+x2/2+1⟺C′(x)=e−x−x2/2.

Also C(x)=∫0xe−s−s2/2 ds+K.C(x) = \int_0^x e^{-s - s^2/2}\,ds + K.C(x)=∫0x​e−s−s2/2ds+K.

Mit −s−s22=12−(s+1)22-s - \frac{s^2}{2} = \frac12 - \frac{(s+1)^2}{2}−s−2s2​=21​−2(s+1)2​ und der Substitution u=s+12u = \frac{s+1}{\sqrt2}u=2​s+1​ (ds=2 duds = \sqrt2\,duds=2​du): ∫e−s−s2/2 ds=e1/22∫e−u2 du=e1/2π2 erf⁡(s+12)+const.\int e^{-s - s^2/2}\,ds = e^{1/2}\sqrt2\int e^{-u^2}\,du = e^{1/2}\sqrt{\frac{\pi}{2}}\,\operatorname{erf}\Bigl(\frac{s+1}{\sqrt2}\Bigr) + \text{const}.∫e−s−s2/2ds=e1/22​∫e−u2du=e1/22π​​erf(2​s+1​)+const.

y=ex+x2/2(K+∫0xe−s−s2/2 ds).y = e^{x + x^2/2}\Bigl(K + \int_0^x e^{-s - s^2/2}\,ds\Bigr).y=ex+x2/2(K+∫0x​e−s−s2/2ds).

In der erf⁡\operatorname{erf}erf-Form: wegen ex+x2/2⋅e1/2=e(x+1)2/2e^{x + x^2/2}\cdot e^{1/2} = e^{(x+1)^2/2}ex+x2/2⋅e1/2=e(x+1)2/2

Ergebnis

y(x)=ex+x22(C+∫0xe−s−s22 ds)=C ex+x22+π2  e(x+1)22erf⁡(x+12),C∈Ry(x) = e^{x + \frac{x^2}{2}}\Bigl(C + \int_0^x e^{-s - \frac{s^2}{2}}\,ds\Bigr) = C\,e^{x + \frac{x^2}{2}} + \sqrt{\tfrac{\pi}{2}}\;e^{\frac{(x+1)^2}{2}}\operatorname{erf}\Bigl(\tfrac{x+1}{\sqrt2}\Bigr), \qquad C \in \Ry(x)=ex+2x2​(C+∫0x​e−s−2s2​ds)=Cex+2x2​+2π​​e2(x+1)2​erf(2​x+1​),C∈R (die Konstanten CCC in beiden Darstellungen unterscheiden sich um eine feste Zahl).

Probe

Für y=ex+x2/2(C+I(x))y = e^{x+x^2/2}\bigl(C + I(x)\bigr)y=ex+x2/2(C+I(x)) mit I′=e−x−x2/2I' = e^{-x-x^2/2}I′=e−x−x2/2: y′=(1+x)y+ex+x2/2e−x−x2/2=(1+x)y+1y' = (1 + x)y + e^{x+x^2/2}e^{-x-x^2/2} = (1 + x)y + 1y′=(1+x)y+ex+x2/2e−x−x2/2=(1+x)y+1 ✓. sympy: Einsetzen der erf-Form ergibt 000, und dsolve liefert dieselbe Form ✓.

Hilfreiches

Variation der Konstanten

y′+a(x)y=b(x)y' + a(x)y = b(x)y′+a(x)y=b(x): y=C(x)e−A(x)y = C(x)e^{-A(x)}y=C(x)e−A(x) mit C′=b eAC' = b\,e^{A}C′=beA.

erf⁡(u)=2π∫0ue−v2 dv,∫e−v2dv=π2erf⁡(v)+c.\operatorname{erf}(u) = \frac{2}{\sqrt\pi}\int_0^u e^{-v^2}\,dv, \qquad \int e^{-v^2}dv = \frac{\sqrt\pi}{2}\operatorname{erf}(v) + c.erf(u)=π​2​∫0u​e−v2dv,∫e−v2dv=2π​​erf(v)+c.

Typische Fehler
  • Den Summanden yyy und xyxyxy nicht zusammenfassen: a(x)=−(1+x)a(x) = -(1 + x)a(x)=−(1+x), nicht −x-x−x.
  • Eine „elementare“ Stammfunktion von e−x2/2e^{-x^2/2}e−x2/2 erfinden.
  • Bei der Substitution u=s+12u = \frac{s+1}{\sqrt2}u=2​s+1​ den Faktor 2\sqrt22​ vergessen.
