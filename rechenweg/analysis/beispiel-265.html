Überblick

Zählergrad 222 < Nennergrad 333, also direkt Partialbruchzerlegung. Dazu faktorisieren wir den Nenner durch Herausheben (Gruppieren); es ergibt sich eine doppelte und eine einfache Nullstelle.

Schritt 1: Nenner faktorisieren

x3+x2−x−1=x2(x+1)−(x+1)(gruppieren)=(x+1)(x2−1)=(x+1)(x−1)(x+1)=(x−1)(x+1)2.\begin{aligned} x^3 + x^2 - x - 1 &= x^2(x + 1) - (x + 1) && \text{(gruppieren)}\\ &= (x + 1)(x^2 - 1) = (x + 1)(x - 1)(x + 1) = (x - 1)(x + 1)^2 . \end{aligned}x3+x2−x−1​=x2(x+1)−(x+1)=(x+1)(x2−1)=(x+1)(x−1)(x+1)=(x−1)(x+1)2.​(gruppieren)

Der Integrand ist für x≠±1x \ne \pm1x=±1 definiert.

Schritt 2: Partialbruchzerlegung

x2+1(x−1)(x+1)2=Ax−1+Bx+1+C(x+1)2,\frac{x^2 + 1}{(x - 1)(x + 1)^2} = \frac{A}{x - 1} + \frac{B}{x + 1} + \frac{C}{(x + 1)^2},(x−1)(x+1)2x2+1​=x−1A​+x+1B​+(x+1)2C​,

x2+1=A(x+1)2+B(x−1)(x+1)+C(x−1).x^2 + 1 = A(x + 1)^2 + B(x - 1)(x + 1) + C(x - 1) .x2+1=A(x+1)2+B(x−1)(x+1)+C(x−1).

  • x=1x = 1x=1: 2=4A2 = 4A2=4A, also A=12A = \frac12A=21​.
  • x=−1x = -1x=−1: 2=−2C2 = -2C2=−2C, also C=−1C = -1C=−1.
  • Koeffizient von x2x^2x2: 1=A+B1 = A + B1=A+B, also B=12B = \frac12B=21​.
  • Kontrolle x=0x = 0x=0: links 111, rechts A−B−C=12−12+1=1A - B - C = \frac12 - \frac12 + 1 = 1A−B−C=21​−21​+1=1 ✓.

x2+1x3+x2−x−1=12⋅1x−1+12⋅1x+1−1(x+1)2.\frac{x^2 + 1}{x^3 + x^2 - x - 1} = \frac12\cdot\frac{1}{x - 1} + \frac12\cdot\frac{1}{x + 1} - \frac{1}{(x + 1)^2} .x3+x2−x−1x2+1​=21​⋅x−11​+21​⋅x+11​−(x+1)21​.

Schritt 3: Integrieren

∫x2+1x3+x2−x−1 dx=12ln⁡∣x−1∣+12ln⁡∣x+1∣−(−1x+1)+C=12ln⁡∣x2−1∣+1x+1+C.(ln⁡a+ln⁡b=ln⁡(ab))\begin{aligned} \int\frac{x^2 + 1}{x^3 + x^2 - x - 1}\,\mathrm dx &= \frac12\ln\vert x - 1\vert + \frac12\ln\vert x + 1\vert - \Bigl(-\frac{1}{x + 1}\Bigr) + C\\ &= \frac12\ln\vert x^2 - 1\vert + \frac{1}{x + 1} + C . && \text{(}\ln a + \ln b = \ln(ab)\text{)} \end{aligned}∫x3+x2−x−1x2+1​dx​=21​ln∣x−1∣+21​ln∣x+1∣−(−x+11​)+C=21​ln∣x2−1∣+x+11​+C.​​(lna+lnb=ln(ab))​

Ergebnis

∫x2+1x3+x2−x−1 dx=12ln⁡∣x−1∣+12ln⁡∣x+1∣+1x+1+C=12ln⁡∣x2−1∣+1x+1+C(x≠±1).\int\frac{x^2 + 1}{x^3 + x^2 - x - 1}\,\mathrm dx = \frac12\ln\vert x - 1\vert + \frac12\ln\vert x + 1\vert + \frac{1}{x + 1} + C = \frac12\ln\vert x^2 - 1\vert + \frac{1}{x + 1} + C \qquad (x \ne \pm1).∫x3+x2−x−1x2+1​dx=21​ln∣x−1∣+21​ln∣x+1∣+x+11​+C=21​ln∣x2−1∣+x+11​+C(x=±1).

Probe

(12ln⁡∣x2−1∣+1x+1)′=xx2−1−1(x+1)2=x(x+1)−(x−1)(x−1)(x+1)2=x2+1(x−1)(x+1)2\Bigl(\frac12\ln\vert x^2 - 1\vert + \frac{1}{x + 1}\Bigr)' = \frac{x}{x^2 - 1} - \frac{1}{(x + 1)^2} = \frac{x(x + 1) - (x - 1)}{(x - 1)(x + 1)^2} = \frac{x^2 + 1}{(x - 1)(x + 1)^2}(21​ln∣x2−1∣+x+11​)′=x2−1x​−(x+1)21​=(x−1)(x+1)2x(x+1)−(x−1)​=(x−1)(x+1)2x2+1​ ✓.

Hilfreiches

Partialbruchzerlegung

Zu (x−a)k(x - a)^k(x−a)k gehören die Teilbrüche A1x−a+⋯+Ak(x−a)k\frac{A_1}{x - a} + \dots + \frac{A_k}{(x - a)^k}x−aA1​​+⋯+(x−a)kAk​​. Die Konstanten zu einfachen Nullstellen und zur höchsten Potenz bekommt man durch Einsetzen der Nullstellen, den Rest durch Koeffizientenvergleich.

Grundintegrale

∫dxx−a=ln⁡∣x−a∣+C,∫dx(x−a)2=−1x−a+C.\int\frac{\mathrm dx}{x - a} = \ln\vert x - a\vert + C, \qquad \int\frac{\mathrm dx}{(x - a)^2} = -\frac{1}{x - a} + C .∫x−adx​=ln∣x−a∣+C,∫(x−a)2dx​=−x−a1​+C.
