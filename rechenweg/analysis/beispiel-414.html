Angabe Originalseite

Man bestimme die Lösung der Differentialgleichung y′+ycos⁡x=sin⁡xcos⁡xy' + y\cos x = \sin x\cos xy′+ycosx=sinxcosx zur Anfangsbedingung y(0)=1y(0) = 1y(0)=1.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Lineare Differentialgleichung y′+a(x)y=b(x)y' + a(x)y = b(x)y′+a(x)y=b(x) mit a(x)=cos⁡xa(x) = \cos xa(x)=cosx, b(x)=sin⁡xcos⁡xb(x) = \sin x\cos xb(x)=sinxcosx. Wir multiplizieren mit dem integrierenden Faktor eA(x)=esin⁡xe^{A(x)} = e^{\sin x}eA(x)=esinx, dann wird die linke Seite eine Produktableitung. Das entstehende Integral lösen wir mit der Substitution t=sin⁡xt = \sin xt=sinx und partieller Integration. Zum Schluss wird CCC aus y(0)=1y(0) = 1y(0)=1 bestimmt.

Schritt 1: Integrierender Faktor

A(x)=∫cos⁡x dx=sin⁡xA(x) = \int \cos x\,dx = \sin xA(x)=∫cosxdx=sinx. Multiplikation der Gleichung mit esin⁡xe^{\sin x}esinx: esin⁡xy′+cos⁡x esin⁡x y=sin⁡xcos⁡x esin⁡x.e^{\sin x}y' + \cos x\,e^{\sin x}\,y = \sin x\cos x\,e^{\sin x}.esinxy′+cosxesinxy=sinxcosxesinx.

Die linke Seite ist (y esin⁡x)′\bigl(y\,e^{\sin x}\bigr)'(yesinx)′ (Produktregel, (esin⁡x)′=cos⁡x esin⁡x(e^{\sin x})' = \cos x\,e^{\sin x}(esinx)′=cosxesinx). Also (y esin⁡x)′=sin⁡xcos⁡x esin⁡x.\bigl(y\,e^{\sin x}\bigr)' = \sin x\cos x\,e^{\sin x}.(yesinx)′=sinxcosxesinx.

Schritt 2: Integral

Substitution t=sin⁡xt = \sin xt=sinx, dt=cos⁡x dxdt = \cos x\,dxdt=cosxdx: ∫sin⁡xcos⁡x esin⁡x dx=∫t et dt=t et−∫et dt(partielle Integration, u=t, v′=et)=(t−1)et+C=(sin⁡x−1)esin⁡x+C.(Ru¨cksubstitution)\begin{aligned} \int \sin x\cos x\,e^{\sin x}\,dx &= \int t\,e^t\,dt &&\\ &= t\,e^t - \int e^t\,dt && \text{(partielle Integration, } u = t,\ v' = e^t\text{)}\\ &= (t - 1)e^t + C &&\\ &= (\sin x - 1)e^{\sin x} + C. && \text{(Rücksubstitution)} \end{aligned}∫sinxcosxesinxdx​=∫tetdt=tet−∫etdt=(t−1)et+C=(sinx−1)esinx+C.​​(partielle Integration, u=t, v′=et)(Ru¨cksubstitution)​

Schritt 3: Allgemeine Lösung

y esin⁡x=(sin⁡x−1)esin⁡x+C⟹y=sin⁡x−1+C e−sin⁡x.y\,e^{\sin x} = (\sin x - 1)e^{\sin x} + C \quad\Longrightarrow\quad y = \sin x - 1 + C\,e^{-\sin x}.yesinx=(sinx−1)esinx+C⟹y=sinx−1+Ce−sinx.

Schritt 4: Anfangsbedingung

y(0)=sin⁡0−1+C e0=−1+C=!1⟹C=2.y(0) = \sin 0 - 1 + C\,e^{0} = -1 + C \overset{!}{=} 1 \quad\Longrightarrow\quad C = 2.y(0)=sin0−1+Ce0=−1+C=!1⟹C=2.

Ergebnis

y(x)=sin⁡x−1+2 e−sin⁡x,x∈R.y(x) = \sin x - 1 + 2\,e^{-\sin x}, \qquad x \in \R.y(x)=sinx−1+2e−sinx,x∈R.

Probe

y′=cos⁡x−2cos⁡x e−sin⁡xy' = \cos x - 2\cos x\,e^{-\sin x}y′=cosx−2cosxe−sinx,  ycos⁡x=sin⁡xcos⁡x−cos⁡x+2cos⁡x e−sin⁡x\ y\cos x = \sin x\cos x - \cos x + 2\cos x\,e^{-\sin x} ycosx=sinxcosx−cosx+2cosxe−sinx. Summe: y′+ycos⁡x=sin⁡xcos⁡xy' + y\cos x = \sin x\cos xy′+ycosx=sinxcosx ✓. y(0)=0−1+2=1y(0) = 0 - 1 + 2 = 1y(0)=0−1+2=1 ✓. sympy checkodesol bestätigt.

Hilfreiches

Integrierender Faktor

Für y′+a(x)y=b(x)y' + a(x)y = b(x)y′+a(x)y=b(x) und A′=aA' = aA′=a gilt (y eA)′=b eA(y\,e^{A})' = b\,e^{A}(yeA)′=beA, also y=e−A(x)(∫b(x)eA(x) dx+C).y = e^{-A(x)}\Bigl(\int b(x)e^{A(x)}\,dx + C\Bigr).y=e−A(x)(∫b(x)eA(x)dx+C).

Partielle Integration

∫u v′ dx=u v−∫u′ v dx.\int u\,v'\,dx = u\,v - \int u'\,v\,dx.∫uv′dx=uv−∫u′vdx.

Typische Fehler
  • Die Anfangsbedingung in die Lösung ohne CCC (also eine partikuläre Lösung) einsetzen – CCC muss erst am Schluss bestimmt werden.
  • Beim Zurückdividieren CCC nicht mit e−sin⁡xe^{-\sin x}e−sinx multiplizieren (Ergebnis wäre sin⁡x−1+C\sin x - 1 + Csinx−1+C, falsch).
