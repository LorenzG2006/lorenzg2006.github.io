Angabe Originalseite

380–382) Die folgenden Aufgaben sollen mit implizitem Differenzieren gelöst werden.

Bestimmen Sie alle Tangenten mit Anstieg ±1\pm 1±1 an die Kurve 2x2−4xy+9y2=362x^2 - 4xy + 9y^2 = 362x2−4xy+9y2=36.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Implizites Differenzieren liefert y′y'y′ als Funktion von xxx und yyy. Die Bedingung y′=1y' = 1y′=1 bzw. y′=−1y' = -1y′=−1 ist eine lineare Gleichung in x,yx, yx,y; zusammen mit der Kurvengleichung erhält man die Berührpunkte und daraus die Tangentengleichungen y=±x+cy = \pm x + cy=±x+c.

Schritt 1: Implizit ableiten

4x−4y−4xy′+18yy′=0⟹y′(18y−4x)=4y−4x⟹y′=2y−2x9y−2x=2x−2y2x−9y.4x - 4y - 4xy' + 18yy' = 0 \quad\Longrightarrow\quad y'(18y - 4x) = 4y - 4x \quad\Longrightarrow\quad y' = \frac{2y - 2x}{9y - 2x} = \frac{2x - 2y}{2x - 9y}.4x−4y−4xy′+18yy′=0⟹y′(18y−4x)=4y−4x⟹y′=9y−2x2y−2x​=2x−9y2x−2y​.

(Gültig, wo 2x−9y≠02x - 9y \ne 02x−9y=0.)

Schritt 2: Anstieg +1+1+1

2x−2y2x−9y=1  ⟺  2x−2y=2x−9y  ⟺  7y=0  ⟺  y=0.\frac{2x - 2y}{2x - 9y} = 1 \iff 2x - 2y = 2x - 9y \iff 7y = 0 \iff y = 0.2x−9y2x−2y​=1⟺2x−2y=2x−9y⟺7y=0⟺y=0.

In die Kurve: 2x2=362x^2 = 362x2=36, x=±32x = \pm 3\sqrt2x=±32​. Nenner 2x−9y=±62≠02x - 9y = \pm 6\sqrt2 \ne 02x−9y=±62​=0 ✓.

  • Berührpunkt (32,0)(3\sqrt2, 0)(32​,0): Tangente y=x−32y = x - 3\sqrt2y=x−32​.
  • Berührpunkt (−32,0)(-3\sqrt2, 0)(−32​,0): Tangente y=x+32y = x + 3\sqrt2y=x+32​.

Schritt 3: Anstieg −1-1−1

2x−2y2x−9y=−1  ⟺  2x−2y=−2x+9y  ⟺  4x=11y  ⟺  x=114y.\frac{2x - 2y}{2x - 9y} = -1 \iff 2x - 2y = -2x + 9y \iff 4x = 11y \iff x = \frac{11}{4}y.2x−9y2x−2y​=−1⟺2x−2y=−2x+9y⟺4x=11y⟺x=411​y.

In die Kurve:

Also y=±96/35=±4635=±421035≈±1,656y = \pm\sqrt{96/35} = \pm\frac{4\sqrt6}{\sqrt{35}} = \pm\frac{4\sqrt{210}}{35} \approx \pm 1{,}656y=±96/35​=±35​46​​=±354210​​≈±1,656 und x=114y=±1121035≈±4,554x = \frac{11}{4}y = \pm\frac{11\sqrt{210}}{35} \approx \pm 4{,}554x=411​y=±3511210​​≈±4,554. Nenner: 2x−9y=2⋅114y−9y=−72y≠02x - 9y = 2\cdot\frac{11}{4}y - 9y = -\frac72y \ne 02x−9y=2⋅411​y−9y=−27​y=0 ✓.

Achsenabschnitt der Tangente y=−x+cy = -x + cy=−x+c: c=x+y=114y+y=154y=±154⋅421035=±32107≈±6,211c = x + y = \frac{11}{4}y + y = \frac{15}{4}y = \pm\frac{15}{4}\cdot\frac{4\sqrt{210}}{35} = \pm\frac{3\sqrt{210}}{7} \approx \pm 6{,}211c=x+y=411​y+y=415​y=±415​⋅354210​​=±73210​​≈±6,211.

Ergebnis

Tangenten mit Anstieg +1+1+1: y=x−32\quad y = x - 3\sqrt2y=x−32​ (Berührpunkt (32,0)(3\sqrt2, 0)(32​,0)) und y=x+32y = x + 3\sqrt2y=x+32​ (Berührpunkt (−32,0)(-3\sqrt2, 0)(−32​,0)).

Tangenten mit Anstieg −1-1−1: y=−x+32107\quad y = -x + \dfrac{3\sqrt{210}}{7}y=−x+73210​​ und y=−x−32107y = -x - \dfrac{3\sqrt{210}}{7}y=−x−73210​​ (Berührpunkte ±(1121035,421035)≈±(4,554; 1,656)\pm\bigl(\frac{11\sqrt{210}}{35}, \frac{4\sqrt{210}}{35}\bigr) \approx \pm(4{,}554;\ 1{,}656)±(3511210​​,354210​​)≈±(4,554; 1,656)).

Setzt man y=x+cy = x + cy=x+c in die Kurve ein: 2x2−4x(x+c)+9(x+c)2−36=7x2+14cx+9c2−36=02x^2 - 4x(x+c) + 9(x+c)^2 - 36 = 7x^2 + 14cx + 9c^2 - 36 = 02x2−4x(x+c)+9(x+c)2−36=7x2+14cx+9c2−36=0. Tangente   ⟺  \iff⟺ doppelte Nullstelle   ⟺  \iff⟺ Diskriminante 196c2−28(9c2−36)=−56c2+1008=0  ⟺  c2=18196c^2 - 28(9c^2 - 36) = -56c^2 + 1008 = 0 \iff c^2 = 18196c2−28(9c2−36)=−56c2+1008=0⟺c2=18, c=±32c = \pm 3\sqrt2c=±32​ ✓. Hilfreiches

Implizites Differenzieren

Für F(x,y)=0F(x,y) = 0F(x,y)=0 mit Fy≠0F_y \ne 0Fy​=0: y′=−FxFyy' = -\dfrac{F_x}{F_y}y′=−Fy​Fx​​. Hier Fx=4x−4yF_x = 4x - 4yFx​=4x−4y, Fy=−4x+18yF_y = -4x + 18yFy​=−4x+18y.

Typische Fehler
  • Nur einen der beiden Berührpunkte je Steigung angeben – die Ellipse ist punktsymmetrisch, es gibt immer zwei parallele Tangenten.
  • Beim Ableiten von −4xy-4xy−4xy die Produktregel vergessen.
  • Nur die Berührpunkte, nicht die Tangentengleichungen angeben.
