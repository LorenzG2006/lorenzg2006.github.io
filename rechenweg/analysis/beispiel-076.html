Angabe Originalseite

74–83) Man untersuche die folgenden Reihen auf Konvergenz:

∑n≥0n+26n\sum_{n\ge 0} \frac{n+2}{6^n}n≥0∑​6nn+2​

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Im Nenner steht eine Exponentialfunktion, im Zähler nur ein lineares Polynom – typischer Fall für das Quotientenkriterium: Das Verhältnis aufeinanderfolgender Glieder strebt gegen 16<1\frac16 < 161​<1. Zusätzlich berechnen wir (als Bonus) den Reihenwert mit Hilfe der geometrischen Reihe.

Schritt 1: Quotient aufeinanderfolgender Glieder

Mit an=n+26n>0a_n = \frac{n+2}{6^n} > 0an​=6nn+2​>0 für alle n∈Nn \in \Nn∈N:

an+1an=n+36n+1⋅6nn+2(Doppelbruch aufgelo¨st)=16⋅n+3n+2.(6n+1=6⋅6n)\begin{aligned} \frac{a_{n+1}}{a_n} &= \frac{n+3}{6^{n+1}} \cdot \frac{6^n}{n+2} && \text{(Doppelbruch aufgelöst)}\\ &= \frac{1}{6}\cdot\frac{n+3}{n+2} . && (6^{n+1} = 6\cdot 6^n) \end{aligned}an​an+1​​​=6n+1n+3​⋅n+26n​=61​⋅n+2n+3​.​​(Doppelbruch aufgelo¨st)(6n+1=6⋅6n)​

Schritt 2: Quotientenkriterium

an+1an=16⋅1+3n1+2n⟶16<1.\frac{a_{n+1}}{a_n} = \frac16\cdot\frac{1 + \frac3n}{1 + \frac2n} \longrightarrow \frac16 < 1 .an​an+1​​=61​⋅1+n2​1+n3​​⟶61​<1.

Noch konkreter (ohne Grenzwert): Für alle n≥0n \ge 0n≥0 ist n+3n+2=1+1n+2≤32\frac{n+3}{n+2} = 1 + \frac{1}{n+2} \le \frac32n+2n+3​=1+n+21​≤23​, also

an+1an≤16⋅32=14=:q<1.\frac{a_{n+1}}{a_n} \le \frac16\cdot\frac32 = \frac14 =: q < 1 .an​an+1​​≤61​⋅23​=41​=:q<1.

Nach dem Quotientenkriterium konvergiert die Reihe (absolut).

Ergebnis

Die Reihe ∑n≥0n+26n\displaystyle\sum_{n\ge0}\frac{n+2}{6^n}n≥0∑​6nn+2​ konvergiert, da an+1an≤14<1\frac{a_{n+1}}{a_n} \le \frac14 < 1an​an+1​​≤41​<1 für alle nnn (bzw. an+1an→16<1\frac{a_{n+1}}{a_n} \to \frac16 < 1an​an+1​​→61​<1). Ihr Wert ist 6625=2,64\frac{66}{25} = 2{,}642566​=2,64 (siehe unten).

Zusatz: Berechnung des Reihenwerts

Wir zerlegen n+26n=n xn+2 xn\frac{n+2}{6^n} = n\,x^n + 2\,x^n6nn+2​=nxn+2xn mit x=16x = \frac16x=61​. Beide Teilreihen konvergieren (die zweite ist geometrisch, die erste nach dem Quotientenkriterium wie oben), also darf man sie getrennt summieren.

Geometrischer Teil: ∑n≥02xn=21−x=25/6=125\sum_{n\ge0} 2x^n = \frac{2}{1-x} = \frac{2}{5/6} = \frac{12}{5}∑n≥0​2xn=1−x2​=5/62​=512​.

Teil T:=∑n≥0nxnT := \sum_{n\ge0} n x^nT:=∑n≥0​nxn: Es ist

T−xT=∑n≥0nxn−∑n≥0nxn+1=∑n≥1nxn−∑n≥1(n−1)xn=∑n≥1xn=x1−x,T - xT = \sum_{n\ge0} n x^n - \sum_{n\ge0} n x^{n+1} = \sum_{n\ge1} n x^n - \sum_{n\ge1}(n-1)x^n = \sum_{n\ge1} x^n = \frac{x}{1-x} ,T−xT=n≥0∑​nxn−n≥0∑​nxn+1=n≥1∑​nxn−n≥1∑​(n−1)xn=n≥1∑​xn=1−xx​,

(Indexverschiebung in der zweiten Reihe; erlaubt, da beide Reihen konvergieren), also

T=x(1−x)2=1/625/36=625.T = \frac{x}{(1-x)^2} = \frac{1/6}{25/36} = \frac{6}{25} .T=(1−x)2x​=25/361/6​=256​.

Zusammen: 625+125=625+6025=6625\frac{6}{25} + \frac{12}{5} = \frac{6}{25} + \frac{60}{25} = \frac{66}{25}256​+512​=256​+2560​=2566​.

Hilfreiches

Quotientenkriterium

Sei an≠0a_n \ne 0an​=0. Gibt es q<1q < 1q<1 mit ∣an+1an∣≤q\left|\frac{a_{n+1}}{a_n}\right| \le q​an​an+1​​​≤q für fast alle nnn (insbesondere wenn ∣an+1an∣→L<1\left|\frac{a_{n+1}}{a_n}\right| \to L < 1​an​an+1​​​→L<1), so konvergiert ∑an\sum a_n∑an​ absolut. Ist ∣an+1an∣≥1\left|\frac{a_{n+1}}{a_n}\right| \ge 1​an​an+1​​​≥1 für fast alle nnn, divergiert sie.

Geometrische Reihe

∑n≥0xn=11−x\sum_{n\ge0} x^n = \frac{1}{1-x}∑n≥0​xn=1−x1​ und ∑n≥0nxn=x(1−x)2\sum_{n\ge0} n x^n = \frac{x}{(1-x)^2}∑n≥0​nxn=(1−x)2x​ für ∣x∣<1|x| < 1∣x∣<1.

Typische Fehler
  • Beim Quotientenkriterium nur „an+1an<1\frac{a_{n+1}}{a_n} < 1an​an+1​​<1 für alle nnn“ zeigen – das reicht nicht (bei ∑1n\sum\frac1n∑n1​ ist der Quotient auch <1< 1<1, aber →1\to 1→1). Man braucht eine feste Schranke q<1q < 1q<1 bzw. einen Grenzwert <1< 1<1.
  • 6n+1=6n+66^{n+1} = 6^n + 66n+1=6n+6 – falsch, es ist 6⋅6n6\cdot6^n6⋅6n.
