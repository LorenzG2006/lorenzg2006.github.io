Angabe Originalseite

Man berechne:

∫0π/4tan⁡2x dx\int_0^{\pi/4}\tan^2 x\,\mathrm dx∫0π/4​tan2xdx

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Der Trick ist die Identität tan⁡2x=1cos⁡2x−1\tan^2 x = \frac{1}{\cos^2 x} - 1tan2x=cos2x1​−1. Für 1cos⁡2x\frac{1}{\cos^2 x}cos2x1​ kennen wir die Stammfunktion tan⁡x\tan xtanx, denn (tan⁡x)′=1cos⁡2x(\tan x)' = \frac{1}{\cos^2 x}(tanx)′=cos2x1​. Damit wird das Integral zu einer Differenz zweier Grundintegrale.

Auf [0,π4][0, \frac\pi4][0,4π​] ist cos⁡x≥22>0\cos x \ge \frac{\sqrt2}{2} > 0cosx≥22​​>0, also ist tan⁡2x\tan^2 xtan2x dort stetig (keine Polstelle).

Schritt 1: Umformung des Integranden

tan⁡2x=sin⁡2xcos⁡2x(Definition des Tangens)=1−cos⁡2xcos⁡2x(sin⁡2x+cos⁡2x=1)=1cos⁡2x−1.(Bruch aufspalten)\begin{aligned} \tan^2 x &= \frac{\sin^2 x}{\cos^2 x} && \text{(Definition des Tangens)}\\ &= \frac{1 - \cos^2 x}{\cos^2 x} && \text{(}\sin^2 x + \cos^2 x = 1\text{)}\\ &= \frac{1}{\cos^2 x} - 1 . && \text{(Bruch aufspalten)} \end{aligned}tan2x​=cos2xsin2x​=cos2x1−cos2x​=cos2x1​−1.​​(Definition des Tangens)(sin2x+cos2x=1)(Bruch aufspalten)​

Schritt 2: Stammfunktion

Die Ableitung des Tangens (Quotientenregel):

(tan⁡x)′=(sin⁡xcos⁡x)′=cos⁡xcos⁡x−sin⁡x(−sin⁡x)cos⁡2x=cos⁡2x+sin⁡2xcos⁡2x=1cos⁡2x.(\tan x)' = \Bigl(\frac{\sin x}{\cos x}\Bigr)' = \frac{\cos x\cos x - \sin x(-\sin x)}{\cos^2 x} = \frac{\cos^2 x + \sin^2 x}{\cos^2 x} = \frac{1}{\cos^2 x} .(tanx)′=(cosxsinx​)′=cos2xcosxcosx−sinx(−sinx)​=cos2xcos2x+sin2x​=cos2x1​.

Also

∫tan⁡2x dx=∫(1cos⁡2x−1)dx=tan⁡x−x+C.\int\tan^2 x\,\mathrm dx = \int\Bigl(\frac{1}{\cos^2 x} - 1\Bigr)\mathrm dx = \tan x - x + C .∫tan2xdx=∫(cos2x1​−1)dx=tanx−x+C.

Schritt 3: Grenzen einsetzen

∫0π/4tan⁡2x dx=[tan⁡x−x]0π/4(Hauptsatz)=(tan⁡π4−π4)−(tan⁡0−0)(Grenzen einsetzen)=1−π4≈0,214602.(tan⁡π4=1, tan⁡0=0)\begin{aligned} \int_0^{\pi/4}\tan^2 x\,\mathrm dx &= \bigl[\tan x - x\bigr]_0^{\pi/4} && \text{(Hauptsatz)}\\ &= \Bigl(\tan\frac\pi4 - \frac\pi4\Bigr) - (\tan 0 - 0) && \text{(Grenzen einsetzen)}\\ &= 1 - \frac\pi4 \approx 0{,}214602 . && \text{(}\tan\tfrac\pi4 = 1,\ \tan 0 = 0\text{)} \end{aligned}∫0π/4​tan2xdx​=[tanx−x]0π/4​=(tan4π​−4π​)−(tan0−0)=1−4π​≈0,214602.​​(Hauptsatz)(Grenzen einsetzen)(tan4π​=1, tan0=0)​

Ergebnis

∫0π/4tan⁡2x dx=1−π4≈0,2146.\int_0^{\pi/4}\tan^2 x\,\mathrm dx = 1 - \frac{\pi}{4} \approx 0{,}2146 .∫0π/4​tan2xdx=1−4π​≈0,2146.

Probe
  • Ableitung: (tan⁡x−x)′=1cos⁡2x−1=tan⁡2x(\tan x - x)' = \frac{1}{\cos^2 x} - 1 = \tan^2 x(tanx−x)′=cos2x1​−1=tan2x ✓.
  • Plausibilität: Auf [0,π4][0, \frac\pi4][0,4π​] wächst tan⁡2x\tan^2 xtan2x von 000 auf 111 und ist konvex; das Integral muss also kleiner als das Dreieck unter der Sehne sein, 12⋅π4⋅1≈0,393\frac12\cdot\frac\pi4\cdot 1 \approx 0{,}39321​⋅4π​⋅1≈0,393, und positiv ✓.
  • Numerisch (mpmath): 0,2146018366030{,}2146018366030,214601836603 ✓.

Hilfreiches

Grundintegrale der Winkelfunktionen

∫dxcos⁡2x=tan⁡x+C,∫dxsin⁡2x=−cot⁡x+C.\int\frac{\mathrm dx}{\cos^2 x} = \tan x + C, \qquad \int\frac{\mathrm dx}{\sin^2 x} = -\cot x + C .∫cos2xdx​=tanx+C,∫sin2xdx​=−cotx+C.

Identitäten

1+tan⁡2x=1cos⁡2x,1+cot⁡2x=1sin⁡2x.1 + \tan^2 x = \frac{1}{\cos^2 x}, \qquad 1 + \cot^2 x = \frac{1}{\sin^2 x} .1+tan2x=cos2x1​,1+cot2x=sin2x1​.

Typische Fehler
  • ∫tan⁡2x dx=tan⁡3x3\int\tan^2 x\,\mathrm dx = \frac{\tan^3 x}{3}∫tan2xdx=3tan3x​ – die Kettenregel liefert dabei einen zusätzlichen Faktor 1cos⁡2x\frac{1}{\cos^2 x}cos2x1​.
  • Das „−1-1−1“ bei der Umformung vergessen und tan⁡π4=1\tan\frac\pi4 = 1tan4π​=1 als Ergebnis angeben.
  • Über eine Polstelle x=π2+kπx = \frac\pi2 + k\pix=2π​+kπ hinweg integrieren – hier nicht der Fall, aber stets prüfen.
