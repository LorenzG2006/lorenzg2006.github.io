Angabe Originalseite

74–83) Man untersuche die folgenden Reihen auf Konvergenz:

∑n≥1(n2+1)nn n2\sum_{n\ge 1} \frac{(n^2+1)^n}{\sqrt{n}^{\,n^2}}n≥1∑​n​n2(n2+1)n​

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Zähler und Nenner sind nnn-te Potenzen (der Nenner sogar eine n2n^2n2-te). Das schreit nach dem Wurzelkriterium: Die nnn-te Wurzel des Summanden ist ein einfacher Ausdruck, n2+1nn/2\frac{n^2+1}{n^{n/2}}nn/2n2+1​, und der geht gegen 0<10 < 10<1.

Schritt 1: Summand umschreiben

n n2=(n1/2)n2=nn2/2=(nn/2)n\sqrt{n}^{\,n^2} = \bigl(n^{1/2}\bigr)^{n^2} = n^{n^2/2} = \bigl(n^{n/2}\bigr)^{n}n​n2=(n1/2)n2=nn2/2=(nn/2)n. Also

an=(n2+1)n(nn/2)n=(n2+1nn/2) ⁣n>0.a_n = \frac{(n^2+1)^n}{\bigl(n^{n/2}\bigr)^{n}} = \left(\frac{n^2+1}{n^{n/2}}\right)^{\!n} > 0 .an​=(nn/2)n(n2+1)n​=(nn/2n2+1​)n>0.

Schritt 2: Wurzelkriterium

ann=n2+1nn/2.\sqrt[n]{a_n} = \frac{n^2+1}{n^{n/2}} .nan​​=nn/2n2+1​.

Wir zeigen, dass dieser Ausdruck gegen 000 geht. Für n≥8n \ge 8n≥8 ist n2≥4\frac n2 \ge 42n​≥4 und wegen n≥1n \ge 1n≥1 daher nn/2≥n4n^{n/2} \ge n^4nn/2≥n4. Damit

0<ann≤n2+1n4(nn/2≥n4 fu¨r n≥8)≤2n2n4=2n2(1≤n2)→n→∞0.\begin{aligned} 0 < \sqrt[n]{a_n} &\le \frac{n^2+1}{n^4} && (n^{n/2} \ge n^4 \text{ für } n \ge 8)\\ &\le \frac{2n^2}{n^4} = \frac{2}{n^2} && (1 \le n^2)\\ &\xrightarrow{n\to\infty} 0 . \end{aligned}0<nan​​​≤n4n2+1​≤n42n2​=n22​n→∞​0.​​(nn/2≥n4 fu¨r n≥8)(1≤n2)​

Also lim⁡n→∞ann=0<1\lim\limits_{n\to\infty}\sqrt[n]{a_n} = 0 < 1n→∞lim​nan​​=0<1. Insbesondere ist ann≤2n2≤132=:q<1\sqrt[n]{a_n} \le \frac{2}{n^2} \le \frac{1}{32} =: q < 1nan​​≤n22​≤321​=:q<1 für n≥8n \ge 8n≥8.

Schritt 3: Schluss

Nach dem Wurzelkriterium konvergiert die Reihe (absolut). Direkt: Für n≥8n \ge 8n≥8 ist an≤qna_n \le q^nan​≤qn und ∑qn\sum q^n∑qn ist eine konvergente geometrische Reihe (Majorante).

Für die Konvergenz zählt nur das Verhalten für große nnn.

Hilfreiches

Wurzelkriterium

Ist lim sup⁡n→∞∣an∣n<1\limsup\limits_{n\to\infty} \sqrt[n]{\vert a_n\vert} < 1n→∞limsup​n∣an​∣​<1, so konvergiert ∑an\sum a_n∑an​ absolut; ist er >1> 1>1, so divergiert ∑an\sum a_n∑an​. Bei =1= 1=1 keine Aussage.

Wann Wurzel-, wann Quotientenkriterium?

Wurzelkriterium bei Gliedern der Form (bn)n(b_n)^n(bn​)n oder cn2c^{n^2}cn2; Quotientenkriterium bei Fakultäten und Produkten.

Typische Fehler
  • n n2\sqrt{n}^{\,n^2}n​n2 als nn 2\sqrt{n^{n}}^{\,2}nn​2 oder nn2n^{n^2}nn2 lesen – richtig ist nn2/2n^{n^2/2}nn2/2.
  • (n2+1)nn=n2+1\sqrt[n]{(n^2+1)^n} = n^2 + 1n(n2+1)n​=n2+1 richtig, aber nn2/2n=nn/2\sqrt[n]{n^{n^2/2}} = n^{n/2}nnn2/2​=nn/2 falsch zu n1/2n^{1/2}n1/2 vereinfachen.
  • Aus den großen Anfangsgliedern auf Divergenz schließen.
