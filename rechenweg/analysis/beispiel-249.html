Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Rationale Funktion mit Zählergrad 111 < Nennergrad 333. Der Nenner hat die Nullstelle x=−1x = -1x=−1 und lässt sich nach der Formel a3+b3=(a+b)(a2−ab+b2)a^3 + b^3 = (a + b)(a^2 - ab + b^2)a3+b3=(a+b)(a2−ab+b2) zerlegen. Danach Partialbruchzerlegung: ein linearer und ein irreduzibler quadratischer Teilbruch; letzterer liefert Logarithmus und Arcustangens.

Schritt 1: Nenner faktorisieren

x3+1=(x+1)(x2−x+1).x^3 + 1 = (x + 1)(x^2 - x + 1) .x3+1=(x+1)(x2−x+1).

Der Faktor x2−x+1x^2 - x + 1x2−x+1 hat Diskriminante (−1)2−4=−3<0(-1)^2 - 4 = -3 < 0(−1)2−4=−3<0, ist also über R\RR irreduzibel (und stets positiv). Der Integrand ist für x≠−1x \ne -1x=−1 definiert.

Schritt 2: Partialbruchzerlegung

x(x+1)(x2−x+1)=Ax+1+Bx+Cx2−x+1⟺x=A(x2−x+1)+(Bx+C)(x+1).\frac{x}{(x + 1)(x^2 - x + 1)} = \frac{A}{x + 1} + \frac{Bx + C}{x^2 - x + 1} \quad\Longleftrightarrow\quad x = A(x^2 - x + 1) + (Bx + C)(x + 1) .(x+1)(x2−x+1)x​=x+1A​+x2−x+1Bx+C​⟺x=A(x2−x+1)+(Bx+C)(x+1).

  • x=−1x = -1x=−1: −1=A(1+1+1)=3A-1 = A(1 + 1 + 1) = 3A−1=A(1+1+1)=3A, also A=−13A = -\frac13A=−31​.
  • Koeffizient von x2x^2x2: 0=A+B0 = A + B0=A+B, also B=13B = \frac13B=31​.
