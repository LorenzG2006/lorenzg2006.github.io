Schritt 3: Einordnung

Eine Abbildung, die alle Normaxiome erfüllt außer „∥f∥=0⇒f=0\Vert f\Vert = 0 \Rightarrow f = 0∥f∥=0⇒f=0“, heißt Halbnorm (Seminorm). ∥⋅∥\Vert\cdot\Vert∥⋅∥ ist also eine Halbnorm auf I[a,b]I[a,b]I[a,b], aber keine Norm. Der Unterschied zu Bsp. 319: Dort erzwingt die Stetigkeit, dass eine Funktion ≠0\ne 0=0 auf einem ganzen Intervall positiver Länge ≠0\ne 0=0 ist. Ohne Stetigkeit kann eine Funktion auf einer „vernachlässigbaren“ Menge (hier ein Punkt; ebenso endlich viele Punkte) von 000 abweichen, ohne dass das Integral es bemerkt.
