Angabe Originalseite

Man zeige, dass die Hamming-Metrik auf Rn\R^nRn nicht durch eine Norm induziert wird.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Eine von einer Norm induzierte Metrik d(x⃗,y⃗)=∥x⃗−y⃗∥d(\vec x,\vec y) = \Vert\vec x - \vec y\Vertd(x,y​)=∥x−y​∥ „skaliert mit“: Verdoppelt man beide Punkte, verdoppelt sich ihr Abstand (absolute Homogenität der Norm). Die Hamming-Metrik zählt dagegen nur, wie viele Koordinaten verschieden sind – das ändert sich beim Strecken nicht. Diesen Widerspruch machen wir an einem konkreten Vektor fest.

Begriffe

Die Hamming-Metrik auf Rn\R^nRn ist

dH(x⃗,y⃗)=#{i∈{1,…,n}:xi≠yi}.d_H(\vec x,\vec y) = \#\{i \in \{1,\dots,n\} : x_i \ne y_i\} .dH​(x,y​)=#{i∈{1,…,n}:xi​=yi​}.

Eine Metrik ddd auf Rn\R^nRn heißt von einer Norm induziert, wenn es eine Norm ∥⋅∥\Vert\cdot\Vert∥⋅∥ auf Rn\R^nRn gibt mit d(x⃗,y⃗)=∥x⃗−y⃗∥d(\vec x,\vec y) = \Vert\vec x - \vec y\Vertd(x,y​)=∥x−y​∥ für alle x⃗,y⃗\vec x,\vec yx,y​. Eine Norm erfüllt insbesondere die absolute Homogenität

∥λx⃗∥=∣λ∣ ∥x⃗∥(λ∈R, x⃗∈Rn).\Vert\lambda\vec x\Vert = \vert\lambda\vert\,\Vert\vec x\Vert \qquad (\lambda \in \R,\ \vec x \in \R^n).∥λx∥=∣λ∣∥x∥(λ∈R, x∈Rn).

Beweis (indirekt)

Annahme: Es gibt eine Norm ∥⋅∥\Vert\cdot\Vert∥⋅∥ auf Rn\R^nRn (n≥1n \ge 1n≥1) mit dH(x⃗,y⃗)=∥x⃗−y⃗∥d_H(\vec x,\vec y) = \Vert\vec x - \vec y\VertdH​(x,y​)=∥x−y​∥ für alle x⃗,y⃗∈Rn\vec x,\vec y \in \R^nx,y​∈Rn.

Sei e⃗1=(1,0,…,0)\vec e_1 = (1, 0, \dots, 0)e1​=(1,0,…,0) der erste Einheitsvektor. Dann gilt:

  1. Mit x⃗=e⃗1\vec x = \vec e_1x=e1​, y⃗=0⃗\vec y = \vec 0y​=0: ∥e⃗1∥=∥e⃗1−0⃗∥=dH(e⃗1,0⃗)=1,\Vert\vec e_1\Vert = \Vert\vec e_1 - \vec 0\Vert = d_H(\vec e_1, \vec 0) = 1,∥e1​∥=∥e1​−0∥=dH​(e1​,0)=1, denn e⃗1\vec e_1e1​ und 0⃗\vec 00 unterscheiden sich genau in der ersten Koordinate (1≠01 \ne 01=0), sonst nirgends.

  2. Mit x⃗=2e⃗1=(2,0,…,0)\vec x = 2\vec e_1 = (2, 0, \dots, 0)x=2e1​=(2,0,…,0), y⃗=0⃗\vec y = \vec 0y​=0: ∥2e⃗1∥=dH(2e⃗1,0⃗)=1,\Vert 2\vec e_1\Vert = d_H(2\vec e_1, \vec 0) = 1,∥2e1​∥=dH​(2e1​,0)=1, denn auch hier unterscheidet sich nur die erste Koordinate (2≠02 \ne 02=0).

  3. Andererseits folgt aus der Homogenität der Norm: ∥2e⃗1∥=∣2∣⋅∥e⃗1∥=2⋅1=2.\Vert 2\vec e_1\Vert = \vert 2\vert\cdot\Vert\vec e_1\Vert = 2\cdot 1 = 2 .∥2e1​∥=∣2∣⋅∥e1​∥=2⋅1=2.

Aus 2. und 3. folgt 1=21 = 21=2 – ein Widerspruch. Also war die Annahme falsch: Es gibt keine Norm, die dHd_HdH​ induziert. ■\blacksquare■

Zweites Argument: Beschränktheit

Auch so sieht man es: dHd_HdH​ nimmt nur die Werte 0,1,…,n0, 1, \dots, n0,1,…,n an, ist also beschränkt. Für eine Norm gilt dagegen für jedes x⃗≠0⃗\vec x \ne \vec 0x=0:

∥tx⃗∥=t ∥x⃗∥  →t→∞  ∞,\Vert t\vec x\Vert = t\,\Vert\vec x\Vert \;\xrightarrow{t\to\infty}\; \infty ,∥tx∥=t∥x∥t→∞​∞,

die induzierte Metrik ist also unbeschränkt. Eine beschränkte Metrik auf Rn\R^nRn (n≥1n \ge 1n≥1) kann daher nie von einer Norm kommen.

Ergebnis

Die Hamming-Metrik dHd_HdH​ auf Rn\R^nRn wird nicht von einer Norm induziert: Sonst müsste ∥2e⃗1∥=2∥e⃗1∥\Vert 2\vec e_1\Vert = 2\Vert\vec e_1\Vert∥2e1​∥=2∥e1​∥ gelten, tatsächlich ist aber dH(2e⃗1,0⃗)=dH(e⃗1,0⃗)=1d_H(2\vec e_1,\vec 0) = d_H(\vec e_1,\vec 0) = 1dH​(2e1​,0)=dH​(e1​,0)=1.

Probe
  • Die Hamming-Metrik ist translationsinvariant: dH(x⃗+a⃗,y⃗+a⃗)=dH(x⃗,y⃗)d_H(\vec x + \vec a, \vec y + \vec a) = d_H(\vec x,\vec y)dH​(x+a,y​+a)=dH​(x,y​) (eine Koordinate unterscheidet sich vorher genau dann, wenn nachher). Das ist die andere Eigenschaft normierter Metriken – sie hilft hier also nicht; der Widerspruch muss wirklich aus der Homogenität kommen ✓.
  • Python-Test: dH((2,0,0),(0,0,0))=1=dH((1,0,0),(0,0,0))d_H((2,0,0),(0,0,0)) = 1 = d_H((1,0,0),(0,0,0))dH​((2,0,0),(0,0,0))=1=dH​((1,0,0),(0,0,0)) ✓.

Hilfreiches

Norm

Eine Abbildung ∥⋅∥:V→R\Vert\cdot\Vert : V \to \R∥⋅∥:V→R auf einem reellen Vektorraum VVV heißt Norm, wenn für alle x⃗,y⃗∈V\vec x,\vec y \in Vx,y​∈V, λ∈R\lambda \in \Rλ∈R: (N1) ∥x⃗∥≥0\Vert\vec x\Vert \ge 0∥x∥≥0 und ∥x⃗∥=0  ⟺  x⃗=0⃗\Vert\vec x\Vert = 0 \iff \vec x = \vec 0∥x∥=0⟺x=0; (N2) ∥λx⃗∥=∣λ∣ ∥x⃗∥\Vert\lambda\vec x\Vert = \vert\lambda\vert\,\Vert\vec x\Vert∥λx∥=∣λ∣∥x∥; (N3) ∥x⃗+y⃗∥≤∥x⃗∥+∥y⃗∥\Vert\vec x + \vec y\Vert \le \Vert\vec x\Vert + \Vert\vec y\Vert∥x+y​∥≤∥x∥+∥y​∥. Die induzierte Metrik ist d(x⃗,y⃗)=∥x⃗−y⃗∥d(\vec x,\vec y) = \Vert\vec x - \vec y\Vertd(x,y​)=∥x−y​∥.

Charakterisierung normierter Metriken

Eine Metrik ddd auf einem Vektorraum wird genau dann von einer Norm induziert, wenn sie translationsinvariant (d(x⃗+a⃗,y⃗+a⃗)=d(x⃗,y⃗)d(\vec x + \vec a,\vec y + \vec a) = d(\vec x,\vec y)d(x+a,y​+a)=d(x,y​)) und homogen (d(λx⃗,λy⃗)=∣λ∣ d(x⃗,y⃗)d(\lambda\vec x,\lambda\vec y) = \vert\lambda\vert\,d(\vec x,\vec y)d(λx,λy​)=∣λ∣d(x,y​)) ist; die Norm ist dann ∥x⃗∥=d(x⃗,0⃗)\Vert\vec x\Vert = d(\vec x,\vec 0)∥x∥=d(x,0).

Typische Fehler
  • Nur zeigen, dass die „Kandidatennorm“ ∥x⃗∥:=dH(x⃗,0⃗)\Vert\vec x\Vert := d_H(\vec x,\vec 0)∥x∥:=dH​(x,0) keine Norm ist – das reicht, ist aber genau zu begründen: Jede induzierende Norm müsste diese Gestalt haben.
  • Mit der Dreiecksungleichung argumentieren: dHd_HdH​ erfüllt sie (es ist ja eine Metrik), daraus entsteht kein Widerspruch.
  • Ein Beispiel mit λ=−1\lambda = -1λ=−1 wählen: dH(−x⃗,0⃗)=dH(x⃗,0⃗)d_H(-\vec x, \vec 0) = d_H(\vec x,\vec 0)dH​(−x,0)=dH​(x,0) ist mit ∣−1∣=1\vert -1\vert = 1∣−1∣=1 verträglich – kein Widerspruch.
