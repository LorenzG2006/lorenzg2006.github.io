Angabe Originalseite

421–430) Lösen Sie die folgenden Differentialgleichungen:

y′=(1−2x)y+(1+x2)y' = (1-2x)y + (1+x^2)y′=(1−2x)y+(1+x2)

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Lineare DGL y′+a(x)y=b(x)y' + a(x)y = b(x)y′+a(x)y=b(x) mit a(x)=2x−1a(x) = 2x - 1a(x)=2x−1, b(x)=1+x2b(x) = 1 + x^2b(x)=1+x2. Die homogene Lösung ist Cex−x2Ce^{x - x^2}Cex−x2. Für eine partikuläre Lösung braucht man ∫(1+x2)ex2−x dx\int (1+x^2)e^{x^2 - x}\,dx∫(1+x2)ex2−xdx – dieses Integral ist nicht elementar (es enthält ∫et2dt\int e^{t^2}dt∫et2dt). Wir vereinfachen es so weit wie möglich und geben die Lösung mit einem bestimmten Integral (bzw. der Funktion erfi⁡\operatorname{erfi}erfi) an. Vorher prüfen wir, dass kein Polynomansatz funktioniert.

Schritt 1: Homogene Lösung

y′=(1−2x)yy' = (1 - 2x)yy′=(1−2x)y: Trennung der Variablen, ln⁡∣y∣=x−x2+c\ln|y| = x - x^2 + cln∣y∣=x−x2+c, also yh=C ex−x2.y_h = C\,e^{x - x^2}.yh​=Cex−x2.

Schritt 2: Gibt es eine polynomiale Lösung?

Ansatz y=p(x)y = p(x)y=p(x) mit Grad ddd: Links hat p′p'p′ Grad d−1d - 1d−1, rechts hat (1−2x)p(1 - 2x)p(1−2x)p Grad d+1d + 1d+1 mit Leitkoeffizient −2⋅(Leitkoeff. von p)≠0-2\cdot(\text{Leitkoeff. von } p) \ne 0−2⋅(Leitkoeff. von p)=0; der Summand 1+x21 + x^21+x2 kann ihn nur für d+1=2d + 1 = 2d+1=2, also d=1d = 1d=1, aufheben. Für p=αx+βp = \alpha x + \betap=αx+β: α=(1−2x)(αx+β)+1+x2=(1−2α)x2+(α−2β)x+β+1.\alpha = (1 - 2x)(\alpha x + \beta) + 1 + x^2 = (1 - 2\alpha)x^2 + (\alpha - 2\beta)x + \beta + 1.α=(1−2x)(αx+β)+1+x2=(1−2α)x2+(α−2β)x+β+1. Koeffizientenvergleich: α=12\alpha = \frac12α=21​, β=α2=14\beta = \frac{\alpha}{2} = \frac14β=2α​=41​, aber dann β+1=54≠12=α\beta + 1 = \frac54 \ne \frac12 = \alphaβ+1=45​=21​=α. Widerspruch – keine polynomiale Lösung.

y=C(x)ex−x2y = C(x)e^{x - x^2}y=C(x)ex−x2 eingesetzt liefert C′(x)=(1+x2)ex2−xC'(x) = (1 + x^2)e^{x^2 - x}C′(x)=(1+x2)ex2−x. Hilfreiches

Variation der Konstanten

y′+a(x)y=b(x)y' + a(x)y = b(x)y′+a(x)y=b(x): Ansatz y=C(x)e−A(x)y = C(x)e^{-A(x)}y=C(x)e−A(x) führt auf C′(x)=b(x)eA(x)C'(x) = b(x)e^{A(x)}C′(x)=b(x)eA(x).

Imaginäre Fehlerfunktion

erfi⁡(t)=2π∫0tes2 ds\operatorname{erfi}(t) = \frac{2}{\sqrt\pi}\int_0^t e^{s^2}\,dserfi(t)=π​2​∫0t​es2ds (keine elementare Stammfunktion, ähnlich wie bei ∫e−s2ds\int e^{-s^2}ds∫e−s2ds).

Typische Fehler
  • „Stammfunktion“ von ex2e^{x^2}ex2 als ex22x\frac{e^{x^2}}{2x}2xex2​ angeben – das ist falsch (Ableitung prüfen!).
  • Mit einem Polynomansatz eine scheinbare partikuläre Lösung erzwingen; der Koeffizientenvergleich zeigt, dass es keine gibt.
  • Bei der quadratischen Ergänzung den Faktor e−1/4e^{-1/4}e−1/4 vergessen (er kürzt sich hier am Ende, muss aber konsequent mitgeführt werden).
