Angabe Originalseite

Man berechne die ersten 4 Ableitungen der Funktion f(x)=e−xcos⁡xf(x) = e^{-x}\cos xf(x)=e−xcosx. Können Sie allgemein einen Ausdruck für die nnn-te Ableitung angeben (Fallunterscheidung nach Restklasse von n mod 4n \bmod 4nmod4)?

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Wie in Bsp. 178: Viermal Produktregel (mit Kettenregel für e−xe^{-x}e−x), dann fällt f(4)=−4ff^{(4)} = -4ff(4)=−4f auf. Für n=4k+rn = 4k + rn=4k+r folgt f(n)=(−4)kf(r)f^{(n)} = (-4)^k f^{(r)}f(n)=(−4)kf(r), was die Fallunterscheidung nach n mod 4n \bmod 4nmod4 liefert. Zusätzlich geben wir eine geschlossene Formel an.

Schritt 1: Die ersten vier Ableitungen

Mit (e−x)′=−e−x(e^{-x})' = -e^{-x}(e−x)′=−e−x (Kettenregel) und der Produktregel:

f′(x)=−e−xcos⁡x+e−x(−sin⁡x)=−e−x(cos⁡x+sin⁡x),f′′(x)=e−x(cos⁡x+sin⁡x)−e−x(−sin⁡x+cos⁡x)=2e−xsin⁡x,f′′′(x)=−2e−xsin⁡x+2e−xcos⁡x=2e−x(cos⁡x−sin⁡x),f(4)(x)=−2e−x(cos⁡x−sin⁡x)+2e−x(−sin⁡x−cos⁡x)=−4e−xcos⁡x.\begin{aligned} f'(x) &= -e^{-x}\cos x + e^{-x}(-\sin x) = -e^{-x}(\cos x + \sin x),\\ f''(x) &= e^{-x}(\cos x + \sin x) - e^{-x}(-\sin x + \cos x) = 2e^{-x}\sin x,\\ f'''(x) &= -2e^{-x}\sin x + 2e^{-x}\cos x = 2e^{-x}(\cos x - \sin x),\\ f^{(4)}(x) &= -2e^{-x}(\cos x - \sin x) + 2e^{-x}(-\sin x - \cos x) = -4e^{-x}\cos x . \end{aligned}f′(x)f′′(x)f′′′(x)f(4)(x)​=−e−xcosx+e−x(−sinx)=−e−x(cosx+sinx),=e−x(cosx+sinx)−e−x(−sinx+cosx)=2e−xsinx,=−2e−xsinx+2e−xcosx=2e−x(cosx−sinx),=−2e−x(cosx−sinx)+2e−x(−sinx−cosx)=−4e−xcosx.​

Hilfreiches

Produkt- und Kettenregel

(uv)′=u′v+uv′(uv)' = u'v + uv'(uv)′=u′v+uv′; (e−x)′=−e−x(e^{-x})' = -e^{-x}(e−x)′=−e−x. Daher (e−xg(x))′=e−x(g′(x)−g(x))\bigl(e^{-x}g(x)\bigr)' = e^{-x}\bigl(g'(x) - g(x)\bigr)(e−xg(x))′=e−x(g′(x)−g(x)).

e−xcos⁡x=Re⁡ e(−1+i)xe^{-x}\cos x = \Re\, e^{(-1 + i)x}e−xcosx=Ree(−1+i)x, und jede Ableitung multipliziert mit −1+i=2 ei 3π/4-1 + i = \sqrt2\,e^{i\,3\pi/4}−1+i=2​ei3π/4.
