Angabe Originalseite

415–420) Man bestimme die allgemeine Lösung der Differentialgleichung bzw. die Lösung der Anfangswertaufgabe:

y′=ysin⁡xy' = y\sin xy′=ysinx

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Die Gleichung ist separabel (y′=g(x)h(y)y' = g(x)h(y)y′=g(x)h(y) mit g=sin⁡g = \sing=sin, h(y)=yh(y) = yh(y)=y) und zugleich homogen linear. Wir trennen die Variablen; die Nullstelle y=0y = 0y=0 von hhh liefert die konstante Lösung y≡0y \equiv 0y≡0.

Schritt 1: Konstante Lösung

y≡0y \equiv 0y≡0: y′=0=0⋅sin⁡xy' = 0 = 0\cdot\sin xy′=0=0⋅sinx ✓.

Schritt 2: Trennung der Variablen (y≠0y \ne 0y=0)

dydx=ysin⁡x∫dyy=∫sin⁡x dx(durch y teilen, integrieren)ln⁡∣y∣=−cos⁡x+c(c∈R)∣y∣=ec e−cos⁡xy=C e−cos⁡x.(C=±ec≠0)\begin{aligned} \frac{dy}{dx} &= y\sin x &&\\ \int \frac{dy}{y} &= \int \sin x\,dx && \text{(durch } y \text{ teilen, integrieren)}\\ \ln|y| &= -\cos x + c && (c \in \R)\\ |y| &= e^{c}\,e^{-\cos x} &&\\ y &= C\,e^{-\cos x}. && (C = \pm e^c \ne 0) \end{aligned}dxdy​∫ydy​ln∣y∣∣y∣y​=ysinx=∫sinxdx=−cosx+c=ece−cosx=Ce−cosx.​​(durch y teilen, integrieren)(c∈R)(C=±ec=0)​

Eine Lösung ohne Nullstelle hat wegen der Stetigkeit festes Vorzeichen, daher ist ±\pm± auf ganz R\RR konstant. Mit C=0C = 0C=0 ist auch y≡0y \equiv 0y≡0 erfasst.

Ergebnis

y(x)=C e−cos⁡x,C∈R, x∈R.y(x) = C\,e^{-\cos x}, \qquad C \in \R, \ x \in \R.y(x)=Ce−cosx,C∈R, x∈R.

Probe

y′=C e−cos⁡x⋅sin⁡x=ysin⁡xy' = C\,e^{-\cos x}\cdot\sin x = y\sin xy′=Ce−cosx⋅sinx=ysinx ✓ (Kettenregel, (−cos⁡x)′=sin⁡x(-\cos x)' = \sin x(−cosx)′=sinx). sympy checkodesol: 000.
