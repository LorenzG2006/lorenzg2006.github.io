Angabe Originalseite

Man berechne:

∫dxsin⁡x\int\frac{\mathrm dx}{\sin x}∫sinxdx​

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Zwei Standardwege: (1) mit sin⁡x\sin xsinx erweitern, sodass im Nenner 1−cos⁡2x1 - \cos^2 x1−cos2x steht, und u=cos⁡xu = \cos xu=cosx substituieren; (2) die universelle Weierstraß-Substitution t=tan⁡x2t = \tan\frac x2t=tan2x​, die jede rationale Funktion in sin⁡x,cos⁡x\sin x, \cos xsinx,cosx in eine rationale Funktion in ttt verwandelt. Beide Ergebnisse stimmen überein.

Definitionsbereich: sin⁡x≠0\sin x \ne 0sinx=0, also x≠kπx \ne k\pix=kπ (k∈Zk \in \Zk∈Z). Die Stammfunktion gilt auf jedem Intervall (kπ,(k+1)π)(k\pi, (k + 1)\pi)(kπ,(k+1)π).

Weg 1: Erweitern und u = cos x

1sin⁡x=sin⁡xsin⁡2x=sin⁡x1−cos⁡2x.\frac{1}{\sin x} = \frac{\sin x}{\sin^2 x} = \frac{\sin x}{1 - \cos^2 x} .sinx1​=sin2xsinx​=1−cos2xsinx​.

Substitution u=cos⁡xu = \cos xu=cosx, du=−sin⁡x dx\mathrm du = -\sin x\,\mathrm dxdu=−sinxdx:

∫sin⁡x1−cos⁡2x dx=−∫du1−u2=∫duu2−1.\int\frac{\sin x}{1 - \cos^2 x}\,\mathrm dx = -\int\frac{\mathrm du}{1 - u^2} = \int\frac{\mathrm du}{u^2 - 1} .∫1−cos2xsinx​dx=−∫1−u2du​=∫u2−1du​.

Partialbrüche: 1u2−1=12(1u−1−1u+1)\frac{1}{u^2 - 1} = \frac12\Bigl(\frac{1}{u - 1} - \frac{1}{u + 1}\Bigr)u2−11​=21​(u−11​−u+11​) (Kontrolle: (u+1)−(u−1)2(u2−1)=1u2−1\frac{(u + 1) - (u - 1)}{2(u^2 - 1)} = \frac{1}{u^2 - 1}2(u2−1)(u+1)−(u−1)​=u2−11​ ✓). Also

∫duu2−1=12ln⁡∣u−1u+1∣=12ln⁡1−cos⁡x1+cos⁡x,\int\frac{\mathrm du}{u^2 - 1} = \frac12\ln\Bigl\vert\frac{u - 1}{u + 1}\Bigr\vert = \frac12\ln\frac{1 - \cos x}{1 + \cos x},∫u2−1du​=21​ln​u+1u−1​​=21​ln1+cosx1−cosx​,

wobei wir ∣cos⁡x−1∣=1−cos⁡x\vert\cos x - 1\vert = 1 - \cos x∣cosx−1∣=1−cosx verwendet haben (1±cos⁡x>01 \pm \cos x > 01±cosx>0 für x≠kπx \ne k\pix=kπ).

Weg 2: Weierstraß-Substitution t = tan(x/2)

Mit t=tan⁡x2t = \tan\frac x2t=tan2x​ gilt (Doppelwinkelformeln, cos⁡2x2=11+t2\cos^2\frac x2 = \frac{1}{1 + t^2}cos22x​=1+t21​):

sin⁡x=2sin⁡x2cos⁡x2=2tan⁡x2cos⁡2x2=2t1+t2,x=2arctan⁡t,dx=2 dt1+t2.\sin x = 2\sin\tfrac x2\cos\tfrac x2 = 2\tan\tfrac x2\cos^2\tfrac x2 = \frac{2t}{1 + t^2}, \qquad x = 2\arctan t,\quad \mathrm dx = \frac{2\,\mathrm dt}{1 + t^2} .sinx=2sin2x​cos2x​=2tan2x​cos22x​=1+t22t​,x=2arctant,dx=1+t22dt​.

∫dxsin⁡x=∫1+t22t⋅2 dt1+t2=∫dtt=ln⁡∣t∣=ln⁡∣tan⁡x2∣.\int\frac{\mathrm dx}{\sin x} = \int\frac{1 + t^2}{2t}\cdot\frac{2\,\mathrm dt}{1 + t^2} = \int\frac{\mathrm dt}{t} = \ln\vert t\vert = \ln\Bigl\vert\tan\frac x2\Bigr\vert .∫sinxdx​=∫2t1+t2​⋅1+t22dt​=∫tdt​=ln∣t∣=ln​tan2x​​.

Vergleich

1−cos⁡x1+cos⁡x=2sin⁡2x22cos⁡2x2=tan⁡2x2⟹12ln⁡1−cos⁡x1+cos⁡x=12ln⁡tan⁡2x2=ln⁡∣tan⁡x2∣.\frac{1 - \cos x}{1 + \cos x} = \frac{2\sin^2\frac x2}{2\cos^2\frac x2} = \tan^2\frac x2 \quad\Longrightarrow\quad \frac12\ln\frac{1 - \cos x}{1 + \cos x} = \frac12\ln\tan^2\frac x2 = \ln\Bigl\vert\tan\frac x2\Bigr\vert .1+cosx1−cosx​=2cos22x​2sin22x​​=tan22x​⟹21​ln1+cosx1−cosx​=21​lntan22x​=ln​tan2x​​.

Hilfreiches

Weierstraß-Substitution

Mit t=tan⁡x2t = \tan\frac x2t=tan2x​: sin⁡x=2t1+t2,cos⁡x=1−t21+t2,dx=2 dt1+t2.\sin x = \frac{2t}{1 + t^2}, \qquad \cos x = \frac{1 - t^2}{1 + t^2}, \qquad \mathrm dx = \frac{2\,\mathrm dt}{1 + t^2} .sinx=1+t22t​,cosx=1+t21−t2​,dx=1+t22dt​.

Halbwinkelformeln

1−cos⁡x=2sin⁡2x2,1+cos⁡x=2cos⁡2x2,sin⁡x=2sin⁡x2cos⁡x2.1 - \cos x = 2\sin^2\frac x2, \qquad 1 + \cos x = 2\cos^2\frac x2, \qquad \sin x = 2\sin\frac x2\cos\frac x2 .1−cosx=2sin22x​,1+cosx=2cos22x​,sinx=2sin2x​cos2x​.

  • Vorzeichen bei du=−sin⁡x dx\mathrm du = -\sin x\,\mathrm dxdu=−sinxdx verlieren; dann steht 12ln⁡1+cos⁡x1−cos⁡x\frac12\ln\frac{1 + \cos x}{1 - \cos x}21​ln1−cosx1+cosx​ da (falsches Vorzeichen).
  • Betragsstriche vergessen: tan⁡x2<0\tan\frac x2 < 0tan2x​<0 z. B. für π<x<2π\pi < x < 2\piπ<x<2π.
