Gegeben seien die Funktionen f(x)=11−xf(x) = \frac{1}{1-x}f(x)=1−x1​, g(x)=11+xg(x) = \frac{1}{1+x}g(x)=1+x1​ und h(x)=11−x2h(x) = \frac{1}{1-x^2}h(x)=1−x21​.

(a) Potenzreihen und Konvergenzradien

Grundlage – geometrische Reihe: Für q≠1q \ne 1q=1 gilt ∑n=0Nqn=1−qN+11−q\sum_{n=0}^{N} q^n = \frac{1 - q^{N+1}}{1 - q}∑n=0N​qn=1−q1−qN+1​. Für ∣q∣<1|q| < 1∣q∣<1 geht qN+1→0q^{N+1} \to 0qN+1→0, also

∑n=0∞qn=11−q(∣q∣<1).\sum_{n=0}^{\infty} q^n = \frac{1}{1-q} \qquad (|q| < 1).n=0∑∞​qn=1−q1​(∣q∣<1).

Für ∣q∣≥1|q| \ge 1∣q∣≥1 ist ∣qn∣≥1|q^n| \ge 1∣qn∣≥1, die Glieder gehen nicht gegen 000, und die Reihe divergiert.

f(x)=11−xf(x) = \frac{1}{1-x}f(x)=1−x1​: Mit q=xq = xq=x:

f(x)=∑n=0∞xn=1+x+x2+x3+⋯(∣x∣<1).f(x) = \sum_{n=0}^{\infty} x^n = 1 + x + x^2 + x^3 + \cdots \qquad (|x| < 1).f(x)=n=0∑∞​xn=1+x+x2+x3+⋯(∣x∣<1).

g(x)=∑n=0∞(−x)n=∑n=0∞(−1)nxn=1−x+x2−x3+⋯(∣x∣<1).g(x) = \sum_{n=0}^{\infty} (-x)^n = \sum_{n=0}^{\infty} (-1)^n x^n = 1 - x + x^2 - x^3 + \cdots \qquad (|x| < 1).g(x)=n=0∑∞​(−x)n=n=0∑∞​(−1)nxn=1−x+x2−x3+⋯(∣x∣<1).

Die Bedingung ∣q∣=∣−x∣=∣x∣<1|q| = |-x| = |x| < 1∣q∣=∣−x∣=∣x∣<1 ergibt Rg=1R_g = 1Rg​=1 (Koeffizienten bn=(−1)nb_n = (-1)^nbn​=(−1)n, ∣bn∣n=1\sqrt[n]{|b_n|} = 1n∣bn​∣​=1).

h(x)=11−x2h(x) = \frac{1}{1-x^2}h(x)=1−x21​: Mit q=x2q = x^2q=x2:

Die Bedingung ∣x2∣<1|x^2| < 1∣x2∣<1 ist äquivalent zu ∣x∣<1|x| < 1∣x∣<1, also Rh=1R_h = 1Rh​=1. Als Potenzreihe ∑dmxm\sum d_m x^m∑dm​xm hat hhh die Koeffizienten dm=1d_m = 1dm​=1 für gerades mmm und dm=0d_m = 0dm​=0 für ungerades mmm; nach Cauchy–Hadamard ist lim sup⁡∣dm∣m=1\limsup \sqrt[m]{|d_m|} = 1limsupm∣dm​∣​=1, also wieder Rh=1R_h = 1Rh​=1.

(b) Cauchyprodukt der Reihen von fff und ggg

Für zwei Potenzreihen ∑anxn\sum a_n x^n∑an​xn und ∑bnxn\sum b_n x^n∑bn​xn ist das Cauchyprodukt die Reihe ∑cnxn\sum c_n x^n∑cn​xn mit

cn=∑k=0nak bn−k=a0bn+a1bn−1+⋯+anb0.c_n = \sum_{k=0}^{n} a_k\, b_{n-k} = a_0 b_n + a_1 b_{n-1} + \dots + a_n b_0 .cn​=k=0∑n​ak​bn−k​=a0​bn​+a1​bn−1​+⋯+an​b0​.

Hier ist ak=1a_k = 1ak​=1 (Reihe von fff) und bj=(−1)jb_j = (-1)^jbj​=(−1)j (Reihe von ggg). Damit:

cn=∑k=0n1⋅(−1)n−k(Koeffizienten einsetzen)=∑j=0n(−1)j(j:=n−k la¨uft ebenfalls von 0 bis n)=1−1+1−⋯+(−1)n⏟n+1 Summanden.(ausgeschrieben)\begin{aligned} c_n &= \sum_{k=0}^{n} 1\cdot(-1)^{n-k} && \text{(Koeffizienten einsetzen)}\\ &= \sum_{j=0}^{n} (-1)^{j} && (j := n - k \text{ läuft ebenfalls von } 0 \text{ bis } n)\\ &= \underbrace{1 - 1 + 1 - \cdots + (-1)^n}_{n+1 \text{ Summanden}} . && \text{(ausgeschrieben)} \end{aligned}cn​​=k=0∑n​1⋅(−1)n−k=j=0∑n​(−1)j=n+1 Summanden1−1+1−⋯+(−1)n​​.​​(Koeffizienten einsetzen)(j:=n−k la¨uft ebenfalls von 0 bis n)(ausgeschrieben)​

Die Summanden heben sich paarweise auf (1−1=01 - 1 = 01−1=0):

  • nnn ungerade: n+1n + 1n+1 ist gerade, alle Summanden bilden Paare, cn=0c_n = 0cn​=0.
  • nnn gerade: n+1n + 1n+1 ist ungerade, ein einzelner Summand (−1)n=+1(-1)^n = +1(−1)n=+1 bleibt übrig, cn=1c_n = 1cn​=1.

Das Cauchyprodukt ist also

∑n=0∞cnxn=1+0⋅x+x2+0⋅x3+x4+⋯=∑m=0∞x2m.\sum_{n=0}^{\infty} c_n x^n = 1 + 0\cdot x + x^2 + 0\cdot x^3 + x^4 + \cdots = \sum_{m=0}^{\infty} x^{2m} .n=0∑∞​cn​xn=1+0⋅x+x2+0⋅x3+x4+⋯=m=0∑∞​x2m.

Wogegen konvergiert es? Für ∣x∣<1|x| < 1∣x∣<1 konvergieren beide Reihen absolut (denn ∑∣x∣n\sum |x|^n∑∣x∣n ist eine konvergente geometrische Reihe). Nach dem Satz über das Cauchyprodukt konvergiert dann auch das Produkt (absolut), und zwar gegen das Produkt der Grenzwerte:

∑n=0∞cnxn=f(x) g(x)=1(1−x)(1+x)=11−x2=h(x).\sum_{n=0}^{\infty} c_n x^n = f(x)\,g(x) = \frac{1}{(1-x)(1+x)} = \frac{1}{1-x^2} = h(x) .n=0∑∞​cn​xn=f(x)g(x)=(1−x)(1+x)1​=1−x21​=h(x).

Das stimmt mit der in (a) direkt gewonnenen Reihe von hhh überein ✓.

Ergebnis

(a) f(x)=∑n=0∞xn,g(x)=∑n=0∞(−1)nxn,h(x)=∑n=0∞x2n,f(x) = \sum_{n=0}^{\infty} x^n,\qquad g(x) = \sum_{n=0}^{\infty} (-1)^n x^n,\qquad h(x) = \sum_{n=0}^{\infty} x^{2n},f(x)=n=0∑∞​xn,g(x)=n=0∑∞​(−1)nxn,h(x)=n=0∑∞​x2n, jeweils mit Konvergenzradius R=1R = 1R=1.

(b) Cauchyprodukt: cn=∑k=0n(−1)n−k={1n gerade,0n ungerade,c_n = \sum_{k=0}^{n} (-1)^{n-k} = \begin{cases} 1 & n \text{ gerade},\\ 0 & n \text{ ungerade},\end{cases}cn​=∑k=0n​(−1)n−k={10​n gerade,n ungerade,​ also (∑n=0∞xn)(∑n=0∞(−1)nxn)=∑m=0∞x2m=h(x)(∣x∣<1).\Bigl(\sum_{n=0}^\infty x^n\Bigr)\Bigl(\sum_{n=0}^\infty (-1)^n x^n\Bigr) = \sum_{m=0}^{\infty} x^{2m} = h(x) \qquad (|x| < 1).(n=0∑∞​xn)(n=0∑∞​(−1)nxn)=m=0∑∞​x2m=h(x)(∣x∣<1).

Hilfreiches

Geometrische Reihe

∑n=0∞qn=11−qfu¨r ∣q∣<1;fu¨r ∣q∣≥1 divergent.\sum_{n=0}^{\infty} q^n = \frac{1}{1-q} \quad\text{für } |q| < 1; \qquad \text{für } |q| \ge 1 \text{ divergent.}n=0∑∞​qn=1−q1​fu¨r ∣q∣<1;fu¨r ∣q∣≥1 divergent.

Konvergenzradius (Cauchy–Hadamard)

Für ∑an(x−x0)n\sum a_n (x - x_0)^n∑an​(x−x0​)n ist R=1lim sup⁡n→∞∣an∣nR = \frac{1}{\limsup_{n\to\infty} \sqrt[n]{|a_n|}}R=limsupn→∞​n∣an​∣​1​ (mit R=∞R = \inftyR=∞, falls der lim sup⁡\limsuplimsup gleich 000 ist). Für ∣x−x0∣<R|x - x_0| < R∣x−x0​∣<R konvergiert die Reihe absolut, für ∣x−x0∣>R|x - x_0| > R∣x−x0​∣>R divergiert sie.

Cauchyprodukt

Konvergieren ∑an\sum a_n∑an​ und ∑bn\sum b_n∑bn​ absolut, so konvergiert auch ∑cn\sum c_n∑cn​ mit cn=∑k=0nakbn−kc_n = \sum_{k=0}^n a_k b_{n-k}cn​=∑k=0n​ak​bn−k​ absolut, und ∑n=0∞cn=(∑n=0∞an)(∑n=0∞bn).\sum_{n=0}^\infty c_n = \Bigl(\sum_{n=0}^\infty a_n\Bigr)\Bigl(\sum_{n=0}^\infty b_n\Bigr).n=0∑∞​cn​=(n=0∑∞​an​)(n=0∑∞​bn​). Für Potenzreihen: Innerhalb beider Konvergenzkreise darf man sie wie Polynome ausmultiplizieren.

Typische Fehler
  • Das Cauchyprodukt mit dem gliedweisen Produkt ∑anbnxn\sum a_n b_n x^n∑an​bn​xn verwechseln – das wäre hier ∑(−1)nxn\sum (-1)^n x^n∑(−1)nxn, also falsch.
  • Bei hhh wegen des x2x^2x2 einen anderen Radius vermuten: Aus ∣x2∣<1|x^2| < 1∣x2∣<1 folgt einfach ∣x∣<1|x| < 1∣x∣<1, also Rh=1R_h = 1Rh​=1.
  • Vergessen, dass man für die Gleichheit ∑cnxn=f(x)g(x)\sum c_n x^n = f(x)g(x)∑cn​xn=f(x)g(x) die (absolute) Konvergenz beider Reihen braucht.
