Angabe Originalseite

421–430) Lösen Sie die folgenden Differentialgleichungen:

xy′=y+x2cos⁡xxy' = y + x^2\cos xxy′=y+x2cosx

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Umgestellt: xy′−y=x2cos⁡xxy' - y = x^2\cos xxy′−y=x2cosx. Die linke Seite ist x2(yx)′x^2\bigl(\frac{y}{x}\bigr)'x2(xy​)′ (Quotientenregel). Division durch x2x^2x2 ergibt (yx)′=cos⁡x\bigl(\frac{y}{x}\bigr)' = \cos x(xy​)′=cosx – sofort integrierbar. Das entspricht dem integrierenden Faktor 1x\frac1xx1​ in der Normalform y′−1xy=xcos⁡xy' - \frac1x y = x\cos xy′−x1​y=xcosx.

Schritt 1: Umformen

xy′−y=x2cos⁡x⟹:x2xy′−yx2=(yx)′=cos⁡x(x≠0).xy' - y = x^2\cos x \quad\overset{:x^2}{\Longrightarrow}\quad \frac{xy' - y}{x^2} = \Bigl(\frac{y}{x}\Bigr)' = \cos x \qquad (x \ne 0).xy′−y=x2cosx⟹:x2​x2xy′−y​=(xy​)′=cosx(x=0).

Schritt 2: Integrieren

yx=sin⁡x+C⟹y=xsin⁡x+Cx.\frac{y}{x} = \sin x + C \quad\Longrightarrow\quad y = x\sin x + Cx.xy​=sinx+C⟹y=xsinx+Cx.

Schritt 3: Verhalten bei x=0x = 0x=0

Die Funktionen y=xsin⁡x+Cxy = x\sin x + Cxy=xsinx+Cx sind auf ganz R\RR differenzierbar, und die Ausgangsgleichung xy′=y+x2cos⁡xxy' = y + x^2\cos xxy′=y+x2cosx ist bei x=0x = 0x=0 erfüllt (0=0+00 = 0 + 00=0+0). Sie sind also sogar Lösungen auf R\RR. (Man könnte links und rechts von 000 verschiedene Konstanten wählen; die Funktion wäre dann bei 000 geknickt, also nicht differenzierbar – auf R\RR daher nur ein CCC.)

Ergebnis

y(x)=xsin⁡x+Cx=x(sin⁡x+C),C∈R.y(x) = x\sin x + Cx = x(\sin x + C), \qquad C \in \R.y(x)=xsinx+Cx=x(sinx+C),C∈R.

Probe

y′=sin⁡x+xcos⁡x+Cy' = \sin x + x\cos x + Cy′=sinx+xcosx+C, also xy′=xsin⁡x+x2cos⁡x+Cx=y+x2cos⁡xxy' = x\sin x + x^2\cos x + Cx = y + x^2\cos xxy′=xsinx+x2cosx+Cx=y+x2cosx ✓. sympy checkodesol: 000.

Hilfreiches

Quotientenregel als integrierender Faktor

(yx)′=xy′−yx2.\Bigl(\frac{y}{x}\Bigr)' = \frac{xy' - y}{x^2}.(xy​)′=x2xy′−y​. Gleichungen der Form xy′−y=r(x)xy' - y = r(x)xy′−y=r(x) werden so zu (yx)′=r(x)x2\bigl(\frac{y}{x}\bigr)' = \frac{r(x)}{x^2}(xy​)′=x2r(x)​.

Struktur

yh=Cxy_h = Cxyh​=Cx löst xy′=yxy' = yxy′=y; yp=xsin⁡xy_p = x\sin xyp​=xsinx ist eine partikuläre Lösung.

Typische Fehler
  • Durch xxx statt durch x2x^2x2 teilen und dann die linke Seite nicht als Ableitung erkennen.
  • Die Konstante nicht mit xxx multiplizieren.
