Angabe Originalseite

Man berechne:

∫(sin⁡x)(1+2cos⁡x)4 dx\int(\sin x)(1 + 2\cos x)^4\,\mathrm dx∫(sinx)(1+2cosx)4dx

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Die innere Funktion 1+2cos⁡x1 + 2\cos x1+2cosx hat die Ableitung −2sin⁡x-2\sin x−2sinx – bis auf einen konstanten Faktor steht genau diese als zweiter Faktor im Integranden. Das ist das typische Muster ∫f(g(x)) g′(x) dx\int f(g(x))\,g'(x)\,\mathrm dx∫f(g(x))g′(x)dx für die Substitutionsregel.

Schritt 1: Substitution

u=1+2cos⁡x,dudx=−2sin⁡x⟹sin⁡x dx=−12 du.u = 1 + 2\cos x, \qquad \frac{\mathrm du}{\mathrm dx} = -2\sin x \quad\Longrightarrow\quad \sin x\,\mathrm dx = -\frac12\,\mathrm du .u=1+2cosx,dxdu​=−2sinx⟹sinxdx=−21​du.

∫sin⁡x (1+2cos⁡x)4 dx=∫u4⋅(−12) du=−12⋅u55=−u510.\int\sin x\,(1 + 2\cos x)^4\,\mathrm dx = \int u^4\cdot\Bigl(-\frac12\Bigr)\,\mathrm du = -\frac12\cdot\frac{u^5}{5} = -\frac{u^5}{10} .∫sinx(1+2cosx)4dx=∫u4⋅(−21​)du=−21​⋅5u5​=−10u5​.

Schritt 2: Rücksubstitution

∫sin⁡x (1+2cos⁡x)4 dx=−(1+2cos⁡x)510+C.\int\sin x\,(1 + 2\cos x)^4\,\mathrm dx = -\frac{(1 + 2\cos x)^5}{10} + C .∫sinx(1+2cosx)4dx=−10(1+2cosx)5​+C.

Ergebnis

∫(sin⁡x)(1+2cos⁡x)4 dx=−(1+2cos⁡x)510+C.\int(\sin x)(1 + 2\cos x)^4\,\mathrm dx = -\frac{(1 + 2\cos x)^5}{10} + C .∫(sinx)(1+2cosx)4dx=−10(1+2cosx)5​+C.

Hilfreiches

Substitutionsregel

∫f(g(x)) g′(x) dx=F(g(x))+C,wobei F′=f.\int f\bigl(g(x)\bigr)\,g'(x)\,\mathrm dx = F\bigl(g(x)\bigr) + C, \qquad\text{wobei } F' = f .∫f(g(x))g′(x)dx=F(g(x))+C,wobei F′=f.

Merke

Man erkennt Substitutionskandidaten daran, dass die Ableitung einer „inneren Funktion“ (bis auf einen konstanten Faktor) als Faktor im Integranden vorkommt. Ausmultiplizieren von (1+2cos⁡x)4(1 + 2\cos x)^4(1+2cosx)4 wäre möglich, aber viel aufwendiger.

Typische Fehler
  • Den Faktor −12-\frac12−21​ aus du=−2sin⁡x dx\mathrm du = -2\sin x\,\mathrm dxdu=−2sinxdx vergessen oder als −2-2−2 statt −12-\frac12−21​ einsetzen.
  • Nicht rücksubstituieren.
