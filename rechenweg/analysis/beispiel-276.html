Angabe Originalseite

Man berechne:

∫0π/2cos⁡2x dx\int_0^{\pi/2}\cos^2 x\,\mathrm dx∫0π/2​cos2xdx

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

cos⁡2x\cos^2 xcos2x hat keine „direkte“ Grundstammfunktion. Mit der Halbwinkelformel cos⁡2x=1+cos⁡2x2\cos^2 x = \frac{1 + \cos 2x}{2}cos2x=21+cos2x​ wird daraus eine Summe aus Konstante und Kosinus, die sofort integrierbar ist. Als Kontrolle zeigen wir zusätzlich einen eleganten Symmetrie-Weg ohne Stammfunktion.

Weg 1: Halbwinkelformel

Aus dem Additionstheorem cos⁡2x=cos⁡2x−sin⁡2x\cos 2x = \cos^2 x - \sin^2 xcos2x=cos2x−sin2x und sin⁡2x=1−cos⁡2x\sin^2 x = 1 - \cos^2 xsin2x=1−cos2x folgt cos⁡2x=2cos⁡2x−1\cos 2x = 2\cos^2 x - 1cos2x=2cos2x−1, also

cos⁡2x=1+cos⁡2x2.\cos^2 x = \frac{1 + \cos 2x}{2} .cos2x=21+cos2x​.

Eine Stammfunktion ist damit (wegen (sin⁡2x)′=2cos⁡2x(\sin 2x)' = 2\cos 2x(sin2x)′=2cos2x)

∫cos⁡2x dx=x2+sin⁡2x4+C.\int\cos^2 x\,\mathrm dx = \frac x2 + \frac{\sin 2x}{4} + C .∫cos2xdx=2x​+4sin2x​+C.

∫0π/2cos⁡2x dx=[x2+sin⁡2x4]0π/2(Hauptsatz)=(π4+sin⁡π4)−(0+sin⁡04)(Grenzen einsetzen)=π4.(sin⁡π=sin⁡0=0)\begin{aligned} \int_0^{\pi/2}\cos^2 x\,\mathrm dx &= \Bigl[\frac x2 + \frac{\sin 2x}{4}\Bigr]_0^{\pi/2} && \text{(Hauptsatz)}\\ &= \Bigl(\frac\pi4 + \frac{\sin\pi}{4}\Bigr) - \Bigl(0 + \frac{\sin 0}{4}\Bigr) && \text{(Grenzen einsetzen)}\\ &= \frac\pi4 . && \text{(}\sin\pi = \sin 0 = 0\text{)} \end{aligned}∫0π/2​cos2xdx​=[2x​+4sin2x​]0π/2​=(4π​+4sinπ​)−(0+4sin0​)=4π​.​​(Hauptsatz)(Grenzen einsetzen)(sinπ=sin0=0)​

Weg 2: Symmetrie (ohne Stammfunktion)

Mit der Substitution x=π2−tx = \frac\pi2 - tx=2π​−t (dx=−dt\mathrm dx = -\mathrm dtdx=−dt, Grenzen 0↦π20 \mapsto \frac\pi20↦2π​, π2↦0\frac\pi2 \mapsto 02π​↦0) und cos⁡(π2−t)=sin⁡t\cos(\frac\pi2 - t) = \sin tcos(2π​−t)=sint erhält man

∫0π/2cos⁡2x dx=∫π/20sin⁡2t (−dt)=∫0π/2sin⁡2t dt.\int_0^{\pi/2}\cos^2 x\,\mathrm dx = \int_{\pi/2}^{0}\sin^2 t\,(-\mathrm dt) = \int_0^{\pi/2}\sin^2 t\,\mathrm dt .∫0π/2​cos2xdx=∫π/20​sin2t(−dt)=∫0π/2​sin2tdt.

Beide Integrale sind also gleich, nennen wir den Wert AAA. Addieren:

2A=∫0π/2(cos⁡2x+sin⁡2x)dx=∫0π/21 dx=π2⟹A=π4.2A = \int_0^{\pi/2}\bigl(\cos^2 x + \sin^2 x\bigr)\mathrm dx = \int_0^{\pi/2} 1\,\mathrm dx = \frac\pi2 \quad\Longrightarrow\quad A = \frac\pi4 .2A=∫0π/2​(cos2x+sin2x)dx=∫0π/2​1dx=2π​⟹A=4π​.

Ergebnis

∫0π/2cos⁡2x dx=π4≈0,7854.\int_0^{\pi/2}\cos^2 x\,\mathrm dx = \frac{\pi}{4} \approx 0{,}7854 .∫0π/2​cos2xdx=4π​≈0,7854.

Probe
  • Ableitung: (x2+sin⁡2x4)′=12+cos⁡2x2=cos⁡2x\bigl(\frac x2 + \frac{\sin 2x}{4}\bigr)' = \frac12 + \frac{\cos 2x}{2} = \cos^2 x(2x​+4sin2x​)′=21​+2cos2x​=cos2x ✓.
  • Plausibilität: Der Mittelwert von cos⁡2\cos^2cos2 über [0,π2][0,\frac\pi2][0,2π​] ist π/4π/2=12\frac{\pi/4}{\pi/2} = \frac12π/2π/4​=21​ – passend zur Abbildung, in der cos⁡2\cos^2cos2 symmetrisch um die Linie y=12y = \frac12y=21​ verläuft ✓.
  • Numerisch (mpmath): 0,7853981633970{,}7853981633970,785398163397 ✓.

Hilfreiches

Halbwinkelformeln

cos⁡2x=1+cos⁡2x2,sin⁡2x=1−cos⁡2x2.\cos^2 x = \frac{1 + \cos 2x}{2}, \qquad \sin^2 x = \frac{1 - \cos 2x}{2} .cos2x=21+cos2x​,sin2x=21−cos2x​.

Mittelwert von sin² und cos²

Über jedes Intervall, dessen Länge ein Vielfaches von π2\frac\pi22π​ ist und das bei einem Vielfachen von π2\frac\pi22π​ beginnt, haben sin⁡2\sin^2sin2 und cos⁡2\cos^2cos2 den Mittelwert 12\frac1221​. Also z. B. ∫0πcos⁡2x dx=π2\int_0^{\pi}\cos^2 x\,\mathrm dx = \frac\pi2∫0π​cos2xdx=2π​, ∫02πsin⁡2x dx=π\int_0^{2\pi}\sin^2 x\,\mathrm dx = \pi∫02π​sin2xdx=π.

Typische Fehler
  • ∫cos⁡2x dx=cos⁡3x3\int\cos^2 x\,\mathrm dx = \frac{\cos^3 x}{3}∫cos2xdx=3cos3x​ oder sin⁡2x\sin^2 xsin2x – beides ergibt abgeleitet nicht cos⁡2x\cos^2 xcos2x.
  • Beim Integrieren von cos⁡2x\cos 2xcos2x den Faktor 12\frac1221​ vergessen: ∫cos⁡2x dx=sin⁡2x2\int\cos 2x\,\mathrm dx = \frac{\sin 2x}{2}∫cos2xdx=2sin2x​.
