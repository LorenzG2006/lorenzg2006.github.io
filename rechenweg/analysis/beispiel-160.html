Angabe Originalseite

Überblick

fff ist eine rationale Funktion mit Polstelle (bzw. Definitionslücke) bei x=tx = tx=t. Damit fff überhaupt in einer Umgebung von 111 definiert ist, muss t≠1t \ne 1t=1 sein. Dann ist fff nahe 111 differenzierbar, und das Vorzeichen von f′f'f′ entscheidet über die Monotonie: Ist f′(1)<0f'(1) < 0f′(1)<0, so ist wegen der Stetigkeit von f′f'f′ auch f′<0f' < 0f′<0 in einer ganzen Umgebung – fff fällt dort streng. Ist f′(1)>0f'(1) > 0f′(1)>0, steigt fff nahe 111. Den Grenzfall f′(1)=0f'(1) = 0f′(1)=0 untersuchen wir gesondert.

Schritt 1: Definitionsbereich

fff ist für x≠tx \ne tx=t definiert. Für t=1t = 1t=1 liegt die Lücke genau bei x0=1x_0 = 1x0​=1; dann gibt es keine Umgebung von 111, auf der fff definiert ist. Also t≠1t \ne 1t=1. Umgekehrt: Ist t≠1t \ne 1t=1, so ist fff mit δ=∣1−t∣>0\delta = |1 - t| > 0δ=∣1−t∣>0 auf der Umgebung (1−δ,1+δ)(1 - \delta, 1 + \delta)(1−δ,1+δ) definiert (die Lücke x=tx = tx=t liegt außerhalb) und dort als Quotient von Polynomen differenzierbar.

Hilfreiches

Monotoniekriterium

Ist fff auf einem Intervall III differenzierbar und f′(x)<0f'(x) < 0f′(x)<0 für alle x∈Ix \in Ix∈I, so ist fff auf III streng monoton fallend.

Lokal fallend

Ist f′f'f′ stetig und f′(x0)<0f'(x_0) < 0f′(x0​)<0, dann gibt es eine Umgebung von x0x_0x0​, in der fff streng fällt. Bei f′(x0)=0f'(x_0) = 0f′(x0​)=0 ist alles möglich (fallend wie −x3-x^3−x3, Extremum wie x2x^2x2) – genauer hinschauen!

Typische Fehler
  • t=1t = 1t=1 nicht ausschließen (Polstelle genau bei x0x_0x0​).
  • Den Grenzfall t=13t = \frac13t=31​ zur Lösung zählen, weil „f′(1)≤0f'(1) \le 0f′(1)≤0“. Bei f′(1)=0f'(1) = 0f′(1)=0 entscheidet das Vorzeichenverhalten von f′f'f′ um 111 herum – hier liegt ein Minimum vor.
  • Vorzeichenfehler bei der Quotientenregel: Der Zähler ist 2x(x−t)−(x2+t)2x(x - t) - (x^2 + t)2x(x−t)−(x2+t), nicht (x2+t)−2x(x−t)(x^2 + t) - 2x(x - t)(x2+t)−2x(x−t).
