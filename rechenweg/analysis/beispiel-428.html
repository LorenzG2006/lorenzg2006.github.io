Hilfreiches

Bernoullische Differentialgleichung

y′+a(x)y=b(x)yny' + a(x)y = b(x)y^ny′+a(x)y=b(x)yn (n≠0,1n \ne 0, 1n=0,1). Mit z=y1−nz = y^{1-n}z=y1−n wird daraus die lineare DGL z′+(1−n)a(x)z=(1−n)b(x).z' + (1-n)a(x)z = (1-n)b(x).z′+(1−n)a(x)z=(1−n)b(x).

Lösungsformel linear

z′+p(x)z=q(x)z' + p(x)z = q(x)z′+p(x)z=q(x):  z=e−P(∫q ePdx+C)\ z = e^{-P}\bigl(\int q\,e^{P}dx + C\bigr) z=e−P(∫qePdx+C), P′=pP' = pP′=p.

Typische Fehler
  • Den Faktor (1−n)=−2(1-n) = -2(1−n)=−2 in der transformierten Gleichung vergessen.
  • Die Lösung y≡0y \equiv 0y≡0 verlieren (für sie ist z=y−2z = y^{-2}z=y−2 nicht definiert).
  • Das ±\pm± beim Wurzelziehen weglassen.
