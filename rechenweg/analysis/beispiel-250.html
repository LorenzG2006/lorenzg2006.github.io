Überblick

Zählergrad 333 ≥\ge≥ Nennergrad 222: Zuerst Polynomdivision, damit ein Polynom plus ein echt gebrochener Rest entsteht. Den Rest zerlegen wir in Partialbrüche – der Nenner x2+5x+6=(x+2)(x+3)x^2 + 5x + 6 = (x + 2)(x + 3)x2+5x+6=(x+2)(x+3) hat zwei einfache reelle Nullstellen.

Schritt 1: Polynomdivision

(x3+x2+0x+7):(x2+5x+6)=x−4Rest 14x+31,\begin{aligned} (x^3 + x^2 + 0x + 7) : (x^2 + 5x + 6) &= x - 4 \quad\text{Rest } 14x + 31, \end{aligned}(x3+x2+0x+7):(x2+5x+6)​=x−4Rest 14x+31,​

denn:

  • x⋅(x2+5x+6)=x3+5x2+6xx\cdot(x^2 + 5x + 6) = x^3 + 5x^2 + 6xx⋅(x2+5x+6)=x3+5x2+6x; Subtraktion: x3+x2+7−(x3+5x2+6x)=−4x2−6x+7x^3 + x^2 + 7 - (x^3 + 5x^2 + 6x) = -4x^2 - 6x + 7x3+x2+7−(x3+5x2+6x)=−4x2−6x+7,
  • −4⋅(x2+5x+6)=−4x2−20x−24-4\cdot(x^2 + 5x + 6) = -4x^2 - 20x - 24−4⋅(x2+5x+6)=−4x2−20x−24; Subtraktion: −4x2−6x+7−(−4x2−20x−24)=14x+31-4x^2 - 6x + 7 - (-4x^2 - 20x - 24) = 14x + 31−4x2−6x+7−(−4x2−20x−24)=14x+31.

Hilfreiches

Polynomdivision zuerst

Die Partialbruchzerlegung funktioniert nur für echt gebrochene rationale Funktionen (Zählergrad < Nennergrad). Sonst liefert der Ansatz falsche Ergebnisse.

Grundintegral

∫dxx−a=ln⁡∣x−a∣+C(x≠a).\int\frac{\mathrm dx}{x - a} = \ln\vert x - a\vert + C \qquad (x \ne a).∫x−adx​=ln∣x−a∣+C(x=a).

Typische Fehler
  • Polynomdivision überspringen und direkt Ax+2+Bx+3\frac{A}{x+2} + \frac{B}{x+3}x+2A​+x+3B​ ansetzen.
  • Vorzeichenfehler beim Subtrahieren in der Division (−6x−(−20x)=+14x-6x - (-20x) = +14x−6x−(−20x)=+14x).
  • Betragsstriche im Logarithmus weglassen.
