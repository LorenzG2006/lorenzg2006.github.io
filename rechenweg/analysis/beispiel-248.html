Man berechne:

∫4x3+x2+3x+5(x−1)2(x2+2x+3) dx\int\frac{4x^3 + x^2 + 3x + 5}{(x - 1)^2(x^2 + 2x + 3)}\,\mathrm dx∫(x−1)2(x2+2x+3)4x3+x2+3x+5​dx

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Rationale Funktion: Zählergrad 333 < Nennergrad 444, also ist keine Polynomdivision nötig. Der Nenner ist schon faktorisiert: doppelte reelle Nullstelle x=1x = 1x=1 und der quadratische Faktor x2+2x+3x^2 + 2x + 3x2+2x+3 mit Diskriminante 4−12=−8<04 - 12 = -8 < 04−12=−8<0 (keine reellen Nullstellen). Wir machen eine Partialbruchzerlegung und integrieren die Teilbrüche einzeln (Logarithmus, Potenz, Logarithmus + Arcustangens).

Schritt 1: Ansatz der Partialbruchzerlegung

4x3+x2+3x+5(x−1)2(x2+2x+3)=Ax−1+B(x−1)2+Cx+Dx2+2x+3.\frac{4x^3 + x^2 + 3x + 5}{(x - 1)^2(x^2 + 2x + 3)} = \frac{A}{x - 1} + \frac{B}{(x - 1)^2} + \frac{Cx + D}{x^2 + 2x + 3} .(x−1)2(x2+2x+3)4x3+x2+3x+5​=x−1A​+(x−1)2B​+x2+2x+3Cx+D​.

Multiplikation mit dem Nenner:

4x3+x2+3x+5=A(x−1)(x2+2x+3)+B(x2+2x+3)+(Cx+D)(x−1)2.4x^3 + x^2 + 3x + 5 = A(x - 1)(x^2 + 2x + 3) + B(x^2 + 2x + 3) + (Cx + D)(x - 1)^2 .4x3+x2+3x+5=A(x−1)(x2+2x+3)+B(x2+2x+3)+(Cx+D)(x−1)2.

Schritt 2: Koeffizienten bestimmen

x=1x = 1x=1 einsetzen (die Terme mit AAA und C,DC, DC,D fallen weg):

4+1+3+5=B (1+2+3)⟹13=6B⟹B=136.4 + 1 + 3 + 5 = B\,(1 + 2 + 3) \quad\Longrightarrow\quad 13 = 6B \quad\Longrightarrow\quad B = \frac{13}{6} .4+1+3+5=B(1+2+3)⟹13=6B⟹B=613​.

Ausmultiplizieren für den Koeffizientenvergleich: (x−1)(x2+2x+3)=x3+x2+x−3(x - 1)(x^2 + 2x + 3) = x^3 + x^2 + x - 3(x−1)(x2+2x+3)=x3+x2+x−3 und (x−1)2=x2−2x+1(x - 1)^2 = x^2 - 2x + 1(x−1)2=x2−2x+1, also

A(x3+x2+x−3)+B(x2+2x+3)+(Cx+D)(x2−2x+1)=(A+C) x3+(A+B−2C+D) x2+(A+2B+C−2D) x+(−3A+3B+D).\begin{aligned} A(x^3 + x^2 + x - 3) + B(x^2 + 2x + 3) + (Cx + D)(x^2 - 2x + 1) &= (A + C)\,x^3 + (A + B - 2C + D)\,x^2\\ &\quad + (A + 2B + C - 2D)\,x + (-3A + 3B + D) . \end{aligned}A(x3+x2+x−3)+B(x2+2x+3)+(Cx+D)(x2−2x+1)​=(A+C)x3+(A+B−2C+D)x2+(A+2B+C−2D)x+(−3A+3B+D).​

Vergleich mit 4x3+x2+3x+54x^3 + x^2 + 3x + 54x3+x2+3x+5:

x3:A+C=4x2:A+B−2C+D=1x1:A+2B+C−2D=3x0:−3A+3B+D=5\begin{aligned} x^3:&\quad A + C = 4\\ x^2:&\quad A + B - 2C + D = 1\\ x^1:&\quad A + 2B + C - 2D = 3\\ x^0:&\quad -3A + 3B + D = 5 \end{aligned}x3:x2:x1:x0:​A+C=4A+B−2C+D=1A+2B+C−2D=3−3A+3B+D=5​

Schritt 4: Der quadratische Teilbruch

Die Ableitung des Nenners ist 2x+22x + 22x+2. Wir zerlegen den Zähler so, dass sie auftaucht:

47x+48=472(2x+2)−47+48=472(2x+2)+1.47x + 48 = \frac{47}{2}(2x + 2) - 47 + 48 = \frac{47}{2}(2x + 2) + 1 .47x+48=247​(2x+2)−47+48=247​(2x+2)+1.

Hilfreiches

Partialbruchzerlegung
  1. Zählergrad ≥\ge≥ Nennergrad? Dann zuerst Polynomdivision.
  2. Nenner in reelle Linearfaktoren und irreduzible quadratische Faktoren zerlegen.
  3. Ansatz: zu (x−a)k(x - a)^k(x−a)k gehören A1x−a+⋯+Ak(x−a)k\frac{A_1}{x - a} + \dots + \frac{A_k}{(x - a)^k}x−aA1​​+⋯+(x−a)kAk​​, zu (x2+px+q)(x^2 + px + q)(x2+px+q) gehört Bx+Cx2+px+q\frac{Bx + C}{x^2 + px + q}x2+px+qBx+C​.
  4. Koeffizienten durch Einsetzen von Nullstellen und Koeffizientenvergleich.

∫f′(x)f(x) dx=ln⁡∣f(x)∣+C,∫dyy2+a2=1aarctan⁡ya+C(a>0).\int\frac{f'(x)}{f(x)}\,\mathrm dx = \ln\vert f(x)\vert + C, \qquad \int\frac{\mathrm dy}{y^2 + a^2} = \frac1a\arctan\frac ya + C \quad (a > 0).∫f(x)f′(x)​dx=ln∣f(x)∣+C,∫y2+a2dy​=a1​arctanay​+C(a>0).
