Angabe Originalseite

Man zeige, dass die Ungleichung ∣d(x,y)−d(y,z)∣≤d(x,z)\vert d(x,y) - d(y,z)\vert \le d(x,z)∣d(x,y)−d(y,z)∣≤d(x,z) in jedem metrischen Raum (X,d)(X,d)(X,d) für alle x,y,z∈Xx, y, z \in Xx,y,z∈X gilt.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Eine Ungleichung ∣a∣≤c\vert a\vert \le c∣a∣≤c ist gleichwertig mit den zwei Ungleichungen a≤ca \le ca≤c und −a≤c-a \le c−a≤c. Beide folgen jeweils aus einer passend angesetzten Dreiecksungleichung, zusammen mit der Symmetrie der Metrik. Mehr als die drei Metrik-Axiome brauchen wir nicht.

Schritt 0: Was dürfen wir verwenden?

(X,d)(X,d)(X,d) ist ein metrischer Raum, d. h. für alle x,y,z∈Xx, y, z \in Xx,y,z∈X gilt:

  1. d(x,y)≥0d(x,y) \ge 0d(x,y)≥0 und d(x,y)=0  ⟺  x=yd(x,y) = 0 \iff x = yd(x,y)=0⟺x=y,
  2. d(x,y)=d(y,x)d(x,y) = d(y,x)d(x,y)=d(y,x) (Symmetrie),
  3. d(x,z)≤d(x,y)+d(y,z)d(x,z) \le d(x,y) + d(y,z)d(x,z)≤d(x,y)+d(y,z) (Dreiecksungleichung).

Seien nun x,y,z∈Xx, y, z \in Xx,y,z∈X beliebig. Wir setzen a:=d(x,y)−d(y,z)a := d(x,y) - d(y,z)a:=d(x,y)−d(y,z) und c:=d(x,z)c := d(x,z)c:=d(x,z). Wegen

∣a∣≤c  ⟺  −c≤a≤c  ⟺  (a≤c und −a≤c)\vert a\vert \le c \iff -c \le a \le c \iff \bigl(a \le c \ \text{und}\ -a \le c\bigr)∣a∣≤c⟺−c≤a≤c⟺(a≤c und −a≤c)

zeigen wir die beiden Ungleichungen einzeln.

Schritt 1: d(x,y) − d(y,z) ≤ d(x,z)

Dreiecksungleichung für den Weg von xxx nach yyy über den Zwischenpunkt zzz:

d(x,y)≤d(x,z)+d(z,y)(Axiom 3 mit Zwischenpunkt z)=d(x,z)+d(y,z).(Symmetrie: d(z,y)=d(y,z))\begin{aligned} d(x,y) &\le d(x,z) + d(z,y) && \text{(Axiom 3 mit Zwischenpunkt } z\text{)}\\ &= d(x,z) + d(y,z) . && \text{(Symmetrie: } d(z,y) = d(y,z)\text{)} \end{aligned}d(x,y)​≤d(x,z)+d(z,y)=d(x,z)+d(y,z).​​(Axiom 3 mit Zwischenpunkt z)(Symmetrie: d(z,y)=d(y,z))​

Subtrahieren von d(y,z)d(y,z)d(y,z) auf beiden Seiten (eine reelle Zahl, das erhält die Ungleichung) liefert

d(x,y)−d(y,z)≤d(x,z).d(x,y) - d(y,z) \le d(x,z) .d(x,y)−d(y,z)≤d(x,z).

Schritt 2: d(y,z) − d(x,y) ≤ d(x,z)

Dreiecksungleichung für den Weg von yyy nach zzz über den Zwischenpunkt xxx:

d(y,z)≤d(y,x)+d(x,z)(Axiom 3 mit Zwischenpunkt x)=d(x,y)+d(x,z).(Symmetrie)\begin{aligned} d(y,z) &\le d(y,x) + d(x,z) && \text{(Axiom 3 mit Zwischenpunkt } x\text{)}\\ &= d(x,y) + d(x,z) . && \text{(Symmetrie)} \end{aligned}d(y,z)​≤d(y,x)+d(x,z)=d(x,y)+d(x,z).​​(Axiom 3 mit Zwischenpunkt x)(Symmetrie)​

Subtrahieren von d(x,y)d(x,y)d(x,y):

d(y,z)−d(x,y)≤d(x,z),d. h.−(d(x,y)−d(y,z))≤d(x,z).d(y,z) - d(x,y) \le d(x,z), \qquad\text{d. h.}\qquad -\bigl(d(x,y) - d(y,z)\bigr) \le d(x,z) .d(y,z)−d(x,y)≤d(x,z),d. h.−(d(x,y)−d(y,z))≤d(x,z).

Schritt 3: Zusammenfassen

Aus Schritt 1 und 2 folgt −d(x,z)≤d(x,y)−d(y,z)≤d(x,z)-d(x,z) \le d(x,y) - d(y,z) \le d(x,z)−d(x,z)≤d(x,y)−d(y,z)≤d(x,z), also

∣d(x,y)−d(y,z)∣≤d(x,z).\bigl\vert d(x,y) - d(y,z)\bigr\vert \le d(x,z) .​d(x,y)−d(y,z)​≤d(x,z).

Da x,y,zx, y, zx,y,z beliebig waren, gilt dies für alle x,y,z∈Xx, y, z \in Xx,y,z∈X. ■\blacksquare■

Ergebnis

In jedem metrischen Raum (X,d)(X,d)(X,d) gilt für alle x,y,z∈Xx, y, z \in Xx,y,z∈X ∣d(x,y)−d(y,z)∣≤d(x,z).\bigl\vert d(x,y) - d(y,z)\bigr\vert \le d(x,z) .​d(x,y)−d(y,z)​≤d(x,z). Beweis: Je eine Dreiecksungleichung mit Zwischenpunkt zzz bzw. xxx liefert die Abschätzung nach oben bzw. nach unten.

Beispiel in (ℝ, |·|)

Mit d(x,y)=∣x−y∣d(x,y) = \vert x - y\vertd(x,y)=∣x−y∣ und x=0x = 0x=0, y=5y = 5y=5, z=3z = 3z=3: ∣d(0,5)−d(5,3)∣=∣5−2∣=3≤d(0,3)=3\vert d(0,5) - d(5,3)\vert = \vert 5 - 2\vert = 3 \le d(0,3) = 3∣d(0,5)−d(5,3)∣=∣5−2∣=3≤d(0,3)=3 ✓ (Gleichheit, weil zzz zwischen xxx und yyy liegt). Mit z=−1z = -1z=−1: ∣5−6∣=1≤d(0,−1)=1\vert 5 - 6\vert = 1 \le d(0,-1) = 1∣5−6∣=1≤d(0,−1)=1 ✓.

Anschauung

Die Aussage sagt: „Eine Dreiecksseite ist mindestens so lang wie die Differenz der beiden anderen.“ Zusammen mit der gewöhnlichen Dreiecksungleichung gilt also ∣d(x,y)−d(y,z)∣≤d(x,z)≤d(x,y)+d(y,z)\vert d(x,y) - d(y,z)\vert \le d(x,z) \le d(x,y) + d(y,z)∣d(x,y)−d(y,z)∣≤d(x,z)≤d(x,y)+d(y,z). Eine Folgerung: Für festes yyy ist die Abbildung x↦d(x,y)x \mapsto d(x,y)x↦d(x,y) Lipschitz-stetig mit Konstante 111.

Hilfreiches

Metrik

Eine Abbildung d:X×X→Rd : X \times X \to \Rd:X×X→R heißt Metrik auf XXX, wenn für alle x,y,z∈Xx, y, z \in Xx,y,z∈X gilt: d(x,y)≥0d(x,y) \ge 0d(x,y)≥0, d(x,y)=0  ⟺  x=yd(x,y) = 0 \iff x = yd(x,y)=0⟺x=y; d(x,y)=d(y,x)d(x,y) = d(y,x)d(x,y)=d(y,x); d(x,z)≤d(x,y)+d(y,z)d(x,z) \le d(x,y) + d(y,z)d(x,z)≤d(x,y)+d(y,z).

Betragsungleichungen

∣a∣≤c  ⟺  a≤c  und  −a≤c.\vert a\vert \le c \iff a \le c \ \text{ und } \ -a \le c .∣a∣≤c⟺a≤c  und  −a≤c.

Typische Fehler
  • Nur eine der beiden Richtungen zeigen – der Betrag verlangt beide.
  • Die Symmetrie stillschweigend verwenden, ohne sie zu erwähnen (in Schritt 1 wird aus d(z,y)d(z,y)d(z,y) erst durch Symmetrie d(y,z)d(y,z)d(y,z)).
  • Eigenschaften des Betrags in R\RR (z. B. ∣x−y∣\vert x - y\vert∣x−y∣) benutzen – in einem allgemeinen metrischen Raum gibt es keine Subtraktion von Punkten.
