Angabe Originalseite

Man berechne:

∫1+7x2 dx\int\sqrt{1 + 7x^2}\,\mathrm dx∫1+7x2​dx

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Wurzeln der Form 1+c2x2\sqrt{1 + c^2x^2}1+c2x2​ beseitigt man mit der hyperbolischen Substitution cx=sinh⁡tcx = \sinh tcx=sinht, weil 1+sinh⁡2t=cosh⁡2t1 + \sinh^2 t = \cosh^2 t1+sinh2t=cosh2t. Danach ist ∫cosh⁡2t dt\int\cosh^2 t\,\mathrm dt∫cosh2tdt zu berechnen – mit der Formel cosh⁡2t=1+cosh⁡2t2\cosh^2 t = \frac{1 + \cosh 2t}{2}cosh2t=21+cosh2t​.

Der Integrand ist auf ganz R\RR stetig.

Schritt 1: Substitution √7 x = sinh t

x=sinh⁡t7,dx=cosh⁡t7 dt,t=arsinh⁡(7 x).x = \frac{\sinh t}{\sqrt7}, \qquad \mathrm dx = \frac{\cosh t}{\sqrt7}\,\mathrm dt, \qquad t = \operatorname{arsinh}(\sqrt7\,x) .x=7​sinht​,dx=7​cosht​dt,t=arsinh(7​x).

Da cosh⁡t>0\cosh t > 0cosht>0:

1+7x2=1+sinh⁡2t=cosh⁡2t=cosh⁡t.\sqrt{1 + 7x^2} = \sqrt{1 + \sinh^2 t} = \sqrt{\cosh^2 t} = \cosh t .1+7x2​=1+sinh2t​=cosh2t​=cosht.

∫1+7x2 dx=∫cosh⁡t⋅cosh⁡t7 dt=17∫cosh⁡2t dt.\int\sqrt{1 + 7x^2}\,\mathrm dx = \int\cosh t\cdot\frac{\cosh t}{\sqrt7}\,\mathrm dt = \frac{1}{\sqrt7}\int\cosh^2 t\,\mathrm dt .∫1+7x2​dx=∫cosht⋅7​cosht​dt=7​1​∫cosh2tdt.

Schritt 2: ∫ cosh² t dt

∫cosh⁡2t dt=∫1+cosh⁡(2t)2 dt(cosh⁡2t=1+cosh⁡2t2)=t2+sinh⁡(2t)4=t2+sinh⁡tcosh⁡t2.(sinh⁡2t=2sinh⁡tcosh⁡t)\begin{aligned} \int\cosh^2 t\,\mathrm dt &= \int\frac{1 + \cosh(2t)}{2}\,\mathrm dt && \text{(}\cosh^2 t = \tfrac{1 + \cosh 2t}{2}\text{)}\\ &= \frac t2 + \frac{\sinh(2t)}{4} = \frac t2 + \frac{\sinh t\cosh t}{2} . && \text{(}\sinh 2t = 2\sinh t\cosh t\text{)} \end{aligned}∫cosh2tdt​=∫21+cosh(2t)​dt=2t​+4sinh(2t)​=2t​+2sinhtcosht​.​​(cosh2t=21+cosh2t​)(sinh2t=2sinhtcosht)​

Mit sinh⁡t=7 x\sinh t = \sqrt7\,xsinht=7​x, cosh⁡t=1+7x2\cosh t = \sqrt{1 + 7x^2}cosht=1+7x2​, t=arsinh⁡(7 x)t = \operatorname{arsinh}(\sqrt7\,x)t=arsinh(7​x):

∫1+7x2 dx=17(arsinh⁡(7 x)2+7 x1+7x22)+C=x21+7x2+127arsinh⁡(7 x)+C.\begin{aligned} \int\sqrt{1 + 7x^2}\,\mathrm dx &= \frac{1}{\sqrt7}\Bigl(\frac{\operatorname{arsinh}(\sqrt7\,x)}{2} + \frac{\sqrt7\,x\sqrt{1 + 7x^2}}{2}\Bigr) + C\\ &= \frac x2\sqrt{1 + 7x^2} + \frac{1}{2\sqrt7}\operatorname{arsinh}(\sqrt7\,x) + C . \end{aligned}∫1+7x2​dx​=7​1​(2arsinh(7​x)​+27​x1+7x2​​)+C=2x​1+7x2​+27​1​arsinh(7​x)+C.​

Wegen arsinh⁡y=ln⁡(y+1+y2)\operatorname{arsinh} y = \ln\bigl(y + \sqrt{1 + y^2}\bigr)arsinhy=ln(y+1+y2​) lässt sich das auch schreiben als

x21+7x2+127ln⁡(7 x+1+7x2)+C.\frac x2\sqrt{1 + 7x^2} + \frac{1}{2\sqrt7}\ln\bigl(\sqrt7\,x + \sqrt{1 + 7x^2}\bigr) + C .2x​1+7x2​+27​1​ln(7​x+1+7x2​)+C.

Ergebnis

∫1+7x2 dx=x21+7x2+127ln⁡(7 x+1+7x2)+C.\int\sqrt{1 + 7x^2}\,\mathrm dx = \frac x2\sqrt{1 + 7x^2} + \frac{1}{2\sqrt7}\ln\bigl(\sqrt7\,x + \sqrt{1 + 7x^2}\bigr) + C .∫1+7x2​dx=2x​1+7x2​+27​1​ln(7​x+1+7x2​)+C.
