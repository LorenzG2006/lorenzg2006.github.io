Angabe Originalseite

421–430) Lösen Sie die folgenden Differentialgleichungen:

xy′−y=x3+3x2−2xxy' - y = x^3 + 3x^2 - 2xxy′−y=x3+3x2−2x

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Lineare DGL 1. Ordnung. Die linke Seite xy′−yxy' - yxy′−y ist (bis auf den Faktor x2x^2x2) die Ableitung des Quotienten yx\frac{y}{x}xy​: (yx)′=xy′−yx2\bigl(\frac{y}{x}\bigr)' = \frac{xy' - y}{x^2}(xy​)′=x2xy′−y​. Division durch x2x^2x2 macht die Gleichung also direkt integrierbar – das ist genau der integrierende Faktor. Wir arbeiten auf x>0x > 0x>0 bzw. x<0x < 0x<0.

Schritt 1: Normalform und integrierender Faktor

Normalform (x≠0x \ne 0x=0): y′−1xy=x2+3x−2y' - \frac1x y = x^2 + 3x - 2y′−x1​y=x2+3x−2, also a(x)=−1xa(x) = -\frac1xa(x)=−x1​, A(x)=−ln⁡∣x∣A(x) = -\ln|x|A(x)=−ln∣x∣, eA=1∣x∣e^{A} = \frac{1}{|x|}eA=∣x∣1​. Auf einem festen Intervall genügt (bis aufs Vorzeichen) der Faktor 1x\frac1xx1​:

y′x−yx2=(yx)′=x2+3x−2x=x+3−2x.\frac{y'}{x} - \frac{y}{x^2} = \Bigl(\frac{y}{x}\Bigr)' = \frac{x^2 + 3x - 2}{x} = x + 3 - \frac2x.xy′​−x2y​=(xy​)′=xx2+3x−2​=x+3−x2​.

Schritt 2: Integrieren

yx=∫(x+3−2x)dx=x22+3x−2ln⁡∣x∣+Cy=x32+3x2−2xln⁡∣x∣+Cx.(mit x multiplizieren)\begin{aligned} \frac{y}{x} &= \int \Bigl(x + 3 - \frac2x\Bigr)dx = \frac{x^2}{2} + 3x - 2\ln|x| + C &&\\ y &= \frac{x^3}{2} + 3x^2 - 2x\ln|x| + Cx. && (\text{mit } x \text{ multiplizieren}) \end{aligned}xy​y​=∫(x+3−x2​)dx=2x2​+3x−2ln∣x∣+C=2x3​+3x2−2xln∣x∣+Cx.​​(mit x multiplizieren)​

Schritt 3: Struktur

  • Homogene Lösung: yh=Cxy_h = Cxyh​=Cx (aus xy′=yxy' = yxy′=y).
  • Partikuläre Lösung: yp=x32+3x2−2xln⁡∣x∣y_p = \frac{x^3}{2} + 3x^2 - 2x\ln|x|yp​=2x3​+3x2−2xln∣x∣.

Der Term −2xln⁡∣x∣-2x\ln|x|−2xln∣x∣ entsteht, weil der Summand −2x-2x−2x der rechten Seite selbst eine Lösung der homogenen Gleichung ist („Resonanz“) – ein polynomialer Ansatz würde hier scheitern.

Ergebnis

y(x)=x32+3x2−2xln⁡∣x∣+Cx,C∈R,y(x) = \frac{x^3}{2} + 3x^2 - 2x\ln|x| + Cx, \qquad C \in \R,y(x)=2x3​+3x2−2xln∣x∣+Cx,C∈R, auf x>0x > 0x>0 bzw. x<0x < 0x<0.

y′+a(x)y=b(x)y' + a(x)y = b(x)y′+a(x)y=b(x):  y=e−A(∫b eAdx+C)\ y = e^{-A}\bigl(\int b\,e^{A}dx + C\bigr) y=e−A(∫beAdx+C), A′=aA' = aA′=a.
