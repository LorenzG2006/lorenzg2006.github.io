Überblick

Behauptung: Auf jedem Intervall, das 000 nicht enthält, ist F(t)=ln⁡∣t∣F(t) = \ln|t|F(t)=ln∣t∣ eine Stammfunktion von 1t\frac1tt1​.

  • Für t>0t > 0t>0 ist ln⁡∣t∣=ln⁡t\ln|t| = \ln tln∣t∣=lnt und (ln⁡t)′=1t(\ln t)' = \frac1t(lnt)′=t1​.
  • Für t<0t < 0t<0 ist ln⁡∣t∣=ln⁡(−t)\ln|t| = \ln(-t)ln∣t∣=ln(−t); mit der Kettenregel (ln⁡(−t))′=1−t⋅(−1)=1t(\ln(-t))' = \frac{1}{-t}\cdot(-1) = \frac1t(ln(−t))′=−t1​⋅(−1)=t1​.

Teil 2: Beweis der Regel mit der Substitutionsregel

Teil 3: ∫dxxln⁡x\int\frac{\mathrm dx}{x\ln x}∫xlnxdx​

Hilfreiches

Substitutionsregel

Ist uuu stetig differenzierbar und F′=fF' = fF′=f (stetig), so gilt ∫f(u(x)) u′(x) dx=F(u(x))+C,∫abf(u(x)) u′(x) dx=∫u(a)u(b)f(t) dt.\int f(u(x))\,u'(x)\,dx = F(u(x)) + C, \qquad \int_a^b f(u(x))\,u'(x)\,dx = \int_{u(a)}^{u(b)} f(t)\,dt .∫f(u(x))u′(x)dx=F(u(x))+C,∫ab​f(u(x))u′(x)dx=∫u(a)u(b)​f(t)dt.

Logarithmische Integration

Steht im Zähler (bis auf einen konstanten Faktor) die Ableitung des Nenners, so ist das Integral ein Logarithmus: ∫u′u=ln⁡∣u∣+C\int\frac{u'}{u} = \ln|u| + C∫uu′​=ln∣u∣+C. Beispiele: ∫2xx2+1 dx=ln⁡(x2+1)+C\int\frac{2x}{x^2 + 1}\,dx = \ln(x^2 + 1) + C∫x2+12x​dx=ln(x2+1)+C, ∫tan⁡x dx=−ln⁡∣cos⁡x∣+C\int\tan x\,dx = -\ln|\cos x| + C∫tanxdx=−ln∣cosx∣+C.

Typische Fehler
  • Den Betrag vergessen: ln⁡u(x)\ln u(x)lnu(x) ist für negative uuu gar nicht definiert.
  • Eine Stammfunktion „über die Polstelle hinweg“ angeben, etwa ∫1/22dxxln⁡x\int_{1/2}^{2}\frac{dx}{x\ln x}∫1/22​xlnxdx​ mit dem Hauptsatz ausrechnen – der Integrand ist bei x=1x = 1x=1 nicht beschränkt.
  • ∫dxxln⁡x=ln⁡x⋅ln⁡∣ln⁡x∣\int\frac{dx}{x\ln x} = \ln x\cdot\ln|\ln x|∫xlnxdx​=lnx⋅ln∣lnx∣ o. Ä. raten – immer durch Ableiten kontrollieren.
