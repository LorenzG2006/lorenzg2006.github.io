Angabe Originalseite

Ein Monopolist produziert eine Ware, wobei die Kosten in Abhängigkeit von der Stückzahl durch die Funktion K(x)=5000+100x+x2K(x) = 5000 + 100x + x^2K(x)=5000+100x+x2 beschrieben werden, der Umsatz durch U(x)=1000x−2x2U(x) = 1000x - 2x^2U(x)=1000x−2x2. Der Staat hebe eine Steuer S(x)=100xS(x) = 100xS(x)=100x auf die Absatzmenge ein.

Maximieren Sie den Unternehmensgewinn. Berechnen Sie die Steuereinnahmen für den Staat bei gewinnmaximaler Absatzmenge.

Ermitteln Sie weiters jenen Steuersatz rrr (also S(x)=rxS(x) = rxS(x)=rx), der dem Staat die maximalen Steuereinnahmen bringt, falls das Unternehmen wieder die gewinnmaximale Menge absetzt.

Lösung verborgen – erst selbst probieren!

Überblick

Der Gewinn ist Umsatz minus Kosten minus Steuer, G(x)=U(x)−K(x)−S(x)G(x) = U(x) - K(x) - S(x)G(x)=U(x)−K(x)−S(x) – hier eine nach unten geöffnete Parabel. Ihr Maximum finden wir über G′(x)=0G'(x) = 0G′(x)=0 und prüfen es mit G′′<0G'' < 0G′′<0. Im zweiten Teil hängt die gewinnmaximale Menge vom Steuersatz rrr ab: x∗(r)x^*(r)x∗(r). Die Steuereinnahmen T(r)=r⋅x∗(r)T(r) = r\cdot x^*(r)T(r)=r⋅x∗(r) sind dann eine Funktion von rrr allein, die wir wieder durch Ableiten maximieren. (Der Staat „denkt mit“: Ein zu hoher Steuersatz senkt die Absatzmenge so stark, dass die Einnahmen wieder sinken.)

Hilfreiches

Extremwerte differenzierbarer Funktionen

Ist fff zweimal differenzierbar, f′(x0)=0f'(x_0) = 0f′(x0​)=0 und f′′(x0)<0f''(x_0) < 0f′′(x0​)<0, so hat fff in x0x_0x0​ ein lokales Maximum. Ist f′′<0f'' < 0f′′<0 auf dem ganzen Intervall (konkave Funktion), ist es sogar das globale Maximum.

Gewinn

G(x)=U(x)−K(x)−S(x)G(x) = U(x) - K(x) - S(x)G(x)=U(x)−K(x)−S(x): Umsatz (Erlös) minus Kosten minus Steuern. Die gewinnmaximale Menge erfüllt U′(x)=K′(x)+S′(x)U'(x) = K'(x) + S'(x)U′(x)=K′(x)+S′(x) („Grenzerlös = Grenzkosten inkl. Steuer“).

Typische Fehler
  • Die Steuer bei der Gewinnfunktion vergessen oder addieren statt abziehen.
  • Im zweiten Teil die Menge x=4003x = \frac{400}{3}x=3400​ festhalten und r⋅4003r\cdot\frac{400}{3}r⋅3400​ maximieren – das wächst unbeschränkt in rrr. Die Menge hängt aber selbst von rrr ab!
  • Die Klammer beim Abziehen von K(x)K(x)K(x) nicht setzen: −(5000+100x+x2)-(5000 + 100x + x^2)−(5000+100x+x2), also auch −x2-x^2−x2.
