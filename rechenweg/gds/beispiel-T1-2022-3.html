Angabe Originalseite

3. (8 Punkte) Die Zahl Z=(B5)16Z = (B5)_{16}Z=(B5)16​ soll in Exzessdarstellung codiert werden. Der Exzess beträgt (36)16(36)_{16}(36)16​. Geben Sie die Zahl ZZZ in Exzessdarstellung sowohl hexadezimal als auch binär an.

Ze=()16=()2Z_e = (\quad)_{16} = (\quad)_2Ze​=()16​=()2​

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

In der Exzessdarstellung wird zu jeder Zahl der Exzess eee addiert: Ze=Z+eZ_e = Z + eZe​=Z+e. Weil beide Zahlen hexadezimal gegeben sind, rechnen wir direkt im Hexadezimalsystem und übersetzen das Ergebnis dann ziffernweise ins Binärsystem (1 Hex-Ziffer = 4 Bit).

Schritt 1: Addition im Hexadezimalsystem

Ziffern: B=11B = 11B=11, 555, 333, 666.

Stelle Rechnung Ziffer Übertrag
16016^0160 5+6=115 + 6 = 115+6=11 BBB 0 (da 11<1611 < 1611<16)
16116^1161 B+3=11+3=14B + 3 = 11 + 3 = 14B+3=11+3=14 EEE 0

Ze=(B5)16+(36)16=(EB)16.Z_e = (B5)_{16} + (36)_{16} = (EB)_{16}.Ze​=(B5)16​+(36)16​=(EB)16​.

Schritt 2: Umrechnung ins Binärsystem

E=14=8+4+2=1110E = 14 = 8 + 4 + 2 = 1110E=14=8+4+2=1110, B=11=8+2+1=1011\quad B = 11 = 8 + 2 + 1 = 1011B=11=8+2+1=1011:

(EB)16=(1110 1011)2.(EB)_{16} = (1110\,1011)_2.(EB)16​=(11101011)2​.

Schritt 3: Kontrolle im Dezimalsystem

(B5)16=11⋅16+5=181(B5)_{16} = 11 \cdot 16 + 5 = 181(B5)16​=11⋅16+5=181, (36)16=3⋅16+6=54(36)_{16} = 3 \cdot 16 + 6 = 54(36)16​=3⋅16+6=54, Summe 235235235; und (EB)16=14⋅16+11=235(EB)_{16} = 14 \cdot 16 + 11 = 235(EB)16​=14⋅16+11=235. ✓

Ergebnis

Ze=(EB)16=(1110 1011)2Z_e = (EB)_{16} = (1110\,1011)_2Ze​=(EB)16​=(11101011)2​

Probe

Interpretiert man 1110 10111110\,101111101011 wieder als Exzesszahl: 235−54=181=(B5)16235 - 54 = 181 = (B5)_{16}235−54=181=(B5)16​. ✓ Das Ergebnis hat 8 Bit, wie die Ausgangszahl.

Wozu so ein „krummer“ Exzess?

Die VO unterscheidet symmetrischen Exzess (2m2^m2m oder 2m−12^m - 12m−1) und nicht-symmetrischen Exzess: Ist die kleinste darzustellende Zahl −k-k−k, wählt man Exzess kkk. Hier wäre e=54e = 54e=54 passend für einen Bereich ab −54-54−54. Am Rechenweg ändert das nichts: immer Ze=Z+eZ_e = Z + eZe​=Z+e.

Hilfreiches

Exzessdarstellung (VO)

Für eine Zahl AAA und den Exzess eee ist Ae=A+eA_e = A + eAe​=A+e die Exzessdarstellung. Rückrechnung: A=Ae−eA = A_e - eA=Ae​−e. Die Darstellung ist ordnungserhaltend: kleinere Zahlen haben kleinere Bitmuster.

Hex ↔ Binär

0=00000 = 00000=0000, …, 9=10019 = 10019=1001, A=1010A = 1010A=1010, B=1011B = 1011B=1011, C=1100C = 1100C=1100, D=1101D = 1101D=1101, E=1110E = 1110E=1110, F=1111F = 1111F=1111.

Typische Fehler
  • Den Exzess abziehen statt addieren (das wäre das Decodieren).
  • 5+6=115 + 6 = 115+6=11 als „1 mit Übertrag 1“ schreiben – im Hexadezimalsystem ist 111111 die einzelne Ziffer BBB.
