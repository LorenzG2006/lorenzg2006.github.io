Angabe Originalseite

8. (10 Punkte) Bei einer mittels Polynomcodierung gesicherten Übertragung wird das Codewort ‘110111001011’ empfangen. Das Generator-Polynom sei: G(x)=x4+x3+xG(x) = x^4 + x^3 + xG(x)=x4+x3+x

(a) Geben Sie den Sicherungsanhang binär an.

(b) Geben Sie den Grad rrr des Generatorpolynoms an.

(c) Ist bei der Übertragung eine erkennbare Störung aufgetreten? Führen Sie zur Überprüfung die Polynomdivision durch und begründen Sie.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Beim Polynomcode hängt der Sender an die Daten einen Sicherungsanhang aus r=grad⁡Gr = \operatorname{grad} Gr=gradG Bits, sodass das ganze Codewort (als Polynom gelesen) durch G(x)G(x)G(x) teilbar ist. Der Empfänger dividiert das empfangene Wort modulo 2 durch G(x)G(x)G(x): Rest 000 → keine erkennbare Störung, Rest ≠0\ne 0=0 → Störung erkannt.

(b) Grad des Generatorpolynoms

G(x)=x4+x3+xG(x) = x^4 + x^3 + xG(x)=x4+x3+x hat die höchste Potenz x4x^4x4, also r=4r = 4r=4. Als Bitfolge (Koeffizienten von x4x^4x4 bis x0x^0x0): G  =^  11010G \;\widehat{=}\; 11010G=11010.

(a) Sicherungsanhang

Der Anhang besteht aus den letzten r=4r = 4r=4 Bits des Codeworts:

11011100 1011‾⇒Sicherungsanhang 1011.11011100\,\underline{1011} \quad\Rightarrow\quad \text{Sicherungsanhang } 1011.110111001011​⇒Sicherungsanhang 1011.

(Die ersten 8 Bit 110111001101110011011100 sind die Nutzdaten.)

(c) Polynomdivision

Empfangenes Polynom: 110111001011  =^  x11+x10+x8+x7+x6+x3+x+1110111001011 \;\widehat{=}\; x^{11} + x^{10} + x^8 + x^7 + x^6 + x^3 + x + 1110111001011=x11+x10+x8+x7+x6+x3+x+1.

Division modulo 2 durch 110101101011010 – in jedem Schritt GGG unter die vorderste verbleibende 111 schreiben und XOR bilden:

11011100101111010000011001011000011010000000011011000000011010000000000001\begin{array}{l} 110111001011\\ 11010\\ \hline \phantom{0000}11001011\\ \phantom{0000}11010\\ \hline \phantom{0000000}11011\\ \phantom{0000000}11010\\ \hline \phantom{00000000}0001 \end{array}11011100101111010000011001011000011010000000011011000000011010000000000001​​

Einzelschritte:

  1. 11011⊕11010=0000111011 \oplus 11010 = 0000111011⊕11010=00001; mit den nachgeholten Bits steht die nächste 111 an Position 5 (von links, ab 1 gezählt): weiter mit 110010111100101111001011.
  2. 11001⊕11010=0001111001 \oplus 11010 = 0001111001⊕11010=00011; weiter mit 110111101111011 (nach den führenden Nullen).
  3. 11011⊕11010=0000111011 \oplus 11010 = 0000111011⊕11010=00001; übrig bleiben die letzten 4 Bit: 000100010001.

Rest R(x)=1R(x) = 1R(x)=1 (Bitfolge 000100010001), also ungleich null.

Ergebnis

(a) Sicherungsanhang 101110111011 · (b) r=4r = 4r=4 · (c) Der Divisionsrest ist 0001≠00000001 \ne 00000001=0000: Das empfangene Wort ist nicht durch G(x)G(x)G(x) teilbar, also ist eine Störung erkannt worden.

Probe

In Polynomschreibweise lautet die Division: Quotient x7+x3+1x^7 + x^3 + 1x7+x3+1 (die Schritte begannen bei x11x^{11}x11, x7x^7x7 und x4x^4x4, also Quotientenglieder x11−4x^{11-4}x11−4, x7−4x^{7-4}x7−4, x4−4x^{4-4}x4−4), und (x4+x3+x)(x7+x3+1)+1=x11+x10+x8+x7+x6+x4+x4+x3+x+1=x11+x10+x8+x7+x6+x3+x+1(x^4 + x^3 + x)(x^7 + x^3 + 1) + 1 = x^{11} + x^{10} + x^8 + x^7 + x^6 + x^4 + x^4 + x^3 + x + 1 = x^{11} + x^{10} + x^8 + x^7 + x^6 + x^3 + x + 1(x4+x3+x)(x7+x3+1)+1=x11+x10+x8+x7+x6+x4+x4+x3+x+1=x11+x10+x8+x7+x6+x3+x+1 ✓ (modulo 2 fällt x4+x4x^4 + x^4x4+x4 weg). Mit Python bestätigt.

Was „erkennbar“ bedeutet

Rest ≠0\ne 0=0 beweist einen Fehler. Rest =0= 0=0 hieße nur, dass kein erkennbarer Fehler vorliegt – ein Fehlermuster, das selbst ein Vielfaches von G(x)G(x)G(x) ist, bliebe unentdeckt.

Hilfreiches

Polynomcode prüfen (Empfänger)
  1. Empfangenes Wort als Polynom (Bits = Koeffizienten, höchste Potenz links).
  2. Modulo 2 durch G(x)G(x)G(x) dividieren (Subtraktion = XOR, keine Überträge).
  3. Rest 000: akzeptieren; Rest ≠0\ne 0=0: Fehler erkannt.
Begriffe

Grad rrr von GGG = höchste vorkommende Potenz = Anzahl der Prüfbits; Sicherungsanhang = die letzten rrr Bits des Codeworts.

Typische Fehler
  • Den Koeffizienten von x2x^2x2 in GGG übersehen: x4+x3+xx^4 + x^3 + xx4+x3+x ist 110101101011010 (fünf Stellen, mit 000 bei x2x^2x2 und x0x^0x0).
  • Beim Prüfen nochmals rrr Nullen anhängen.
  • Den Sicherungsanhang mit dem Rest verwechseln.
