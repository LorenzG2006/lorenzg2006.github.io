Aufgabe A3: Codierung und Informationstheorie (20 Punkte)

a) (10 Punkte) Lösen Sie folgende Aufagben zum Thema Hamming-Code.

(i) Wie viele Prüfbits werden benötigt um 11 Datenbits zu kodieren? Welche Länge (in Bit) haben die Codewörter?

(ii) Codieren Sie das Datenwort 10001.

(iii) Sie empfangen die Bitfolge 1000101. Überprüfen Sie, ob ein Fehler aufgetreten ist, und korrigieren Sie diesen gegebenenfalls. Geben Sie das korrigierte Datenwort an.

b) (10 Punkte) Eine Datenübertragung wird mit einem Polynomcode gesicherten. Das Generator-Polynom ist: G(x)=x3+x2+1G(x) = x^3 + x^2 + 1G(x)=x3+x2+1.

Aus diesem Code wird das Codewort ‘011011111000’ empfangen.

(i) Geben Sie den Grad rrr des Generatorpolynoms an.

(ii) Geben Sie den Sicherungsanhang binär an.

(iii) Ist bei der Übertragung eine erkennbare Störung aufgetreten? Führen Sie zur Überprüfung die Polynomdivision durch und begründen Sie Ihre Antwort.

(b) Polynomcode mit G(x)=x3+x2+1G(x) = x^3 + x^2 + 1G(x)=x3+x2+1

(i) Grad

Die höchste Potenz in G(x)G(x)G(x) ist x3x^3x3: r=3r = 3r=3.

(ii) Sicherungsanhang

Der Sender hängt an die Daten den rrr-stelligen Divisionsrest an. Der Sicherungsanhang sind also die letzten 3 Bit des Codeworts:

011011111 000‾⇒Sicherungsanhang 000.011011111\,\underline{000} \quad\Rightarrow\quad \text{Sicherungsanhang } 000.011011111000​⇒Sicherungsanhang 000.

(iii) Prüfung durch Polynomdivision

Das empfangene Wort entspricht R(x)=x10+x9+x7+x6+x5+x4+x3R(x) = x^{10} + x^9 + x^7 + x^6 + x^5 + x^4 + x^3R(x)=x10+x9+x7+x6+x5+x4+x3. Division modulo 2 durch G=1101G = 1101G=1101 (führende 000 weggelassen; XOR statt Subtraktion):

Hilfreiches

Hamming-Code (VO)
  • Anzahl Prüfbits: kleinstes rrr mit 2r≥m+r+12^r \ge m + r + 12r≥m+r+1.
  • Prüfbits an Positionen 1,2,4,8,…1, 2, 4, 8, \dots1,2,4,8,…; Codebit kkk trägt zu den Prüfbits bei, deren Zweierpotenzen in der Binärdarstellung von kkk vorkommen (z. B. 11=8+2+111 = 8 + 2 + 111=8+2+1).
  • Prüfung: Für jedes abweichende Prüfbit ckc_kck​ wird kkk zum Korrekturindikator addiert; 000 = fehlerfrei, sonst Nummer des gestörten Bits.
Polynomcode prüfen

Empfangenes Wort als Polynom durch G(x)G(x)G(x) modulo 2 teilen. Rest =0= 0=0: kein (erkennbarer) Fehler. Rest ≠0\ne 0=0: Fehler erkannt. Sicherungsanhang = letzte r=grad⁡Gr = \operatorname{grad} Gr=gradG Bits.

Typische Fehler
  • Beim Codieren von 5 Datenbits nur 3 Prüfbits verwenden (23=8<92^3 = 8 < 923=8<9!).
  • Prüfbits ans Ende hängen statt an die Zweierpotenz-Positionen.
  • Bei der CRC-Prüfung zusätzlich rrr Nullen anhängen – das macht nur der Sender vor dem Codieren.
  • Den Sicherungsanhang mit dem Divisionsrest verwechseln: Anhang = letzte rrr Bits des empfangenen Worts.

Verwandte Beispiele: T1-2022.8, T1-2022.9, T1-2024.3, T1-2025.3.
