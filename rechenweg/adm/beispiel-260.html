Angabe Originalseite

Stellen Sie eine Rekursion für die gesuchten Zahlen ana_nan​ auf und lösen Sie diese:

Es sei ana_nan​ wie in Bsp. 259), jedoch gilt jetzt auch 1 als Nachfolger von nnn (zyklische Anordnung).

(Bsp. 259: ana_nan​ ist die Anzahl der Teilmengen von {1,…,n}\{1, \dots, n\}{1,…,n}, die keine zwei aufeinanderfolgenden Zahlen enthalten.)

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Die Zahlen 1,…,n1, \dots, n1,…,n sitzen jetzt im Kreis; zusätzlich zu den Paaren {k,k+1}\{k, k+1\}{k,k+1} sind auch nnn und 111 benachbart. Um Verwechslungen zu vermeiden, nennen wir die neue Anzahl bnb_nbn​ und die (lineare) Anzahl aus Bsp. 259 weiterhin an=Fn+2a_n = F_{n+2}an​=Fn+2​. Durch Fallunterscheidung nach dem Element nnn führen wir das zyklische Problem auf das lineare zurück; danach leiten wir eine Rekursion für bnb_nbn​ allein her und lösen sie.

Eine Teilmenge heißt wieder zulässig, wenn sie keine zwei (zyklisch) benachbarten Zahlen enthält. Wir betrachten n≥2n \ge 2n≥2 (zu n=1n = 1n=1 siehe den Hinweis unten).

Schritt 2: Rückführung auf das lineare Problem

Sei n≥3n \ge 3n≥3 und TTT zulässig (zyklisch).

  1. n∉Tn \notin Tn∈/T: Dann ist T⊆{1,…,n−1}T \subseteq \{1, \dots, n-1\}T⊆{1,…,n−1}. Ohne nnn ist der Kreis „aufgeschnitten“: 111 und n−1n - 1n−1 sind nicht benachbart, es gelten nur die linearen Nachbarschaften {k,k+1}\{k, k+1\}{k,k+1}. Also sind das genau die zulässigen Teilmengen von {1,…,n−1}\{1, \dots, n-1\}{1,…,n−1} im Sinne von Bsp. 259: an−1a_{n-1}an−1​ Stück.
  2. n∈Tn \in Tn∈T: Dann sind beide Nachbarn n−1n - 1n−1 und 111 ausgeschlossen. T∖{n}T \setminus \{n\}T∖{n} ist eine (linear) zulässige Teilmenge von {2,…,n−2}\{2, \dots, n-2\}{2,…,n−2} – einer Kette aus n−3n - 3n−3 aufeinanderfolgenden Zahlen; umgekehrt ergibt jede solche Teilmenge zusammen mit nnn eine zyklisch zulässige Menge. Anzahl: an−3a_{n-3}an−3​ (für n=3n = 3n=3 ist die Kette leer, a0=1a_0 = 1a0​=1: nur T={3}T = \{3\}T={3}).

Also

bn=an−1+an−3(n≥3).b_n = a_{n-1} + a_{n-3} \qquad (n \ge 3).bn​=an−1​+an−3​(n≥3).

Kontrolle: b3=a2+a0=3+1=4b_3 = a_2 + a_0 = 3 + 1 = 4b3​=a2​+a0​=3+1=4 ✓, b4=a3+a1=5+2=7b_4 = a_3 + a_1 = 5 + 2 = 7b4​=a3​+a1​=5+2=7 ✓.

Schritt 3: Rekursion für bnb_nbn​ allein

Für n≥5n \ge 5n≥5 gelten an−1=an−2+an−3a_{n-1} = a_{n-2} + a_{n-3}an−1​=an−2​+an−3​ und an−3=an−4+an−5a_{n-3} = a_{n-4} + a_{n-5}an−3​=an−4​+an−5​ (Rekursion aus Bsp. 259). Daher

bn=an−1+an−3=(an−2+an−3)+(an−4+an−5)(Bsp. 259)=(an−2+an−4)+(an−3+an−5)(umsortiert)=bn−1+bn−2.(Schritt 2 fu¨r n−1 und n−2)\begin{aligned} b_n &= a_{n-1} + a_{n-3} && \\ &= (a_{n-2} + a_{n-3}) + (a_{n-4} + a_{n-5}) && \text{(Bsp. 259)}\\ &= (a_{n-2} + a_{n-4}) + (a_{n-3} + a_{n-5}) && \text{(umsortiert)}\\ &= b_{n-1} + b_{n-2}. && \text{(Schritt 2 für } n-1 \text{ und } n-2\text{)} \end{aligned}bn​​=an−1​+an−3​=(an−2​+an−3​)+(an−4​+an−5​)=(an−2​+an−4​)+(an−3​+an−5​)=bn−1​+bn−2​.​​(Bsp. 259)(umsortiert)(Schritt 2 fu¨r n−1 und n−2)​

Zusätzlich gilt b4=7=4+3=b3+b2b_4 = 7 = 4 + 3 = b_3 + b_2b4​=7=4+3=b3​+b2​. Damit:

bn=bn−1+bn−2(n≥4),b2=3, b3=4.b_n = b_{n-1} + b_{n-2} \quad (n \ge 4), \qquad b_2 = 3,\ b_3 = 4.bn​=bn−1​+bn−2​(n≥4),b2​=3, b3​=4.

Schritt 4: Rekursion lösen

Gleiche charakteristische Gleichung wie in Bsp. 259: λ2−λ−1=0\lambda^2 - \lambda - 1 = 0λ2−λ−1=0 mit φ=1+52\varphi = \frac{1 + \sqrt5}{2}φ=21+5​​, ψ=1−52\psi = \frac{1 - \sqrt5}{2}ψ=21−5​​, also bn=Aφn+Bψnb_n = A\varphi^n + B\psi^nbn​=Aφn+Bψn.

Statt das Gleichungssystem für n=2,3n = 2, 3n=2,3 direkt zu lösen, rechnen wir die Rekursion zwei Schritte rückwärts: b1:=b3−b2=1b_1 := b_3 - b_2 = 1b1​:=b3​−b2​=1, b0:=b2−b1=2b_0 := b_2 - b_1 = 2b0​:=b2​−b1​=2. Die so fortgesetzte Folge erfüllt die Rekursion für alle n≥2n \ge 2n≥2, also gilt die Formel auch für diese Werte:

n=0:A+B=2,n=1:Aφ+Bψ=1.\begin{aligned} n = 0:&\quad A + B = 2,\\ n = 1:&\quad A\varphi + B\psi = 1. \end{aligned}n=0:n=1:​A+B=2,Aφ+Bψ=1.​

Wegen φ+ψ=1\varphi + \psi = 1φ+ψ=1 löst A=B=1A = B = 1A=B=1 beide Gleichungen, und die Lösung ist eindeutig (Determinante ψ−φ=−5≠0\psi - \varphi = -\sqrt5 \ne 0ψ−φ=−5​=0). Somit

bn=φn+ψn=(1+52)n+(1−52)n(n≥2).b_n = \varphi^n + \psi^n = \Bigl(\frac{1 + \sqrt5}{2}\Bigr)^n + \Bigl(\frac{1 - \sqrt5}{2}\Bigr)^n \qquad (n \ge 2).bn​=φn+ψn=(21+5​​)n+(21−5​​)n(n≥2).

Das sind die Lucas-Zahlen LnL_nLn​ (2,1,3,4,7,11,18,…2, 1, 3, 4, 7, 11, 18, \dots2,1,3,4,7,11,18,…).

Ergebnis

Der Randfall n=1n = 1n=1

Für n=1n = 1n=1 ist „111 ist Nachfolger von 111“ ein Grenzfall. Fasst man das so auf, dass {1}\{1\}{1} dann zwei benachbarte Elemente enthält, ist nur ∅\emptyset∅ zulässig und b1=1=L1b_1 = 1 = L_1b1​=1=L1​ – die Formel gilt dann für alle n≥1n \ge 1n≥1. Ignoriert man die Selbstnachbarschaft, ist b1=2b_1 = 2b1​=2. Für n=0n = 0n=0 liefert die Formel L0=2L_0 = 2L0​=2, gezählt wird aber nur ∅\emptyset∅; dieser Fall ist ohne Bedeutung.

Hilfreiches

Zyklische Probleme aufschneiden

Bei Kreisanordnungen unterscheidet man nach einem festen Element: Ist es „nicht dabei“, entsteht das lineare Problem der Länge n−1n - 1n−1; ist es „dabei“, fallen seine beiden Nachbarn weg und es entsteht das lineare Problem der Länge n−3n - 3n−3.

Lucas-Zahlen

L0=2L_0 = 2L0​=2, L1=1L_1 = 1L1​=1, Ln=Ln−1+Ln−2L_n = L_{n-1} + L_{n-2}Ln​=Ln−1​+Ln−2​; explizit Ln=φn+ψnL_n = \varphi^n + \psi^nLn​=φn+ψn. Es gilt Ln=Fn+1+Fn−1L_n = F_{n+1} + F_{n-1}Ln​=Fn+1​+Fn−1​.

Typische Fehler
  • Im Fall n∈Tn \in Tn∈T nur den Nachbarn n−1n - 1n−1 ausschließen und den zyklischen Nachbarn 111 vergessen (dann erhielte man wieder die Fibonacci-Zahlen aus Bsp. 259).
  • Im Fall n∉Tn \notin Tn∈/T glauben, man habe wieder ein zyklisches Problem der Länge n−1n - 1n−1 – ohne nnn sind n−1n - 1n−1 und 111 nicht benachbart.
  • Die Rekursion bn=bn−1+bn−2b_n = b_{n-1} + b_{n-2}bn​=bn−1​+bn−2​ ohne Begründung von Bsp. 259 übernehmen; sie gilt zwar, muss aber hergeleitet werden (Schritt 3).
