Angabe Originalseite

Berechnen Sie zur folgenden Matrix AAA mit Einträgen aus R\RR die Matrix A3A^3A3:

A=(0ab00c000).A = \begin{pmatrix} 0 & a & b \\ 0 & 0 & c \\ 0 & 0 & 0 \end{pmatrix}.A=​000​a00​bc0​​.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Wir berechnen A2=A⋅AA^2 = A\cdot AA2=A⋅A und danach A3=A⋅A2A^3 = A \cdot A^2A3=A⋅A2 mit „Zeile mal Spalte“. AAA ist eine strikte obere Dreiecksmatrix; jede weitere Multiplikation schiebt die von null verschiedenen Einträge eine Diagonale weiter nach rechts oben, bis nichts mehr übrig bleibt.

Schritt 1: A2A^2A2

Zeilen von AAA: z1=(0,a,b)z_1 = (0,a,b)z1​=(0,a,b), z2=(0,0,c)z_2 = (0,0,c)z2​=(0,0,c), z3=(0,0,0)z_3 = (0,0,0)z3​=(0,0,0). Spalten von AAA: s1=(0,0,0)Ts_1 = (0,0,0)^Ts1​=(0,0,0)T, s2=(a,0,0)Ts_2 = (a,0,0)^Ts2​=(a,0,0)T, s3=(b,c,0)Ts_3 = (b,c,0)^Ts3​=(b,c,0)T.

  • Die erste Spalte von AAA ist null, also ist die erste Spalte von A2A^2A2 null.
  • Zeile 1: z1⋅s2=0⋅a+a⋅0+b⋅0=0z_1\cdot s_2 = 0\cdot a + a\cdot 0 + b\cdot 0 = 0z1​⋅s2​=0⋅a+a⋅0+b⋅0=0,  z1⋅s3=0⋅b+a⋅c+b⋅0=ac\ z_1\cdot s_3 = 0\cdot b + a\cdot c + b\cdot 0 = ac z1​⋅s3​=0⋅b+a⋅c+b⋅0=ac.
  • Zeile 2: z2⋅s2=0⋅a+0+c⋅0=0z_2\cdot s_2 = 0\cdot a + 0 + c\cdot 0 = 0z2​⋅s2​=0⋅a+0+c⋅0=0,  z2⋅s3=0⋅b+0⋅c+c⋅0=0\ z_2 \cdot s_3 = 0\cdot b + 0\cdot c + c\cdot 0 = 0 z2​⋅s3​=0⋅b+0⋅c+c⋅0=0.
  • Zeile 3 ist null.

A2=(00ac000000).A^2 = \begin{pmatrix} 0 & 0 & ac \\ 0 & 0 & 0 \\ 0 & 0 & 0 \end{pmatrix}.A2=​000​000​ac00​​.

Schritt 2: A3=A⋅A2A^3 = A \cdot A^2A3=A⋅A2

Die einzige von null verschiedene Spalte von A2A^2A2 ist die dritte, (ac,0,0)T(ac, 0, 0)^T(ac,0,0)T. Für sie gilt

  • z1⋅(ac,0,0)T=0⋅ac+a⋅0+b⋅0=0z_1 \cdot (ac,0,0)^T = 0\cdot ac + a\cdot 0 + b \cdot 0 = 0z1​⋅(ac,0,0)T=0⋅ac+a⋅0+b⋅0=0,
  • z2⋅(ac,0,0)T=0z_2 \cdot (ac,0,0)^T = 0z2​⋅(ac,0,0)T=0,  z3⋅(ac,0,0)T=0\ z_3\cdot(ac,0,0)^T = 0 z3​⋅(ac,0,0)T=0,

weil der erste Eintrag jeder Zeile von AAA gleich 000 ist. Alle anderen Spalten von A2A^2A2 sind ohnehin null.

A3=(000000000).A^3 = \begin{pmatrix} 0 & 0 & 0 \\ 0 & 0 & 0 \\ 0 & 0 & 0 \end{pmatrix}.A3=​000​000​000​​.

Hilfreiches

Matrizenprodukt

(XY)ij=∑kxikykj(XY)_{ij} = \sum_k x_{ik} y_{kj}(XY)ij​=∑k​xik​ykj​ – Zeile iii von XXX mal Spalte jjj von YYY.

Strikte Dreiecksmatrizen sind nilpotent

Ist N∈Rn×nN \in \R^{n\times n}N∈Rn×n eine strikte obere (oder untere) Dreiecksmatrix, so ist Nn=0N^n = 0Nn=0. Beweisidee: NNN bildet span⁡(e1,…,ek)\operatorname{span}(e_1,\dots,e_k)span(e1​,…,ek​) in span⁡(e1,…,ek−1)\operatorname{span}(e_1,\dots,e_{k-1})span(e1​,…,ek−1​) ab.

Potenzen und Transponieren

(AB)T=BTAT(AB)^T = B^T A^T(AB)T=BTAT, insbesondere (Ak)T=(AT)k(A^k)^T = (A^T)^k(Ak)T=(AT)k.

Typische Fehler
  • Eintragsweise potenzieren statt Matrizen multiplizieren.
  • Die Reihenfolge der Faktoren für unerheblich halten: Hier ist A⋅A2=A2⋅AA\cdot A^2 = A^2\cdot AA⋅A2=A2⋅A (Potenzen derselben Matrix kommutieren), aber im Allgemeinen gilt XY≠YXXY \ne YXXY=YX.
