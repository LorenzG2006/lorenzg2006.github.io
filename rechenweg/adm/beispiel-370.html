Angabe Originalseite

Man ergänze die folgende Operationstafel so, dass ({a,b,c,d},∗)(\{a,b,c,d\},\ast)({a,b,c,d},∗) eine Gruppe ist.

∗\ast∗ aaa bbb ccc ddd
aaa aaa
bbb ccc
ccc
ddd

Überblick

a∗a=aa\ast a = aa∗a=a ⇒ aaa ist neutral. Die Angabe b∗b=cb\ast b = cb∗b=c sagt b2=cb^2 = cb2=c. Wir bestimmen, welche weiteren Potenzen von bbb sich ergeben; das legt die ganze Tafel fest. Die reine Lateinische-Quadrat-Regel reicht hier nicht ganz – wir brauchen zusätzlich die Kürzungsregel in der Form „b∗x=xb\ast x = xb∗x=x ⇒ b=eb = eb=e“.

Schritt 1: Neutrales Element

a∗a=aa\ast a = aa∗a=a ⇒ a=ea = ea=e. Zeile und Spalte von aaa = Kopfzeile.

Schritt 2: Potenzen von b

Wir schreiben b2=b∗b=cb^2 = b\ast b = cb2=b∗b=c und b3=b∗cb^3 = b\ast cb3=b∗c. In Zeile bbb stehen schon bbb (bei b∗ab\ast ab∗a) und ccc (bei b∗bb\ast bb∗b), also b∗c∈{a,d}b\ast c\in\{a, d\}b∗c∈{a,d}.

  • Angenommen b∗c=ab\ast c = ab∗c=a. Dann bliebe b∗d=db\ast d = db∗d=d. Rechtsmultiplikation mit d−1d^{-1}d−1 ergäbe b=a=eb = a = eb=a=e – Widerspruch, da b∗b=c≠bb\ast b = c\ne bb∗b=c=b.
  • Also b3=b∗c=db^3 = b\ast c = db3=b∗c=d und b∗d=ab\ast d = ab∗d=a, d. h. b4=b∗d=a=eb^4 = b\ast d = a = eb4=b∗d=a=e.

Die Elemente sind also a=b0a = b^0a=b0, b=b1b = b^1b=b1, c=b2c = b^2c=b2, d=b3d = b^3d=b3 mit b4=eb^4 = eb4=e: Die Gruppe ist zyklisch, erzeugt von bbb, und es gilt bi∗bj=b(i+j) mod 4.b^i\ast b^j = b^{(i+j) \bmod 4}.bi∗bj=b(i+j)mod4.

  • Lateinisches Quadrat: jede Zeile/Spalte enthält a,b,c,da,b,c,da,b,c,d genau einmal ✓; b∗b=cb\ast b = cb∗b=c wie vorgegeben ✓.

Hilfreiches

Zyklische Gruppen

Ist G={e,g,g2,…,gn−1}G = \{e, g, g^2, \dots, g^{n-1}\}G={e,g,g2,…,gn−1} mit gn=eg^n = egn=e, so gilt gigj=g(i+j) mod ng^i g^j = g^{(i+j)\bmod n}gigj=g(i+j)modn und G≅(Zn,+)G\cong(\Z_n,+)G≅(Zn​,+).

Kürzungsregel

x∗y=yx\ast y = yx∗y=y ⇒ x=ex = ex=e; allgemein x∗y=x∗zx\ast y = x\ast zx∗y=x∗z ⇒ y=zy = zy=z.

Typische Fehler
  • Nach dem lateinischen Quadrat „b∗c=ab\ast c = ab∗c=a, b∗d=db\ast d = db∗d=d“ wählen – das widerspricht der Kürzungsregel.
  • Annehmen, es könne sich auch um die Kleinsche Vierergruppe handeln – dort wäre b∗b=ab\ast b = ab∗b=a.
