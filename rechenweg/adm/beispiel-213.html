Angabe Originalseite

200–213) Die folgenden Aufgaben sollen mit dem Inklusions-Exklusionsprinzip bearbeitet werden!

Auf wie viele Arten können 8 Türme derart auf ein Schachbrett gestellt werden, dass sie einander nicht schlagen können und die weiße Diagonale freibleibt? (Ein Turm kann eine andere Figur nur dann schlagen, wenn diese horizontal oder vertikal auf gleicher Höhe steht und keine andere Figur dazwischen steht.)

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Zuerst übersetzen wir „8 Türme, die einander nicht schlagen“ in Permutationen von {1,…,8}\{1, \dots, 8\}{1,…,8}: In jeder Spalte und jeder Zeile steht genau ein Turm. Die Bedingung „weiße Diagonale frei“ verbietet dann für jede Spalte genau eine Zeile. Die Anzahl der Permutationen, die keine dieser 888 verbotenen Positionen benutzen, berechnen wir mit Inklusion-Exklusion – es ist die Anzahl der fixpunktfreien Permutationen (Derangements) von 888 Elementen.

Schritt 1: Nicht schlagende Türme = Permutationen

Wir nummerieren die Spalten (Linien a–h) und die Zeilen (Reihen 1–8) jeweils mit 1,…,81, \dots, 81,…,8.

Höchstens ein Turm pro Zeile: Stünden zwei oder mehr Türme in derselben Zeile, so betrachte man zwei davon, die in dieser Zeile benachbart sind (zwischen ihnen steht keine weitere Figur). Diese beiden schlagen einander – Widerspruch. Ebenso höchstens ein Turm pro Spalte.

Genau einer pro Zeile/Spalte: 888 Türme auf 888 Spalten mit höchstens einem pro Spalte heißt: in jeder Spalte genau einer; analog für Zeilen.

Steht in Spalte iii der Turm in Zeile σ(i)\sigma(i)σ(i), so ist σ:{1,…,8}→{1,…,8}\sigma : \{1, \dots, 8\} \to \{1, \dots, 8\}σ:{1,…,8}→{1,…,8} injektiv (verschiedene Spalten haben verschiedene Zeilen), also eine Permutation. Umgekehrt liefert jede Permutation eine zulässige Aufstellung: Zwei Türme in verschiedenen Zeilen und Spalten stehen weder horizontal noch vertikal auf gleicher Höhe. Es gibt also 8!=40 3208! = 40\,3208!=40320 Aufstellungen nicht schlagender Türme.

Schritt 2: Die weiße Diagonale

Das Feld h1 rechts unten ist weiß, die lange weiße Diagonale verläuft daher von a8 nach h1 und besteht aus den Feldern

(i, 9−i),i=1,…,8(Spalte i, Zeile 9−i).(i,\ 9-i), \qquad i = 1, \dots, 8 \quad (\text{Spalte } i, \text{ Zeile } 9-i).(i, 9−i),i=1,…,8(Spalte i, Zeile 9−i).

Sie enthält aus jeder Spalte und jeder Zeile genau ein Feld. Die Bedingung „Diagonale bleibt frei“ lautet:

σ(i)≠9−ifu¨r alle i=1,…,8.\sigma(i) \ne 9 - i \qquad \text{für alle } i = 1, \dots, 8.σ(i)=9−ifu¨r alle i=1,…,8.

(Für die schwarze Diagonale σ(i)≠i\sigma(i) \ne iσ(i)=i ergäbe sich aus Symmetriegründen dieselbe Anzahl – es kommt nur darauf an, dass pro Spalte genau ein Feld verboten ist und diese Felder in verschiedenen Zeilen liegen.)

Hilfreiches

Inklusions-Exklusions-Prinzip

Für Teilmengen A1,…,AnA_1, \dots, A_nA1​,…,An​ einer endlichen Menge SSS gilt ∣S∖⋃i=1nAi∣=∑k=0n(−1)k∑1≤i1<⋯<ik≤n∣Ai1∩⋯∩Aik∣\Bigl\vert S\setminus \bigcup_{i=1}^n A_i\Bigr\vert = \sum_{k=0}^{n} (-1)^k \sum_{1\le i_1<\dots<i_k\le n} \vert A_{i_1}\cap\dots\cap A_{i_k}\vert​S∖i=1⋃n​Ai​​=k=0∑n​(−1)k1≤i1​<⋯<ik​≤n∑​∣Ai1​​∩⋯∩Aik​​∣ (der Summand für k=0k = 0k=0 ist ∣S∣\vert S\vert∣S∣).

Derangement

Eine Permutation σ\sigmaσ von {1,…,n}\{1, \dots, n\}{1,…,n} heißt fixpunktfrei (Derangement), wenn σ(i)≠i\sigma(i) \ne iσ(i)=i für alle iii. Ihre Anzahl ist Dn=n!∑k=0n(−1)kk!.D_n = n!\sum_{k=0}^{n} \frac{(-1)^k}{k!}.Dn​=n!k=0∑n​k!(−1)k​. Allgemeiner: Ist für jedes iii genau ein Wert τ(i)\tau(i)τ(i) verboten und ist τ\tauτ selbst eine Permutation, so gibt es ebenfalls DnD_nDn​ Permutationen mit σ(i)≠τ(i)\sigma(i) \ne \tau(i)σ(i)=τ(i) für alle iii (denn σ↦τ−1∘σ\sigma \mapsto \tau^{-1}\circ\sigmaσ↦τ−1∘σ ist eine Bijektion auf die Derangements).

Typische Fehler
  • „Nicht schlagen“ nicht sauber begründen: Auch mit der Zusatzregel „keine Figur dazwischen“ dürfen keine zwei Türme in einer Zeile stehen, weil dann zwei benachbarte einander schlagen.
  • Statt Inklusion-Exklusion einfach 787^878 (jede Spalte meidet ein Feld) rechnen – das vergisst, dass die Zeilen verschieden sein müssen.
  • Vorzeichenfehler in der alternierenden Summe; insbesondere den letzten Summanden +1+1+1 (k=8k = 8k=8) vergessen.
