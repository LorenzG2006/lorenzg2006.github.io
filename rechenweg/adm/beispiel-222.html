Angabe Originalseite

Man bestimme die allgemeine Lösung der Differenzengleichung

xn+1=23xn+1(fu¨r n≥0)x_{n+1} = \frac23 x_n + 1 \quad (\text{für } n \ge 0)xn+1​=32​xn​+1(fu¨r n≥0)

und die partikuläre Lösung, die der Anfangsbedingung x0=6x_0 = 6x0​=6 genügt.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Lineare Differenzengleichung erster Ordnung mit konstanten Koeffizienten xn+1=a xn+bx_{n+1} = a\,x_n + bxn+1​=axn​+b, hier a=23a = \frac23a=32​, b=1b = 1b=1. Allgemeine Lösung = homogene Lösung C anC\,a^nCan + konstante partikuläre Lösung (Fixpunkt). Danach bestimmen wir CCC aus x0=6x_0 = 6x0​=6.

Schritt 1: Homogene Gleichung

xn+1=23xnx_{n+1} = \frac23 x_nxn+1​=32​xn​ hat die Lösungen xn(h)=C(23)nx_n^{(h)} = C\left(\frac23\right)^nxn(h)​=C(32​)n, C∈RC \in \RC∈R (jeder Schritt multipliziert mit 23\frac2332​).

Schritt 2: Partikuläre Lösung

Weil a=23≠1a = \frac23 \ne 1a=32​=1, gibt es eine konstante Lösung xn=x∗x_n = x^*xn​=x∗:

x∗=23x∗+1  ⟺  13x∗=1  ⟺  x∗=3.x^* = \frac23 x^* + 1 \iff \frac13 x^* = 1 \iff x^* = 3.x∗=32​x∗+1⟺31​x∗=1⟺x∗=3.

Schritt 3: Allgemeine Lösung

xn=C(23)n+3,C∈R.x_n = C\left(\frac23\right)^n + 3, \qquad C \in \R.xn​=C(32​)n+3,C∈R.

Begründung, dass es keine weiteren gibt: Für jede Lösung erfüllt yn:=xn−3y_n := x_n - 3yn​:=xn​−3

yn+1=23xn+1−3=23(xn−3)=23yn,y_{n+1} = \tfrac23 x_n + 1 - 3 = \tfrac23 (x_n - 3) = \tfrac23 y_n,yn+1​=32​xn​+1−3=32​(xn​−3)=32​yn​,

also yn=y0(23)ny_n = y_0\left(\frac23\right)^nyn​=y0​(32​)n und xn=(x0−3)(23)n+3x_n = (x_0 - 3)\left(\frac23\right)^n + 3xn​=(x0​−3)(32​)n+3.

Probe: 23(C(23)n+3)+1=C(23)n+1+2+1=xn+1\frac23\Bigl(C\left(\frac23\right)^n + 3\Bigr) + 1 = C\left(\frac23\right)^{n+1} + 2 + 1 = x_{n+1}32​(C(32​)n+3)+1=C(32​)n+1+2+1=xn+1​ ✓.

Schritt 4: Anfangsbedingung x0=6x_0 = 6x0​=6

x0=C⋅(23)0+3=C+3=6  ⟹  C=3.x_0 = C\cdot\left(\tfrac23\right)^0 + 3 = C + 3 = 6 \implies C = 3.x0​=C⋅(32​)0+3=C+3=6⟹C=3.

Also

xn=3(23)n+3=2n3n−1+3.x_n = 3\left(\frac23\right)^n + 3 = \frac{2^n}{3^{n-1}} + 3.xn​=3(32​)n+3=3n−12n​+3.

Kontrolle

Rekursion direkt: x0=6x_0 = 6x0​=6, x1=23⋅6+1=5x_1 = \frac23\cdot 6 + 1 = 5x1​=32​⋅6+1=5, x2=103+1=133x_2 = \frac{10}{3} + 1 = \frac{13}{3}x2​=310​+1=313​, x3=269+1=359x_3 = \frac{26}{9} + 1 = \frac{35}{9}x3​=926​+1=935​, x4=7027+1=9727x_4 = \frac{70}{27} + 1 = \frac{97}{27}x4​=2770​+1=2797​.

Formel: 3+3=63 + 3 = 63+3=6,  2+3=5\ 2 + 3 = 5 2+3=5,  43+3=133\ \frac43 + 3 = \frac{13}{3} 34​+3=313​,  89+3=359\ \frac89 + 3 = \frac{35}{9} 98​+3=935​,  1627+3=9727\ \frac{16}{27} + 3 = \frac{97}{27} 2716​+3=2797​ ✓. Plausibilität: Wegen ∣23∣<1\left\vert\frac23\right\vert < 1​32​​<1 geht (23)n→0\left(\frac23\right)^n \to 0(32​)n→0; die Folge fällt monoton gegen den Fixpunkt 333.

Ergebnis
  • Allgemeine Lösung: xn=C(23)n+3x_n = C\left(\dfrac23\right)^n + 3xn​=C(32​)n+3, C∈RC \in \RC∈R.
  • Lösung mit x0=6x_0 = 6x0​=6: xn=3(23)n+3x_n = 3\left(\dfrac23\right)^n + 3xn​=3(32​)n+3.

Hilfreiches

Lösung von xn+1=a xn+bx_{n+1} = a\,x_n + bxn+1​=axn​+b, a≠1a \ne 1a=1

xn=(x0−b1−a)an+b1−a.x_n = \Bigl(x_0 - \frac{b}{1-a}\Bigr)a^n + \frac{b}{1-a}.xn​=(x0​−1−ab​)an+1−ab​. Für ∣a∣<1\vert a\vert < 1∣a∣<1 konvergiert xnx_nxn​ gegen den Fixpunkt b1−a\frac{b}{1-a}1−ab​, unabhängig vom Startwert.

Typische Fehler
  • Die Anfangsbedingung in die homogene Lösung allein einsetzen (C=6C = 6C=6) und den partikulären Anteil vergessen – richtig ist C+3=6C + 3 = 6C+3=6.
  • Den Fixpunkt falsch: x∗=b1−a=11/3=3x^* = \frac{b}{1-a} = \frac{1}{1/3} = 3x∗=1−ab​=1/31​=3, nicht 12/3\frac{1}{2/3}2/31​.
  • „Partikuläre Lösung“ verwechseln: In der Angabe ist die Lösung zum Anfangswert gemeint; die konstante Lösung 333 ist eine andere partikuläre Lösung (die zu x0=3x_0 = 3x0​=3).
