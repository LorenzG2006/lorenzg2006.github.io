Angabe Originalseite

Bestimmen Sie alle Lösungen der folgenden Kongruenzen bzw. beweisen Sie die Unlösbarkeit (in Z\ZZ).

a) x2−3x+2≡0(mod5)x^2 - 3x + 2 \equiv 0 \pmod 5x2−3x+2≡0(mod5), b) x2−3x+2≡0(mod6)x^2 - 3x + 2 \equiv 0 \pmod 6x2−3x+2≡0(mod6).

Lösung verborgen – erst selbst probieren!

Überblick

Das Polynom zerfällt: x2−3x+2=(x−1)(x−2)x^2 - 3x + 2 = (x - 1)(x - 2)x2−3x+2=(x−1)(x−2). Modulo der Primzahl 555 ist ein Produkt nur dann ≡0\equiv 0≡0, wenn ein Faktor ≡0\equiv 0≡0 ist – also genau zwei Lösungen. Modulo 666 (keine Primzahl!) gilt das nicht: Dort gibt es Nullteiler (2⋅3≡02 \cdot 3 \equiv 02⋅3≡0), und wir finden mehr Lösungen. Wir zerlegen 6=2⋅36 = 2\cdot 36=2⋅3 und untersuchen beide Primfaktoren getrennt.

Faktorisierung: (x−1)(x−2)=x2−2x−x+2=x2−3x+2(x - 1)(x - 2) = x^2 - 2x - x + 2 = x^2 - 3x + 2(x−1)(x−2)=x2−2x−x+2=x2−3x+2. ✓

Hilfreiches

Polynomkongruenzen modulo Primzahl

Modulo einer Primzahl ppp hat ein Polynom vom Grad nnn (mit Leitkoeffizient ≢0\not\equiv 0≡0) höchstens nnn Lösungen. Modulo zusammengesetzter Zahlen kann es mehr geben.

Zerlegung des Moduls

Sind m1,m2m_1, m_2m1​,m2​ teilerfremd, so gilt a≡0(modm1m2)  ⟺  a≡0(modm1)a \equiv 0 \pmod{m_1 m_2} \iff a \equiv 0 \pmod{m_1}a≡0(modm1​m2​)⟺a≡0(modm1​) und a≡0(modm2)a \equiv 0 \pmod{m_2}a≡0(modm2​) (Spezialfall des Chinesischen Restsatzes).

Typische Fehler
  • Modulo 666 wie modulo einer Primzahl argumentieren und nur x≡1,2x \equiv 1, 2x≡1,2 angeben – es fehlen 444 und 555.
  • Die Mitternachtsformel modulo mmm anwenden: Division durch 222 ist modulo 666 nicht erlaubt.
