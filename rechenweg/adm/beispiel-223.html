Angabe Originalseite

Man bestimme die allgemeine Lösung der Differenzengleichung

xn+1=xn1+xn,n=0,1,2,…x_{n+1} = \frac{x_n}{1 + x_n}, \qquad n = 0, 1, 2, \dotsxn+1​=1+xn​xn​​,n=0,1,2,…

mit x0≠−1,−1/2,−1/3,…x_0 \ne -1, -1/2, -1/3, \dotsx0​=−1,−1/2,−1/3,…. (Hinweis: Man benütze die Transformation xn=1/ynx_n = 1/y_nxn​=1/yn​.)

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Die Gleichung ist nicht linear. Nimmt man aber Kehrwerte, wird aus xn1+xn\frac{x_n}{1+x_n}1+xn​xn​​ der Ausdruck 1+xnxn=1xn+1\frac{1+x_n}{x_n} = \frac{1}{x_n} + 1xn​1+xn​​=xn​1​+1: Für yn=1/xny_n = 1/x_nyn​=1/xn​ entsteht die lineare Gleichung yn+1=yn+1y_{n+1} = y_n + 1yn+1​=yn​+1 mit Lösung yn=y0+ny_n = y_0 + nyn​=y0​+n. Zurücktransformieren liefert xnx_nxn​. Gesondert behandeln muss man den Fall x0=0x_0 = 0x0​=0 (dann ist 1/xn1/x_n1/xn​ nicht definiert) und klären, wozu die Bedingung an x0x_0x0​ dient.

Schritt 1: Der Fall x0=0x_0 = 0x0​=0

Ist x0=0x_0 = 0x0​=0, so ist x1=01=0x_1 = \frac{0}{1} = 0x1​=10​=0 und induktiv xn=0x_n = 0xn​=0 für alle nnn. Die Nullfolge ist eine Lösung.

Schritt 2: Der Fall x0≠0x_0 \ne 0x0​=0 – Transformation

Ist xn≠0x_n \ne 0xn​=0 und xn≠−1x_n \ne -1xn​=−1, so ist auch xn+1=xn1+xn≠0x_{n+1} = \frac{x_n}{1+x_n} \ne 0xn+1​=1+xn​xn​​=0. Solange die Folge definiert ist, sind also alle Glieder ≠0\ne 0=0, und wir dürfen yn:=1xny_n := \frac{1}{x_n}yn​:=xn​1​ setzen. Kehrwert der Rekursion:

yn+1=1xn+1=1+xnxn(Kehrwert von xn1+xn)=1xn+1(Bruch aufteilen)=yn+1.\begin{aligned} y_{n+1} = \frac{1}{x_{n+1}} &= \frac{1 + x_n}{x_n} && \text{(Kehrwert von } \tfrac{x_n}{1+x_n}\text{)}\\ &= \frac{1}{x_n} + 1 && \text{(Bruch aufteilen)}\\ &= y_n + 1. && \end{aligned}yn+1​=xn+1​1​​=xn​1+xn​​=xn​1​+1=yn​+1.​​(Kehrwert von 1+xn​xn​​)(Bruch aufteilen)​

Die transformierte Gleichung yn+1=yn+1y_{n+1} = y_n + 1yn+1​=yn​+1 ist linear: In jedem Schritt kommt 111 dazu, also (Induktion)

yn=y0+n=1x0+n.y_n = y_0 + n = \frac{1}{x_0} + n.yn​=y0​+n=x0​1​+n.

Schritt 3: Rücktransformation

xn=1yn=11x0+n=x01+n x0(erweitern mit x0).x_n = \frac{1}{y_n} = \frac{1}{\frac{1}{x_0} + n} = \frac{x_0}{1 + n\,x_0} \qquad (\text{erweitern mit } x_0).xn​=yn​1​=x0​1​+n1​=1+nx0​x0​​(erweitern mit x0​).

Diese Formel liefert für x0=0x_0 = 0x0​=0 auch die Nullfolge aus Schritt 1. Sie gilt daher für alle zulässigen Startwerte.

Schritt 4: Wozu die Bedingung x0≠−1/kx_0 \ne -1/kx0​=−1/k?

Die Rekursion ist nur definiert, solange 1+xn≠01 + x_n \ne 01+xn​=0, also xn≠−1x_n \ne -1xn​=−1. Aus der Formel:

1+xn=1+x01+nx0=1+(n+1)x01+nx0.1 + x_n = 1 + \frac{x_0}{1 + n x_0} = \frac{1 + (n+1)x_0}{1 + n x_0}.1+xn​=1+1+nx0​x0​​=1+nx0​1+(n+1)x0​​.

  • Ist x0=−1kx_0 = -\frac1kx0​=−k1​ für ein k∈{1,2,3,… }k \in \{1, 2, 3, \dots\}k∈{1,2,3,…}, so wird 1+k x0=01 + k\,x_0 = 01+kx0​=0, d. h. xk−1=−1x_{k-1} = -1xk−1​=−1 und xkx_kxk​ wäre eine Division durch 000. (Beispiel x0=−12x_0 = -\frac12x0​=−21​: x1=−1/21/2=−1x_1 = \frac{-1/2}{1/2} = -1x1​=1/2−1/2​=−1, und x2=−10x_2 = \frac{-1}{0}x2​=0−1​ ist undefiniert.)
  • Ist x0∉{−1,−12,−13,… }x_0 \notin \{-1, -\frac12, -\frac13, \dots\}x0​∈/{−1,−21​,−31​,…}, so ist 1+nx0≠01 + n x_0 \ne 01+nx0​=0 für alle n≥0n \ge 0n≥0 (für n=0n = 0n=0 ist der Wert 111, für n≥1n \ge 1n≥1 wäre 1+nx0=0  ⟺  x0=−1n1 + nx_0 = 0 \iff x_0 = -\frac1n1+nx0​=0⟺x0​=−n1​). Dann sind alle Nenner ≠0\ne 0=0 und die Folge ist für alle nnn definiert.

Die Bedingung in der Angabe ist also genau die Bedingung dafür, dass die Folge nie abbricht.

Ergebnis

Die allgemeine Lösung lautet xn=x01+n x0,n=0,1,2,…,x_n = \frac{x_0}{1 + n\,x_0}, \qquad n = 0, 1, 2, \dots,xn​=1+nx0​x0​​,n=0,1,2,…, mit beliebigem x0∈R∖{−1,−12,−13,… }x_0 \in \R\setminus\{-1, -\frac12, -\frac13, \dots\}x0​∈R∖{−1,−21​,−31​,…} (für x0=0x_0 = 0x0​=0 die Nullfolge). Äquivalent: xn=1C+nx_n = \dfrac{1}{C + n}xn​=C+n1​ mit C=1x0C = \frac{1}{x_0}C=x0​1​, zusammen mit xn≡0x_n \equiv 0xn​≡0.

Hilfreiches

Transformation auf eine lineare Gleichung

Rekursionen der Form xn+1=xna+b xnx_{n+1} = \frac{x_n}{a + b\,x_n}xn+1​=a+bxn​xn​​ werden durch yn=1xny_n = \frac{1}{x_n}yn​=xn​1​ linear: yn+1=a yn+by_{n+1} = a\,y_n + byn+1​=ayn​+b. Diese löst man wie in Bsp. 221/222 und transformiert zurück. Fälle, in denen die Transformation nicht erlaubt ist (xn=0x_n = 0xn​=0), gesondert betrachten.

Lineare Gleichung yn+1=yn+by_{n+1} = y_n + byn+1​=yn​+b

Lösung: yn=y0+b ny_n = y_0 + b\,nyn​=y0​+bn (arithmetische Folge).

Typische Fehler
  • Den Fall x0=0x_0 = 0x0​=0 unter den Tisch fallen lassen – dort ist yn=1/xny_n = 1/x_nyn​=1/xn​ gar nicht definiert (die Endformel deckt ihn aber mit ab).
  • Beim Kehrwert 1xn+11\frac{1}{x_n} + \frac{1}{1}xn​1​+11​ mit 1xn+1\frac{1}{x_n + 1}xn​+11​ verwechseln: 1+xnxn=1xn+1\frac{1+x_n}{x_n} = \frac{1}{x_n} + 1xn​1+xn​​=xn​1​+1.
  • Die Bedingung an x0x_0x0​ ignorieren oder falsch begründen: Sie sorgt dafür, dass nie xn=−1x_n = -1xn​=−1 auftritt.
