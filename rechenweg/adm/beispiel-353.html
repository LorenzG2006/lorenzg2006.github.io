Angabe Originalseite

Untersuchen Sie, ob die Menge MMM mit der Operation ∘\circ∘ ein Gruppoid, eine Halbgruppe, ein Monoid bzw. eine Gruppe ist:

M=P(A)M = \mathcal P(A)M=P(A), d. h. die Potenzmenge der Menge AAA, B∘C=B∪CB \circ C = B \cup CB∘C=B∪C.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

P(A)\mathcal P(A)P(A) ist die Menge aller Teilmengen von AAA. Wir prüfen die Axiome mit den Gesetzen der Mengenalgebra: Abgeschlossenheit, Assoziativität von ∪\cup∪, neutrales Element (welche Menge ändert beim Vereinigen nichts?) und Inverse (kann man eine Vereinigung „rückgängig machen“?).

Gruppoid

Sind B,C⊆AB, C \subseteq AB,C⊆A, so ist auch B∪C⊆AB\cup C \subseteq AB∪C⊆A (jedes Element von B∪CB\cup CB∪C liegt in BBB oder in CCC, also in AAA). ⇒ B∪C∈P(A)B\cup C \in \mathcal P(A)B∪C∈P(A), Gruppoid ✓.

Halbgruppe

Für alle Mengen gilt (B∪C)∪D=B∪(C∪D)(B\cup C)\cup D = B\cup(C\cup D)(B∪C)∪D=B∪(C∪D): Beide Seiten enthalten genau die Elemente, die in mindestens einer der drei Mengen B,C,DB, C, DB,C,D liegen. ⇒ Halbgruppe ✓. (Auch kommutativ: B∪C=C∪BB\cup C = C\cup BB∪C=C∪B.)

Monoid

∅∈P(A)\emptyset \in \mathcal P(A)∅∈P(A) und B∪∅=∅∪B=BB\cup\emptyset = \emptyset\cup B = BB∪∅=∅∪B=B ⇒ neutrales Element ∅\emptyset∅, Monoid ✓.

Gruppe

Ein Inverses CCC zu BBB müsste B∪C=∅B\cup C = \emptysetB∪C=∅ erfüllen. Wegen B⊆B∪CB \subseteq B\cup CB⊆B∪C folgt dann B=∅B = \emptysetB=∅. Also besitzt nur ∅\emptyset∅ ein Inverses (nämlich ∅\emptyset∅ selbst).

  • Ist A≠∅A \ne \emptysetA=∅, so ist z. B. B=AB = AB=A eine nichtleere Teilmenge ohne Inverses ⇒ keine Gruppe.
  • Nur im Sonderfall A=∅A = \emptysetA=∅ ist P(A)={∅}\mathcal P(A) = \{\emptyset\}P(A)={∅} die triviale Gruppe.
Kontrolle

Python für A={1,2}A = \{1,2\}A={1,2} (444 Teilmengen): alle 646464 Tripel assoziativ, einziges neutrales Element ∅\emptyset∅, und B∪C=∅B\cup C = \emptysetB∪C=∅ nur für B=C=∅B = C = \emptysetB=C=∅ ✓.

Ergebnis

(P(A),∪)(\mathcal P(A), \cup)(P(A),∪) ist ein kommutatives Monoid mit neutralem Element ∅\emptyset∅. Für A≠∅A \ne\emptysetA=∅ ist es keine Gruppe (nur ∅\emptyset∅ ist invertierbar); für A=∅A = \emptysetA=∅ liegt die triviale Gruppe {∅}\{\emptyset\}{∅} vor.

Hilfreiches

Gesetze der Vereinigung

Assoziativ, kommutativ, idempotent (B∪B=BB\cup B = BB∪B=B), B∪∅=BB\cup\emptyset = BB∪∅=B, B⊆B∪CB \subseteq B\cup CB⊆B∪C.

Idempotenz und Gruppen

In einer Gruppe folgt aus x∘x=xx\circ x = xx∘x=x schon x=ex = ex=e (Bsp. 373). Da hier B∪B=BB\cup B = BB∪B=B für jedes BBB gilt, kann (P(A),∪)(\mathcal P(A),\cup)(P(A),∪) nur dann eine Gruppe sein, wenn es ein einziges Element gibt.

Typische Fehler
  • Das Komplement A∖BA\setminus BA∖B für das Inverse halten: B∪(A∖B)=AB\cup(A\setminus B) = AB∪(A∖B)=A, nicht ∅\emptyset∅.
  • AAA selbst als neutrales Element ansehen – AAA ist bezüglich ∪\cup∪ absorbierend.
