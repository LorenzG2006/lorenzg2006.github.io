Wieviele natürliche Zahlen nnn mit 1≤n≤1061 \le n \le 10^61≤n≤106 gibt es, die weder Quadrat, noch dritte, vierte oder fünfte Potenz einer natürlichen Zahl sind?

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Wir zählen das Komplement: alle 10610^6106 Zahlen minus jene, die eine Quadratzahl, dritte, vierte oder fünfte Potenz sind. Die Größe dieser Vereinigung liefert Inklusion-Exklusion. Zwei Beobachtungen machen die Rechnung kurz:

  1. Jede vierte Potenz ist auch ein Quadrat (a4=(a2)2a^4 = (a^2)^2a4=(a2)2) – die vierten Potenzen fallen also gar nicht ins Gewicht.
  2. Eine Zahl ist zugleich kkk-te und ℓ\ellℓ-te Potenz genau dann, wenn sie eine kgV⁡(k,ℓ)\kgV(k, \ell)kgV(k,ℓ)-te Potenz ist.

Die Anzahl der kkk-ten Potenzen in {1,…,N}\{1, \dots, N\}{1,…,N} ist ⌊N1/k⌋\lfloor N^{1/k}\rfloor⌊N1/k⌋.

Sei M={1,2,…,106}M = \{1, 2, \dots, 10^6\}M={1,2,…,106} und für k≥2k \ge 2k≥2

Pk={n∈M:n=ak fu¨r ein a∈N}.P_k = \{n \in M : n = a^k \text{ für ein } a \in \N\}.Pk​={n∈M:n=ak fu¨r ein a∈N}.

Gesucht ist ∣M∖(P2∪P3∪P4∪P5)∣\vert M \setminus (P_2 \cup P_3 \cup P_4 \cup P_5)\vert∣M∖(P2​∪P3​∪P4​∪P5​)∣. (Die Zahl 1=1k1 = 1^k1=1k ist für jedes kkk eine kkk-te Potenz und liegt in allen PkP_kPk​.)

Schritt 1: Vierte Potenzen weglassen

Ist n=a4n = a^4n=a4, so ist n=(a2)2n = (a^2)^2n=(a2)2 ein Quadrat. Also P4⊆P2P_4 \subseteq P_2P4​⊆P2​ und damit

P2∪P3∪P4∪P5=P2∪P3∪P5.P_2 \cup P_3 \cup P_4 \cup P_5 = P_2 \cup P_3 \cup P_5.P2​∪P3​∪P4​∪P5​=P2​∪P3​∪P5​.

Schritt 2: Durchschnitte bestimmen

Behauptung: Pk∩Pℓ=PkgV⁡(k,ℓ)P_k \cap P_\ell = P_{\kgV(k,\ell)}Pk​∩Pℓ​=PkgV(k,ℓ)​.

  • „⊇\supseteq⊇“: Ist m=kgV⁡(k,ℓ)m = \kgV(k, \ell)m=kgV(k,ℓ) und n=amn = a^mn=am, so ist n=(am/k)k=(am/ℓ)ℓn = (a^{m/k})^k = (a^{m/\ell})^\elln=(am/k)k=(am/ℓ)ℓ.
  • „⊆\subseteq⊆“: Ist n=bk=cℓn = b^k = c^\elln=bk=cℓ, so betrachten wir die Primfaktorzerlegung n=∏pepn = \prod p^{e_p}n=∏pep​. Aus n=bkn = b^kn=bk folgt, dass jeder Exponent epe_pep​ durch kkk teilbar ist; aus n=cℓn = c^\elln=cℓ, dass er durch ℓ\ellℓ teilbar ist. Also ist jedes epe_pep​ durch kgV⁡(k,ℓ)\kgV(k, \ell)kgV(k,ℓ) teilbar, d. h. n=(∏pep/m)mn = \bigl(\prod p^{e_p/m}\bigr)^mn=(∏pep​/m)m ist eine mmm-te Potenz.

Damit: P2∩P3=P6P_2 \cap P_3 = P_6P2​∩P3​=P6​, P2∩P5=P10P_2 \cap P_5 = P_{10}P2​∩P5​=P10​, P3∩P5=P15P_3 \cap P_5 = P_{15}P3​∩P5​=P15​, P2∩P3∩P5=P30P_2 \cap P_3 \cap P_5 = P_{30}P2​∩P3​∩P5​=P30​.

Schritt 4: Inklusion-Exklusion

∣P2∪P3∪P5∣=∣P2∣+∣P3∣+∣P5∣−∣P6∣−∣P10∣−∣P15∣+∣P30∣(Inklusion-Exklusion)=1000+100+15−10−3−2+1(Tabelle)=1101.\begin{aligned} \vert P_2\cup P_3\cup P_5\vert &= \vert P_2\vert + \vert P_3\vert + \vert P_5\vert - \vert P_6\vert - \vert P_{10}\vert - \vert P_{15}\vert + \vert P_{30}\vert && \text{(Inklusion-Exklusion)}\\ &= 1000 + 100 + 15 - 10 - 3 - 2 + 1 && \text{(Tabelle)}\\ &= 1101. \end{aligned}∣P2​∪P3​∪P5​∣​=∣P2​∣+∣P3​∣+∣P5​∣−∣P6​∣−∣P10​∣−∣P15​∣+∣P30​∣=1000+100+15−10−3−2+1=1101.​​(Inklusion-Exklusion)(Tabelle)​

Gesuchte Anzahl:

106−1101=998 899.10^6 - 1101 = 998\,899.106−1101=998899.

Kontrolle
  • Python-Brute-Force: Für jedes n≤106n \le 10^6n≤106 wird geprüft, ob nnn eine 2., 3., 4. oder 5. Potenz ist – es bleiben genau 998 899998\,899998899 Zahlen ✓.
  • Rechnet man stur mit allen vier Mengen P2,P3,P4,P5P_2, P_3, P_4, P_5P2​,P3​,P4​,P5​ (also 151515 Terme), kommt dasselbe heraus, weil sich wegen P4⊆P2P_4 \subseteq P_2P4​⊆P2​ alle Terme mit P4P_4P4​ gegenseitig aufheben.

Hilfreiches

Inklusions-Exklusions-Prinzip

∣⋃i=1rAi∣=∑∅≠I⊆{1,…,r}(−1)∣I∣+1∣⋂i∈IAi∣.\Bigl\vert \bigcup_{i=1}^{r} A_i\Bigr\vert = \sum_{\emptyset \ne I \subseteq \{1,\dots,r\}}(-1)^{\vert I\vert + 1}\Bigl\vert\bigcap_{i \in I}A_i\Bigr\vert.​i=1⋃r​Ai​​=∅=I⊆{1,…,r}∑​(−1)∣I∣+1​i∈I⋂​Ai​​.

Potenzen zählen
  • In {1,…,N}\{1, \dots, N\}{1,…,N} gibt es genau ⌊N1/k⌋\lfloor N^{1/k}\rfloor⌊N1/k⌋ kkk-te Potenzen.
  • nnn ist kkk-te und ℓ\ellℓ-te Potenz   ⟺  \iff⟺ nnn ist kgV⁡(k,ℓ)\kgV(k,\ell)kgV(k,ℓ)-te Potenz.
  • Ist k∣mk \mid mk∣m, so ist jede mmm-te Potenz auch eine kkk-te Potenz.
Typische Fehler
  • P2∩P3P_2 \cap P_3P2​∩P3​ als P5P_5P5​ (Exponenten addiert) statt P6P_6P6​ (kgV⁡\kgVkgV) ansetzen.
  • Die vierten Potenzen als eigene Menge mitzählen, ohne die Durchschnitte mit P2P_2P2​ korrekt abzuziehen – dann werden sie doppelt gezählt.
  • Die Zahl 111 vergessen: Sie ist Potenz jeder Ordnung und muss ebenfalls ausgeschlossen werden (sie steckt in jedem PkP_kPk​).
  • ⌊106/5⌋\lfloor 10^{6/5}\rfloor⌊106/5⌋ falsch schätzen: 101,2≈15,8510^{1{,}2} \approx 15{,}85101,2≈15,85, also 151515.
