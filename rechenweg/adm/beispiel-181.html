Angabe Originalseite

Zeigen Sie die Formel von Vandermonde aus Bsp. 180 mit Hilfe kombinatorischer Deutung.

(Bsp. 180: Für x,y,n∈Nx, y, n \in \Nx,y,n∈N gilt (x+yn)=∑k=0n(xk)(yn−k)\binom{x+y}{n} = \sum_{k=0}^{n}\binom{x}{k}\binom{y}{n-k}(nx+y​)=∑k=0n​(kx​)(n−ky​).)

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Wir zählen dieselbe Menge auf zwei Arten (doppeltes Abzählen): die nnn-elementigen Teilmengen einer Menge, die aus xxx „roten“ und yyy „blauen“ Elementen besteht. Direkt gezählt sind es (x+yn)\binom{x+y}{n}(nx+y​). Sortieren wir nach der Anzahl kkk der roten Elemente in der Teilmenge, so gibt es für jedes kkk genau (xk)(yn−k)\binom{x}{k}\binom{y}{n-k}(kx​)(n−ky​) Teilmengen; Summieren über kkk ergibt die rechte Seite.

Aufbau

Seien x,y,n∈Nx, y, n \in \Nx,y,n∈N. Wir wählen zwei disjunkte Mengen

R={r1,…,rx} (rot),B={b1,…,by} (blau),R∩B=∅,R = \{r_1, \dots, r_x\} \ (\text{rot}), \qquad B = \{b_1, \dots, b_y\} \ (\text{blau}), \qquad R \cap B = \emptyset,R={r1​,…,rx​} (rot),B={b1​,…,by​} (blau),R∩B=∅,

und setzen M=R∪BM = R \cup BM=R∪B, also ∣M∣=x+y\vert M\vert = x + y∣M∣=x+y. Sei

T={ T⊆M:∣T∣=n }.\mathcal{T} = \{\, T \subseteq M : \vert T\vert = n \,\}.T={T⊆M:∣T∣=n}.

(Anschaulich: Aus einer Gruppe von xxx Frauen und yyy Männern wird ein Komitee aus nnn Personen gebildet.)

Erste Zählung: direkt

T\mathcal{T}T besteht aus den nnn-elementigen Teilmengen einer (x+y)(x+y)(x+y)-elementigen Menge, also

∣T∣=(x+yn).\vert\mathcal{T}\vert = \binom{x+y}{n}.∣T∣=(nx+y​).

Zweite Zählung: nach der Anzahl roter Elemente

Für T∈TT \in \mathcal{T}T∈T sei k=∣T∩R∣k = \vert T \cap R\vertk=∣T∩R∣ die Anzahl der roten Elemente. Da T=(T∩R) ∪˙ (T∩B)T = (T \cap R) \,\dot\cup\, (T \cap B)T=(T∩R)∪˙(T∩B) (disjunkt, weil R∩B=∅R \cap B = \emptysetR∩B=∅), ist ∣T∩B∣=n−k\vert T \cap B\vert = n - k∣T∩B∣=n−k, und es gilt 0≤k≤n0 \le k \le n0≤k≤n. Damit zerfällt

T=T0 ∪˙ T1 ∪˙ ⋯ ∪˙ Tn,Tk={T∈T:∣T∩R∣=k},\mathcal{T} = \mathcal{T}_0 \,\dot\cup\, \mathcal{T}_1 \,\dot\cup\, \cdots \,\dot\cup\, \mathcal{T}_n, \qquad \mathcal{T}_k = \{T \in \mathcal{T} : \vert T \cap R\vert = k\},T=T0​∪˙T1​∪˙⋯∪˙Tn​,Tk​={T∈T:∣T∩R∣=k},

disjunkt (jedes TTT hat genau einen Wert kkk).

Größe von Tk\mathcal{T}_kTk​. Die Abbildung

Tk→{k-Teilmengen von R}×{(n−k)-Teilmengen von B},T↦(T∩R, T∩B)\mathcal{T}_k \to \{\text{$k$-Teilmengen von } R\} \times \{\text{$(n-k)$-Teilmengen von } B\}, \qquad T \mapsto (T \cap R,\ T \cap B)Tk​→{k-Teilmengen von R}×{(n−k)-Teilmengen von B},T↦(T∩R, T∩B)

ist bijektiv: Ihre Umkehrung ist (S1,S2)↦S1∪S2(S_1, S_2) \mapsto S_1 \cup S_2(S1​,S2​)↦S1​∪S2​ (die Vereinigung einer kkk-Teilmenge von RRR und einer (n−k)(n-k)(n−k)-Teilmenge von BBB hat wegen der Disjunktheit genau nnn Elemente, davon kkk rote). Nach der Produktregel

∣Tk∣=(xk)(yn−k).\vert\mathcal{T}_k\vert = \binom{x}{k}\binom{y}{n-k}.∣Tk​∣=(kx​)(n−ky​).

Ist k>xk > xk>x oder n−k>yn - k > yn−k>y, gibt es keine solchen Teilmengen – und genau dann ist (xk)=0\binom{x}{k} = 0(kx​)=0 bzw. (yn−k)=0\binom{y}{n-k} = 0(n−ky​)=0. Die Formel stimmt also für alle k=0,…,nk = 0, \dots, nk=0,…,n.

Summenregel:

∣T∣=∑k=0n∣Tk∣=∑k=0n(xk)(yn−k).\vert\mathcal{T}\vert = \sum_{k=0}^{n}\vert\mathcal{T}_k\vert = \sum_{k=0}^{n}\binom{x}{k}\binom{y}{n-k}.∣T∣=k=0∑n​∣Tk​∣=k=0∑n​(kx​)(n−ky​).

Vergleich

Beide Zählungen bestimmen die Mächtigkeit derselben Menge T\mathcal{T}T, also

(x+yn)=∑k=0n(xk)(yn−k).\binom{x+y}{n} = \sum_{k=0}^{n}\binom{x}{k}\binom{y}{n-k}.(nx+y​)=k=0∑n​(kx​)(n−ky​).

x=3x = 3x=3 Frauen, y=2y = 2y=2 Männer, Komitee aus n=2n = 2n=2

Insgesamt (52)=10\binom{5}{2} = 10(25​)=10 Komitees. Nach Frauenanzahl:

  • k=0k = 0k=0: zwei Männer: (30)(22)=1\binom{3}{0}\binom{2}{2} = 1(03​)(22​)=1,
  • k=1k = 1k=1: eine Frau, ein Mann: (31)(21)=6\binom{3}{1}\binom{2}{1} = 6(13​)(12​)=6,
  • k=2k = 2k=2: zwei Frauen: (32)(20)=3\binom{3}{2}\binom{2}{0} = 3(23​)(02​)=3.

1+6+3=101 + 6 + 3 = 101+6+3=10 ✓.

Kontrolle

Für x=4x = 4x=4, y=3y = 3y=3, n=3n = 3n=3: (73)=35\binom{7}{3} = 35(37​)=35 und (40)(33)+(41)(32)+(42)(31)+(43)(30)=1+12+18+4=35\binom{4}{0}\binom{3}{3} + \binom{4}{1}\binom{3}{2} + \binom{4}{2}\binom{3}{1} + \binom{4}{3}\binom{3}{0} = 1 + 12 + 18 + 4 = 35(04​)(33​)+(14​)(23​)+(24​)(13​)+(34​)(03​)=1+12+18+4=35 ✓.

Ergebnis

Die nnn-Teilmengen einer Menge aus xxx roten und yyy blauen Elementen werden einmal direkt ((x+yn)\binom{x+y}{n}(nx+y​)) und einmal nach der Anzahl kkk roter Elemente sortiert ((xk)(yn−k)\binom{x}{k}\binom{y}{n-k}(kx​)(n−ky​) für jedes kkk) gezählt. Daraus folgt (x+yn)=∑k=0n(xk)(yn−k).■\binom{x+y}{n} = \sum_{k=0}^{n}\binom{x}{k}\binom{y}{n-k}. \qquad \blacksquare(nx+y​)=k=0∑n​(kx​)(n−ky​).■

Hilfreiches

Doppeltes Abzählen

Um A=BA = BA=B für zwei Zahlausdrücke zu zeigen, sucht man eine Menge, deren Mächtigkeit sich auf eine Weise als AAA und auf eine andere Weise als BBB berechnen lässt. Eine Summe auf einer Seite deutet meist auf eine Fallunterscheidung (disjunkte Zerlegung) hin.

Summen- und Produktregel
  • Disjunkte Vereinigung: ∣A0 ∪˙ ⋯ ∪˙ An∣=∑∣Ak∣\vert A_0 \,\dot\cup\, \cdots \,\dot\cup\, A_n\vert = \sum \vert A_k\vert∣A0​∪˙⋯∪˙An​∣=∑∣Ak​∣.
  • Kartesisches Produkt: ∣A×B∣=∣A∣⋅∣B∣\vert A \times B\vert = \vert A\vert \cdot \vert B\vert∣A×B∣=∣A∣⋅∣B∣.
Typische Fehler
  • Vergessen, dass RRR und BBB disjunkt sein müssen – sonst ist ∣R∪B∣≠x+y\vert R \cup B\vert \neq x + y∣R∪B∣=x+y.
  • Die Fälle nicht disjunkt wählen (z. B. „mindestens kkk rote“) – dann darf man nicht addieren.
  • Die Randfälle k>xk > xk>x bzw. n−k>yn - k > yn−k>y nicht kommentieren.

Verwandte Beispiele: Bsp. 180 (algebraischer Beweis), Bsp. 179, Bsp. 159, Bsp. 171.
