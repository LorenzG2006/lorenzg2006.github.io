Angabe Originalseite

18–21) Man untersuche mittels vollständiger Induktion, für welche n≥0n \ge 0n≥0 die angegebene Ungleichung gilt:

3n+2n≤3n3n + 2^n \le 3^n3n+2n≤3n

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Wertetabelle für kleine nnn, dann Induktion ab der Schwelle. Im Schritt multiplizieren wir die IV mit 3: 3n+1≥9n+3⋅2n3^{n+1} \ge 9n + 3\cdot 2^n3n+1≥9n+3⋅2n, und vergleichen mit der Zielseite 3(n+1)+2n+1=3n+3+2⋅2n3(n+1) + 2^{n+1} = 3n + 3 + 2\cdot 2^n3(n+1)+2n+1=3n+3+2⋅2n.

Vermutung: Die Ungleichung gilt für n=0n = 0n=0 und alle n≥3n \ge 3n≥3; für n=1,2n = 1, 2n=1,2 ist sie falsch.

Induktionsbeweis für n ≥ 3

Induktionsanfang (n=3n = 3n=3): 9+8=17≤27=339 + 8 = 17 \le 27 = 3^39+8=17≤27=33. ✓

Induktionsvoraussetzung (IV): Für ein festes, aber beliebiges n≥3n \ge 3n≥3 gelte 3n+2n≤3n3n + 2^n \le 3^n3n+2n≤3n.

Induktionsbehauptung: 3(n+1)+2n+1≤3n+13(n+1) + 2^{n+1} \le 3^{n+1}3(n+1)+2n+1≤3n+1.

Induktionsschritt (n→n+1n \to n+1n→n+1):

3n+1=3⋅3n(Potenzregel)≥3 (3n+2n)=9n+3⋅2n(IV, mit 3 multipliziert)=(3n+3+2⋅2n)+(6n−3+2n)(geschickt aufteilen)≥3n+3+2⋅2n(da 6n−3+2n>0 fu¨r n≥1)=3(n+1)+2n+1.(2⋅2n=2n+1)\begin{aligned} 3^{n+1} &= 3 \cdot 3^n && \text{(Potenzregel)}\\ &\ge 3\,(3n + 2^n) = 9n + 3 \cdot 2^n && \text{(IV, mit 3 multipliziert)}\\ &= (3n + 3 + 2 \cdot 2^n) + (6n - 3 + 2^n) && \text{(geschickt aufteilen)}\\ &\ge 3n + 3 + 2 \cdot 2^n && \text{(da } 6n - 3 + 2^n > 0 \text{ für } n \ge 1\text{)}\\ &= 3(n+1) + 2^{n+1}. && \text{(}2 \cdot 2^n = 2^{n+1}\text{)} \end{aligned}3n+1​=3⋅3n≥3(3n+2n)=9n+3⋅2n=(3n+3+2⋅2n)+(6n−3+2n)≥3n+3+2⋅2n=3(n+1)+2n+1.​​(Potenzregel)(IV, mit 3 multipliziert)(geschickt aufteilen)(da 6n−3+2n>0 fu¨r n≥1)(2⋅2n=2n+1)​

Zur Aufteilung: (3n+3+2⋅2n)+(6n−3+2n)=9n+3⋅2n(3n + 3 + 2\cdot 2^n) + (6n - 3 + 2^n) = 9n + 3\cdot 2^n(3n+3+2⋅2n)+(6n−3+2n)=9n+3⋅2n ✓. Der zweite Klammerausdruck ist für n≥3n \ge 3n≥3 sicher positiv (6n−3≥156n - 3 \ge 156n−3≥15).

Damit gilt die Ungleichung für alle n≥3n \ge 3n≥3.

Ergebnis

3n+2n≤3n⟺n=0  oder  n≥3.3n + 2^n \le 3^n \quad\Longleftrightarrow\quad n = 0 \ \text{ oder } \ n \ge 3.3n+2n≤3n⟺n=0  oder  n≥3. Für n=1n = 1n=1 und n=2n = 2n=2 ist sie falsch (5>35 > 35>3, 10>910 > 910>9). ■\blacksquare■

Hilfreiches

Differenz abschätzen

Statt nach einem passenden Trick zu suchen, berechnet man „neue untere Schranke minus Ziel“: (9n+3⋅2n)−(3n+3+2⋅2n)=6n−3+2n(9n + 3\cdot 2^n) - (3n + 3 + 2\cdot 2^n) = 6n - 3 + 2^n(9n+3⋅2n)−(3n+3+2⋅2n)=6n−3+2n, und zeigt, dass diese Differenz ≥0\ge 0≥0 ist.
