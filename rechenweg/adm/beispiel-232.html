Angabe Originalseite

Gesucht sind die allgemeinen Lösungen der linearen homogenen Differenzengleichungen

(a)xn+2+12xn+1+36xn=0,(b)xn+2−2xn+1+5xn=0,(c)xn+2+11xn+1+28xn=0.\begin{aligned} &(a) \quad x_{n+2} + 12x_{n+1} + 36x_n = 0,\\ &(b) \quad x_{n+2} - 2x_{n+1} + 5x_n = 0,\\ &(c) \quad x_{n+2} + 11x_{n+1} + 28x_n = 0. \end{aligned}​(a)xn+2​+12xn+1​+36xn​=0,(b)xn+2​−2xn+1​+5xn​=0,(c)xn+2​+11xn+1​+28xn​=0.​

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Ansatz xn=λnx_n = \lambda^nxn​=λn liefert die charakteristische Gleichung λ2+pλ+q=0\lambda^2 + p\lambda + q = 0λ2+pλ+q=0. Teil (a) hat eine doppelte, Teil (b) konjugiert komplexe, Teil (c) zwei verschiedene reelle Wurzeln. Negative Wurzeln sind kein Problem: (−6)n(-6)^n(−6)n wechselt einfach in jedem Schritt das Vorzeichen.

(a) xn+2+12xn+1+36xn=0x_{n+2} + 12x_{n+1} + 36x_n = 0xn+2​+12xn+1​+36xn​=0

Charakteristische Gleichung: λ2+12λ+36=0\lambda^2 + 12\lambda + 36 = 0λ2+12λ+36=0, Diskriminante 144−144=0144 - 144 = 0144−144=0:

λ2+12λ+36=(λ+6)2  ⟹  λ=−6 (doppelt).\lambda^2 + 12\lambda + 36 = (\lambda + 6)^2 \implies \lambda = -6 \text{ (doppelt)}.λ2+12λ+36=(λ+6)2⟹λ=−6 (doppelt).

Lösungen sind (−6)n(-6)^n(−6)n und n(−6)nn(-6)^nn(−6)n. Probe für n(−6)nn(-6)^nn(−6)n:

(−6)n[36(n+2)+12⋅(−6)(n+1)+36n]=(−6)n[36n+72−72n−72+36n]=0  ✓(-6)^n\bigl[36(n+2) + 12\cdot(-6)(n+1) + 36n\bigr] = (-6)^n\bigl[36n + 72 - 72n - 72 + 36n\bigr] = 0 \;✓(−6)n[36(n+2)+12⋅(−6)(n+1)+36n]=(−6)n[36n+72−72n−72+36n]=0✓

Allgemeine Lösung:

xn=(C1+C2 n)(−6)n.x_n = (C_1 + C_2\,n)(-6)^n.xn​=(C1​+C2​n)(−6)n.

(b) xn+2−2xn+1+5xn=0x_{n+2} - 2x_{n+1} + 5x_n = 0xn+2​−2xn+1​+5xn​=0

Charakteristische Gleichung: λ2−2λ+5=0\lambda^2 - 2\lambda + 5 = 0λ2−2λ+5=0, Diskriminante 4−20=−16<04 - 20 = -16 < 04−20=−16<0:

λ1,2=2±−162=2±4i2=1±2i.\lambda_{1,2} = \frac{2 \pm \sqrt{-16}}{2} = \frac{2 \pm 4i}{2} = 1 \pm 2i.λ1,2​=22±−16​​=22±4i​=1±2i.

Polardarstellung: r=12+22=5r = \sqrt{1^2 + 2^2} = \sqrt5r=12+22​=5​, und wegen cos⁡φ=15>0\cos\varphi = \frac{1}{\sqrt5} > 0cosφ=5​1​>0, sin⁡φ=25>0\sin\varphi = \frac{2}{\sqrt5} > 0sinφ=5​2​>0 (erster Quadrant)

φ=arctan⁡2≈1,1071 (≈63,43∘).\varphi = \arctan 2 \approx 1{,}1071 \ (\approx 63{,}43^\circ).φ=arctan2≈1,1071 (≈63,43∘).

Also λ1,2=[5,±arctan⁡2]\lambda_{1,2} = [\sqrt5, \pm\arctan 2]λ1,2​=[5​,±arctan2]. Mit de Moivre ist λ1n=5n/2(cos⁡nφ+isin⁡nφ)\lambda_1^n = 5^{n/2}(\cos n\varphi + i\sin n\varphi)λ1n​=5n/2(cosnφ+isinnφ); Real- und Imaginärteil sind reelle Lösungen. Allgemeine reelle Lösung:

xn=5n/2(C1cos⁡(nφ)+C2sin⁡(nφ)),φ=arctan⁡2.x_n = 5^{n/2}\bigl(C_1\cos(n\varphi) + C_2\sin(n\varphi)\bigr), \qquad \varphi = \arctan 2.xn​=5n/2(C1​cos(nφ)+C2​sin(nφ)),φ=arctan2.

(Der Winkel ist kein „schöner“ Bruchteil von π\piπ; man lässt ihn als arctan⁡2\arctan 2arctan2 stehen. Komplex: xn=D1(1+2i)n+D2(1−2i)nx_n = D_1(1+2i)^n + D_2(1-2i)^nxn​=D1​(1+2i)n+D2​(1−2i)n.)

(c) xn+2+11xn+1+28xn=0x_{n+2} + 11x_{n+1} + 28x_n = 0xn+2​+11xn+1​+28xn​=0

Charakteristische Gleichung: λ2+11λ+28=0\lambda^2 + 11\lambda + 28 = 0λ2+11λ+28=0:

λ1,2=−11±121−1122=−11±32  ⟹  λ1=−4,λ2=−7.\lambda_{1,2} = \frac{-11 \pm \sqrt{121 - 112}}{2} = \frac{-11 \pm 3}{2} \implies \lambda_1 = -4,\quad \lambda_2 = -7.λ1,2​=2−11±121−112​​=2−11±3​⟹λ1​=−4,λ2​=−7.

(Probe: (λ+4)(λ+7)=λ2+11λ+28(\lambda + 4)(\lambda + 7) = \lambda^2 + 11\lambda + 28(λ+4)(λ+7)=λ2+11λ+28 ✓.) Allgemeine Lösung:
