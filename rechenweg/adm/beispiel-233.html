Angabe Originalseite

Gesucht sind die allgemeinen Lösungen der linearen homogenen Differenzengleichungen

(a)xn+2+3xn+1+2xn=0,(b)xn+2−6xn+1+25xn=0,(c)xn+2+11xn+1+30.25xn=0.\begin{aligned} &(a) \quad x_{n+2} + 3x_{n+1} + 2x_n = 0,\\ &(b) \quad x_{n+2} - 6x_{n+1} + 25x_n = 0,\\ &(c) \quad x_{n+2} + 11x_{n+1} + 30.25x_n = 0. \end{aligned}​(a)xn+2​+3xn+1​+2xn​=0,(b)xn+2​−6xn+1​+25xn​=0,(c)xn+2​+11xn+1​+30.25xn​=0.​

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Der Ansatz xn=λnx_n = \lambda^nxn​=λn ergibt die charakteristische Gleichung λ2+pλ+q=0\lambda^2 + p\lambda + q = 0λ2+pλ+q=0. In (a) gibt es zwei verschiedene reelle, in (b) konjugiert komplexe Wurzeln, in (c) eine doppelte Wurzel. Daraus liest man die allgemeine Lösung nach dem Standardsatz ab (siehe Hilfreiches).

(a) xn+2+3xn+1+2xn=0x_{n+2} + 3x_{n+1} + 2x_n = 0xn+2​+3xn+1​+2xn​=0

Charakteristische Gleichung: λ2+3λ+2=0\lambda^2 + 3\lambda + 2 = 0λ2+3λ+2=0:

λ1,2=−3±9−82=−3±12  ⟹  λ1=−1,λ2=−2.\lambda_{1,2} = \frac{-3 \pm \sqrt{9 - 8}}{2} = \frac{-3 \pm 1}{2} \implies \lambda_1 = -1,\quad \lambda_2 = -2.λ1,2​=2−3±9−8​​=2−3±1​⟹λ1​=−1,λ2​=−2.

(Probe: (λ+1)(λ+2)=λ2+3λ+2(\lambda + 1)(\lambda + 2) = \lambda^2 + 3\lambda + 2(λ+1)(λ+2)=λ2+3λ+2 ✓.) Allgemeine Lösung:

xn=C1(−1)n+C2(−2)n.x_n = C_1(-1)^n + C_2(-2)^n.xn​=C1​(−1)n+C2​(−2)n.

Probe: (−1)n(1−3+2)=0(-1)^n(1 - 3 + 2) = 0(−1)n(1−3+2)=0 ✓, (−2)n(4−6+2)=0(-2)^n(4 - 6 + 2) = 0(−2)n(4−6+2)=0 ✓.

(b) xn+2−6xn+1+25xn=0x_{n+2} - 6x_{n+1} + 25x_n = 0xn+2​−6xn+1​+25xn​=0

Charakteristische Gleichung: λ2−6λ+25=0\lambda^2 - 6\lambda + 25 = 0λ2−6λ+25=0, Diskriminante 36−100=−64<036 - 100 = -64 < 036−100=−64<0:

λ1,2=6±8i2=3±4i.\lambda_{1,2} = \frac{6 \pm 8i}{2} = 3 \pm 4i.λ1,2​=26±8i​=3±4i.

Polardarstellung: r=32+42=5r = \sqrt{3^2 + 4^2} = 5r=32+42​=5; cos⁡φ=35\cos\varphi = \frac35cosφ=53​, sin⁡φ=45\sin\varphi = \frac45sinφ=54​ (erster Quadrant), also

φ=arctan⁡43≈0,9273 (≈53,13∘).\varphi = \arctan\frac43 \approx 0{,}9273 \ (\approx 53{,}13^\circ).φ=arctan34​≈0,9273 (≈53,13∘).

Somit λ1,2=[5,±φ]\lambda_{1,2} = [5, \pm\varphi]λ1,2​=[5,±φ] und nach de Moivre λ1n=5n(cos⁡nφ+isin⁡nφ)\lambda_1^n = 5^n(\cos n\varphi + i\sin n\varphi)λ1n​=5n(cosnφ+isinnφ). Allgemeine reelle Lösung:

xn=5n(C1cos⁡(nφ)+C2sin⁡(nφ)),φ=arctan⁡43.x_n = 5^n\bigl(C_1\cos(n\varphi) + C_2\sin(n\varphi)\bigr), \qquad \varphi = \arctan\frac43.xn​=5n(C1​cos(nφ)+C2​sin(nφ)),φ=arctan34​.

(Komplex: xn=D1(3+4i)n+D2(3−4i)nx_n = D_1(3+4i)^n + D_2(3-4i)^nxn​=D1​(3+4i)n+D2​(3−4i)n.)

(c) xn+2+11xn+1+30.25xn=0x_{n+2} + 11x_{n+1} + 30.25x_n = 0xn+2​+11xn+1​+30.25xn​=0

Charakteristische Gleichung: λ2+11λ+30.25=0\lambda^2 + 11\lambda + 30.25 = 0λ2+11λ+30.25=0, Diskriminante 121−4⋅30.25=121−121=0121 - 4\cdot 30.25 = 121 - 121 = 0121−4⋅30.25=121−121=0:

λ2+11λ+1214=(λ+112)2  ⟹  λ=−112 (doppelt).\lambda^2 + 11\lambda + \tfrac{121}{4} = \Bigl(\lambda + \tfrac{11}{2}\Bigr)^2 \implies \lambda = -\tfrac{11}{2} \text{ (doppelt)}.λ2+11λ+4121​=(λ+211​)2⟹λ=−211​ (doppelt).

Neben (−112)n\left(-\frac{11}{2}\right)^n(−211​)n ist n(−112)nn\left(-\frac{11}{2}\right)^nn(−211​)n Lösung: Mit μ=−112\mu = -\frac{11}{2}μ=−211​, also p=−2μ=11p = -2\mu = 11p=−2μ=11 und q=μ2=30.25q = \mu^2 = 30.25q=μ2=30.25, ist

Hilfreiches

Homogene lineare Differenzengleichung 2. Ordnung

Für xn+2+p xn+1+q xn=0x_{n+2} + p\,x_{n+1} + q\,x_n = 0xn+2​+pxn+1​+qxn​=0 (q≠0q \ne 0q=0) mit Wurzeln λ1,2\lambda_{1,2}λ1,2​ von λ2+pλ+q=0\lambda^2 + p\lambda + q = 0λ2+pλ+q=0:

  • λ1≠λ2\lambda_1 \ne \lambda_2λ1​=λ2​ reell: xn=C1λ1n+C2λ2nx_n = C_1\lambda_1^n + C_2\lambda_2^nxn​=C1​λ1n​+C2​λ2n​;
  • λ1=λ2=λ\lambda_1 = \lambda_2 = \lambdaλ1​=λ2​=λ: xn=(C1+C2n)λnx_n = (C_1 + C_2 n)\lambda^nxn​=(C1​+C2​n)λn;
  • λ1,2=[r,±φ]\lambda_{1,2} = [r, \pm\varphi]λ1,2​=[r,±φ]: xn=rn(C1cos⁡nφ+C2sin⁡nφ)x_n = r^n(C_1\cos n\varphi + C_2\sin n\varphi)xn​=rn(C1​cosnφ+C2​sinnφ).
