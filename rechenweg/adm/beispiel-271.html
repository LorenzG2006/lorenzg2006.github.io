Angabe Originalseite

Lösen Sie das System von Rekursionen an+1=2an−3bna_{n+1} = 2a_n - 3b_nan+1​=2an​−3bn​, bn+1=4an−bnb_{n+1} = 4a_n - b_nbn+1​=4an​−bn​ (n≥0)(n \ge 0)(n≥0) mit den Startwerten a0=0a_0 = 0a0​=0, b0=1b_0 = 1b0​=1, indem Sie das System in eine äquivalente Rekursion zweiter Ordnung umformen.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Elimination von bnb_nbn​ liefert eine Rekursion 2. Ordnung für ana_nan​. Ihre charakteristische Gleichung hat hier konjugiert komplexe Wurzeln. Wir lösen zuerst komplex und schreiben die Lösung dann mit der Polardarstellung λ=[r,θ]\lambda = [r, \theta]λ=[r,θ] in eine reelle Form mit sin⁡\sinsin und cos⁡\coscos um.

Schritt 1: Elimination von bnb_nbn​

Aus der ersten Gleichung:

an+1=2an−3bn  ⟺  bn=2an−an+13.(1)a_{n+1} = 2a_n - 3b_n \iff b_n = \frac{2a_n - a_{n+1}}{3}. \tag{1}an+1​=2an​−3bn​⟺bn​=32an​−an+1​​.(1)

an+2=2an+1−3bn+1(1. Gleichung, Index n+1)=2an+1−3(4an−bn)(2. Gleichung)=2an+1−12an+3bn=2an+1−12an+(2an−an+1)(3bn=2an−an+1 nach (1))=an+1−10an.\begin{aligned} a_{n+2} &= 2a_{n+1} - 3b_{n+1} && \text{(1. Gleichung, Index } n+1)\\ &= 2a_{n+1} - 3(4a_n - b_n) && \text{(2. Gleichung)}\\ &= 2a_{n+1} - 12a_n + 3b_n && \\ &= 2a_{n+1} - 12a_n + (2a_n - a_{n+1}) && (3b_n = 2a_n - a_{n+1} \text{ nach (1)})\\ &= a_{n+1} - 10a_n . && \end{aligned}an+2​​=2an+1​−3bn+1​=2an+1​−3(4an​−bn​)=2an+1​−12an​+3bn​=2an+1​−12an​+(2an​−an+1​)=an+1​−10an​.​​(1. Gleichung, Index n+1)(2. Gleichung)(3bn​=2an​−an+1​ nach (1))​

Startwerte: a0=0a_0 = 0a0​=0, a1=2⋅0−3⋅1=−3a_1 = 2\cdot 0 - 3\cdot 1 = -3a1​=2⋅0−3⋅1=−3.

an+2=an+1−10an (n≥0),a0=0, a1=−3,bn=2an−an+13.a_{n+2} = a_{n+1} - 10a_n\ (n \ge 0),\quad a_0 = 0,\ a_1 = -3, \qquad b_n = \frac{2a_n - a_{n+1}}{3}.an+2​=an+1​−10an​ (n≥0),a0​=0, a1​=−3,bn​=32an​−an+1​​.

n=0:A+B=0,n=1:Aλ1+Bλ2=−3.\begin{aligned} n = 0:&\quad A + B = 0,\\ n = 1:&\quad A\lambda_1 + B\lambda_2 = -3. \end{aligned}n=0:n=1:​A+B=0,Aλ1​+Bλ2​=−3.​

Hilfreiches

Konjugiert komplexe Wurzeln

Hat die charakteristische Gleichung einer reellen Rekursion 2. Ordnung die Wurzeln λ1,2=r(cos⁡θ±isin⁡θ)\lambda_{1,2} = r(\cos\theta \pm i\sin\theta)λ1,2​=r(cosθ±isinθ), so ist jede reelle Lösung von der Form an=rn(C1cos⁡nθ+C2sin⁡nθ),C1,C2∈R.a_n = r^n\bigl(C_1\cos n\theta + C_2\sin n\theta\bigr), \qquad C_1, C_2 \in \R .an​=rn(C1​cosnθ+C2​sinnθ),C1​,C2​∈R.

System → Rekursion 2. Ordnung

an+1=p an+q bna_{n+1} = p\,a_n + q\,b_nan+1​=pan​+qbn​, bn+1=r an+s bnb_{n+1} = r\,a_n + s\,b_nbn+1​=ran​+sbn​ ⇒\Rightarrow⇒ an+2=(p+s)an+1−(ps−qr)ana_{n+2} = (p + s)a_{n+1} - (ps - qr)a_nan+2​=(p+s)an+1​−(ps−qr)an​. Hier p+s=1p + s = 1p+s=1, ps−qr=−2+12=10ps - qr = -2 + 12 = 10ps−qr=−2+12=10.

Typische Fehler
  • Bei bn=2an−an+13b_n = \frac{2a_n - a_{n+1}}{3}bn​=32an​−an+1​​ das Vorzeichen falsch übernehmen (Koeffizient von bnb_nbn​ ist −3-3−3).
  • θ\thetaθ mit dem Taschenrechner falsch bestimmen (Quadrant!) oder Grad und Bogenmaß mischen.
  • Die komplexe Lösung stehen lassen, ohne zu bemerken, dass sie reell ist – zur Kontrolle immer a1a_1a1​ nachrechnen.
