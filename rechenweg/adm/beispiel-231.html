Angabe Originalseite

Gesucht sind die allgemeinen Lösungen der linearen homogenen Differenzengleichungen

(a)xn+2−7xn+1+12xn=0,(b)xn+2+xn+1+xn=0,(c)xn+2−8xn+1+16xn=0.\begin{aligned} &(a) \quad x_{n+2} - 7x_{n+1} + 12x_n = 0,\\ &(b) \quad x_{n+2} + x_{n+1} + x_n = 0,\\ &(c) \quad x_{n+2} - 8x_{n+1} + 16x_n = 0. \end{aligned}​(a)xn+2​−7xn+1​+12xn​=0,(b)xn+2​+xn+1​+xn​=0,(c)xn+2​−8xn+1​+16xn​=0.​

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Ansatz xn=λnx_n = \lambda^nxn​=λn führt auf die charakteristische Gleichung λ2+pλ+q=0\lambda^2 + p\lambda + q = 0λ2+pλ+q=0. Je nach Lösungstyp ergibt sich die allgemeine Lösung:

  • zwei verschiedene reelle Wurzeln: C1λ1n+C2λ2nC_1\lambda_1^n + C_2\lambda_2^nC1​λ1n​+C2​λ2n​ – Teil (a);
  • konjugiert komplexe Wurzeln [r,±φ][r, \pm\varphi][r,±φ]: rn(C1cos⁡nφ+C2sin⁡nφ)r^n(C_1\cos n\varphi + C_2\sin n\varphi)rn(C1​cosnφ+C2​sinnφ) – Teil (b);
  • doppelte Wurzel: (C1+C2n)λn(C_1 + C_2 n)\lambda^n(C1​+C2​n)λn – Teil (c).

(a) xn+2−7xn+1+12xn=0x_{n+2} - 7x_{n+1} + 12x_n = 0xn+2​−7xn+1​+12xn​=0

Charakteristische Gleichung: λ2−7λ+12=0\lambda^2 - 7\lambda + 12 = 0λ2−7λ+12=0.

λ1,2=7±49−482=7±12  ⟹  λ1=4,λ2=3.\lambda_{1,2} = \frac{7 \pm \sqrt{49 - 48}}{2} = \frac{7 \pm 1}{2} \implies \lambda_1 = 4,\quad \lambda_2 = 3.λ1,2​=27±49−48​​=27±1​⟹λ1​=4,λ2​=3.

(Probe: (λ−3)(λ−4)=λ2−7λ+12(\lambda - 3)(\lambda - 4) = \lambda^2 - 7\lambda + 12(λ−3)(λ−4)=λ2−7λ+12 ✓.) Allgemeine Lösung:

xn=C1⋅3n+C2⋅4n.x_n = C_1\cdot 3^n + C_2\cdot 4^n.xn​=C1​⋅3n+C2​⋅4n.

Probe: 3n(9−21+12)=03^n(9 - 21 + 12) = 03n(9−21+12)=0 ✓, 4n(16−28+12)=04^n(16 - 28 + 12) = 04n(16−28+12)=0 ✓.

(b) xn+2+xn+1+xn=0x_{n+2} + x_{n+1} + x_n = 0xn+2​+xn+1​+xn​=0

Charakteristische Gleichung: λ2+λ+1=0\lambda^2 + \lambda + 1 = 0λ2+λ+1=0, Diskriminante 1−4=−3<01 - 4 = -3 < 01−4=−3<0:

λ1,2=−1±3 i2.\lambda_{1,2} = \frac{-1 \pm \sqrt3\,i}{2}.λ1,2​=2−1±3​i​.

Polardarstellung: r=14+34=1r = \sqrt{\frac14 + \frac34} = 1r=41​+43​​=1, cos⁡φ=−12\cos\varphi = -\frac12cosφ=−21​, sin⁡φ=32\sin\varphi = \frac{\sqrt3}{2}sinφ=23​​, also φ=2π3\varphi = \frac{2\pi}{3}φ=32π​ (zweiter Quadrant). Damit λ1,2=[1,±2π3]\lambda_{1,2} = [1, \pm\frac{2\pi}{3}]λ1,2​=[1,±32π​] – es sind die dritten Einheitswurzeln ≠1\ne 1=1 (wegen λ3−1=(λ−1)(λ2+λ+1)\lambda^3 - 1 = (\lambda - 1)(\lambda^2 + \lambda + 1)λ3−1=(λ−1)(λ2+λ+1)).

Mit de Moivre: λ1n=cos⁡2nπ3+isin⁡2nπ3\lambda_1^n = \cos\frac{2n\pi}{3} + i\sin\frac{2n\pi}{3}λ1n​=cos32nπ​+isin32nπ​. Real- und Imaginärteil sind reelle Lösungen; allgemeine reelle Lösung:

xn=C1cos⁡2nπ3+C2sin⁡2nπ3.x_n = C_1\cos\frac{2n\pi}{3} + C_2\sin\frac{2n\pi}{3}.xn​=C1​cos32nπ​+C2​sin32nπ​.

Periodizität

Aus der Rekursion selbst folgt xn+3=−xn+2−xn+1=(xn+1+xn)−xn+1=xnx_{n+3} = -x_{n+2} - x_{n+1} = (x_{n+1} + x_n) - x_{n+1} = x_nxn+3​=−xn+2​−xn+1​=(xn+1​+xn​)−xn+1​=xn​: Jede Lösung ist periodisch mit Periode 333, nämlich x0,x1,−x0−x1,x0,x1,…x_0, x_1, -x_0 - x_1, x_0, x_1, \dotsx0​,x1​,−x0​−x1​,x0​,x1​,…. Das passt zu cos⁡\coscos und sin⁡\sinsin von 2nπ3\frac{2n\pi}{3}32nπ​, die ebenfalls Periode 333 haben.

(c) xn+2−8xn+1+16xn=0x_{n+2} - 8x_{n+1} + 16x_n = 0xn+2​−8xn+1​+16xn​=0

Charakteristische Gleichung: λ2−8λ+16=(λ−4)2=0\lambda^2 - 8\lambda + 16 = (\lambda - 4)^2 = 0λ2−8λ+16=(λ−4)2=0, also λ=4\lambda = 4λ=4 doppelt (Diskriminante 64−64=064 - 64 = 064−64=0).

Neben 4n4^n4n ist n⋅4nn\cdot 4^nn⋅4n Lösung: 4n[16(n+2)−8⋅4(n+1)+16n]=4n[16n+32−32n−32+16n]=04^n\bigl[16(n+2) - 8\cdot 4(n+1) + 16n\bigr] = 4^n[16n + 32 - 32n - 32 + 16n] = 04n[16(n+2)−8⋅4(n+1)+16n]=4n[16n+32−32n−32+16n]=0 ✓. Allgemeine Lösung:

xn=(C1+C2 n) 4n.x_n = (C_1 + C_2\,n)\,4^n.xn​=(C1​+C2​n)4n.

Hilfreiches

Homogene lineare Differenzengleichung 2. Ordnung

Für xn+2+p xn+1+q xn=0x_{n+2} + p\,x_{n+1} + q\,x_n = 0xn+2​+pxn+1​+qxn​=0 (q≠0q \ne 0q=0) mit Wurzeln λ1,2\lambda_{1,2}λ1,2​ von λ2+pλ+q=0\lambda^2 + p\lambda + q = 0λ2+pλ+q=0:

  • λ1≠λ2\lambda_1 \ne \lambda_2λ1​=λ2​ reell: xn=C1λ1n+C2λ2nx_n = C_1\lambda_1^n + C_2\lambda_2^nxn​=C1​λ1n​+C2​λ2n​;
  • λ1=λ2=λ\lambda_1 = \lambda_2 = \lambdaλ1​=λ2​=λ: xn=(C1+C2n)λnx_n = (C_1 + C_2 n)\lambda^nxn​=(C1​+C2​n)λn;
  • λ1,2=[r,±φ]\lambda_{1,2} = [r, \pm\varphi]λ1,2​=[r,±φ]: xn=rn(C1cos⁡nφ+C2sin⁡nφ)x_n = r^n(C_1\cos n\varphi + C_2\sin n\varphi)xn​=rn(C1​cosnφ+C2​sinnφ).
Satz von de Moivre

[r,φ]n=[rn,nφ][r, \varphi]^n = [r^n, n\varphi][r,φ]n=[rn,nφ], d. h. (r(cos⁡φ+isin⁡φ))n=rn(cos⁡nφ+isin⁡nφ)\bigl(r(\cos\varphi + i\sin\varphi)\bigr)^n = r^n(\cos n\varphi + i\sin n\varphi)(r(cosφ+isinφ))n=rn(cosnφ+isinnφ).
