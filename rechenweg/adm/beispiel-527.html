Angabe Originalseite

Beweisen Sie, dass jede quadratische Matrix AAA als Summe einer symmetrischen Matrix BBB (d.h., B=BTB = B^TB=BT) und einer schiefsymmetrischen Matrix CCC (d.h., C=−CTC = -C^TC=−CT) geschrieben werden kann. (Hinweis: Wählen Sie B=12(A+AT)B = \frac12(A + A^T)B=21​(A+AT).) Wie sieht diese Zerlegung konkret für die Matrix

A=(1−22411305)A = \begin{pmatrix} 1 & -2 & 2\\ 4 & 1 & 1\\ 3 & 0 & 5\end{pmatrix}A=​143​−210​215​​

aus?

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Mit dem Hinweis B=12(A+AT)B = \frac12(A + A^T)B=21​(A+AT) bleibt für CCC nur C=A−B=12(A−AT)C = A - B = \frac12(A - A^T)C=A−B=21​(A−AT). Wir rechnen mit den Regeln (X+Y)T=XT+YT(X + Y)^T = X^T + Y^T(X+Y)T=XT+YT, (λX)T=λXT(\lambda X)^T = \lambda X^T(λX)T=λXT und (XT)T=X(X^T)^T = X(XT)T=X nach, dass BBB symmetrisch und CCC schiefsymmetrisch ist. Zusätzlich zeigen wir, dass die Zerlegung eindeutig ist. Dann setzen wir die konkrete Matrix ein.

Teil 1: Allgemeiner Beweis

Sei A∈Rn×nA\in\R^{n\times n}A∈Rn×n (allgemein über einem Körper, in dem 2≠02 \neq 02=0 ist). Definiere

B:=12(A+AT),C:=12(A−AT).B := \tfrac12(A + A^T),\qquad C := \tfrac12(A - A^T).B:=21​(A+AT),C:=21​(A−AT).

Summe: B+C=12A+12AT+12A−12AT=AB + C = \frac12A + \frac12A^T + \frac12A - \frac12A^T = AB+C=21​A+21​AT+21​A−21​AT=A ✓.

BBB ist symmetrisch:

BT=(12(A+AT))T=12(AT+(AT)T)(Transponieren ist linear)=12(AT+A)=B.((AT)T=A)\begin{aligned} B^T &= \bigl(\tfrac12(A + A^T)\bigr)^T = \tfrac12\bigl(A^T + (A^T)^T\bigr) && \text{(Transponieren ist linear)}\\ &= \tfrac12(A^T + A) = B . && ((A^T)^T = A) \end{aligned}BT​=(21​(A+AT))T=21​(AT+(AT)T)=21​(AT+A)=B.​​(Transponieren ist linear)((AT)T=A)​

CCC ist schiefsymmetrisch:

CT=12(AT−(AT)T)=12(AT−A)=−12(A−AT)=−C.\begin{aligned} C^T &= \tfrac12\bigl(A^T - (A^T)^T\bigr) = \tfrac12(A^T - A) = -\tfrac12(A - A^T) = -C . \end{aligned}CT​=21​(AT−(AT)T)=21​(AT−A)=−21​(A−AT)=−C.​

Aus CT=−CC^T = -CCT=−C folgt durch Transponieren auch C=−CTC = -C^TC=−CT, wie in der Angabe gefordert.

Eindeutigkeit (Zusatz): Ist A=B′+C′A = B' + C'A=B′+C′ mit B′B'B′ symmetrisch und C′C'C′ schiefsymmetrisch, so gilt AT=B′T+C′T=B′−C′A^T = B'^T + C'^T = B' - C'AT=B′T+C′T=B′−C′. Addition bzw. Subtraktion von A=B′+C′A = B' + C'A=B′+C′ und AT=B′−C′A^T = B' - C'AT=B′−C′ ergibt B′=12(A+AT)=BB' = \frac12(A + A^T) = BB′=21​(A+AT)=B und C′=12(A−AT)=CC' = \frac12(A - A^T) = CC′=21​(A−AT)=C.

Hilfreiches

Rechenregeln für die Transponierte

(X+Y)T=XT+YT(X + Y)^T = X^T + Y^T(X+Y)T=XT+YT, (λX)T=λXT(\lambda X)^T = \lambda X^T(λX)T=λXT, (XT)T=X(X^T)^T = X(XT)T=X, (XY)T=YTXT(XY)^T = Y^TX^T(XY)T=YTXT.

Schiefsymmetrische Matrizen

Aus cii=−ciic_{ii} = -c_{ii}cii​=−cii​ folgt cii=0c_{ii} = 0cii​=0: Die Diagonale einer schiefsymmetrischen (reellen) Matrix ist null. Der Diagonalteil von AAA landet daher vollständig in BBB.

Typische Fehler
  • Den Faktor 12\frac1221​ vergessen: A+ATA + A^TA+AT und A−ATA - A^TA−AT summieren sich zu 2A2A2A, nicht zu AAA.
  • Beim Transponieren Zeilen und Spalten nur teilweise vertauschen.
