Angabe Originalseite

Untersuchen Sie, ob die Relation ARB:⟺A△B=∅ARB :\Longleftrightarrow A \triangle B = \emptysetARB:⟺A△B=∅ (△\triangle△ die symmetrische Differenz) auf der Potenzmenge einer Menge MMM eine Äquivalenzrelation bildet.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Die Grundmenge der Relation ist P(M)\mathcal P(M)P(M); ihre Elemente sind Teilmengen A,B⊆MA, B \subseteq MA,B⊆M. Der Schlüssel ist die Beobachtung A△B=∅  ⟺  A=BA \triangle B = \emptyset \iff A = BA△B=∅⟺A=B. Damit ist RRR einfach die Gleichheitsrelation auf P(M)\mathcal P(M)P(M), und diese ist eine Äquivalenzrelation. Wir zeigen die Beobachtung und prüfen die drei Eigenschaften trotzdem ausdrücklich.

Schritt 1: A△B=∅  ⟺  A=BA \triangle B = \emptyset \iff A = BA△B=∅⟺A=B

Es ist A△B=(A∖B)∪(B∖A)A \triangle B = (A \setminus B) \cup (B \setminus A)A△B=(A∖B)∪(B∖A). Eine Vereinigung ist genau dann leer, wenn beide Teile leer sind:

A△B=∅  ⟺  A∖B=∅ ∧ B∖A=∅(Vereinigung leer)  ⟺  A⊆B ∧ B⊆A(X∖Y=∅  ⟺  X⊆Y)  ⟺  A=B.(Mengengleichheit)\begin{aligned} A \triangle B = \emptyset &\iff A \setminus B = \emptyset \ \wedge\ B \setminus A = \emptyset && \text{(Vereinigung leer)}\\ &\iff A \subseteq B \ \wedge\ B \subseteq A && (X \setminus Y = \emptyset \iff X \subseteq Y)\\ &\iff A = B. && \text{(Mengengleichheit)} \end{aligned}A△B=∅​⟺A∖B=∅ ∧ B∖A=∅⟺A⊆B ∧ B⊆A⟺A=B.​​(Vereinigung leer)(X∖Y=∅⟺X⊆Y)(Mengengleichheit)​

(Der mittlere Schritt: X∖Y=∅X \setminus Y = \emptysetX∖Y=∅ heißt, es gibt kein Element von XXX, das nicht in YYY liegt – also X⊆YX \subseteq YX⊆Y.)

Schritt 2: Die drei Eigenschaften

  • Reflexiv: A△A=(A∖A)∪(A∖A)=∅A \triangle A = (A \setminus A)\cup(A \setminus A) = \emptysetA△A=(A∖A)∪(A∖A)=∅, also ARAARAARA für alle A∈P(M)A \in \mathcal P(M)A∈P(M).
  • Symmetrisch: B△A=(B∖A)∪(A∖B)=A△BB \triangle A = (B \setminus A) \cup (A \setminus B) = A \triangle BB△A=(B∖A)∪(A∖B)=A△B. Ist das leer, so auch B△AB \triangle AB△A; also ARB⇒BRAARB \Rightarrow BRAARB⇒BRA.
  • Transitiv: Aus ARBARBARB und BRCBRCBRC folgt nach Schritt 1 A=BA = BA=B und B=CB = CB=C, also A=CA = CA=C und damit A△C=∅A \triangle C = \emptysetA△C=∅, d. h. ARCARCARC.

Schritt 3: Äquivalenzklassen

Die Klasse von AAA ist [A]R={B∈P(M):B=A}={A}[A]_R = \{B \in \mathcal P(M) : B = A\} = \{A\}[A]R​={B∈P(M):B=A}={A}. Jede Klasse enthält genau ein Element.

Ergebnis

Ja, RRR ist eine Äquivalenzrelation auf P(M)\mathcal P(M)P(M) – es ist sogar die Gleichheitsrelation, denn A△B=∅  ⟺  A=BA \triangle B = \emptyset \iff A = BA△B=∅⟺A=B. Die Partition besteht aus lauter einelementigen Klassen {A}\{A\}{A}, A⊆MA \subseteq MA⊆M. (Außerdem ist RRR antisymmetrisch, also gleichzeitig eine Halbordnung.)

Beispiel M={1,2}M = \{1, 2\}M={1,2}

P(M)={∅,{1},{2},{1,2}}\mathcal P(M) = \{\emptyset, \{1\}, \{2\}, \{1,2\}\}P(M)={∅,{1},{2},{1,2}}. Etwa {1}△{2}={1,2}≠∅\{1\} \triangle \{2\} = \{1,2\} \ne \emptyset{1}△{2}={1,2}=∅, {1}△{1,2}={2}≠∅\{1\}\triangle\{1,2\} = \{2\} \ne \emptyset{1}△{1,2}={2}=∅ – verschiedene Mengen stehen nie in Relation; jede Menge nur mit sich selbst. R={(X,X):X∈P(M)}R = \{(X, X) : X \in \mathcal P(M)\}R={(X,X):X∈P(M)} hat 444 Paare ✓.

Hilfreiches

Symmetrische Differenz

A△B=(A∖B)∪(B∖A)A \triangle B = (A \setminus B)\cup(B \setminus A)A△B=(A∖B)∪(B∖A): die Elemente, die in genau einer der beiden Mengen liegen.

Gleichheitsrelation

Die Diagonale ΔX={(x,x):x∈X}\Delta_X = \{(x,x) : x \in X\}ΔX​={(x,x):x∈X} ist die kleinste Äquivalenzrelation auf XXX (feinste Partition: lauter Einermengen) und die einzige Relation, die zugleich Äquivalenzrelation und Halbordnung ist.

Typische Fehler
  • Die Relation auf MMM statt auf P(M)\mathcal P(M)P(M) betrachten: Die Elemente sind Mengen.
  • Transitivität mit „∅△∅=∅\emptyset \triangle \emptyset = \emptyset∅△∅=∅“ begründen – man muss von A△BA\triangle BA△B und B△CB \triangle CB△C auf A△CA \triangle CA△C schließen.
