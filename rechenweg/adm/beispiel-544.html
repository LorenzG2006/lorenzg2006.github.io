Angabe Originalseite

Sei V=Rn[x]V = \R_n[x]V=Rn​[x] der Vektorraum der Polynome in xxx vom Grad ≤n\le n≤n mit Koeffizienten aus R\RR. Sei weiters eine Abbildung DDD definiert durch

D(∑k=0nakxk)=∑k=1nkakxk−1.D\Bigl(\sum_{k=0}^{n} a_kx^k\Bigr) = \sum_{k=1}^{n} ka_kx^{k-1}.D(k=0∑n​ak​xk)=k=1∑n​kak​xk−1.

Untersuchen Sie, ob DDD eine lineare Abbildung ist. Untersuchen Sie DDD weiters auf Injektivität und Surjektivität.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

DDD ist das (formale) Ableiten von Polynomen. Linearität prüfen wir direkt über die Koeffizienten. Für Injektivität bestimmen wir den Kern (Polynome mit Ableitung 000 – das sind die Konstanten), für Surjektivität das Bild (Grad sinkt um 111, also wird xnx^nxn nie getroffen). DDD bildet VVV in sich ab (D:V→VD: V\to VD:V→V), da der Grad nicht steigt.

Seien p=∑k=0nakxkp = \sum_{k=0}^n a_kx^kp=∑k=0n​ak​xk, q=∑k=0nbkxk∈Vq = \sum_{k=0}^n b_kx^k\in Vq=∑k=0n​bk​xk∈V und λ∈R\lambda\in\Rλ∈R.

Schritt 1: Linearität

Additivität: p+q=∑k=0n(ak+bk)xkp + q = \sum_{k=0}^n (a_k + b_k)x^kp+q=∑k=0n​(ak​+bk​)xk, also

D(p+q)=∑k=1nk(ak+bk)xk−1(Definition, Koeffizienten ak+bk)=∑k=1nkakxk−1+∑k=1nkbkxk−1=D(p)+D(q).(Summe aufteilen)\begin{aligned} D(p + q) &= \sum_{k=1}^n k(a_k + b_k)x^{k-1} && \text{(Definition, Koeffizienten } a_k + b_k)\\ &= \sum_{k=1}^n ka_kx^{k-1} + \sum_{k=1}^n kb_kx^{k-1} = D(p) + D(q). && \text{(Summe aufteilen)} \end{aligned}D(p+q)​=k=1∑n​k(ak​+bk​)xk−1=k=1∑n​kak​xk−1+k=1∑n​kbk​xk−1=D(p)+D(q).​​(Definition, Koeffizienten ak​+bk​)(Summe aufteilen)​

Homogenität: λp=∑k=0n(λak)xk\lambda p = \sum_{k=0}^n(\lambda a_k)x^kλp=∑k=0n​(λak​)xk, also

D(λp)=∑k=1nkλakxk−1=λ∑k=1nkakxk−1=λD(p).D(\lambda p) = \sum_{k=1}^n k\lambda a_kx^{k-1} = \lambda\sum_{k=1}^n ka_kx^{k-1} = \lambda D(p).D(λp)=k=1∑n​kλak​xk−1=λk=1∑n​kak​xk−1=λD(p).

Damit ist DDD linear.

Schritt 2: Injektivität (Kern)

Eine lineare Abbildung ist genau dann injektiv, wenn ihr Kern nur aus dem Nullvektor besteht.

D(p)=∑k=1nkakxk−1=0  ⟺  kak=0 fu¨r k=1,…,n  ⟺  a1=⋯=an=0,D(p) = \sum_{k=1}^n ka_kx^{k-1} = 0 \iff ka_k = 0 \text{ für } k = 1,\dots,n \iff a_1 = \dots = a_n = 0,D(p)=k=1∑n​kak​xk−1=0⟺kak​=0 fu¨r k=1,…,n⟺a1​=⋯=an​=0,

denn ein Polynom ist genau dann das Nullpolynom, wenn alle Koeffizienten verschwinden, und k≠0k\ne 0k=0. Der Koeffizient a0a_0a0​ bleibt frei:

ker⁡D={a0∣a0∈R}=R0[x](die konstanten Polynome),dim⁡ker⁡D=1.\ker D = \{a_0\mid a_0\in\R\} = \R_0[x]\quad(\text{die konstanten Polynome}),\qquad\dim\ker D = 1.kerD={a0​∣a0​∈R}=R0​[x](die konstanten Polynome),dimkerD=1.

Da etwa D(1)=0=D(0)D(1) = 0 = D(0)D(1)=0=D(0), aber 1≠01\ne 01=0, ist DDD nicht injektiv.

Schritt 3: Surjektivität (Bild)

Jedes Bild D(p)=a1+2a2x+⋯+nanxn−1D(p) = a_1 + 2a_2x + \dots + na_nx^{n-1}D(p)=a1​+2a2​x+⋯+nan​xn−1 hat Grad ≤n−1\le n-1≤n−1. Umgekehrt ist jedes r=∑j=0n−1cjxj∈Rn−1[x]r = \sum_{j=0}^{n-1} c_jx^j\in\R_{n-1}[x]r=∑j=0n−1​cj​xj∈Rn−1​[x] ein Bild, nämlich von

p=∑j=0n−1cjj+1xj+1,D(p)=∑j=0n−1(j+1)cjj+1xj=r.p = \sum_{j=0}^{n-1}\frac{c_j}{j+1}x^{j+1},\qquad D(p) = \sum_{j=0}^{n-1}(j+1)\frac{c_j}{j+1}x^{j} = r.p=j=0∑n−1​j+1cj​​xj+1,D(p)=j=0∑n−1​(j+1)j+1cj​​xj=r.

Also D(V)=Rn−1[x]D(V) = \R_{n-1}[x]D(V)=Rn−1​[x] (für n=0n = 0n=0: D(V)={0}D(V) = \{0\}D(V)={0}). Insbesondere liegt xn∈Vx^n\in Vxn∈V nicht im Bild, d. h. DDD ist nicht surjektiv.

Probe

Dimensionsformel: dim⁡ker⁡D+dim⁡D(V)=1+n=n+1=dim⁡Rn[x]\dim\ker D + \dim D(V) = 1 + n = n + 1 = \dim\R_n[x]dimkerD+dimD(V)=1+n=n+1=dimRn​[x] ✓. Für n=3n = 3n=3: D(2−x+4x3)=−1+12x2D(2 - x + 4x^3) = -1 + 12x^2D(2−x+4x3)=−1+12x2 – passt zur Ableitungsregel.

Ergebnis

DDD ist linear, aber weder injektiv (ker⁡D=\ker D = kerD= konstante Polynome) noch surjektiv (D(V)=Rn−1[x]≠Rn[x]D(V) = \R_{n-1}[x]\ne\R_n[x]D(V)=Rn−1​[x]=Rn​[x]; xnx^nxn hat kein Urbild).

Hinweis

Bei einem endlichdimensionalen Raum und D:V→VD: V\to VD:V→V hängen Injektivität und Surjektivität zusammen: Nach der Dimensionsformel ist DDD genau dann injektiv, wenn es surjektiv ist. Hier scheitert beides gleichzeitig – konsistent.

Hilfreiches

Lineare Abbildung

f:V→Wf: V\to Wf:V→W ist linear, wenn f(u+v)=f(u)+f(v)f(\mathbf{u} + \mathbf{v}) = f(\mathbf{u}) + f(\mathbf{v})f(u+v)=f(u)+f(v) und f(λu)=λf(u)f(\lambda\mathbf{u}) = \lambda f(\mathbf{u})f(λu)=λf(u).

Injektivität und Kern

Eine lineare Abbildung fff ist genau dann injektiv, wenn ker⁡f={0}\ker f = \{\mathbf{0}\}kerf={0}.

Dimensionsformel

dim⁡ker⁡f+dim⁡f(V)=dim⁡V\dim\ker f + \dim f(V) = \dim Vdimkerf+dimf(V)=dimV; für f:V→Vf: V\to Vf:V→V mit dim⁡V<∞\dim V<\inftydimV<∞ gilt: injektiv   ⟺  \iff⟺ surjektiv   ⟺  \iff⟺ bijektiv.

Typische Fehler
  • Aus „jedes Polynom hat eine Stammfunktion“ auf Surjektivität schließen: Die Stammfunktion von xnx^nxn hat Grad n+1n+1n+1 und liegt nicht in Rn[x]\R_n[x]Rn​[x].
  • Den Kern als {0}\{0\}{0} angeben und die Konstanten vergessen.
