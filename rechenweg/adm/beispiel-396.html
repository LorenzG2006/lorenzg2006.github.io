Angabe Originalseite

Sei φ:G→H\varphi : G \to Hφ:G→H ein Gruppenhomomorphismus und eee das neutrale Element von GGG. Man zeige, dass φ(e)\varphi(e)φ(e) das neutrale Element von HHH ist. (Hinweis: Man verwende Bsp. 373.)

(Bsp. 373: Gilt in einer Gruppe a∗a=aa \ast a = aa∗a=a, so ist aaa das neutrale Element.)

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Wir zeigen, dass φ(e)\varphi(e)φ(e) in HHH idempotent ist, d. h. φ(e)φ(e)=φ(e)\varphi(e)\varphi(e) = \varphi(e)φ(e)φ(e)=φ(e). Nach Bsp. 373 ist ein idempotentes Element einer Gruppe das neutrale Element. Zur Vollständigkeit beweisen wir diesen Hilfssatz kurz mit.

Schritt 1: φ(e) ist idempotent

Da eee neutral in GGG ist, gilt e=e ee = e\,ee=ee. Daraus

φ(e)=φ(e e)(e=ee)=φ(e) φ(e).(φ Homomorphismus)\begin{aligned} \varphi(e) &= \varphi(e\,e) && \text{(}e = ee\text{)}\\ &= \varphi(e)\,\varphi(e). && \text{(}\varphi\text{ Homomorphismus)} \end{aligned}φ(e)​=φ(ee)=φ(e)φ(e).​​(e=ee)(φ Homomorphismus)​

Das Element x:=φ(e)∈Hx := \varphi(e) \in Hx:=φ(e)∈H erfüllt also xx=xxx = xxx=x.

Warum nicht einfach „φ(e)·φ(g) = φ(g)“?

Daraus folgt nur, dass φ(e)\varphi(e)φ(e) auf dem Bild φ(G)\varphi(G)φ(G) neutral wirkt. Ist φ\varphiφ nicht surjektiv, sagt das zunächst nichts über alle h∈Hh \in Hh∈H. Erst die Kürzungsregel in der Gruppe HHH (Schritt 2) liefert φ(e)=eH\varphi(e) = e_Hφ(e)=eH​. In Halbgruppen/Monoiden ohne Inverse kann φ(e)≠eH\varphi(e) \ne e_Hφ(e)=eH​ tatsächlich vorkommen.

Hilfreiches

Bsp. 373

In einer Gruppe ist jedes Element aaa mit a∗a=aa \ast a = aa∗a=a das neutrale Element.

Gruppenhomomorphismus

φ(ab)=φ(a)φ(b)\varphi(ab) = \varphi(a)\varphi(b)φ(ab)=φ(a)φ(b) für alle a,b∈Ga, b \in Ga,b∈G; dass φ(eG)=eH\varphi(e_G) = e_Hφ(eG​)=eH​, muss nicht gefordert werden – es folgt (dieses Beispiel).

Typische Fehler
  • Im Beweis φ(e)=eH\varphi(e) = e_Hφ(e)=eH​ schon voraussetzen.
  • Mit dem Inversen von eee statt von φ(e)\varphi(e)φ(e) multiplizieren (das Inverse muss in HHH gebildet werden).
