Angabe Originalseite

Berechnen Sie die folgenden Summen durch Aufstellen und Lösen einer Rekursion mittels Ansatzmethode.

∑i=1ni(i−1)\sum_{i=1}^{n} i(i-1)i=1∑n​i(i−1)

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Sn=∑i=1ni(i−1)S_n = \sum_{i=1}^n i(i-1)Sn​=∑i=1n​i(i−1) erfüllt Sn−Sn−1=n(n−1)=n2−nS_n - S_{n-1} = n(n-1) = n^2 - nSn​−Sn−1​=n(n−1)=n2−n, S0=0S_0 = 0S0​=0. Homogene Lösung: Konstante. Die Störfunktion ist ein Polynom vom Grad 222 (mal 1n1^n1n), und 111 ist einfache Wurzel der charakteristischen Gleichung – Ansatz n⋅(Polynom vom Grad 2)n\cdot(\text{Polynom vom Grad } 2)n⋅(Polynom vom Grad 2).

Schritt 1: Rekursion aufstellen

Sn=Sn−1+n(n−1)(n≥1),S0=0,S_n = S_{n-1} + n(n-1) \quad (n \ge 1), \qquad S_0 = 0,Sn​=Sn−1​+n(n−1)(n≥1),S0​=0,

also Sn−Sn−1=n2−nS_n - S_{n-1} = n^2 - nSn​−Sn−1​=n2−n.

Schritt 2: Homogene Gleichung

Charakteristische Gleichung λ−1=0\lambda - 1 = 0λ−1=0, also Sn(h)=KS_n^{(h)} = KSn(h)​=K.

Schritt 3: Partikuläre Lösung

Ansatz (Faktor nnn wegen der Wurzel 111):

Sn(p)=An3+Bn2+Cn.S_n^{(p)} = An^3 + Bn^2 + Cn.Sn(p)​=An3+Bn2+Cn.

Mit n3−(n−1)3=3n2−3n+1n^3 - (n-1)^3 = 3n^2 - 3n + 1n3−(n−1)3=3n2−3n+1 und n2−(n−1)2=2n−1n^2 - (n-1)^2 = 2n - 1n2−(n−1)2=2n−1:

Sn(p)−Sn−1(p)=A(3n2−3n+1)+B(2n−1)+C=3A n2+(−3A+2B) n+(A−B+C).(geordnet)\begin{aligned} S_n^{(p)} - S_{n-1}^{(p)} &= A(3n^2 - 3n + 1) + B(2n - 1) + C && \\ &= 3A\,n^2 + (-3A + 2B)\,n + (A - B + C). && \text{(geordnet)} \end{aligned}Sn(p)​−Sn−1(p)​​=A(3n2−3n+1)+B(2n−1)+C=3An2+(−3A+2B)n+(A−B+C).​​(geordnet)​

Koeffizientenvergleich mit n2−n+0n^2 - n + 0n2−n+0:

n2:3A=1  ⟹  A=13,n1:−3A+2B=−1  ⟹  −1+2B=−1, B=0,n0:A−B+C=0  ⟹  C=−13.\begin{aligned} n^2:&\quad 3A = 1 &&\implies A = \tfrac13,\\ n^1:&\quad -3A + 2B = -1 &&\implies -1 + 2B = -1,\ B = 0,\\ n^0:&\quad A - B + C = 0 &&\implies C = -\tfrac13. \end{aligned}n2:n1:n0:​3A=1−3A+2B=−1A−B+C=0​​⟹A=31​,⟹−1+2B=−1, B=0,⟹C=−31​.​

Also Sn(p)=n3−n3=(n−1) n (n+1)3S_n^{(p)} = \frac{n^3 - n}{3} = \frac{(n-1)\,n\,(n+1)}{3}Sn(p)​=3n3−n​=3(n−1)n(n+1)​ (wegen n3−n=n(n2−1)=n(n−1)(n+1)n^3 - n = n(n^2 - 1) = n(n-1)(n+1)n3−n=n(n2−1)=n(n−1)(n+1)).

Schritt 4: Allgemeine Lösung und Anfangswert

Sn=K+(n−1)n(n+1)3,S0=K=0.S_n = K + \frac{(n-1)n(n+1)}{3}, \qquad S_0 = K = 0.Sn​=K+3(n−1)n(n+1)​,S0​=K=0.

Ergebnis

∑i=1ni(i−1)=(n−1) n (n+1)3=n3−n3.\sum_{i=1}^{n} i(i-1) = \frac{(n-1)\,n\,(n+1)}{3} = \frac{n^3 - n}{3}.i=1∑n​i(i−1)=3(n−1)n(n+1)​=3n3−n​.

Hilfreiches

Ansatz bei polynomialer Störfunktion und Wurzel 1

Für Sn−Sn−1=p(n)S_n - S_{n-1} = p(n)Sn​−Sn−1​=p(n) (ppp Polynom vom Grad ddd) setzt man Sn(p)=n q(n)S_n^{(p)} = n\,q(n)Sn(p)​=nq(n) mit deg⁡q=d\deg q = ddegq=d an. Der konstante Term von qqq würde wegfallen, wenn man den Faktor nnn wegließe – genau das ist die Resonanz.

Fallende Faktorielle

i(i−1)=2(i2)i(i-1) = 2\binom{i}{2}i(i−1)=2(2i​), und ∑i=1n(i2)=(n+13)\sum_{i=1}^n \binom{i}{2} = \binom{n+1}{3}∑i=1n​(2i​)=(3n+1​) (Hockey-Stick-Identität). Daraus folgt sofort ∑i(i−1)=2(n+13)=(n+1)n(n−1)3\sum i(i-1) = 2\binom{n+1}{3} = \frac{(n+1)n(n-1)}{3}∑i(i−1)=2(3n+1​)=3(n+1)n(n−1)​.

Typische Fehler
  • Ansatz vom Grad 222 statt 333.
  • Beim Koeffizientenvergleich die rechte Seite n2−nn^2 - nn2−n mit n2+nn^2 + nn2+n verwechseln (dann käme B=1B = 1B=1 heraus).
  • Den Summanden für i=1i = 1i=1 (er ist 000) als Startwert S1=1S_1 = 1S1​=1 missverstehen.
