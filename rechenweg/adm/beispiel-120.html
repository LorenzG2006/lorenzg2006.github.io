Angabe Originalseite

Untersuchen Sie, ob die Relation ARB:⟺A△B=AARB :\Longleftrightarrow A \triangle B = AARB:⟺A△B=A (△\triangle△ die symmetrische Differenz) auf der Potenzmenge einer Menge MMM eine Äquivalenzrelation bildet.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Wir vereinfachen die Bedingung: A△B=AA \triangle B = AA△B=A gilt genau dann, wenn B=∅B = \emptysetB=∅. Die Relation besteht also nur aus den Paaren (A,∅)(A, \emptyset)(A,∅). Dann prüfen wir die drei Eigenschaften; Reflexivität und Symmetrie scheitern, sobald MMM nicht leer ist.

Schritt 1: A△B=A  ⟺  B=∅A \triangle B = A \iff B = \emptysetA△B=A⟺B=∅

„⇐\Leftarrow⇐“: Für B=∅B = \emptysetB=∅ ist A△∅=(A∖∅)∪(∅∖A)=A∪∅=AA \triangle \emptyset = (A \setminus \emptyset) \cup (\emptyset \setminus A) = A \cup \emptyset = AA△∅=(A∖∅)∪(∅∖A)=A∪∅=A.

„⇒\Rightarrow⇒“: Gelte A△B=AA \triangle B = AA△B=A. Angenommen, es gibt ein x∈Bx \in Bx∈B.

  • Ist x∈Ax \in Ax∈A, so liegt xxx in beiden Mengen, also x∉A△B=Ax \notin A \triangle B = Ax∈/A△B=A – Widerspruch zu x∈Ax \in Ax∈A.
  • Ist x∉Ax \notin Ax∈/A, so liegt xxx in genau einer der Mengen, also x∈A△B=Ax \in A \triangle B = Ax∈A△B=A – Widerspruch zu x∉Ax \notin Ax∈/A.

Also hat BBB kein Element: B=∅B = \emptysetB=∅.

Damit ist

R={(A,∅):A∈P(M)}.R = \{(A, \emptyset) : A \in \mathcal P(M)\}.R={(A,∅):A∈P(M)}.

Schritt 2: Eigenschaften (für M≠∅M \ne \emptysetM=∅)

Sei m∈Mm \in Mm∈M und A0:={m}≠∅A_0 := \{m\} \ne \emptysetA0​:={m}=∅.

  • Reflexiv: nein. A0△A0=∅≠A0A_0 \triangle A_0 = \emptyset \ne A_0A0​△A0​=∅=A0​, also ¬(A0RA0)\neg(A_0 R A_0)¬(A0​RA0​). (Allgemein gilt ARAARAARA nur für A=∅A = \emptysetA=∅.)
  • Symmetrisch: nein. A0R∅A_0 R \emptysetA0​R∅ (denn A0△∅=A0A_0 \triangle \emptyset = A_0A0​△∅=A0​), aber ∅△A0=A0≠∅\emptyset \triangle A_0 = A_0 \ne \emptyset∅△A0​=A0​=∅, also ¬(∅RA0)\neg(\emptyset R A_0)¬(∅RA0​).
  • Transitiv: ja. Aus ARBARBARB und BRCBRCBRC folgt nach Schritt 1 insbesondere C=∅C = \emptysetC=∅. Dann ist A△C=A△∅=AA \triangle C = A \triangle \emptyset = AA△C=A△∅=A, also ARCARCARC.
  • (Antisymmetrisch: ja. Aus ARBARBARB und BRABRABRA folgt B=∅B = \emptysetB=∅ und A=∅A = \emptysetA=∅, also A=BA = BA=B.)

Sonderfall M=∅M = \emptysetM=∅

Dann ist P(M)={∅}\mathcal P(M) = \{\emptyset\}P(M)={∅} und R={(∅,∅)}R = \{(\emptyset, \emptyset)\}R={(∅,∅)} – das ist die Gleichheitsrelation auf einer einelementigen Menge und damit (trivialerweise) eine Äquivalenzrelation.

Ergebnis

Es gilt ARB  ⟺  B=∅ARB \iff B = \emptysetARB⟺B=∅. Für M≠∅M \ne \emptysetM=∅ ist RRR transitiv (und antisymmetrisch), aber weder reflexiv noch symmetrisch, also keine Äquivalenzrelation. Nur im trivialen Fall M=∅M = \emptysetM=∅ ist R={(∅,∅)}R = \{(\emptyset,\emptyset)\}R={(∅,∅)} eine Äquivalenzrelation.

Beispiel M={1,2}M = \{1, 2\}M={1,2}

R={(∅,∅),({1},∅),({2},∅),({1,2},∅)}R = \{(\emptyset,\emptyset), (\{1\},\emptyset), (\{2\},\emptyset), (\{1,2\},\emptyset)\}R={(∅,∅),({1},∅),({2},∅),({1,2},∅)}. Kontrolle eines Nicht-Paares: {1}△{1,2}={2}≠{1}\{1\}\triangle\{1,2\} = \{2\} \ne \{1\}{1}△{1,2}={2}={1} ✓. Reflexivität scheitert an {1}△{1}=∅≠{1}\{1\}\triangle\{1\} = \emptyset \ne \{1\}{1}△{1}=∅={1} ✓.

Hilfreiches

Rechenregeln der symmetrischen Differenz

A△∅=AA \triangle \emptyset = AA△∅=A, A△A=∅A \triangle A = \emptysetA△A=∅, A△B=B△AA \triangle B = B \triangle AA△B=B△A, (A△B)△C=A△(B△C)(A \triangle B) \triangle C = A \triangle (B \triangle C)(A△B)△C=A△(B△C). Daraus folgt Schritt 1 auch kurz: B=A△(A△B)=A△A=∅B = A \triangle (A \triangle B) = A \triangle A = \emptysetB=A△(A△B)=A△A=∅.

Typische Fehler
  • „A△B=AA \triangle B = AA△B=A“ als „B⊆AB \subseteq AB⊆A“ deuten – das wäre richtig für A∪B=AA \cup B = AA∪B=A, nicht für △\triangle△.
  • Den Sonderfall M=∅M = \emptysetM=∅ übersehen (dort wird die Aussage trivial wahr).
