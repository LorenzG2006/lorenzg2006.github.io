Einzeln ausmultipliziert:

4 p(n)=4Cn2+4Dn+4E,−2 p(n−1)=−2C(n2−2n+1)−2D(n−1)−2E=−2Cn2+(4C−2D) n−2C+2D−2E,p(n−2)=C(n2−4n+4)+D(n−2)+E=Cn2+(−4C+D) n+4C−2D+E.\begin{aligned} 4\,p(n) &= 4Cn^2 + 4Dn + 4E,\\ -2\,p(n-1) &= -2C(n^2 - 2n + 1) - 2D(n - 1) - 2E = -2Cn^2 + (4C - 2D)\,n - 2C + 2D - 2E,\\ p(n-2) &= C(n^2 - 4n + 4) + D(n - 2) + E = Cn^2 + (-4C + D)\,n + 4C - 2D + E. \end{aligned}4p(n)−2p(n−1)p(n−2)​=4Cn2+4Dn+4E,=−2C(n2−2n+1)−2D(n−1)−2E=−2Cn2+(4C−2D)n−2C+2D−2E,=C(n2−4n+4)+D(n−2)+E=Cn2+(−4C+D)n+4C−2D+E.​

3C n2+3D n+(2C+3E)=4n2+0⋅n+0.3C\,n^2 + 3D\,n + (2C + 3E) = 4n^2 + 0\cdot n + 0.3Cn2+3Dn+(2C+3E)=4n2+0⋅n+0.

Hilfreiches

Ansatz bei Störfunktion p(n) μnp(n)\,\mu^np(n)μn

μ\muμ keine Wurzel: q(n) μnq(n)\,\mu^nq(n)μn mit vollständigem Polynom qqq, deg⁡q=deg⁡p\deg q = \deg pdegq=degp; μ\muμ kkk-fache Wurzel: zusätzlich Faktor nkn^knk.
