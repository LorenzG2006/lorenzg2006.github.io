Angabe Originalseite

Man zeige ∣z1+z22∣2+∣z1−z22∣2=12(∣z1∣2+∣z2∣2).\left|\frac{z_1 + z_2}{2}\right|^2 + \left|\frac{z_1 - z_2}{2}\right|^2 = \frac12\bigl(|z_1|^2 + |z_2|^2\bigr).​2z1​+z2​​​2+​2z1​−z2​​​2=21​(∣z1​∣2+∣z2​∣2).

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Der Schlüssel ist ∣w∣2=w w‾|w|^2 = w\,\overline w∣w∣2=ww: Damit werden Beträge zu Produkten, die man ausmultiplizieren kann. Die gemischten Terme z1z2‾z_1\overline{z_2}z1​z2​​ und z1‾z2\overline{z_1} z_2z1​​z2​ kommen in den beiden Summanden mit entgegengesetztem Vorzeichen vor und heben sich weg.

Schritt 1: Die Quadrate ausrechnen

Wir verwenden ∣w∣2=ww‾|w|^2 = w\overline w∣w∣2=ww und die Rechenregeln z1±z2‾=z1‾±z2‾\overline{z_1 \pm z_2} = \overline{z_1} \pm \overline{z_2}z1​±z2​​=z1​​±z2​​:

∣z1+z2∣2=(z1+z2) (z1+z2)‾(∣w∣2=ww‾)=(z1+z2)(z1‾+z2‾)(Konjugation additiv)=z1z1‾+z1z2‾+z2z1‾+z2z2‾(ausmultiplizieren)=∣z1∣2+z1z2‾+z1‾z2+∣z2∣2.\begin{aligned} |z_1 + z_2|^2 &= (z_1 + z_2)\,\overline{(z_1 + z_2)} && \text{(}|w|^2 = w\overline w\text{)}\\ &= (z_1 + z_2)(\overline{z_1} + \overline{z_2}) && \text{(Konjugation additiv)}\\ &= z_1\overline{z_1} + z_1\overline{z_2} + z_2\overline{z_1} + z_2\overline{z_2} && \text{(ausmultiplizieren)}\\ &= |z_1|^2 + z_1\overline{z_2} + \overline{z_1} z_2 + |z_2|^2. && \end{aligned}∣z1​+z2​∣2​=(z1​+z2​)(z1​+z2​)​=(z1​+z2​)(z1​​+z2​​)=z1​z1​​+z1​z2​​+z2​z1​​+z2​z2​​=∣z1​∣2+z1​z2​​+z1​​z2​+∣z2​∣2.​​(∣w∣2=ww)(Konjugation additiv)(ausmultiplizieren)​

Genauso mit Minus:

∣z1−z2∣2=(z1−z2)(z1‾−z2‾)=∣z1∣2−z1z2‾−z1‾z2+∣z2∣2.\begin{aligned} |z_1 - z_2|^2 &= (z_1 - z_2)(\overline{z_1} - \overline{z_2}) && \\ &= |z_1|^2 - z_1\overline{z_2} - \overline{z_1} z_2 + |z_2|^2. && \end{aligned}∣z1​−z2​∣2​=(z1​−z2​)(z1​​−z2​​)=∣z1​∣2−z1​z2​​−z1​​z2​+∣z2​∣2.​​​

Schritt 2: Addieren

∣z1+z2∣2+∣z1−z2∣2=2∣z1∣2+2∣z2∣2,|z_1 + z_2|^2 + |z_1 - z_2|^2 = 2|z_1|^2 + 2|z_2|^2,∣z1​+z2​∣2+∣z1​−z2​∣2=2∣z1​∣2+2∣z2​∣2, denn die gemischten Terme ±(z1z2‾+z1‾z2)\pm(z_1\overline{z_2} + \overline{z_1}z_2)±(z1​z2​​+z1​​z2​) heben sich auf.

Schritt 3: Faktor 1/2 einbauen

Wegen ∣w2∣2=∣w∣24\left|\frac w2\right|^2 = \frac{|w|^2}{4}​2w​​2=4∣w∣2​:

∣z1+z22∣2+∣z1−z22∣2=∣z1+z2∣2+∣z1−z2∣24(∣w/2∣2=∣w∣2/4)=2∣z1∣2+2∣z2∣24(Schritt 2)=12(∣z1∣2+∣z2∣2).(ku¨rzen)\begin{aligned} \left|\frac{z_1 + z_2}{2}\right|^2 + \left|\frac{z_1 - z_2}{2}\right|^2 &= \frac{|z_1 + z_2|^2 + |z_1 - z_2|^2}{4} && \text{(}|w/2|^2 = |w|^2/4\text{)}\\ &= \frac{2|z_1|^2 + 2|z_2|^2}{4} && \text{(Schritt 2)}\\ &= \frac12\bigl(|z_1|^2 + |z_2|^2\bigr). && \text{(kürzen)} \end{aligned}​2z1​+z2​​​2+​2z1​−z2​​​2​=4∣z1​+z2​∣2+∣z1​−z2​∣2​=42∣z1​∣2+2∣z2​∣2​=21​(∣z1​∣2+∣z2​∣2).​​(∣w/2∣2=∣w∣2/4)(Schritt 2)(ku¨rzen)​

Ergebnis

Für alle z1,z2∈Cz_1, z_2 \in \Cz1​,z2​∈C gilt ∣z1+z22∣2+∣z1−z22∣2=12(∣z1∣2+∣z2∣2).■\left|\frac{z_1 + z_2}{2}\right|^2 + \left|\frac{z_1 - z_2}{2}\right|^2 = \frac12\bigl(|z_1|^2 + |z_2|^2\bigr). \quad \blacksquare​2z1​+z2​​​2+​2z1​−z2​​​2=21​(∣z1​∣2+∣z2​∣2).■

Probe

z1=3z_1 = 3z1​=3, z2=4iz_2 = 4iz2​=4i: ∣3+4i2∣2=254\left|\frac{3 + 4i}{2}\right|^2 = \frac{25}{4}​23+4i​​2=425​, ∣3−4i2∣2=254\left|\frac{3 - 4i}{2}\right|^2 = \frac{25}{4}​23−4i​​2=425​, Summe 252\frac{25}{2}225​; rechts 12(9+16)=252\frac12(9 + 16) = \frac{25}{2}21​(9+16)=225​ ✓. sympy mit z1=a1+b1iz_1 = a_1 + b_1 iz1​=a1​+b1​i, z2=a2+b2iz_2 = a_2 + b_2 iz2​=a2​+b2​i (reelle Symbole): Differenz beider Seiten vereinfacht zu 000.

Geometrische Bedeutung

z1+z2z_1 + z_2z1​+z2​ und z1−z2z_1 - z_2z1​−z2​ sind die Diagonalen des von z1z_1z1​ und z2z_2z2​ aufgespannten Parallelogramms. Die Gleichung (mal 4) sagt: Die Summe der Quadrate der Diagonalen ist gleich der Summe der Quadrate aller vier Seiten – die Parallelogrammgleichung.

Hilfreiches

Betrag über Konjugation

∣w∣2=w w‾|w|^2 = w\,\overline w∣w∣2=ww, z1±z2‾=z1‾±z2‾\overline{z_1 \pm z_2} = \overline{z_1} \pm \overline{z_2}z1​±z2​​=z1​​±z2​​, ∣cw∣=∣c∣ ∣w∣|cw| = |c|\,|w|∣cw∣=∣c∣∣w∣.

Gemischte Terme

z1z2‾+z1‾z2=2Re⁡(z1z2‾)z_1\overline{z_2} + \overline{z_1}z_2 = 2\Re(z_1\overline{z_2})z1​z2​​+z1​​z2​=2Re(z1​z2​​) – eine reelle Zahl (entspricht dem doppelten Skalarprodukt der Vektoren).

Typische Fehler

  • ∣z∣2=z2|z|^2 = z^2∣z∣2=z2 rechnen – richtig ist ∣z∣2=zz‾|z|^2 = z\overline z∣z∣2=zz.
