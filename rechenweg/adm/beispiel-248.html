Lösen Sie die Rekursion mit der Ansatzmethode:

an+an−1+an−2=sin⁡(2nπ/3)(n≥2),a0=0, a1=−1.a_n + a_{n-1} + a_{n-2} = \sin(2n\pi/3) \quad (n \ge 2), \qquad a_0 = 0,\ a_1 = -1.an​+an−1​+an−2​=sin(2nπ/3)(n≥2),a0​=0, a1​=−1.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Die charakteristische Gleichung λ2+λ+1=0\lambda^2 + \lambda + 1 = 0λ2+λ+1=0 hat die Wurzeln e±2πi/3=[1,±2π3]e^{\pm 2\pi i/3} = [1, \pm\frac{2\pi}{3}]e±2πi/3=[1,±32π​]. Die homogenen Lösungen sind also cos⁡2nπ3\cos\frac{2n\pi}{3}cos32nπ​ und sin⁡2nπ3\sin\frac{2n\pi}{3}sin32nπ​ – und die Störfunktion sin⁡2nπ3\sin\frac{2n\pi}{3}sin32nπ​ ist selbst eine davon: Resonanz. Der übliche Ansatz Pcos⁡+Qsin⁡P\cos + Q\sinPcos+Qsin muss deshalb mit nnn multipliziert werden.

Schritt 1: Homogene Rekursion

λ2+λ+1=0  ⟹  λ1,2=−12±32i=[1,±2π3]\lambda^2 + \lambda + 1 = 0 \implies \lambda_{1,2} = -\frac12 \pm \frac{\sqrt3}{2}i = [1, \pm\frac{2\pi}{3}]λ2+λ+1=0⟹λ1,2​=−21​±23​​i=[1,±32π​] (vgl. Bsp. 247). Mit θ:=2π3\theta := \frac{2\pi}{3}θ:=32π​:

an(h)=Acos⁡(nθ)+Bsin⁡(nθ).a_n^{(h)} = A\cos(n\theta) + B\sin(n\theta).an(h)​=Acos(nθ)+Bsin(nθ).

Schritt 2: Warum Resonanz?

Setzt man un=Pcos⁡(nθ)+Qsin⁡(nθ)u_n = P\cos(n\theta) + Q\sin(n\theta)un​=Pcos(nθ)+Qsin(nθ) ein, erhält man un+un−1+un−2=0u_n + u_{n-1} + u_{n-2} = 0un​+un−1​+un−2​=0 für alle P,QP, QP,Q, weil unu_nun​ homogene Lösung ist. Damit kann man sin⁡(nθ)\sin(n\theta)sin(nθ) nicht erzeugen. Da eiθe^{i\theta}eiθ eine einfache Wurzel ist, lautet der Ansatz

an(p)=n un=n(Pcos⁡(nθ)+Qsin⁡(nθ)).a_n^{(p)} = n\,u_n = n\bigl(P\cos(n\theta) + Q\sin(n\theta)\bigr).an(p)​=nun​=n(Pcos(nθ)+Qsin(nθ)).

Schritt 3: Einsetzen

an(p)+an−1(p)+an−2(p)=n un+(n−1) un−1+(n−2) un−2=n(un+un−1+un−2)⏟= 0−un−1−2un−2(nach n sortiert)=−un−1−2un−2.\begin{aligned} a_n^{(p)} + a_{n-1}^{(p)} + a_{n-2}^{(p)} &= n\,u_n + (n-1)\,u_{n-1} + (n-2)\,u_{n-2} && \\ &= n\underbrace{\bigl(u_n + u_{n-1} + u_{n-2}\bigr)}_{=\,0} - u_{n-1} - 2u_{n-2} && \text{(nach } n \text{ sortiert)}\\ &= -u_{n-1} - 2u_{n-2}. && \end{aligned}an(p)​+an−1(p)​+an−2(p)​​=nun​+(n−1)un−1​+(n−2)un−2​=n=0(un​+un−1​+un−2​)​​−un−1​−2un−2​=−un−1​−2un−2​.​​(nach n sortiert)​

Mit den Additionstheoremen und cos⁡θ=−12\cos\theta = -\frac12cosθ=−21​, sin⁡θ=32\sin\theta = \frac{\sqrt3}{2}sinθ=23​​, cos⁡2θ=−12\cos 2\theta = -\frac12cos2θ=−21​, sin⁡2θ=−32\sin 2\theta = -\frac{\sqrt3}{2}sin2θ=−23​​:

un−1=(Pcos⁡θ−Qsin⁡θ)cos⁡nθ+(Psin⁡θ+Qcos⁡θ)sin⁡nθ=(−12P−32Q)cos⁡nθ+(32P−12Q)sin⁡nθ,un−2=(Pcos⁡2θ−Qsin⁡2θ)cos⁡nθ+(Psin⁡2θ+Qcos⁡2θ)sin⁡nθ=(−12P+32Q)cos⁡nθ+(−32P−12Q)sin⁡nθ.\begin{aligned} u_{n-1} &= (P\cos\theta - Q\sin\theta)\cos n\theta + (P\sin\theta + Q\cos\theta)\sin n\theta = \Bigl(-\tfrac12 P - \tfrac{\sqrt3}{2}Q\Bigr)\cos n\theta + \Bigl(\tfrac{\sqrt3}{2}P - \tfrac12 Q\Bigr)\sin n\theta,\\ u_{n-2} &= (P\cos 2\theta - Q\sin 2\theta)\cos n\theta + (P\sin 2\theta + Q\cos 2\theta)\sin n\theta = \Bigl(-\tfrac12 P + \tfrac{\sqrt3}{2}Q\Bigr)\cos n\theta + \Bigl(-\tfrac{\sqrt3}{2}P - \tfrac12 Q\Bigr)\sin n\theta. \end{aligned}un−1​un−2​​=(Pcosθ−Qsinθ)cosnθ+(Psinθ+Qcosθ)sinnθ=(−21​P−23​​Q)cosnθ+(23​​P−21​Q)sinnθ,=(Pcos2θ−Qsin2θ)cosnθ+(Psin2θ+Qcos2θ)sinnθ=(−21​P+23​​Q)cosnθ+(−23​​P−21​Q)sinnθ.​

Daraus

−un−1−2un−2=(32P−32Q)cos⁡nθ+(32P+32Q)sin⁡nθ=!sin⁡nθ.-u_{n-1} - 2u_{n-2} = \Bigl(\tfrac32 P - \tfrac{\sqrt3}{2}Q\Bigr)\cos n\theta + \Bigl(\tfrac{\sqrt3}{2}P + \tfrac32 Q\Bigr)\sin n\theta \overset{!}{=} \sin n\theta.−un−1​−2un−2​=(23​P−23​​Q)cosnθ+(23​​P+23​Q)sinnθ=!sinnθ.

Koeffizientenvergleich (zulässig: αcos⁡nθ+βsin⁡nθ=0\alpha\cos n\theta + \beta\sin n\theta = 0αcosnθ+βsinnθ=0 für alle nnn liefert mit n=0n = 0n=0 α=0\alpha = 0α=0, mit n=1n = 1n=1 β=0\beta = 0β=0):

32P−32Q=0  ⟹  Q=3 P,32P+32Q=1  ⟹  32P+332P=23 P=1,\begin{aligned} \tfrac32 P - \tfrac{\sqrt3}{2}Q &= 0 &&\implies Q = \sqrt3\,P,\\ \tfrac{\sqrt3}{2}P + \tfrac32 Q &= 1 &&\implies \tfrac{\sqrt3}{2}P + \tfrac{3\sqrt3}{2}P = 2\sqrt3\,P = 1, \end{aligned}23​P−23​​Q23​​P+23​Q​=0=1​​⟹Q=3​P,⟹23​​P+233​​P=23​P=1,​

also P=123=36P = \frac{1}{2\sqrt3} = \frac{\sqrt3}{6}P=23​1​=63​​ und Q=12Q = \frac12Q=21​.

Schritt 4: Allgemeine Lösung und Anfangsbedingungen

Hilfreiches

Resonanz bei trigonometrischer Störfunktion

Ist eiθe^{i\theta}eiθ eine kkk-fache Wurzel der charakteristischen Gleichung, so setzt man für αcos⁡nθ+βsin⁡nθ\alpha\cos n\theta + \beta\sin n\thetaαcosnθ+βsinnθ den Ansatz nk(Pcos⁡nθ+Qsin⁡nθ)n^k\bigl(P\cos n\theta + Q\sin n\theta\bigr)nk(Pcosnθ+Qsinnθ) an.

Trick beim Einsetzen des Resonanzansatzes

Für an=n una_n = n\,u_nan​=nun​ mit homogener Lösung unu_nun​ gilt ∑kck an−k=−∑kk ck un−k\sum_k c_k\,a_{n-k} = -\sum_k k\,c_k\,u_{n-k}∑k​ck​an−k​=−∑k​kck​un−k​: Der Anteil mit nnn fällt immer weg, es bleiben nur die „Verschiebungsterme“.

Typische Fehler
  • Den Ansatz ohne Faktor nnn wählen: Man erhält 0=sin⁡2nπ30 = \sin\frac{2n\pi}{3}0=sin32nπ​ – ein Widerspruch.
  • sin⁡2θ=sin⁡4π3=−32\sin 2\theta = \sin\frac{4\pi}{3} = -\frac{\sqrt3}{2}sin2θ=sin34π​=−23​​ mit falschem Vorzeichen verwenden.
  • Bei den Anfangsbedingungen den partikulären Teil weglassen.
