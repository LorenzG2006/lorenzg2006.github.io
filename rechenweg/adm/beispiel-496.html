Wir „heben“ jedes davon durch Addition von x3x^3x3 auf Grad 3 an und zeigen, dass das Ergebnis immer noch eine Basis ist.

Teil 2: Basis aus Polynomen dritten Grades

Wir wählen

B={ q1,q2,q3,q4 }={ x3, x3+x2, x3+x, x3+1 }.B = \{\,q_1, q_2, q_3, q_4\,\} = \{\,x^3,\ x^3 + x^2,\ x^3 + x,\ x^3 + 1\,\}.B={q1​,q2​,q3​,q4​}={x3, x3+x2, x3+x, x3+1}.

Jedes dieser Polynome hat Grad genau 3 (Leitkoeffizient 1).

Ergebnis

P3(R)P_3(\R)P3​(R) ist ein Vektorraum über R\RR der Dimension 4. Eine Basis, die nur Polynome dritten Grades enthält, ist { x3, x3+x2, x3+x, x3+1 }.\{\,x^3,\ x^3 + x^2,\ x^3 + x,\ x^3 + 1\,\}.{x3, x3+x2, x3+x, x3+1}.

Probe

Beispiel p=2−x+5x2+4x3p = 2 - x + 5x^2 + 4x^3p=2−x+5x2+4x3: Die Formel liefert 2(x3+1)−(x3+x)+5(x3+x2)+(4−2+1−5)x3=2−x+5x2+(2−1+5−2)x3=2−x+5x2+4x32(x^3 + 1) - (x^3 + x) + 5(x^3 + x^2) + (4 - 2 + 1 - 5)x^3 = 2 - x + 5x^2 + (2 - 1 + 5 - 2)x^3 = 2 - x + 5x^2 + 4x^32(x3+1)−(x3+x)+5(x3+x2)+(4−2+1−5)x3=2−x+5x2+(2−1+5−2)x3=2−x+5x2+4x3 ✓.

Andere Lösungen

Die Basis ist nicht eindeutig; z. B. ist auch {x3, x3+x2+x+1, 2x3+x, −x3+1}\{x^3,\ x^3 + x^2 + x + 1,\ 2x^3 + x,\ -x^3 + 1\}{x3, x3+x2+x+1, 2x3+x, −x3+1} eine (das prüft man genauso). Wichtig ist nur: vier Polynome vom Grad 3, die linear unabhängig sind.

Hilfreiches

Basis

Eine Teilmenge BBB eines Vektorraums VVV ist eine Basis, wenn BBB linear unabhängig ist und [B]=V[B] = V[B]=V gilt.

Basisergänzung / Dimension

In einem nnn-dimensionalen Vektorraum ist jede linear unabhängige Menge mit nnn Elementen bereits eine Basis.

Typische Fehler
  • Die Menge der Polynome vom Grad genau 3 ist kein Vektorraum (x3+(−x3+x)=xx^3 + (-x^3 + x) = xx3+(−x3+x)=x); trotzdem kann eine Basis nur aus solchen Polynomen bestehen.
  • Vier Polynome mit lauter x3x^3x3-Termen, z. B. x3,2x3,x3+x,x3+1x^3, 2x^3, x^3 + x, x^3 + 1x3,2x3,x3+x,x3+1: linear abhängig, da x2x^2x2 nicht erzeugt wird.
