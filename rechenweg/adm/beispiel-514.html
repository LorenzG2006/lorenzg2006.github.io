Angabe Originalseite

Wie 513, nur für 1−x+x31 - x + x^31−x+x3, 3−x2+x33 - x^2 + x^33−x2+x3 und −5+3x+x2−4x3-5 + 3x + x^2 - 4x^3−5+3x+x2−4x3.

(Bsp. 513: Im Vektorraum V={∑i=0naixi∣ai∈R, n∈N}V = \left\{\sum_{i=0}^n a_ix^i \mid a_i \in \R,\ n \in \N\right\}V={∑i=0n​ai​xi∣ai​∈R, n∈N} aller reellen Polynome untersuchen, ob die gegebenen Polynome linear unabhängig sind.)

Lösung verborgen – erst selbst probieren!

Überblick

Linearkombination gleich Nullpolynom setzen, nach Potenzen ordnen, Koeffizientenvergleich. Das homogene Gleichungssystem entscheidet: nur triviale Lösung ⇒ unabhängig.

p1=1−x+x3,p2=3−x2+x3,p3=−5+3x+x2−4x3.p_1 = 1 - x + x^3,\qquad p_2 = 3 - x^2 + x^3,\qquad p_3 = -5 + 3x + x^2 - 4x^3 .p1​=1−x+x3,p2​=3−x2+x3,p3​=−5+3x+x2−4x3.

Schritt 1: Ansatz und Koeffizientenvergleich

Aus λ1p1+λ2p2+λ3p3=0\lambda_1p_1 + \lambda_2p_2 + \lambda_3p_3 = 0λ1​p1​+λ2​p2​+λ3​p3​=0 folgt

(λ1+3λ2−5λ3)+(−λ1+3λ3) x+(−λ2+λ3) x2+(λ1+λ2−4λ3) x3=0,(\lambda_1 + 3\lambda_2 - 5\lambda_3) + (-\lambda_1 + 3\lambda_3)\,x + (-\lambda_2 + \lambda_3)\,x^2 + (\lambda_1 + \lambda_2 - 4\lambda_3)\,x^3 = 0,(λ1​+3λ2​−5λ3​)+(−λ1​+3λ3​)x+(−λ2​+λ3​)x2+(λ1​+λ2​−4λ3​)x3=0,

also

λ1+3λ2−5λ3=0(I: x0)−λ1+3λ3=0(II: x1)−λ2+λ3=0(III: x2)λ1+λ2−4λ3=0(IV: x3)\begin{aligned} \lambda_1 + 3\lambda_2 - 5\lambda_3 &= 0 && \text{(I: } x^0)\\ -\lambda_1 + 3\lambda_3 &= 0 && \text{(II: } x^1)\\ -\lambda_2 + \lambda_3 &= 0 && \text{(III: } x^2)\\ \lambda_1 + \lambda_2 - 4\lambda_3 &= 0 && \text{(IV: } x^3) \end{aligned}λ1​+3λ2​−5λ3​−λ1​+3λ3​−λ2​+λ3​λ1​+λ2​−4λ3​​=0=0=0=0​​(I: x0)(II: x1)(III: x2)(IV: x3)​

Schritt 2: Lösen

  • II: λ1=3λ3\lambda_1 = 3\lambda_3λ1​=3λ3​.
  • III: λ2=λ3\lambda_2 = \lambda_3λ2​=λ3​.
  • In I: 3λ3+3λ3−5λ3=λ3=03\lambda_3 + 3\lambda_3 - 5\lambda_3 = \lambda_3 = 03λ3​+3λ3​−5λ3​=λ3​=0.
  • Also λ1=λ2=λ3=0\lambda_1 = \lambda_2 = \lambda_3 = 0λ1​=λ2​=λ3​=0. (IV: 3λ3+λ3−4λ3=03\lambda_3 + \lambda_3 - 4\lambda_3 = 03λ3​+λ3​−4λ3​=0 – hätte allein nichts entschieden!)

Nur die triviale Lösung.

Ergebnis

1−x+x31 - x + x^31−x+x3, 3−x2+x33 - x^2 + x^33−x2+x3 und −5+3x+x2−4x3-5 + 3x + x^2 - 4x^3−5+3x+x2−4x3 sind linear unabhängig.

Knapp an der Abhängigkeit vorbei

Die x3x^3x3-Gleichung IV ist für die Lösungen von II und III automatisch erfüllt. Nur die konstante Gleichung I erzwingt λ3=0\lambda_3 = 0λ3​=0. Wer I übersieht oder sich dort verrechnet, kommt fälschlich auf „linear abhängig“.

Hilfreiches

Koeffizientenvergleich

∑iaixi=0\sum_i a_ix^i = 0∑i​ai​xi=0 (als Polynom)   ⟺  \iff⟺ ai=0a_i = 0ai​=0 für alle iii.

Typische Fehler
  • Nur so viele Gleichungen wie Unbekannte (drei) verwenden und die vierte ignorieren – jede Gleichung muss erfüllt sein.
  • Vorzeichen bei −x-x−x und −x2-x^2−x2 übersehen.
