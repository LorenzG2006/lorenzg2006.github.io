Überblick

Wir wenden das Gauß-Verfahren auf die erweiterte Matrix an. Über R\RR wird sich ein Widerspruch 0=c≠00 = c\ne 00=c=0 ergeben. In Z2\Z_2Z2​ rechnet man modulo 222: Dort kann aus ccc eine 000 werden, und das System wird lösbar. Wichtig: In Z2\Z_2Z2​ gilt −1=1-1 = 1−1=1 und 2=02 = 02=0; man reduziert am besten zuerst alle Koeffizienten modulo 222.

Hilfreiches

Lösbarkeitskriterium

Ax=bA\mathbf{x} = \mathbf{b}Ax=b ist genau dann lösbar, wenn rg⁡A=rg⁡(A∣b)\rg A = \rg(A\mid\mathbf{b})rgA=rg(A∣b); die Lösungsmenge hat dann n−rg⁡An - \rg An−rgA freie Parameter. Über einem endlichen Körper Zp\Z_pZp​ sind das genau p n−rg⁡Ap^{\,n - \rg A}pn−rgA Lösungen.

Rechnen in ℤ₂

0+0=00 + 0 = 00+0=0, 0+1=10 + 1 = 10+1=1, 1+1=01 + 1 = 01+1=0; −a=a-a = a−a=a. Ganze Zahlen werden durch ihren Rest modulo 222 ersetzt.

Typische Fehler
  • Das Ergebnis aus (a) einfach nach (b) übertragen („unlösbar“) – der Rang hängt vom Körper ab.
  • In Z2\Z_2Z2​ negative Koeffizienten stehen lassen, statt sie auf 000 oder 111 zu reduzieren.
