Angabe Originalseite

Gesucht ist die allgemeine Lösung der Differenzengleichung

xn+2−6xn+1+9xn=8+3n,n=0,1,2,…x_{n+2} - 6x_{n+1} + 9x_n = 8 + 3^n, \qquad n = 0, 1, 2, \dotsxn+2​−6xn+1​+9xn​=8+3n,n=0,1,2,…

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Allgemeine Lösung = homogene Lösung + partikuläre Lösung. Die charakteristische Gleichung λ2−6λ+9=(λ−3)2\lambda^2 - 6\lambda + 9 = (\lambda - 3)^2λ2−6λ+9=(λ−3)2 hat die doppelte Wurzel 333. Die rechte Seite zerlegen wir in 888 und 3n3^n3n und suchen für jeden Teil eine partikuläre Lösung (Superposition):

  • für 888: konstanter Ansatz ccc (da 111 keine Wurzel ist),
  • für 3n3^n3n: Weil 333 eine doppelte Wurzel ist, lösen 3n3^n3n und n 3nn\,3^nn3n bereits die homogene Gleichung („Resonanz“); der Ansatz muss daher mit n2n^2n2 multipliziert werden: D n2 3nD\,n^2\,3^nDn23n.

Schritt 1: Homogene Gleichung

λ2−6λ+9=0  ⟺  (λ−3)2=0\lambda^2 - 6\lambda + 9 = 0 \iff (\lambda - 3)^2 = 0λ2−6λ+9=0⟺(λ−3)2=0, also λ=3\lambda = 3λ=3 doppelt. Damit

xn(h)=(C1+C2 n) 3n.x_n^{(h)} = (C_1 + C_2\,n)\,3^n.xn(h)​=(C1​+C2​n)3n.

Schritt 2: Partikuläre Lösung zur rechten Seite 888

Ansatz xn=cx_n = cxn​=c: c−6c+9c=4c=8c - 6c + 9c = 4c = 8c−6c+9c=4c=8, also c=2c = 2c=2.

Schritt 3: Partikuläre Lösung zur rechten Seite 3n3^n3n

Warum nicht D⋅3nD\cdot 3^nD⋅3n oder D n 3nD\,n\,3^nDn3n? Beide lösen die homogene Gleichung, ergeben beim Einsetzen also 000 statt 3n3^n3n – egal wie man DDD wählt. Daher der Ansatz

xn=D n2 3n.x_n = D\,n^2\,3^n.xn​=Dn23n.

Einsetzen:

D(n+2)2 3n+2−6D(n+1)2 3n+1+9D n2 3n=9D⋅3n[(n+2)2−2(n+1)2+n2](3n+2=9⋅3n, 6⋅3n+1=18⋅3n)=9D⋅3n[n2+4n+4−2n2−4n−2+n2](ausmultipliziert)=9D⋅3n⋅2=18D⋅3n.\begin{aligned} &D(n+2)^2\,3^{n+2} - 6D(n+1)^2\,3^{n+1} + 9D\,n^2\,3^n && \\ &= 9D\cdot 3^n\bigl[(n+2)^2 - 2(n+1)^2 + n^2\bigr] && \bigl(3^{n+2} = 9\cdot 3^n,\ 6\cdot 3^{n+1} = 18\cdot 3^n\bigr)\\ &= 9D\cdot 3^n\bigl[n^2 + 4n + 4 - 2n^2 - 4n - 2 + n^2\bigr] && \text{(ausmultipliziert)}\\ &= 9D\cdot 3^n\cdot 2 = 18D\cdot 3^n. && \end{aligned}​D(n+2)23n+2−6D(n+1)23n+1+9Dn23n=9D⋅3n[(n+2)2−2(n+1)2+n2]=9D⋅3n[n2+4n+4−2n2−4n−2+n2]=9D⋅3n⋅2=18D⋅3n.​​(3n+2=9⋅3n, 6⋅3n+1=18⋅3n)(ausmultipliziert)​

Das soll gleich 3n3^n3n sein: 18D=118D = 118D=1, also D=118D = \frac{1}{18}D=181​. Partikuläre Lösung:

Schritt 4: Allgemeine Lösung

Hilfreiches

Ansatz bei rechter Seite s⋅μns\cdot\mu^ns⋅μn

Für xn+2+p xn+1+q xn=s μnx_{n+2} + p\,x_{n+1} + q\,x_n = s\,\mu^nxn+2​+pxn+1​+qxn​=sμn setzt man

  • xn=D μnx_n = D\,\mu^nxn​=Dμn, wenn μ\muμ keine Wurzel der charakteristischen Gleichung ist,
  • xn=D n μnx_n = D\,n\,\mu^nxn​=Dnμn, wenn μ\muμ eine einfache Wurzel ist,
  • xn=D n2μnx_n = D\,n^2\mu^nxn​=Dn2μn, wenn μ\muμ eine doppelte Wurzel ist („Resonanz“).

Konstante rechte Seiten sind der Fall μ=1\mu = 1μ=1.

Superpositionsprinzip

Löst unu_nun​ die Gleichung mit rechter Seite sns_nsn​ und vnv_nvn​ die mit rechter Seite tnt_ntn​, so löst un+vnu_n + v_nun​+vn​ die Gleichung mit rechter Seite sn+tns_n + t_nsn​+tn​.

Typische Fehler
  • Ansatz D 3nD\,3^nD3n oder D n 3nD\,n\,3^nDn3n für den Teil 3n3^n3n: Er löst die homogene Gleichung und führt auf den Widerspruch 0=3n0 = 3^n0=3n.
  • Beim Einsetzen die Potenzen nicht sauber herausziehen: 6⋅3n+1=18⋅3n=9⋅2⋅3n6\cdot 3^{n+1} = 18\cdot 3^n = 9\cdot 2\cdot 3^n6⋅3n+1=18⋅3n=9⋅2⋅3n.
  • Die Konstante 222 für die rechte Seite 888 vergessen oder als 888 übernehmen (Koeffizientensumme 1−6+9=41 - 6 + 9 = 41−6+9=4).
