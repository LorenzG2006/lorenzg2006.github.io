Angabe Originalseite

Berechnen Sie die folgenden Summen durch Aufstellen und Lösen einer Rekursion mittels Ansatzmethode.

∑i=1ni2\sum_{i=1}^{n} i^2i=1∑n​i2

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Wie in Bsp. 236: Sn=∑i=1ni2S_n = \sum_{i=1}^n i^2Sn​=∑i=1n​i2 erfüllt Sn−Sn−1=n2S_n - S_{n-1} = n^2Sn​−Sn−1​=n2, S0=0S_0 = 0S0​=0. Die homogene Lösung ist eine Konstante (charakteristische Wurzel 111). Die Störfunktion n2=n2⋅1nn^2 = n^2\cdot 1^nn2=n2⋅1n ist ein Polynom vom Grad 222; weil 111 einfache Wurzel ist, lautet der Ansatz n⋅(Polynom vom Grad 2)n\cdot(\text{Polynom vom Grad } 2)n⋅(Polynom vom Grad 2).

Schritt 1: Rekursion aufstellen

Sn=∑i=1n−1i2+n2=Sn−1+n2(n≥1),S0=0,S_n = \sum_{i=1}^{n-1} i^2 + n^2 = S_{n-1} + n^2 \qquad (n \ge 1), \qquad S_0 = 0,Sn​=i=1∑n−1​i2+n2=Sn−1​+n2(n≥1),S0​=0,

also Sn−Sn−1=n2S_n - S_{n-1} = n^2Sn​−Sn−1​=n2.

Schritt 2: Homogene Gleichung

Charakteristische Gleichung von Sn−Sn−1=0S_n - S_{n-1} = 0Sn​−Sn−1​=0: λ−1=0\lambda - 1 = 0λ−1=0, also λ=1\lambda = 1λ=1 und

Sn(h)=C.S_n^{(h)} = C.Sn(h)​=C.

Schritt 3: Partikuläre Lösung

Ansatz (Resonanz mit der Wurzel 111, daher Faktor nnn):

Sn(p)=n(An2+Bn+C′)=An3+Bn2+C′n.S_n^{(p)} = n(An^2 + Bn + C') = An^3 + Bn^2 + C'n.Sn(p)​=n(An2+Bn+C′)=An3+Bn2+C′n.

Für das Einsetzen brauchen wir die Differenzen der Potenzen:

n3−(n−1)3=3n2−3n+1,n2−(n−1)2=2n−1,n−(n−1)=1.n^3 - (n-1)^3 = 3n^2 - 3n + 1, \qquad n^2 - (n-1)^2 = 2n - 1, \qquad n - (n-1) = 1.n3−(n−1)3=3n2−3n+1,n2−(n−1)2=2n−1,n−(n−1)=1.

(Aus (n−1)3=n3−3n2+3n−1(n-1)^3 = n^3 - 3n^2 + 3n - 1(n−1)3=n3−3n2+3n−1 und (n−1)2=n2−2n+1(n-1)^2 = n^2 - 2n + 1(n−1)2=n2−2n+1.) Damit

Sn(p)−Sn−1(p)=A(3n2−3n+1)+B(2n−1)+C′=3A n2+(−3A+2B) n+(A−B+C′).(nach Potenzen geordnet)\begin{aligned} S_n^{(p)} - S_{n-1}^{(p)} &= A(3n^2 - 3n + 1) + B(2n - 1) + C' && \\ &= 3A\,n^2 + (-3A + 2B)\,n + (A - B + C'). && \text{(nach Potenzen geordnet)} \end{aligned}Sn(p)​−Sn−1(p)​​=A(3n2−3n+1)+B(2n−1)+C′=3An2+(−3A+2B)n+(A−B+C′).​​(nach Potenzen geordnet)​

Koeffizientenvergleich mit n2=1⋅n2+0⋅n+0n^2 = 1\cdot n^2 + 0\cdot n + 0n2=1⋅n2+0⋅n+0:

n2:3A=1  ⟹  A=13,n1:−3A+2B=0  ⟹  2B=1, B=12,n0:A−B+C′=0  ⟹  C′=12−13=16.\begin{aligned} n^2:&\quad 3A = 1 &&\implies A = \tfrac13,\\ n^1:&\quad -3A + 2B = 0 &&\implies 2B = 1,\ B = \tfrac12,\\ n^0:&\quad A - B + C' = 0 &&\implies C' = \tfrac12 - \tfrac13 = \tfrac16. \end{aligned}n2:n1:n0:​3A=1−3A+2B=0A−B+C′=0​​⟹A=31​,⟹2B=1, B=21​,⟹C′=21​−31​=61​.​

Also

Sn(p)=n33+n22+n6=2n3+3n2+n6=n(2n2+3n+1)6=n(n+1)(2n+1)6.S_n^{(p)} = \frac{n^3}{3} + \frac{n^2}{2} + \frac{n}{6} = \frac{2n^3 + 3n^2 + n}{6} = \frac{n(2n^2 + 3n + 1)}{6} = \frac{n(n+1)(2n+1)}{6}.Sn(p)​=3n3​+2n2​+6n​=62n3+3n2+n​=6n(2n2+3n+1)​=6n(n+1)(2n+1)​.

(Faktorisierung: (n+1)(2n+1)=2n2+n+2n+1=2n2+3n+1(n+1)(2n+1) = 2n^2 + n + 2n + 1 = 2n^2 + 3n + 1(n+1)(2n+1)=2n2+n+2n+1=2n2+3n+1 ✓.)

Hilfreiches

Ansatz bei polynomialer Störfunktion

Für Sn−Sn−1=p(n)S_n - S_{n-1} = p(n)Sn​−Sn−1​=p(n) mit einem Polynom ppp vom Grad ddd ist Sn(p)=n⋅q(n)S_n^{(p)} = n\cdot q(n)Sn(p)​=n⋅q(n) mit einem Polynom qqq vom Grad ddd anzusetzen – die Summe ist also ein Polynom vom Grad d+1d + 1d+1.

Differenzen von Potenzen

n2−(n−1)2=2n−1,n3−(n−1)3=3n2−3n+1.n^2 - (n-1)^2 = 2n - 1,\qquad n^3 - (n-1)^3 = 3n^2 - 3n + 1.n2−(n−1)2=2n−1,n3−(n−1)3=3n2−3n+1. Allgemein ist nk−(n−1)kn^k - (n-1)^knk−(n−1)k ein Polynom vom Grad k−1k - 1k−1 mit Leitkoeffizient kkk.

Typische Fehler
  • Ansatz nur vom Grad 222 (An2+Bn+CAn^2 + Bn + CAn2+Bn+C): Die Differenz wäre dann nur linear und kann n2n^2n2 nicht treffen.
  • Vorzeichenfehler in (n−1)3=n3−3n2+3n−1(n-1)^3 = n^3 - 3n^2 + 3n - 1(n−1)3=n3−3n2+3n−1.
  • Die Konstante der homogenen Lösung und die Konstante im Ansatz mit demselben Buchstaben bezeichnen und dann verwechseln.
