Angabe Originalseite

Entscheiden Sie mit Hilfe einer Wahrheitstafel, ob die folgenden Äquivalenzen richtig sind. →\to→ und ↔\leftrightarrow↔ bezeichnen Sub- bzw. Bijunktion.

(a∧¬b)∧¬c⟺a∧¬(b∧¬c)(a \land \lnot b) \land \lnot c \Longleftrightarrow a \land \lnot(b \land \lnot c)(a∧¬b)∧¬c⟺a∧¬(b∧¬c)

Ergebnis

Die Äquivalenz ist falsch. Gegenbeispiel: a=1, b=1, c=1a = 1,\ b = 1,\ c = 1a=1, b=1, c=1 liefert links 000, rechts 111 (ebenso a=1,b=0,c=1a = 1, b = 0, c = 1a=1,b=0,c=1). Es gilt nur die Implikation (a∧¬b)∧¬c⇒a∧¬(b∧¬c)(a \land \lnot b) \land \lnot c \Rightarrow a \land \lnot(b \land \lnot c)(a∧¬b)∧¬c⇒a∧¬(b∧¬c).

Hilfreiches

Regeln von de Morgan

¬(p∧q)⟺¬p∨¬q,¬(p∨q)⟺¬p∧¬q.\lnot(p \land q) \Longleftrightarrow \lnot p \lor \lnot q, \qquad \lnot(p \lor q) \Longleftrightarrow \lnot p \land \lnot q .¬(p∧q)⟺¬p∨¬q,¬(p∨q)⟺¬p∧¬q.

Gegenbeispiel genügt

Um eine Äquivalenz zu widerlegen, reicht eine einzige Belegung, bei der die Seiten verschiedene Werte haben. Um sie zu beweisen, braucht man alle Belegungen.

Typische Fehler
  • Die Negation „in die Klammer ziehen“, ohne ∧\land∧ in ∨\lor∨ zu verwandeln: ¬(b∧¬c)≠¬b∧c\lnot(b \land \lnot c) \ne \lnot b \land c¬(b∧¬c)=¬b∧c.
  • Vergessen, dass ¬¬c=c\lnot \lnot c = c¬¬c=c.
