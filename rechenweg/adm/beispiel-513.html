Angabe Originalseite

Sei V={∑i=0naixi∣ai∈R, n∈N}V = \left\{\sum_{i=0}^n a_ix^i \mid a_i \in \R,\ n \in \N\right\}V={∑i=0n​ai​xi∣ai​∈R, n∈N} der Vektorraum aller Polynome mit reellen Koeffizienten. Untersuchen Sie, ob 1+x+x31 + x + x^31+x+x3, 3−x+x23 - x + x^23−x+x2 und −5+x+x2−x3-5 + x + x^2 - x^3−5+x+x2−x3 linear unabhängig sind.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Wir setzen eine Linearkombination gleich dem Nullpolynom. Ein Polynom ist genau dann das Nullpolynom, wenn alle Koeffizienten null sind (Koeffizientenvergleich). Das liefert ein homogenes lineares Gleichungssystem für die Skalare; hat es nur die triviale Lösung, sind die Polynome unabhängig.

p1=1+x+x3,p2=3−x+x2,p3=−5+x+x2−x3.p_1 = 1 + x + x^3,\qquad p_2 = 3 - x + x^2,\qquad p_3 = -5 + x + x^2 - x^3 .p1​=1+x+x3,p2​=3−x+x2,p3​=−5+x+x2−x3.

Schritt 1: Ansatz

Seien λ1,λ2,λ3∈R\lambda_1,\lambda_2,\lambda_3\in\Rλ1​,λ2​,λ3​∈R mit λ1p1+λ2p2+λ3p3=0\lambda_1p_1 + \lambda_2p_2 + \lambda_3p_3 = 0λ1​p1​+λ2​p2​+λ3​p3​=0 (Nullpolynom). Nach Potenzen geordnet:

(λ1+3λ2−5λ3)+(λ1−λ2+λ3) x+(λ2+λ3) x2+(λ1−λ3) x3=0.(\lambda_1 + 3\lambda_2 - 5\lambda_3) + (\lambda_1 - \lambda_2 + \lambda_3)\,x + (\lambda_2 + \lambda_3)\,x^2 + (\lambda_1 - \lambda_3)\,x^3 = 0 .(λ1​+3λ2​−5λ3​)+(λ1​−λ2​+λ3​)x+(λ2​+λ3​)x2+(λ1​−λ3​)x3=0.

Schritt 2: Koeffizientenvergleich

λ1+3λ2−5λ3=0(I: x0)λ1−λ2+λ3=0(II: x1)λ2+λ3=0(III: x2)λ1−λ3=0(IV: x3)\begin{aligned} \lambda_1 + 3\lambda_2 - 5\lambda_3 &= 0 && \text{(I: } x^0)\\ \lambda_1 - \lambda_2 + \lambda_3 &= 0 && \text{(II: } x^1)\\ \lambda_2 + \lambda_3 &= 0 && \text{(III: } x^2)\\ \lambda_1 - \lambda_3 &= 0 && \text{(IV: } x^3) \end{aligned}λ1​+3λ2​−5λ3​λ1​−λ2​+λ3​λ2​+λ3​λ1​−λ3​​=0=0=0=0​​(I: x0)(II: x1)(III: x2)(IV: x3)​

Schritt 3: Lösen

  • Aus IV: λ1=λ3\lambda_1 = \lambda_3λ1​=λ3​.
  • Aus III: λ2=−λ3\lambda_2 = -\lambda_3λ2​=−λ3​.
  • In II: λ3−(−λ3)+λ3=3λ3=0\lambda_3 - (-\lambda_3) + \lambda_3 = 3\lambda_3 = 0λ3​−(−λ3​)+λ3​=3λ3​=0, also λ3=0\lambda_3 = 0λ3​=0.
  • Damit λ1=0\lambda_1 = 0λ1​=0 und λ2=0\lambda_2 = 0λ2​=0. (I ist dann ebenfalls erfüllt.)

Nur die triviale Lösung.

Hilfreiches

Koeffizientenvergleich

Zwei Polynome sind genau dann gleich, wenn sie in allen Koeffizienten übereinstimmen. Insbesondere ist ∑aixi=0\sum a_ix^i = 0∑ai​xi=0 genau dann, wenn alle ai=0a_i = 0ai​=0 sind (die Monome 1,x,x2,…1, x, x^2, \dots1,x,x2,… sind linear unabhängig).

Typische Fehler
  • Fehlende Potenzen übersehen: p1p_1p1​ hat keinen x2x^2x2-Term, p2p_2p2​ keinen x3x^3x3-Term – deren Koeffizient ist 000.
  • Nur einige Gleichungen verwenden und aus einer gefundenen Lösung voreilig schließen.
