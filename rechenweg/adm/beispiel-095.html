Angabe Originalseite

Beweisen Sie die folgenden Beziehungen mit Hilfe von Elementtafeln oder geben Sie ein konkretes Gegenbeispiel an.

(A∪B)∩(B∪C)′⊆A∩B′(A \cup B) \cap (B \cup C)' \subseteq A \cap B'(A∪B)∩(B∪C)′⊆A∩B′

Überblick

Diesmal ist eine Inklusion X⊆YX \subseteq YX⊆Y gefragt, keine Gleichheit. In der Elementtafel bedeutet das: In jeder Zeile, in der die Spalte von XXX eine 111 hat, muss auch die Spalte von YYY eine 111 haben. (Zeilen mit 000 links und 111 rechts sind erlaubt.)

Komplemente beziehen sich auf eine feste Grundmenge M⊇A∪B∪CM \supseteq A \cup B \cup CM⊇A∪B∪C.

Die linke Menge enthält nur Elemente des Typs von Zeile 4 (x∈Ax \in Ax∈A, x∉Bx \notin Bx∈/B, x∉Cx \notin Cx∈/C). In dieser Zeile ist auch x∈A∩B′x \in A \cap B'x∈A∩B′. Es gibt also keine Zeile mit „links 111, rechts 000“ – die Inklusion gilt.

Zeile 3 zeigt zugleich, dass keine Gleichheit gilt: Ein Element x∈A∩Cx \in A \cap Cx∈A∩C, x∉Bx \notin Bx∈/B, liegt rechts, aber nicht links.

Ergebnis

Die Inklusion (A∪B)∩(B∪C)′⊆A∩B′(A \cup B) \cap (B \cup C)' \subseteq A \cap B'(A∪B)∩(B∪C)′⊆A∩B′ gilt für alle Mengen; genauer ist die linke Seite gleich A∩B′∩C′A \cap B' \cap C'A∩B′∩C′. Gleichheit gilt im Allgemeinen nicht (z. B. A=C={1}A = C = \{1\}A=C={1}, B=∅B = \emptysetB=∅: links ∅\emptyset∅, rechts {1}\{1\}{1}). ■\blacksquare■

Kontrolle

Mit Python an 300030003000 zufälligen Teilmengen von {0,…,7}\{0, \dots, 7\}{0,…,7} geprüft: Die Inklusion gilt immer. Für A=C={1}A = C = \{1\}A=C={1}, B=∅B = \emptysetB=∅: (A∪B)∩(B∪C)′={1}∩{1}′=∅(A \cup B) \cap (B \cup C)' = \{1\} \cap \{1\}' = \emptyset(A∪B)∩(B∪C)′={1}∩{1}′=∅. ✓

Hilfreiches

Inklusion in der Elementtafel

X⊆YX \subseteq YX⊆Y gilt genau dann, wenn in jeder Zeile aus „x∈Xx \in Xx∈X“ (111) auch „x∈Yx \in Yx∈Y“ (111) folgt – aussagenlogisch: (x∈X)→(x∈Y)(x \in X) \to (x \in Y)(x∈X)→(x∈Y) ist eine Tautologie.

Rechenregeln

De Morgan: (B∪C)′=B′∩C′(B \cup C)' = B' \cap C'(B∪C)′=B′∩C′. Distributivgesetz: (A∪B)∩D=(A∩D)∪(B∩D)(A \cup B) \cap D = (A \cap D) \cup (B \cap D)(A∪B)∩D=(A∩D)∪(B∩D). Außerdem X∩Y⊆XX \cap Y \subseteq XX∩Y⊆X.

Typische Fehler
  • Bei einer Inklusion Gleichheit der Spalten verlangen und deshalb fälschlich „gilt nicht“ antworten.
  • Die Richtung verwechseln: Zeile 3 widerlegt nur ⊇\supseteq⊇, nicht ⊆\subseteq⊆.

Verwandte Beispiele: Bsp. 94, Bsp. 93, Bsp. 91.
