Überblick
  1. Charakteristische Gleichung λ2−λ+1=0\lambda^2 - \lambda + 1 = 0λ2−λ+1=0 mit den komplexen Wurzeln [1,±π3][1, \pm\frac{\pi}{3}][1,±3π​] – homogene Lösung mit cos⁡nπ3\cos\frac{n\pi}{3}cos3nπ​, sin⁡nπ3\sin\frac{n\pi}{3}sin3nπ​.
  2. Störfunktion 1+cos⁡nπ41 + \cos\frac{n\pi}{4}1+cos4nπ​: für 111 Ansatz ccc, für cos⁡nπ4\cos\frac{n\pi}{4}cos4nπ​ Ansatz Pcos⁡nπ4+Qsin⁡nπ4P\cos\frac{n\pi}{4} + Q\sin\frac{n\pi}{4}Pcos4nπ​+Qsin4nπ​. Keine Resonanz, da π4≠±π3\frac{\pi}{4} \ne \pm\frac{\pi}{3}4π​=±3π​ (und 111 keine Wurzel ist).
  3. Konstanten aus a0a_0a0​, a1a_1a1​.

Schritt 1: Homogene Rekursion

λ2−λ+1=0  ⟹  λ1,2=1±1−42=12±32 i.\lambda^2 - \lambda + 1 = 0 \implies \lambda_{1,2} = \frac{1 \pm \sqrt{1 - 4}}{2} = \frac12 \pm \frac{\sqrt3}{2}\,i.λ2−λ+1=0⟹λ1,2​=21±1−4​​=21​±23​​i.

Betrag 14+34=1\sqrt{\frac14 + \frac34} = 141​+43​​=1, Winkel φ\varphiφ mit cos⁡φ=12\cos\varphi = \frac12cosφ=21​, sin⁡φ=32\sin\varphi = \frac{\sqrt3}{2}sinφ=23​​, also φ=π3\varphi = \frac{\pi}{3}φ=3π​:

an(h)=Acos⁡nπ3+Bsin⁡nπ3.a_n^{(h)} = A\cos\frac{n\pi}{3} + B\sin\frac{n\pi}{3}.an(h)​=Acos3nπ​+Bsin3nπ​.

Schritt 2: Partikuläre Lösung zur Störfunktion 111

111 ist keine Wurzel (1−1+1=1≠01 - 1 + 1 = 1 \ne 01−1+1=1=0). Ansatz ccc: c−c+c=c=1c - c + c = c = 1c−c+c=c=1.

Schritt 3: Partikuläre Lösung zur Störfunktion cos⁡(nπ/4)\cos(n\pi/4)cos(nπ/4)

un−1=22(P−Q)cos⁡nθ+22(P+Q)sin⁡nθ,un−2=−Qcos⁡nθ+Psin⁡nθ.\begin{aligned} u_{n-1} &= \tfrac{\sqrt2}{2}(P - Q)\cos n\theta + \tfrac{\sqrt2}{2}(P + Q)\sin n\theta,\\ u_{n-2} &= -Q\cos n\theta + P\sin n\theta. \end{aligned}un−1​un−2​​=22​​(P−Q)cosnθ+22​​(P+Q)sinnθ,=−Qcosnθ+Psinnθ.​

Damit

un−un−1+un−2=(P−22(P−Q)−Q)cos⁡nθ+(Q−22(P+Q)+P)sin⁡nθ=(1−22)(P−Q)cos⁡nθ+(1−22)(P+Q)sin⁡nθ=!cos⁡nθ.\begin{aligned} u_n - u_{n-1} + u_{n-2} &= \Bigl(P - \tfrac{\sqrt2}{2}(P - Q) - Q\Bigr)\cos n\theta + \Bigl(Q - \tfrac{\sqrt2}{2}(P + Q) + P\Bigr)\sin n\theta\\ &= \Bigl(1 - \tfrac{\sqrt2}{2}\Bigr)(P - Q)\cos n\theta + \Bigl(1 - \tfrac{\sqrt2}{2}\Bigr)(P + Q)\sin n\theta \overset{!}{=} \cos n\theta. \end{aligned}un​−un−1​+un−2​​=(P−22​​(P−Q)−Q)cosnθ+(Q−22​​(P+Q)+P)sinnθ=(1−22​​)(P−Q)cosnθ+(1−22​​)(P+Q)sinnθ=!cosnθ.​

P+Q=0,(1−22)(P−Q)=1.P + Q = 0, \qquad \Bigl(1 - \tfrac{\sqrt2}{2}\Bigr)(P - Q) = 1.P+Q=0,(1−22​​)(P−Q)=1.

Hilfreiches

Ansatz bei trigonometrischer Störfunktion

Für αcos⁡nθ+βsin⁡nθ\alpha\cos n\theta + \beta\sin n\thetaαcosnθ+βsinnθ setzt man Pcos⁡nθ+Qsin⁡nθP\cos n\theta + Q\sin n\thetaPcosnθ+Qsinnθ an (immer beide Terme). Resonanz – und damit ein zusätzlicher Faktor nnn – liegt nur vor, wenn eiθe^{i\theta}eiθ eine Wurzel der charakteristischen Gleichung ist.

Additionstheoreme

cos⁡(x−y)=cos⁡xcos⁡y+sin⁡xsin⁡y,sin⁡(x−y)=sin⁡xcos⁡y−cos⁡xsin⁡y.\cos(x - y) = \cos x\cos y + \sin x\sin y, \qquad \sin(x - y) = \sin x\cos y - \cos x\sin y.cos(x−y)=cosxcosy+sinxsiny,sin(x−y)=sinxcosy−cosxsiny.

Typische Fehler
  • Nur Pcos⁡nπ4P\cos\frac{n\pi}{4}Pcos4nπ​ ansetzen: Dann bleibt ein sin⁡\sinsin-Rest übrig, den man nicht ausgleichen kann.
  • Die homogene Lösung mit dem Winkel der Störfunktion (π4\frac{\pi}{4}4π​) statt mit dem Winkel der Wurzeln (π3\frac{\pi}{3}3π​) schreiben.
  • Den konstanten Ansatz falsch auswerten: Die Koeffizientensumme ist 1−1+1=11 - 1 + 1 = 11−1+1=1, also c=1c = 1c=1.
