Angabe Originalseite

Untersuchen Sie, ob die Menge MMM mit der Operation ∘\circ∘ ein Gruppoid, eine Halbgruppe, ein Monoid bzw. eine Gruppe ist:

M=P(A)M = \mathcal P(A)M=P(A), d. h. die Potenzmenge der Menge AAA, B∘C=B∩CB \circ C = B \cap CB∘C=B∩C.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Wie bei der Vereinigung prüfen wir die vier Stufen. Beim Durchschnitt ist die „größte“ Menge AAA neutral (Schneiden mit AAA ändert eine Teilmenge nicht), und Durchschnitte können Mengen nur verkleinern – das verhindert Inverse.

Gruppoid

Für B,C⊆AB, C\subseteq AB,C⊆A ist B∩C⊆B⊆AB\cap C\subseteq B \subseteq AB∩C⊆B⊆A, also B∩C∈P(A)B\cap C\in\mathcal P(A)B∩C∈P(A) ⇒ Gruppoid ✓.

Halbgruppe

(B∩C)∩D=B∩(C∩D)(B\cap C)\cap D = B\cap(C\cap D)(B∩C)∩D=B∩(C∩D): Beide Seiten bestehen aus den Elementen, die in allen drei Mengen liegen ⇒ Halbgruppe ✓. Auch kommutativ.

Monoid

A∈P(A)A\in\mathcal P(A)A∈P(A) und für jedes B⊆AB\subseteq AB⊆A gilt B∩A=A∩B=BB\cap A = A\cap B = BB∩A=A∩B=B ⇒ neutrales Element AAA, Monoid ✓.

(Kein anderes Element ist neutral: Wäre EEE neutral, so A=A∩E=EA = A\cap E = EA=A∩E=E.)

Gruppe

Ein Inverses CCC zu BBB müsste B∩C=AB\cap C = AB∩C=A erfüllen. Wegen B∩C⊆B⊆AB\cap C\subseteq B\subseteq AB∩C⊆B⊆A folgt B=AB = AB=A. Also ist nur AAA invertierbar (mit Inversem AAA).

  • Für A≠∅A\ne\emptysetA=∅ hat z. B. B=∅≠AB = \emptyset \ne AB=∅=A kein Inverses ⇒ keine Gruppe.
  • Für A=∅A = \emptysetA=∅ ist P(A)={∅}\mathcal P(A) = \{\emptyset\}P(A)={∅} die triviale Gruppe.
Kontrolle

Python für A={1,2}A = \{1,2\}A={1,2}: assoziativ, einziges neutrales Element {1,2}=A\{1,2\} = A{1,2}=A; B∩C=AB\cap C = AB∩C=A nur für B=C=AB = C = AB=C=A ✓.

Ergebnis

(P(A),∩)(\mathcal P(A),\cap)(P(A),∩) ist ein kommutatives Monoid mit neutralem Element AAA. Für A≠∅A\ne\emptysetA=∅ ist es keine Gruppe (nur AAA ist invertierbar); für A=∅A=\emptysetA=∅ ist es die triviale Gruppe.

Hilfreiches

Gesetze des Durchschnitts

Assoziativ, kommutativ, idempotent (B∩B=BB\cap B = BB∩B=B), B∩A=BB\cap A = BB∩A=B für B⊆AB\subseteq AB⊆A, B∩C⊆BB\cap C\subseteq BB∩C⊆B.

Dualität

Vertauscht man ∪↔∩\cup\leftrightarrow\cap∪↔∩ und ∅↔A\emptyset\leftrightarrow A∅↔A, gehen die Aussagen von Bsp. 353 in die dieses Beispiels über (Komplementbildung B↦A∖BB\mapsto A\setminus BB↦A∖B ist ein Isomorphismus (P(A),∪)→(P(A),∩)(\mathcal P(A),\cup)\to(\mathcal P(A),\cap)(P(A),∪)→(P(A),∩) nach den De Morganschen Regeln).

Typische Fehler
  • ∅\emptyset∅ als neutrales Element annehmen (das gilt für ∪\cup∪, nicht für ∩\cap∩: B∩∅=∅B\cap\emptyset = \emptysetB∩∅=∅).
  • Das Komplement als Inverses ansehen: B∩(A∖B)=∅B\cap(A\setminus B) = \emptysetB∩(A∖B)=∅, nicht AAA.
