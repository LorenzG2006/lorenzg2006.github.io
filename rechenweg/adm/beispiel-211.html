Angabe Originalseite

200–213) Die folgenden Aufgaben sollen mit dem Inklusions-Exklusionsprinzip bearbeitet werden!

Man bestimme die Anzahl aller Anordnungen (Permutationen) der Buchstaben a, b, c, d, e, f, in denen weder der Block „bcf“ noch der Block „eb“ vorkommt.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Wir zählen komplementär: alle 6!6!6! Permutationen minus jene, die „bcf“ oder „eb“ enthalten. Die Größe dieser Vereinigung liefert Inklusion-Exklusion. Permutationen mit einem vorgeschriebenen Block zählt man, indem man den Block zu einem einzigen Symbol „verklebt“. Beide Blöcke enthalten den Buchstaben b – im Durchschnitt verschmelzen sie daher zum Block „ebcf“.

Sei SSS die Menge aller Permutationen der 666 Buchstaben, also ∣S∣=6!=720\vert S\vert = 6! = 720∣S∣=6!=720, und

A={π∈S:π entha¨lt den Block bcf},B={π∈S:π entha¨lt den Block eb}.A = \{\pi \in S : \pi \text{ enthält den Block bcf}\}, \qquad B = \{\pi \in S : \pi \text{ enthält den Block eb}\}.A={π∈S:π entha¨lt den Block bcf},B={π∈S:π entha¨lt den Block eb}.

Gesucht ist die Anzahl der Permutationen, die in keiner der beiden Mengen liegen:

∣S∖(A∪B)∣=∣S∣−∣A∣−∣B∣+∣A∩B∣.\vert S\setminus(A\cup B)\vert = \vert S\vert - \vert A\vert - \vert B\vert + \vert A\cap B\vert.∣S∖(A∪B)∣=∣S∣−∣A∣−∣B∣+∣A∩B∣.

Schritt 1: ∣A∣\vert A\vert∣A∣

Kommt „bcf“ vor, stehen b, c, f unmittelbar hintereinander in genau dieser Reihenfolge. Wir fassen sie zu einem Symbol X=X = X= „bcf“ zusammen. Übrig bleiben die 444 Objekte

X, a, d, e,X,\ \texttt{a},\ \texttt{d},\ \texttt{e},X, a, d, e,

die beliebig angeordnet werden können. Jede Anordnung dieser Objekte liefert (nach „Auspacken“ von XXX) genau eine Permutation aus AAA, und jede Permutation aus AAA entsteht so genau einmal. Also

∣A∣=4!=24.\vert A\vert = 4! = 24.∣A∣=4!=24.

Schritt 2: ∣B∣\vert B\vert∣B∣

Genauso mit Y=Y = Y= „eb“: Die Objekte sind YYY, a, c, d, f – das sind 555 Stück:

∣B∣=5!=120.\vert B\vert = 5! = 120.∣B∣=5!=120.

Schritt 3: ∣A∩B∣\vert A\cap B\vert∣A∩B∣

Eine Permutation aus A∩BA\cap BA∩B enthält beide Blöcke. Da b nur einmal vorkommt, ist es in beiden Blöcken derselbe Buchstabe:

  • wegen „eb“ steht unmittelbar vor b der Buchstabe e,
  • wegen „bcf“ stehen unmittelbar nach b die Buchstaben c, f.

Die Permutation enthält also den Block „ebcf“. Umgekehrt enthält jede Permutation mit „ebcf“ sowohl „eb“ als auch „bcf“. Daher

A∩B={π∈S:π entha¨lt den Block ebcf}.A\cap B = \{\pi \in S : \pi \text{ enthält den Block ebcf}\}.A∩B={π∈S:π entha¨lt den Block ebcf}.

Verkleben zu Z=Z = Z= „ebcf“ lässt die 333 Objekte ZZZ, a, d:

∣A∩B∣=3!=6.\vert A\cap B\vert = 3! = 6.∣A∩B∣=3!=6.

Schritt 4: Inklusion-Exklusion

6!−4!−5!+3!=720−24−120+6=5826! - 4! - 5! + 3! = 720 - 24 - 120 + 6 = 5826!−4!−5!+3!=720−24−120+6=582 Permutationen von a, …, f enthalten weder „bcf“ noch „eb“.

Hilfreiches

Inklusions-Exklusions-Prinzip (Komplementform, zwei Mengen)

Für Teilmengen A,BA, BA,B einer endlichen Menge SSS gilt ∣S∖(A∪B)∣=∣S∣−∣A∣−∣B∣+∣A∩B∣.\vert S\setminus(A\cup B)\vert = \vert S\vert - \vert A\vert - \vert B\vert + \vert A\cap B\vert.∣S∖(A∪B)∣=∣S∣−∣A∣−∣B∣+∣A∩B∣.

Blöcke verkleben

Soll in einer Permutation von nnn verschiedenen Buchstaben ein fest geordneter Block aus kkk Buchstaben vorkommen, behandelt man den Block als ein Symbol: Es gibt (n−k+1)!(n-k+1)!(n−k+1)! solche Permutationen. Haben zwei Blöcke gemeinsame Buchstaben, so verschmelzen sie (wenn die Überlappung passt) zu einem längeren Block – andernfalls ist der Durchschnitt leer.

Typische Fehler
  • Im Durchschnitt zwei getrennte Blöcke „bcf“ und „eb“ verkleben (XXX, YYY, a, d – das wären 4!=244! = 244!=24): unmöglich, weil b nur einmal vorkommt. Richtig ist der verschmolzene Block „ebcf“.
  • ∣A∩B∣=0\vert A\cap B\vert = 0∣A∩B∣=0 setzen, weil man die Überlappung übersieht – dann käme 576576576 statt 582582582 heraus.
  • Die Objektanzahl falsch: Ein Block der Länge kkk aus nnn Buchstaben ergibt n−k+1n - k + 1n−k+1 Objekte (nicht n−kn - kn−k).
