Boolesche Ringe sind kommutativ

Angabe Originalseite

Sei ⟨R,+,⋅⟩\langle R, +, \cdot\rangle⟨R,+,⋅⟩ ein Ring, in dem a2=aa^2 = aa2=a für alle a∈Ra\in Ra∈R gilt. Man zeige, dass dann RRR kommutativ ist. (Hinweis: Man betrachte (a+a)2(a + a)^2(a+a)2 und (a+b)2(a + b)^2(a+b)2.)

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Zwei Schritte:

  1. Aus (a+a)2=a+a(a + a)^2 = a + a(a+a)2=a+a folgt a+a=0a + a = 0a+a=0, also −a=a-a = a−a=a (wie Bsp. 441, hier nochmals vollständig).
  2. Aus (a+b)2=a+b(a + b)^2 = a + b(a+b)2=a+b folgt durch Ausmultiplizieren ab+ba=0ab + ba = 0ab+ba=0, also ab=−(ba)=baab = -(ba) = baab=−(ba)=ba nach Schritt 1.

Seien a,b∈Ra, b\in Ra,b∈R beliebig.

Schritt 1: x+x=0x + x = 0x+x=0 für alle xxx

(x+x)2=(x+x)x+(x+x)x=(x2+x2)+(x2+x2)=(x+x)+(x+x).(x + x)^2 = (x + x)x + (x + x)x = (x^2 + x^2) + (x^2 + x^2) = (x + x) + (x + x).(x+x)2=(x+x)x+(x+x)x=(x2+x2)+(x2+x2)=(x+x)+(x+x). Nach Voraussetzung ist aber (x+x)2=x+x(x + x)^2 = x + x(x+x)2=x+x. Also (x+x)+(x+x)=x+x(x + x) + (x + x) = x + x(x+x)+(x+x)=x+x; Addition von −(x+x)-(x + x)−(x+x) auf beiden Seiten liefert x+x=0,d. h.−x=x.x + x = 0, \qquad\text{d. h.}\qquad -x = x.x+x=0,d. h.−x=x.

Schritt 2: (a+b)2(a + b)^2(a+b)2 ausmultiplizieren

(a+b)2=(a+b)(a+b)=(a+b)a+(a+b)b(linkes Distributivgesetz)=aa+ba+ab+bb(rechtes Distributivgesetz)=a+ba+ab+b.(a2=a, b2=b)\begin{aligned} (a + b)^2 &= (a + b)(a + b)\\ &= (a + b)a + (a + b)b && \text{(linkes Distributivgesetz)}\\ &= aa + ba + ab + bb && \text{(rechtes Distributivgesetz)}\\ &= a + ba + ab + b. && (a^2 = a,\ b^2 = b) \end{aligned}(a+b)2​=(a+b)(a+b)=(a+b)a+(a+b)b=aa+ba+ab+bb=a+ba+ab+b.​​(linkes Distributivgesetz)(rechtes Distributivgesetz)(a2=a, b2=b)​ (Reihenfolge der Faktoren beachten: bababa und ababab dürfen wir noch nicht gleichsetzen!)

Schritt 3: Vergleichen

Nach Voraussetzung ist (a+b)2=a+b(a + b)^2 = a + b(a+b)2=a+b. Mit der Kommutativität der Addition ordnen wir um: a+b+(ab+ba)=a+b.a + b + (ab + ba) = a + b.a+b+(ab+ba)=a+b. Addition von −(a+b)-(a + b)−(a+b) auf beiden Seiten ergibt ab+ba=0.ab + ba = 0.ab+ba=0.

Schritt 4: Schluss

Aus ab+ba=0ab + ba = 0ab+ba=0 folgt ab=−(ba)ab = -(ba)ab=−(ba) (Eindeutigkeit des additiven Inversen). Nach Schritt 1 (mit x=bax = bax=ba) ist −(ba)=ba-(ba) = ba−(ba)=ba. Also ab=ba.ab = ba.ab=ba.

Da a,ba, ba,b beliebig waren, ist RRR kommutativ.

Ergebnis

Ein Ring mit a2=aa^2 = aa2=a für alle aaa ist kommutativ: aus (a+b)2=a+b(a+b)^2 = a + b(a+b)2=a+b folgt ab+ba=0ab + ba = 0ab+ba=0, und wegen x+x=0x + x = 0x+x=0 (also −x=x-x = x−x=x) ist ab=baab = baab=ba. ■\blacksquare■

Beispiel

In ⟨P(M),Δ,∩⟩\langle\mathbf P(M),\Delta,\cap\rangle⟨P(M),Δ,∩⟩ ist A∩A=AA\cap A = AA∩A=A; tatsächlich ist ∩\cap∩ kommutativ ✓. In Z2×Z2\Z_2\times\Z_2Z2​×Z2​ (komponentenweise) gilt (x,y)2=(x2,y2)=(x,y)(x,y)^2 = (x^2,y^2) = (x,y)(x,y)2=(x2,y2)=(x,y) und das Produkt ist kommutativ ✓.

Hilfreiches

Kommutativer Ring

Ein Ring heißt kommutativ, wenn ab=baab = baab=ba für alle a,ba,ba,b gilt (die Addition ist in jedem Ring kommutativ).

Boolesche Ringe

Ist a2=aa^2 = aa2=a für alle a∈Ra\in Ra∈R, so gilt a+a=0a + a = 0a+a=0 und ab=baab = baab=ba für alle a,b∈Ra, b\in Ra,b∈R.

Typische Fehler
  • (a+b)2=a2+2ab+b2(a + b)^2 = a^2 + 2ab + b^2(a+b)2=a2+2ab+b2 schreiben – damit setzt man ab=baab = baab=ba schon voraus (Zirkelschluss).
  • Bei ab=−(ba)ab = -(ba)ab=−(ba) aufhören: Erst mit −x=x-x = x−x=x folgt ab=baab = baab=ba.
