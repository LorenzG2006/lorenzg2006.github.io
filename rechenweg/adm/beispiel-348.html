Angabe Originalseite

Untersuchen Sie, ob die Menge MMM mit der Operation ∘\circ∘ ein Gruppoid, eine Halbgruppe, ein Monoid bzw. eine Gruppe ist:

M={−2,−1,0,1,2}M = \{-2, -1, 0, 1, 2\}M={−2,−1,0,1,2}, m∘n=mnm \circ n = mnm∘n=mn

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Die Begriffe bauen aufeinander auf: Jede Gruppe ist ein Monoid, jedes Monoid eine Halbgruppe, jede Halbgruppe ein Gruppoid. Scheitert schon die Abgeschlossenheit (Gruppoid), so ist (M,∘)(M,\circ)(M,∘) nichts davon. Wir prüfen daher zuerst, ob alle Produkte in MMM liegen.

Gruppoid

Wir berechnen die Produkte:

⋅\cdot⋅ −2-2−2 −1-1−1 000 111 222
−2-2−2 4 2 0 −2-2−2 −4
−1-1−1 2 1 0 −1-1−1 −2-2−2
000 0 0 0 0 0
111 −2-2−2 −1-1−1 0 1 2
222 −4 −2-2−2 0 2 4

Es ist z. B. 2∘2=4∉M2\circ 2 = 4 \notin M2∘2=4∈/M und 2∘(−2)=−4∉M2\circ(-2) = -4 \notin M2∘(−2)=−4∈/M. Die Multiplikation führt also aus MMM heraus; sie ist auf MMM nur eine partielle Operation. ⇒ (M,∘)(M,\circ)(M,∘) ist kein Gruppoid.

Halbgruppe, Monoid, Gruppe

Da schon die Abgeschlossenheit verletzt ist, ist (M,∘)(M,\circ)(M,∘) auch keine Halbgruppe, kein Monoid und keine Gruppe. (Assoziativität, Kommutativität und das „neutrale“ 111 wären zwar dort, wo definiert, vorhanden, das genügt aber nicht.)

Kontrolle

Python: Unter den 252525 Produkten liegen genau vier außerhalb von MMM, nämlich (±2)(±2)=±4(\pm2)(\pm2) = \pm 4(±2)(±2)=±4 ✓.

Ergebnis

({−2,−1,0,1,2},⋅)(\{-2,-1,0,1,2\}, \cdot)({−2,−1,0,1,2},⋅) ist kein Gruppoid (z. B. 2⋅2=4∉M2\cdot 2 = 4 \notin M2⋅2=4∈/M) und damit auch keine Halbgruppe, kein Monoid und keine Gruppe.

Zum Vergleich

Die Teilmenge {−1,0,1}\{-1, 0, 1\}{−1,0,1} ist unter der Multiplikation abgeschlossen und bildet ein kommutatives Monoid; {−1,1}\{-1, 1\}{−1,1} ist sogar eine Gruppe.

Hilfreiches

Gruppoid

Ein Gruppoid (M,∘)(M,\circ)(M,∘) ist eine Menge mit einer Abbildung ∘:M×M→M\circ: M\times M\to M∘:M×M→M – für alle Paare muss das Ergebnis in MMM liegen.

Typische Fehler
  • Assoziativität und neutrales Element prüfen, ohne vorher die Abgeschlossenheit zu kontrollieren.
  • Nur einige Produkte testen und dabei die Randfälle ±2⋅±2\pm 2\cdot\pm 2±2⋅±2 übersehen.
