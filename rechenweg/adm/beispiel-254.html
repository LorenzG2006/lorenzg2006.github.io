2an−7an−1+6an−2=(n−1)2n+2(n≥2),a0=0, a1=1.2a_n - 7a_{n-1} + 6a_{n-2} = (n-1)2^{n+2} \quad (n \ge 2), \qquad a_0 = 0,\ a_1 = 1.2an​−7an−1​+6an−2​=(n−1)2n+2(n≥2),a0​=0, a1​=1.

Lösung verborgen – erst selbst probieren!

Überblick

Gleiche linke Seite wie in Bsp. 253, charakteristische Wurzeln 222 und 32\frac3223​. Die Störfunktion (n−1)2n+2=4(n−1) 2n(n-1)2^{n+2} = 4(n-1)\,2^n(n−1)2n+2=4(n−1)2n ist ein Polynom vom Grad 111 mal 2n2^n2n – und 222 ist eine einfache Wurzel (Resonanz). Ansatz daher n(Cn+D) 2nn(Cn + D)\,2^nn(Cn+D)2n.

Schritt 1: Homogene Rekursion

2λ2−7λ+6=(λ−2)(2λ−3)=0  ⟹  λ1=2, λ2=32,2\lambda^2 - 7\lambda + 6 = (\lambda - 2)(2\lambda - 3) = 0 \implies \lambda_1 = 2,\ \lambda_2 = \frac32,2λ2−7λ+6=(λ−2)(2λ−3)=0⟹λ1​=2, λ2​=23​,

an(h)=A 2n+B(32)n.a_n^{(h)} = A\,2^n + B\Bigl(\frac32\Bigr)^n.an(h)​=A2n+B(23​)n.

Schritt 2: Ansatz für die partikuläre Lösung

Ein Ansatz (Cn+D) 2n(Cn + D)\,2^n(Cn+D)2n reicht nicht: Der Anteil D 2nD\,2^nD2n ist homogene Lösung und fällt beim Einsetzen weg. Wegen der einfachen Wurzel 222 multiplizieren wir mit nnn:

an(p)=p(n) 2n,p(n)=Cn2+Dn.a_n^{(p)} = p(n)\,2^n, \qquad p(n) = Cn^2 + Dn.an(p)​=p(n)2n,p(n)=Cn2+Dn.

Schritt 3: Einsetzen

Division durch 2n−22^{n-2}2n−2 (2⋅2n=8⋅2n−22\cdot 2^n = 8\cdot 2^{n-2}2⋅2n=8⋅2n−2, 7⋅2n−1=14⋅2n−27\cdot 2^{n-1} = 14\cdot 2^{n-2}7⋅2n−1=14⋅2n−2, 2n+2=16⋅2n−22^{n+2} = 16\cdot 2^{n-2}2n+2=16⋅2n−2):

8 p(n)−14 p(n−1)+6 p(n−2)=16(n−1).8\,p(n) - 14\,p(n-1) + 6\,p(n-2) = 16(n - 1).8p(n)−14p(n−1)+6p(n−2)=16(n−1).

Einzeln ausmultipliziert:

8 p(n)=8Cn2+8Dn,−14 p(n−1)=−14C(n2−2n+1)−14D(n−1)=−14Cn2+(28C−14D) n−14C+14D,6 p(n−2)=6C(n2−4n+4)+6D(n−2)=6Cn2+(−24C+6D) n+24C−12D.\begin{aligned} 8\,p(n) &= 8Cn^2 + 8Dn,\\ -14\,p(n-1) &= -14C(n^2 - 2n + 1) - 14D(n - 1) = -14Cn^2 + (28C - 14D)\,n - 14C + 14D,\\ 6\,p(n-2) &= 6C(n^2 - 4n + 4) + 6D(n - 2) = 6Cn^2 + (-24C + 6D)\,n + 24C - 12D. \end{aligned}8p(n)−14p(n−1)6p(n−2)​=8Cn2+8Dn,=−14C(n2−2n+1)−14D(n−1)=−14Cn2+(28C−14D)n−14C+14D,=6C(n2−4n+4)+6D(n−2)=6Cn2+(−24C+6D)n+24C−12D.​

Summe:

0⋅n2+4C n+(10C+2D)=16n−16.0\cdot n^2 + 4C\,n + (10C + 2D) = 16n - 16.0⋅n2+4Cn+(10C+2D)=16n−16.

(Dass der n2n^2n2-Term wegfällt, ist kein Zufall: Es ist 8−14+6=08 - 14 + 6 = 08−14+6=0, weil 222 Wurzel ist.)

Koeffizientenvergleich: 4C=16  ⟹  C=44C = 16 \implies C = 44C=16⟹C=4; 10C+2D=−16  ⟹  2D=−5610C + 2D = -16 \implies 2D = -5610C+2D=−16⟹2D=−56, D=−28D = -28D=−28. Also

an(p)=(4n2−28n) 2n=n(n−7) 2n+2.a_n^{(p)} = (4n^2 - 28n)\,2^n = n(n - 7)\,2^{n+2}.an(p)​=(4n2−28n)2n=n(n−7)2n+2.

Schritt 4: Allgemeine Lösung und Anfangsbedingungen

an=A 2n+B(32)n+n(n−7) 2n+2.a_n = A\,2^n + B\Bigl(\frac32\Bigr)^n + n(n - 7)\,2^{n+2}.an​=A2n+B(23​)n+n(n−7)2n+2.

n=0:A+B=0,n=1:2A+32B+1⋅(−6)⋅8=1  ⟹  2A+32B=49.\begin{aligned} n = 0:&\quad A + B = 0,\\ n = 1:&\quad 2A + \tfrac32 B + 1\cdot(-6)\cdot 8 = 1 &&\implies 2A + \tfrac32 B = 49. \end{aligned}n=0:n=1:​A+B=0,2A+23​B+1⋅(−6)⋅8=1​​⟹2A+23​B=49.​

Mit B=−AB = -AB=−A: 12A=49\frac12 A = 4921​A=49, also A=98A = 98A=98, B=−98B = -98B=−98.

Hilfreiches

Ansatz bei Störfunktion p(n) μnp(n)\,\mu^np(n)μn mit Resonanz

Ist μ\muμ eine kkk-fache Wurzel der charakteristischen Gleichung, setzt man nk q(n) μnn^k\,q(n)\,\mu^nnkq(n)μn an, deg⁡q=deg⁡p\deg q = \deg pdegq=degp. Hier: μ=2\mu = 2μ=2, k=1k = 1k=1, deg⁡p=1\deg p = 1degp=1, also n(Cn+D) 2nn(Cn + D)\,2^nn(Cn+D)2n.

Kontrolle beim Koeffizientenvergleich

Bei Resonanz muss der höchste Koeffizient nach dem Einsetzen wegfallen (hier n2n^2n2). Fällt er nicht weg, hat man sich verrechnet.

Typische Fehler
  • Ansatz (Cn+D) 2n(Cn + D)\,2^n(Cn+D)2n – Resonanz übersehen; man erhält ein unlösbares System.
  • 2n+22^{n+2}2n+2 nicht in 4⋅2n4\cdot 2^n4⋅2n umschreiben und dadurch die Resonanz mit der Wurzel 222 nicht erkennen.
  • Beim Ansatz n(Cn+D)n(Cn + D)n(Cn+D) zusätzlich eine Konstante EEE mitnehmen: Sie wäre homogen und unbestimmbar (harmlos, aber überflüssig).
