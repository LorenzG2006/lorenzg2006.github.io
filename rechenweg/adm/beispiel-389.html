Angabe Originalseite

Man zeige, dass die von 3ˉ\bar 33ˉ erzeugte Untergruppe UUU von ⟨Z12,+⟩\langle \Z_{12}, + \rangle⟨Z12​,+⟩ ein Normalteiler von ⟨Z12,+⟩\langle \Z_{12}, + \rangle⟨Z12​,+⟩ ist, und bestimme die Gruppentafel der Faktorgruppe Z12/U\Z_{12}/UZ12​/U.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Diesmal erzeugt 3ˉ\bar 33ˉ in Z12\Z_{12}Z12​ eine Untergruppe mit vier Elementen, die Faktorgruppe hat daher 12/4=312/4 = 312/4=3 Elemente. Normalteiler ist UUU, weil (Z12,+)(\Z_{12},+)(Z12​,+) kommutativ ist. Wir listen die Nebenklassen und rechnen vertreterweise.

Schritt 1: U = ⟨3̄⟩

1⋅3ˉ=3ˉ,2⋅3ˉ=6ˉ,3⋅3ˉ=9ˉ,4⋅3ˉ=12‾=0ˉ.1\cdot\bar 3 = \bar 3,\quad 2\cdot\bar 3 = \bar 6,\quad 3\cdot\bar 3 = \bar 9,\quad 4\cdot\bar 3 = \overline{12} = \bar 0.1⋅3ˉ=3ˉ,2⋅3ˉ=6ˉ,3⋅3ˉ=9ˉ,4⋅3ˉ=12=0ˉ. U={0ˉ,3ˉ,6ˉ,9ˉ},∣U∣=4.U = \{\bar 0, \bar 3, \bar 6, \bar 9\}, \qquad |U| = 4.U={0ˉ,3ˉ,6ˉ,9ˉ},∣U∣=4.

Schritt 2: U ist Normalteiler

Da aˉ+uˉ=uˉ+aˉ\bar a + \bar u = \bar u + \bar aaˉ+uˉ=uˉ+aˉ für alle Restklassen gilt, ist aˉ+U=U+aˉ\bar a + U = U + \bar aaˉ+U=U+aˉ für alle aˉ∈Z12\bar a \in \Z_{12}aˉ∈Z12​. Linksnebenklassen = Rechtsnebenklassen, also U⊴Z12U \trianglelefteq \Z_{12}U⊴Z12​.

Schritt 3: Nebenklassen

[Z12:U]=12/4=3[\Z_{12} : U] = 12/4 = 3[Z12​:U]=12/4=3. Es gilt aˉ+U=bˉ+U  ⟺  aˉ−bˉ∈U  ⟺  3∣a−b\bar a + U = \bar b + U \iff \bar a - \bar b \in U \iff 3 \mid a - baˉ+U=bˉ+U⟺aˉ−bˉ∈U⟺3∣a−b: 0ˉ+U={0ˉ,3ˉ,6ˉ,9ˉ},1ˉ+U={1ˉ,4ˉ,7ˉ,10‾},2ˉ+U={2ˉ,5ˉ,8ˉ,11‾}.\begin{aligned} \bar 0 + U &= \{\bar 0, \bar 3, \bar 6, \bar 9\},\\ \bar 1 + U &= \{\bar 1, \bar 4, \bar 7, \overline{10}\},\\ \bar 2 + U &= \{\bar 2, \bar 5, \bar 8, \overline{11}\}. \end{aligned}0ˉ+U1ˉ+U2ˉ+U​={0ˉ,3ˉ,6ˉ,9ˉ},={1ˉ,4ˉ,7ˉ,10},={2ˉ,5ˉ,8ˉ,11}.​ Kontrolle: 3⋅4=123 \cdot 4 = 123⋅4=12 ✓.

Schritt 4: Gruppentafel

(iˉ+U)+(jˉ+U)=(iˉ+jˉ)+U(\bar i + U) + (\bar j + U) = (\bar i + \bar j) + U(iˉ+U)+(jˉ​+U)=(iˉ+jˉ​)+U, Vertreter modulo 3 reduzieren:

  • (1ˉ+U)+(1ˉ+U)=2ˉ+U(\bar 1 + U) + (\bar 1 + U) = \bar 2 + U(1ˉ+U)+(1ˉ+U)=2ˉ+U,
  • (1ˉ+U)+(2ˉ+U)=3ˉ+U=U(\bar 1 + U) + (\bar 2 + U) = \bar 3 + U = U(1ˉ+U)+(2ˉ+U)=3ˉ+U=U (da 3ˉ∈U\bar 3 \in U3ˉ∈U),
  • (2ˉ+U)+(2ˉ+U)=4ˉ+U=1ˉ+U(\bar 2 + U) + (\bar 2 + U) = \bar 4 + U = \bar 1 + U(2ˉ+U)+(2ˉ+U)=4ˉ+U=1ˉ+U (da 4ˉ∈1ˉ+U\bar 4 \in \bar 1 + U4ˉ∈1ˉ+U).

Wohldefiniertheit: Vertreter 10‾∈1ˉ+U\overline{10} \in \bar 1 + U10∈1ˉ+U und 11‾∈2ˉ+U\overline{11} \in \bar 2 + U11∈2ˉ+U liefern 21‾=9ˉ∈U\overline{21} = \bar 9 \in U21=9ˉ∈U ✓, in Übereinstimmung mit 1ˉ+2ˉ=3ˉ∈U\bar 1 + \bar 2 = \bar 3 \in U1ˉ+2ˉ=3ˉ∈U.
