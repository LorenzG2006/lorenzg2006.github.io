Angabe Originalseite

Zeigen Sie, dass in jedem Vektorraum VVV über dem Körper KKK für alle a∈Va \in Va∈V und alle λ∈K\lambda \in Kλ∈K gilt:

λ(−a)=−(λa)\lambda(-a) = -(\lambda a)λ(−a)=−(λa)

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Hier steht das Minus beim Vektor. Wir zeigen, dass λ(−a)\lambda(-a)λ(−a) zu λa\lambda aλa addiert den Nullvektor ergibt; wegen der Eindeutigkeit des Inversen in der Gruppe (V,+)(V, +)(V,+) ist dann λ(−a)=−(λa)\lambda(-a) = -(\lambda a)λ(−a)=−(λa). Benötigt werden das Distributivgesetz λ(u+v)=λu+λv\lambda(u + v) = \lambda u + \lambda vλ(u+v)=λu+λv (diesmal das „vektorielle“) und die Regel λo=o\lambda o = oλo=o aus Bsp. 487.

Beweis

λa+λ(−a)=λ(a+(−a))(Distributivgesetz λ(u+v)=λu+λv)=λo(a+(−a)=o)=o.(Bsp. 487: λo=o)\begin{aligned} \lambda a + \lambda(-a) &= \lambda\bigl(a + (-a)\bigr) && \text{(Distributivgesetz } \lambda(u + v) = \lambda u + \lambda v\text{)}\\ &= \lambda o && (a + (-a) = o)\\ &= o. && \text{(Bsp. 487: } \lambda o = o\text{)} \end{aligned}λa+λ(−a)​=λ(a+(−a))=λo=o.​​(Distributivgesetz λ(u+v)=λu+λv)(a+(−a)=o)(Bsp. 487: λo=o)​

Also ist λ(−a)\lambda(-a)λ(−a) ein inverses Element zu λa\lambda aλa.

Eindeutigkeit des Inversen: Gilt x+y=ox + y = ox+y=o, dann y=o+y=((−x)+x)+y=(−x)+(x+y)=(−x)+o=−x.y = o + y = \bigl((-x) + x\bigr) + y = (-x) + (x + y) = (-x) + o = -x.y=o+y=((−x)+x)+y=(−x)+(x+y)=(−x)+o=−x. Mit x=λax = \lambda ax=λa und y=λ(−a)y = \lambda(-a)y=λ(−a) folgt λ(−a)=−(λa).■\lambda(-a) = -(\lambda a). \qquad\blacksquareλ(−a)=−(λa).■

Alternativer Weg über Bsp. 488

−a=(−1)a-a = (-1)a−a=(−1)a (Bsp. 488 mit λ=1\lambda = 1λ=1). Dann λ(−a)=λ((−1)a)=(λ⋅(−1))a=(−λ)a=−(λa),\lambda(-a) = \lambda\bigl((-1)a\bigr) = \bigl(\lambda\cdot(-1)\bigr)a = (-\lambda)a = -(\lambda a),λ(−a)=λ((−1)a)=(λ⋅(−1))a=(−λ)a=−(λa), mit dem Assoziativgesetz (λμ)a=λ(μa)(\lambda\mu)a = \lambda(\mu a)(λμ)a=λ(μa) und nochmals Bsp. 488.

Beispiel im R2\R^2R2

λ=4\lambda = 4λ=4, a=(1,−3)a = (1, -3)a=(1,−3): λ(−a)=4⋅(−1,3)=(−4,12)\lambda(-a) = 4\cdot(-1, 3) = (-4, 12)λ(−a)=4⋅(−1,3)=(−4,12) und −(λa)=−(4,−12)=(−4,12)-(\lambda a) = -(4, -12) = (-4, 12)−(λa)=−(4,−12)=(−4,12) ✓.

Ergebnis

In jedem KKK-Vektorraum gilt λ(−a)=−(λa)\lambda(-a) = -(\lambda a)λ(−a)=−(λa) für alle λ∈K\lambda \in Kλ∈K, a∈Va \in Va∈V. ■\blacksquare■

Hilfreiches

Benutzte Regeln
  • λ(u+v)=λu+λv\lambda(u + v) = \lambda u + \lambda vλ(u+v)=λu+λv (Axiom).
  • λo=o\lambda o = oλo=o (Bsp. 487).
  • Eindeutigkeit des Inversen in (V,+)(V,+)(V,+).
Typische Fehler
  • Das falsche Distributivgesetz verwenden: Hier wird über eine Vektorsumme verteilt, nicht über eine Skalarsumme (wie in Bsp. 488).
  • λo=o\lambda o = oλo=o benutzen, ohne es (Bsp. 487) begründet zu haben.

Verwandte Beispiele: Bsp. 487, Bsp. 488, Bsp. 490.
