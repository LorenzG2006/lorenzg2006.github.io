Angabe Originalseite

Bildet R2\R^2R2 mit den angegebenen Operationen einen Vektorraum über R\RR?

(x1,x2)+(y1,y2)=(0,x2+y2)(x_1, x_2) + (y_1, y_2) = (0, x_2 + y_2)(x1​,x2​)+(y1​,y2​)=(0,x2​+y2​), λ(x1,x2)=(0,λx2)\lambda(x_1, x_2) = (0, \lambda x_2)λ(x1​,x2​)=(0,λx2​).

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Wir prüfen die Vektorraumaxiome. Auffällig: Jede Summe und jedes skalare Vielfache hat erste Koordinate 000, liegt also auf der x2x_2x2​-Achse. Dann kann x+o=xx + o = xx+o=x für Vektoren mit x1≠0x_1 \ne 0x1​=0 nie stimmen – das neutrale Element fehlt. Ein einziges verletztes Axiom genügt für die Antwort „nein“.

Sei x=(x1,x2)x = (x_1, x_2)x=(x1​,x2​), y=(y1,y2)y = (y_1, y_2)y=(y1​,y2​), z=(z1,z2)∈R2z = (z_1, z_2) \in \R^2z=(z1​,z2​)∈R2.

Addition

Kommutativ: x+y=(0,x2+y2)=(0,y2+x2)=y+xx + y = (0, x_2 + y_2) = (0, y_2 + x_2) = y + xx+y=(0,x2​+y2​)=(0,y2​+x2​)=y+x. ✓

Assoziativ: (x+y)+z=(0,x2+y2)+z=(0,x2+y2+z2)(x + y) + z = (0, x_2 + y_2) + z = (0, x_2 + y_2 + z_2)(x+y)+z=(0,x2​+y2​)+z=(0,x2​+y2​+z2​), ebenso x+(y+z)=x+(0,y2+z2)=(0,x2+y2+z2)x + (y + z) = x + (0, y_2 + z_2) = (0, x_2 + y_2 + z_2)x+(y+z)=x+(0,y2​+z2​)=(0,x2​+y2​+z2​). ✓

Neutrales Element: Für ein o=(o1,o2)o = (o_1, o_2)o=(o1​,o2​) müsste x+o=(0,x2+o2)=(x1,x2)x + o = (0, x_2 + o_2) = (x_1, x_2)x+o=(0,x2​+o2​)=(x1​,x2​) für alle xxx gelten. Für x=(1,0)x = (1, 0)x=(1,0) ist aber die erste Koordinate von x+ox + ox+o gleich 0≠10 \ne 10=1. Kein neutrales Element ✗ – also ist (R2,+)(\R^2, +)(R2,+) keine Gruppe.

Damit liegt kein Vektorraum vor.

Ergebnis

Nein, kein Vektorraum: Es gibt kein neutrales Element der Addition (Vektoren mit x1≠0x_1 \ne 0x1​=0 sind nie Summen), außerdem ist 1⋅(1,0)=(0,0)≠(1,0)1\cdot(1,0) = (0,0) \ne (1,0)1⋅(1,0)=(0,0)=(1,0). Kommutativität, Assoziativität, beide Distributivgesetze und (λμ)x=λ(μx)(\lambda\mu)x = \lambda(\mu x)(λμ)x=λ(μx) gelten.
