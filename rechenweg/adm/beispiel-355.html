Angabe Originalseite

Untersuchen Sie, ob die Menge MMM mit der Operation ∘\circ∘ ein Gruppoid, eine Halbgruppe, ein Monoid bzw. eine Gruppe ist:

M=P(A)M = \mathcal P(A)M=P(A), d. h. die Potenzmenge der Menge AAA, B∘C=B△CB\circ C = B\triangle CB∘C=B△C (die symmetrische Differenz).

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

B△C=(B∖C)∪(C∖B)B\triangle C = (B\setminus C)\cup(C\setminus B)B△C=(B∖C)∪(C∖B) enthält die Elemente, die in genau einer der beiden Mengen liegen. Die Assoziativität ist der einzige nichttriviale Punkt. Ein eleganter Weg: Man beschreibt Mengen durch ihre Indikatorfunktionen; dann wird △\triangle△ zur Addition modulo 222, und alle Gesetze folgen aus den Rechenregeln in Z2\Z_2Z2​.

Gruppoid

Für B,C⊆AB, C\subseteq AB,C⊆A ist B△C⊆B∪C⊆AB\triangle C \subseteq B\cup C\subseteq AB△C⊆B∪C⊆A ⇒ B△C∈P(A)B\triangle C\in\mathcal P(A)B△C∈P(A), Gruppoid ✓.

Halbgruppe

Für X⊆AX\subseteq AX⊆A und x∈Ax\in Ax∈A sei 1X(x)=1\mathbf 1_X(x) = 11X​(x)=1, falls x∈Xx\in Xx∈X, und 000 sonst. Eine Teilmenge ist durch ihre Indikatorfunktion eindeutig bestimmt. Es gilt 1B△C(x)≡1B(x)+1C(x)(mod2),\mathbf 1_{B\triangle C}(x) \equiv \mathbf 1_B(x) + \mathbf 1_C(x) \pmod 2,1B△C​(x)≡1B​(x)+1C​(x)(mod2), denn: Liegt xxx in keiner der Mengen, ist 0+0=00+0 = 00+0=0; in genau einer: 1+0=11+0 = 11+0=1 und x∈B△Cx\in B\triangle Cx∈B△C; in beiden: 1+1=2≡01+1 = 2\equiv 01+1=2≡0 und x∉B△Cx\notin B\triangle Cx∈/B△C ✓.

Damit für jedes x∈Ax\in Ax∈A: 1(B△C)△D(x)≡(1B(x)+1C(x))+1D(x)(mod2),1B△(C△D)(x)≡1B(x)+(1C(x)+1D(x))(mod2).\begin{aligned} \mathbf 1_{(B\triangle C)\triangle D}(x) &\equiv \bigl(\mathbf 1_B(x) + \mathbf 1_C(x)\bigr) + \mathbf 1_D(x) \pmod 2,\\ \mathbf 1_{B\triangle (C\triangle D)}(x) &\equiv \mathbf 1_B(x) + \bigl(\mathbf 1_C(x) + \mathbf 1_D(x)\bigr) \pmod 2. \end{aligned}1(B△C)△D​(x)1B△(C△D)​(x)​≡(1B​(x)+1C​(x))+1D​(x)(mod2),≡1B​(x)+(1C​(x)+1D​(x))(mod2).​ Die rechten Seiten sind gleich (Addition ist assoziativ). Also haben beide Mengen dieselbe Indikatorfunktion und sind gleich: (B△C)△D=B△(C△D).(B\triangle C)\triangle D = B\triangle(C\triangle D).(B△C)△D=B△(C△D). Anschaulich: Beide Seiten enthalten genau die Elemente, die in einer ungeraden Anzahl der Mengen B,C,DB, C, DB,C,D liegen. ⇒ Halbgruppe ✓. Kommutativ ist △\triangle△ offensichtlich.

Monoid

B△∅=(B∖∅)∪(∅∖B)=B∪∅=BB\triangle\emptyset = (B\setminus\emptyset)\cup(\emptyset\setminus B) = B\cup\emptyset = BB△∅=(B∖∅)∪(∅∖B)=B∪∅=B, ebenso ∅△B=B\emptyset\triangle B = B∅△B=B ⇒ neutrales Element ∅\emptyset∅, Monoid ✓.

Gruppe

B△B=(B∖B)∪(B∖B)=∅B\triangle B = (B\setminus B)\cup(B\setminus B) = \emptysetB△B=(B∖B)∪(B∖B)=∅. Jedes Element ist also zu sich selbst invers: B−1=BB^{-1} = BB−1=B. ⇒ Gruppe ✓ (abelsch).

Kontrolle
  • Beispiel B={1,2}B = \{1,2\}B={1,2}, C={2,3}C = \{2,3\}C={2,3}, D={3,4}D = \{3,4\}D={3,4}: (B△C)△D={1,3}△{3,4}={1,4}(B\triangle C)\triangle D = \{1,3\}\triangle\{3,4\} = \{1,4\}(B△C)△D={1,3}△{3,4}={1,4} und B△(C△D)={1,2}△{2,4}={1,4}B\triangle(C\triangle D) = \{1,2\}\triangle\{2,4\} = \{1,4\}B△(C△D)={1,2}△{2,4}={1,4} ✓.
  • Python für A={1,2}A = \{1,2\}A={1,2}: alle Tripel assoziativ, neutrales Element ∅\emptyset∅ ✓.
Ergebnis

(P(A),△)(\mathcal P(A),\triangle)(P(A),△) ist eine abelsche Gruppe (also auch Gruppoid, Halbgruppe, Monoid). Neutrales Element ist ∅\emptyset∅, und jedes BBB ist sein eigenes Inverses: B△B=∅B\triangle B = \emptysetB△B=∅.

Struktur

Für endliches AAA mit ∣A∣=n\lvert A\rvert = n∣A∣=n ist B↦(1B(x))x∈AB\mapsto(\mathbf 1_B(x))_{x\in A}B↦(1B​(x))x∈A​ ein Isomorphismus (P(A),△)≅(Z2n,+)(\mathcal P(A),\triangle)\cong(\Z_2^n,+)(P(A),△)≅(Z2n​,+). Für ∣A∣=2\lvert A\rvert = 2∣A∣=2 ist das die Kleinsche Vierergruppe.

Hilfreiches

Symmetrische Differenz

B△C=(B∖C)∪(C∖B)=(B∪C)∖(B∩C)B\triangle C = (B\setminus C)\cup(C\setminus B) = (B\cup C)\setminus(B\cap C)B△C=(B∖C)∪(C∖B)=(B∪C)∖(B∩C).

Gruppe

Halbgruppe mit neutralem Element, in der jedes Element ein Inverses hat. Gilt x∘x=ex\circ x = ex∘x=e für alle xxx, so ist jedes Element selbstinvers (und die Gruppe ist automatisch abelsch).

Typische Fehler
  • Die Assoziativität nur an einem Venn-Diagramm „ablesen“, ohne Begründung – entweder über Indikatorfunktionen oder über die Zählung „ungerade oft enthalten“ argumentieren.
  • Das Komplement als Inverses ansehen: B△(A∖B)=A≠∅B\triangle(A\setminus B) = A \ne\emptysetB△(A∖B)=A=∅.
