Angabe Originalseite

Man finde alle Lösungen der Differenzengleichung

(a)2xn+1−3xn+1=0(n≥0),(b)xn+1−xn+7=0(n≥0).\begin{aligned} &(a) \quad 2x_{n+1} - 3x_n + 1 = 0 \quad (n \ge 0),\\ &(b) \quad x_{n+1} - x_n + 7 = 0 \quad (n \ge 0). \end{aligned}​(a)2xn+1​−3xn​+1=0(n≥0),(b)xn+1​−xn​+7=0(n≥0).​

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Beide Gleichungen haben die Form xn+1=a xn+bx_{n+1} = a\,x_n + bxn+1​=axn​+b mit Konstanten a,ba, ba,b. Die allgemeine Lösung ist homogene Lösung + eine partikuläre Lösung:

  • homogen (xn+1=a xnx_{n+1} = a\,x_nxn+1​=axn​): xn(h)=C anx_n^{(h)} = C\,a^nxn(h)​=Can,
  • partikulär: für a≠1a \ne 1a=1 eine konstante Lösung (Fixpunkt) x∗=b1−ax^* = \frac{b}{1-a}x∗=1−ab​; für a=1a = 1a=1 wächst die Folge linear, xn=x0+b nx_n = x_0 + b\,nxn​=x0​+bn.

Die Konstante CCC ist frei (sie entspricht dem frei wählbaren Anfangswert x0x_0x0​), daher gibt es unendlich viele Lösungen.

(a) 2xn+1−3xn+1=02x_{n+1} - 3x_n + 1 = 02xn+1​−3xn​+1=0

Umformen: Nach xn+1x_{n+1}xn+1​ aufgelöst:

xn+1=32 xn−12(a=32, b=−12).x_{n+1} = \frac32\,x_n - \frac12 \qquad (a = \tfrac32,\ b = -\tfrac12).xn+1​=23​xn​−21​(a=23​, b=−21​).

Homogene Gleichung xn+1=32xnx_{n+1} = \frac32 x_nxn+1​=23​xn​: Jeder Schritt multipliziert mit 32\frac3223​, also xn(h)=C(32)nx_n^{(h)} = C\left(\frac32\right)^nxn(h)​=C(23​)n.

Partikuläre Lösung (Fixpunkt): Wir suchen eine konstante Folge xn=x∗x_n = x^*xn​=x∗:

x∗=32x∗−12  ⟺  12x∗=12  ⟺  x∗=1.x^* = \frac32 x^* - \frac12 \iff \frac12 x^* = \frac12 \iff x^* = 1.x∗=23​x∗−21​⟺21​x∗=21​⟺x∗=1.

Probe in der Originalgleichung: 2⋅1−3⋅1+1=02\cdot 1 - 3\cdot 1 + 1 = 02⋅1−3⋅1+1=0 ✓.

Allgemeine Lösung: xn=C(32)n+1x_n = C\left(\frac32\right)^n + 1xn​=C(23​)n+1.

Dass das alle Lösungen sind: Ist (xn)(x_n)(xn​) irgendeine Lösung, so erfüllt yn:=xn−1y_n := x_n - 1yn​:=xn​−1 die Gleichung

yn+1=xn+1−1=32xn−12−1=32(xn−1)=32yn,y_{n+1} = x_{n+1} - 1 = \tfrac32 x_n - \tfrac12 - 1 = \tfrac32 (x_n - 1) = \tfrac32 y_n,yn+1​=xn+1​−1=23​xn​−21​−1=23​(xn​−1)=23​yn​,

also yn=y0(32)ny_n = y_0 \left(\frac32\right)^nyn​=y0​(23​)n (Induktion) und xn=(x0−1)(32)n+1x_n = (x_0 - 1)\left(\frac32\right)^n + 1xn​=(x0​−1)(23​)n+1. Jede Lösung hat somit die angegebene Form mit C=x0−1C = x_0 - 1C=x0​−1.

Probe: Mit xn=C(3/2)n+1x_n = C(3/2)^n + 1xn​=C(3/2)n+1:

2xn+1−3xn+1=2C(32)n+1+2−3C(32)n−3+1=3C(32)n−3C(32)n+0=0  ✓2x_{n+1} - 3x_n + 1 = 2C\left(\tfrac32\right)^{n+1} + 2 - 3C\left(\tfrac32\right)^n - 3 + 1 = 3C\left(\tfrac32\right)^n - 3C\left(\tfrac32\right)^n + 0 = 0 \;✓2xn+1​−3xn​+1=2C(23​)n+1+2−3C(23​)n−3+1=3C(23​)n−3C(23​)n+0=0✓

(b) xn+1−xn+7=0x_{n+1} - x_n + 7 = 0xn+1​−xn​+7=0

Umformen: xn+1=xn−7x_{n+1} = x_n - 7xn+1​=xn​−7. Hier ist a=1a = 1a=1, ein Fixpunkt existiert nicht (x∗=x∗−7x^* = x^* - 7x∗=x∗−7 ist unmöglich). Stattdessen sieht man direkt: In jedem Schritt wird 777 abgezogen, also nach nnn Schritten 7n7n7n.

Beweis per Induktion, dass xn=x0−7nx_n = x_0 - 7nxn​=x0​−7n: Für n=0n = 0n=0 klar. Gilt xn=x0−7nx_n = x_0 - 7nxn​=x0​−7n, so ist xn+1=xn−7=x0−7n−7=x0−7(n+1)x_{n+1} = x_n - 7 = x_0 - 7n - 7 = x_0 - 7(n+1)xn+1​=xn​−7=x0​−7n−7=x0​−7(n+1) ✓.

(Im Schema „homogen + partikulär“: homogene Lösung C⋅1n=CC\cdot 1^n = CC⋅1n=C, partikuläre Lösung −7n-7n−7n, denn −7(n+1)−(−7n)+7=0-7(n+1) - (-7n) + 7 = 0−7(n+1)−(−7n)+7=0.)

Allgemeine Lösung: xn=C−7nx_n = C - 7nxn​=C−7n mit C=x0∈RC = x_0 \in \RC=x0​∈R beliebig.

Die Lösungen von xn+1=a xn+bx_{n+1} = a\,x_n + bxn+1​=axn​+b sind xn={C an+b1−a,a≠1,C+b n,a=1,C∈R.x_n = \begin{cases} C\,a^n + \dfrac{b}{1-a}, & a \ne 1,\\[4pt] C + b\,n, & a = 1, \end{cases} \qquad C \in \R.xn​=⎩⎨⎧​Can+1−ab​,C+bn,​a=1,a=1,​C∈R.

Struktur der Lösungsmenge

Allgemeine Lösung der inhomogenen Gleichung = allgemeine Lösung der homogenen Gleichung + eine partikuläre Lösung. Die Differenz zweier Lösungen der inhomogenen Gleichung löst die homogene.

Typische Fehler
  • Vor dem Lösen nicht nach xn+1x_{n+1}xn+1​ auflösen und dann a=3a = 3a=3 statt a=32a = \frac32a=23​ verwenden.
  • Bei a=1a = 1a=1 einen konstanten Ansatz versuchen – der führt auf einen Widerspruch; der richtige Ansatz ist linear in nnn.
  • „Alle Lösungen“ mit nur einer Lösung beantworten: Die freie Konstante CCC gehört dazu.
