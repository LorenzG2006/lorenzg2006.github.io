Angabe Originalseite

Man ergänze die folgende Operationstafel so, dass ({a,b,c},∗)(\{a,b,c\},\ast)({a,b,c},∗) eine Gruppe ist.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Zuerst finden wir das neutrale Element eee – es ist einer von a,b,ca, b, ca,b,c, und wir schließen die falschen Kandidaten aus. Danach füllen wir die Tafel mit der Regel „jedes Element genau einmal pro Zeile und Spalte“ (lateinisches Quadrat) und prüfen die Gruppenaxiome.

Schritt 1: Welches Element ist neutral?

  • e=ae = ae=a? Dann wäre a∗a=aa\ast a = aa∗a=a, aber es ist a∗a=b≠aa\ast a = b\ne aa∗a=b=a. ✗
  • e=be = be=b? Dann wären Zeile und Spalte von bbb die Kopfzeile, insbesondere b∗c=cb\ast c = cb∗c=c und a∗b=aa\ast b = aa∗b=a. In Zeile aaa stünden dann schon bbb (bei a∗aa\ast aa∗a) und aaa (bei a∗ba\ast ba∗b), also müsste a∗c=ca\ast c = ca∗c=c sein. Dann stünde ccc in Spalte ccc zweimal (a∗c=c=b∗ca\ast c = c = b\ast ca∗c=c=b∗c) – Widerspruch zum lateinischen Quadrat. ✗
  • Also e=ce = ce=c.

bbb bbb

Schritt 2: Restliche Felder

  • a∗ba\ast ba∗b: Zeile aaa enthält bbb und aaa ⇒ a∗b=ca\ast b = ca∗b=c.
  • b∗ab\ast ab∗a: Spalte aaa enthält bbb (aus a∗aa\ast aa∗a) und aaa (aus c∗ac\ast ac∗a) ⇒ b∗a=cb\ast a = cb∗a=c.
  • b∗bb\ast bb∗b: Zeile bbb enthält ccc und bbb ⇒ b∗b=ab\ast b = ab∗b=a.

Alle Schritte waren erzwungen – die Lösung ist eindeutig.

Schritt 3: Gruppenaxiome

Umbenennen c↦0c\mapsto 0c↦0, a↦1a\mapsto 1a↦1, b↦2b\mapsto 2b↦2 liefert: 1+1=21+1 = 21+1=2 (a∗a=ba\ast a = ba∗a=b), 1+2=01+2 = 01+2=0 (a∗b=ca\ast b = ca∗b=c), 2+2=12+2 = 12+2=1 (b∗b=ab\ast b = ab∗b=a) – die Addition modulo 333. Also ist ({a,b,c},∗)≅(Z3,+)(\{a,b,c\},\ast)\cong(\Z_3,+)({a,b,c},∗)≅(Z3​,+) eine Gruppe; Inverse: c−1=cc^{-1} = cc−1=c, a−1=ba^{-1} = ba−1=b, b−1=ab^{-1} = ab−1=a.

Kontrolle
  • (a∗a)∗a=b∗a=c(a\ast a)\ast a = b\ast a = c(a∗a)∗a=b∗a=c und a∗(a∗a)=a∗b=ca\ast(a\ast a) = a\ast b = ca∗(a∗a)=a∗b=c ✓.
  • Python: Unter allen lateinischen Quadraten mit a∗a=ba\ast a = ba∗a=b ist genau eines eine Gruppentafel – die folgende ✓.

Neutrales Element ist ccc; die Ergänzung ist eindeutig, die Gruppe ist zyklisch (≅Z3\cong\Z_3≅Z3​, erzeugt von aaa).

Hilfreiches

Kürzungsregel

In einer Gruppe ist jede Zeile und jede Spalte der Tafel eine Permutation der Elemente (lateinisches Quadrat).

Ablesen des neutralen Elements

eee ist das Element, dessen Zeile und Spalte mit der Kopfzeile bzw. Kopfspalte übereinstimmen. Ein Feld x∗x=y≠xx\ast x = y\ne xx∗x=y=x zeigt, dass xxx nicht neutral ist.

Typische Fehler
  • Stillschweigend aaa als neutrales Element annehmen, weil es zuerst in der Tafel steht.
  • Den Fall e=be = be=b nicht sauber ausschließen.
