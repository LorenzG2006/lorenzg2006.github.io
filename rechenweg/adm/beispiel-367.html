Angabe Originalseite

Man ergänze die folgende Operationstafel so, dass ({a,b,c},∗)(\{a,b,c\},\ast)({a,b,c},∗) eine Gruppe ist.

∗\ast∗ aaa bbb ccc
aaa aaa
bbb
ccc

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Zwei Werkzeuge genügen:

  1. Idempotente Elemente: Gilt in einer Gruppe x∗x=xx\ast x = xx∗x=x, so ist xxx das neutrale Element (Bsp. 373).
  2. Lateinisches Quadrat: In der Tafel einer Gruppe kommt in jeder Zeile und jeder Spalte jedes Element genau einmal vor (Kürzungsregel).

Damit füllen wir die Tafel Schritt für Schritt eindeutig aus und prüfen am Ende die Gruppenaxiome.

Schritt 1: Das neutrale Element

Gegeben ist a∗a=aa\ast a = aa∗a=a. Multipliziert man in einer Gruppe von links mit a−1a^{-1}a−1, folgt a=ea = ea=e. Also ist aaa neutral: Zeile und Spalte von aaa wiederholen die Kopfzeile.

∗\ast∗ aaa bbb ccc
aaa aaa bbb ccc
bbb bbb
ccc ccc

Schritt 2: Lateinisches Quadrat

Warum? Wäre x∗y=x∗zx\ast y = x\ast zx∗y=x∗z mit y≠zy\ne zy=z, so folgte durch Linksmultiplikation mit x−1x^{-1}x−1 y=zy = zy=z. In jeder Zeile stehen also lauter verschiedene Elemente, d. h. (bei 3 Spalten) jedes genau einmal; analog für Spalten.

  • Feld b∗cb\ast cb∗c: In Zeile bbb steht schon bbb, also b∗c∈{a,c}b\ast c\in\{a,c\}b∗c∈{a,c}. In Spalte ccc steht schon ccc (aus a∗ca\ast ca∗c), also b∗c≠cb\ast c\ne cb∗c=c. Daher b∗c=ab\ast c = ab∗c=a.
  • Feld b∗bb\ast bb∗b: Zeile bbb enthält jetzt bbb und aaa, also b∗b=cb\ast b = cb∗b=c.
  • Feld c∗bc\ast bc∗b: Spalte bbb enthält bbb und ccc, also c∗b=ac\ast b = ac∗b=a.
  • Feld c∗cc\ast cc∗c: Zeile ccc enthält ccc und aaa, also c∗c=bc\ast c = bc∗c=b.

Jeder Schritt war erzwungen – die Ergänzung ist eindeutig.

Schritt 3: Ist das wirklich eine Gruppe?

Das lateinische Quadrat allein garantiert noch keine Assoziativität. Wir benennen um: a↦0a\mapsto 0a↦0, b↦1b\mapsto 1b↦1, c↦2c\mapsto 2c↦2. Dann lautet die Tafel

+++ 0 1 2
0 0 1 2
1 1 2 0
2 2 0 1

– das ist genau die Addition modulo 333, also die Gruppe (Z3,+)(\Z_3,+)(Z3​,+). Damit sind Assoziativität, neutrales Element (aaa) und Inverse (a−1=aa^{-1} = aa−1=a, b−1=cb^{-1} = cb−1=c, c−1=bc^{-1} = bc−1=b) gesichert.

Kontrolle
  • Beispiel Assoziativität: (b∗b)∗c=c∗c=b(b\ast b)\ast c = c\ast c = b(b∗b)∗c=c∗c=b und b∗(b∗c)=b∗a=bb\ast(b\ast c) = b\ast a = bb∗(b∗c)=b∗a=b ✓.
  • Python: Unter allen lateinischen Quadraten auf {a,b,c}\{a,b,c\}{a,b,c} mit a∗a=aa\ast a = aa∗a=a gibt es genau eines, das eine Gruppe ist – die obige Tafel ✓.
Ergebnis
∗\ast∗ aaa bbb ccc
aaa aaa bbb ccc
bbb bbb ccc aaa
ccc ccc aaa bbb

Die Ergänzung ist eindeutig; aaa ist neutral, und die Gruppe ist isomorph zu (Z3,+)(\Z_3,+)(Z3​,+).

Hilfreiches

Kürzungsregel

In einer Gruppe folgt aus x∗y=x∗zx\ast y = x\ast zx∗y=x∗z stets y=zy = zy=z und aus y∗x=z∗xy\ast x = z\ast xy∗x=z∗x stets y=zy = zy=z. Daher ist die Gruppentafel ein lateinisches Quadrat.

Gruppen kleiner Ordnung

Jede Gruppe mit 3 Elementen ist zyklisch, also isomorph zu Z3\Z_3Z3​.

Typische Fehler
  • Nur das lateinische Quadrat prüfen und die Assoziativität vergessen – es gibt lateinische Quadrate, die keine Gruppentafeln sind.
  • Übersehen, dass a∗a=aa\ast a = aa∗a=a schon a=ea = ea=e erzwingt.
