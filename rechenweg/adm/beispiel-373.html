Angabe Originalseite

Man zeige: Gilt für ein Element aaa einer Gruppe GGG: a∗a=aa\ast a = aa∗a=a, dann ist aaa das neutrale Element von GGG.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

In einer Gruppe darf man „kürzen“, weil jedes Element ein Inverses hat. Wir multiplizieren die Gleichung a∗a=aa\ast a = aa∗a=a von links mit a−1a^{-1}a−1 und vereinfachen mit Assoziativität, Inversen und neutralem Element. Dabei verwenden wir nur die Gruppenaxiome.

Voraussetzungen

(G,∗)(G,\ast)(G,∗) ist eine Gruppe, d. h.:

  1. ∗\ast∗ ist assoziativ,
  2. es gibt ein neutrales Element eee mit e∗x=x∗e=xe\ast x = x\ast e = xe∗x=x∗e=x für alle x∈Gx\in Gx∈G,
  3. zu jedem x∈Gx\in Gx∈G gibt es x−1∈Gx^{-1}\in Gx−1∈G mit x−1∗x=x∗x−1=ex^{-1}\ast x = x\ast x^{-1} = ex−1∗x=x∗x−1=e.

Sei a∈Ga\in Ga∈G mit a∗a=aa\ast a = aa∗a=a. Zu zeigen: a=ea = ea=e.

Plausibilität
  • Umgekehrt ist eee tatsächlich idempotent: e∗e=ee\ast e = ee∗e=e. Also gilt in jeder Gruppe: x∗x=x  ⟺  x=ex\ast x = x \iff x = ex∗x=x⟺x=e.
  • Beispiel (Z,+)(\Z,+)(Z,+): x+x=xx + x = xx+x=x ⇒ x=0x = 0x=0 ✓. Beispiel (Q∖{0},⋅)(\Q\setminus\{0\},\cdot)(Q∖{0},⋅): x⋅x=xx\cdot x = xx⋅x=x ⇒ x=1x = 1x=1 (die Lösung x=0x = 0x=0 liegt nicht in der Gruppe) ✓.
Ergebnis

Aus a∗a=aa\ast a = aa∗a=a folgt durch Linksverknüpfung mit a−1a^{-1}a−1: a=e∗a=(a−1∗a)∗a=a−1∗(a∗a)=a−1∗a=e.a = e\ast a = (a^{-1}\ast a)\ast a = a^{-1}\ast(a\ast a) = a^{-1}\ast a = e.a=e∗a=(a−1∗a)∗a=a−1∗(a∗a)=a−1∗a=e. In einer Gruppe ist daher das neutrale Element das einzige idempotente Element.

In Monoiden falsch

Ohne Inverse gilt die Aussage nicht: Im Monoid (P(A),∪)(\mathcal P(A),\cup)(P(A),∪) ist jedes Element idempotent (B∪B=BB\cup B = BB∪B=B), aber nur ∅\emptyset∅ ist neutral (Bsp. 353). Ebenso in (N,max⁡)(\N,\max)(N,max) (Bsp. 363). Der Beweis benötigt also wirklich das Inverse von aaa.

Hilfreiches

Gruppe

Eine Menge mit assoziativer Operation, neutralem Element und Inversen zu jedem Element.

Kürzungsregel

In einer Gruppe folgt aus x∗y=x∗zx\ast y = x\ast zx∗y=x∗z stets y=zy = zy=z. (Beweis wie oben durch Linksverknüpfung mit x−1x^{-1}x−1.) Die Aussage dieses Beispiels ist der Spezialfall x=y=ax = y = ax=y=a, z=ez = ez=e: a∗a=a=a∗ea\ast a = a = a\ast ea∗a=a=a∗e ⇒ a=ea = ea=e.

Typische Fehler
  • „Durch aaa dividieren“ – in einer allgemeinen Gruppe gibt es keine Division, nur die Verknüpfung mit a−1a^{-1}a−1; und man muss angeben, von welcher Seite verknüpft wird (auf beiden Seiten der Gleichung von derselben Seite!).
  • Die Assoziativität stillschweigend verwenden, ohne sie zu nennen.
