Angabe Originalseite

Ein Polynom heißt irreduzibel, wenn es nicht als Produkt zweier Polynome kleineren Grades darstellbar ist.

Untersuchen Sie das Polynom x2+x+1x^2 + x + 1x2+x+1 auf Irreduzibilität a) über Q\QQ, b) über Z3\Z_3Z3​.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Für Polynome vom Grad 2 oder 3 über einem Körper KKK gibt es ein einfaches Kriterium: Ist f=g⋅hf = g\cdot hf=g⋅h mit deg⁡g,deg⁡h<deg⁡f\deg g, \deg h < \deg fdegg,degh<degf, so muss einer der Faktoren Grad 111 haben (denn die Grade addieren sich: 2=1+12 = 1 + 12=1+1 bzw. 3=1+23 = 1 + 23=1+2). Ein Faktor c(x−x0)c(x - x_0)c(x−x0​) vom Grad 1 entspricht genau einer Nullstelle x0∈Kx_0 \in Kx0​∈K. Also: deg⁡f∈{2,3}:f reduzibel u¨ber K  ⟺  f hat eine Nullstelle in K.\deg f \in \{2, 3\}: \quad f \text{ reduzibel über } K \iff f \text{ hat eine Nullstelle in } K.degf∈{2,3}:f reduzibel u¨ber K⟺f hat eine Nullstelle in K. Wir suchen daher Nullstellen in Q\QQ bzw. in Z3\Z_3Z3​.

Sei f(x)=x2+x+1f(x) = x^2 + x + 1f(x)=x2+x+1.

(a) Über Q\QQ

Die Diskriminante ist D=12−4⋅1⋅1=−3<0D = 1^2 - 4\cdot 1\cdot 1 = -3 < 0D=12−4⋅1⋅1=−3<0. Damit hat fff nicht einmal reelle Nullstellen (die Nullstellen sind −1±i32∈C∖R\frac{-1 \pm i\sqrt3}{2} \in \C \setminus \R2−1±i3​​∈C∖R), erst recht keine rationalen.

Alternativ ohne Diskriminante: Für alle x∈Rx \in \Rx∈R ist x2+x+1=(x+12)2+34≥34>0,x^2 + x + 1 = \Bigl(x + \tfrac12\Bigr)^2 + \tfrac34 \ge \tfrac34 > 0,x2+x+1=(x+21​)2+43​≥43​>0, also f(x)≠0f(x) \ne 0f(x)=0.

Nach dem Kriterium aus der Idee-Box ist fff über Q\QQ irreduzibel.

(b) Über Z3\Z_3Z3​

Z3\Z_3Z3​ hat nur drei Elemente, wir setzen alle ein (Rechnung modulo 333):

0 0+0+1=10 + 0 + 1 = 10+0+1=1 1
1 1+1+1=31 + 1 + 1 = 31+1+1=3 0

x=1x = 1x=1 ist eine Nullstelle, also ist x−1x - 1x−1 ein Faktor. Polynomdivision (oder Koeffizientenvergleich) liefert den zweiten Faktor: Ansatz x2+x+1=(x−1)(x+c)x^2 + x + 1 = (x - 1)(x + c)x2+x+1=(x−1)(x+c). Ausmultiplizieren ergibt x2+(c−1)x−cx^2 + (c - 1)x - cx2+(c−1)x−c. Vergleich der xxx-Koeffizienten: c−1≡1c - 1 \equiv 1c−1≡1, also c≡2≡−1c \equiv 2 \equiv -1c≡2≡−1. Konstante: −c=1-c = 1−c=1 ✓. Somit x2+x+1=(x−1)(x−1)=(x−1)2=(x+2)2in Z3[x].x^2 + x + 1 = (x - 1)(x - 1) = (x - 1)^2 = (x + 2)^2 \quad\text{in } \Z_3[x].x2+x+1=(x−1)(x−1)=(x−1)2=(x+2)2in Z3​[x].

Ausmultiplizieren

(x+2)2=x2+4x+4≡x2+x+1(mod3)(x + 2)^2 = x^2 + 4x + 4 \equiv x^2 + x + 1 \pmod 3(x+2)2=x2+4x+4≡x2+x+1(mod3). ✓

Das ist eine Zerlegung in zwei Polynome vom Grad 1<21 < 21<2, also ist fff über Z3\Z_3Z3​ reduzibel.

Ergebnis
  • (a) x2+x+1x^2 + x + 1x2+x+1 ist über Q\QQ irreduzibel (keine rationale, nicht einmal reelle Nullstelle).
  • (b) Über Z3\Z_3Z3​ ist x2+x+1=(x+2)2x^2 + x + 1 = (x + 2)^2x2+x+1=(x+2)2 reduzibel (doppelte Nullstelle x=1x = 1x=1).
Warum gerade Z3\Z_3Z3​?

In Z3\Z_3Z3​ ist D=−3≡0D = -3 \equiv 0D=−3≡0. Eine Diskriminante 000 bedeutet eine doppelte Nullstelle – genau das sieht man an (x+2)2(x+2)^2(x+2)2. (Die Lösungsformel selbst ist in Z3\Z_3Z3​ allerdings noch anwendbar, weil 2≠02 \ne 02=0 ist; x0=−b(2a)−1=−1⋅2−1=−2≡1x_0 = -b(2a)^{-1} = -1\cdot 2^{-1} = -2 \equiv 1x0​=−b(2a)−1=−1⋅2−1=−2≡1.)

Hilfreiches

Nullstellenkriterium für kleine Grade

Sei KKK ein Körper und f∈K[x]f \in K[x]f∈K[x] mit deg⁡f∈{2,3}\deg f \in \{2, 3\}degf∈{2,3}. Dann ist fff genau dann reduzibel über KKK, wenn fff eine Nullstelle in KKK hat. Grund: x0x_0x0​ ist Nullstelle   ⟺  (x−x0)∣f\iff (x - x_0) \mid f⟺(x−x0​)∣f, und eine echte Zerlegung muss einen Faktor vom Grad 1 enthalten.

Typische Fehler
  • Das Kriterium auf Grad ≥4\ge 4≥4 übertragen: (x2+1)2(x^2+1)^2(x2+1)2 hat über Q\QQ keine Nullstelle, ist aber reduzibel.
  • Bei endlichen Körpern nicht alle Elemente einsetzen – die Tabelle muss vollständig sein.
  • „Irreduzibel über Q\QQ“ mit „irreduzibel über C\CC“ verwechseln: Über C\CC zerfällt jedes Polynom vom Grad ≥2\ge 2≥2.
