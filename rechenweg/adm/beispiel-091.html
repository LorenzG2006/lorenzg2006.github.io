Angabe Originalseite

Man beweise, dass die folgenden drei Aussagen äquivalent sind. (D. h., gilt eine der drei Aussagen, dann gelten alle drei.)

(i) A⊆B,(ii) A∪B=B,(iii) A∩B=A.\text{(i) } A \subseteq B, \qquad \text{(ii) } A \cup B = B, \qquad \text{(iii) } A \cap B = A .(i) A⊆B,(ii) A∪B=B,(iii) A∩B=A.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Statt sechs Implikationen zu zeigen, genügt ein Ringschluss (i) ⇒\Rightarrow⇒ (ii) ⇒\Rightarrow⇒ (iii) ⇒\Rightarrow⇒ (i): Daraus folgt jede Aussage aus jeder anderen, indem man im Kreis weitergeht. Mengengleichheit X=YX = YX=Y zeigen wir über die beiden Inklusionen X⊆YX \subseteq YX⊆Y und Y⊆XY \subseteq XY⊆X, jeweils elementweise.

(i) ⇒\Rightarrow⇒ (ii)

Voraussetzung: A⊆BA \subseteq BA⊆B, d. h. jedes Element von AAA liegt in BBB. Zu zeigen: A∪B=BA \cup B = BA∪B=B.

  • „⊇\supseteq⊇“: B⊆A∪BB \subseteq A \cup BB⊆A∪B gilt immer, denn jedes x∈Bx \in Bx∈B erfüllt „x∈Ax \in Ax∈A oder x∈Bx \in Bx∈B“.
  • „⊆\subseteq⊆“: Sei x∈A∪Bx \in A \cup Bx∈A∪B. Dann ist x∈Ax \in Ax∈A oder x∈Bx \in Bx∈B. Im ersten Fall ist wegen A⊆BA \subseteq BA⊆B ebenfalls x∈Bx \in Bx∈B. In beiden Fällen x∈Bx \in Bx∈B.

Also A∪B=BA \cup B = BA∪B=B.

(ii) ⇒\Rightarrow⇒ (iii)

Voraussetzung: A∪B=BA \cup B = BA∪B=B. Zu zeigen: A∩B=AA \cap B = AA∩B=A.

  • „⊆\subseteq⊆“: A∩B⊆AA \cap B \subseteq AA∩B⊆A gilt immer (jedes Element des Durchschnitts liegt in AAA).
  • „⊇\supseteq⊇“: Sei x∈Ax \in Ax∈A. Dann ist x∈A∪B=Bx \in A \cup B = Bx∈A∪B=B (Voraussetzung), also x∈Bx \in Bx∈B. Mit x∈Ax \in Ax∈A folgt x∈A∩Bx \in A \cap Bx∈A∩B.

Also A∩B=AA \cap B = AA∩B=A.

(iii) ⇒\Rightarrow⇒ (i)

Voraussetzung: A∩B=AA \cap B = AA∩B=A. Zu zeigen: A⊆BA \subseteq BA⊆B.

Sei x∈Ax \in Ax∈A. Wegen A=A∩BA = A \cap BA=A∩B ist x∈A∩Bx \in A \cap Bx∈A∩B, also insbesondere x∈Bx \in Bx∈B. Damit liegt jedes Element von AAA in BBB, d. h. A⊆BA \subseteq BA⊆B.

Abschluss

Aus (i) ⇒\Rightarrow⇒ (ii) ⇒\Rightarrow⇒ (iii) ⇒\Rightarrow⇒ (i) folgt z. B. auch (ii) ⇒\Rightarrow⇒ (i) (über (iii)) und (iii) ⇒\Rightarrow⇒ (ii) (über (i)). Alle drei Aussagen sind äquivalent. ■\blacksquare■

Illustration

A={1,2}A = \{1, 2\}A={1,2}, B={1,2,3}B = \{1, 2, 3\}B={1,2,3}: A⊆BA \subseteq BA⊆B, A∪B={1,2,3}=BA \cup B = \{1,2,3\} = BA∪B={1,2,3}=B, A∩B={1,2}=AA \cap B = \{1, 2\} = AA∩B={1,2}=A – alle drei wahr. A={1,4}A = \{1, 4\}A={1,4}, B={1,2,3}B = \{1, 2, 3\}B={1,2,3}: A⊈BA \not\subseteq BA⊆B, A∪B={1,2,3,4}≠BA \cup B = \{1,2,3,4\} \ne BA∪B={1,2,3,4}=B, A∩B={1}≠AA \cap B = \{1\} \ne AA∩B={1}=A – alle drei falsch.

Ergebnis

A⊆B  ⟺  A∪B=B  ⟺  A∩B=A,A \subseteq B \iff A \cup B = B \iff A \cap B = A,A⊆B⟺A∪B=B⟺A∩B=A, bewiesen durch den Ringschluss (i) ⇒\Rightarrow⇒ (ii) ⇒\Rightarrow⇒ (iii) ⇒\Rightarrow⇒ (i). ■\blacksquare■

Kontrolle

Mit Python an 300030003000 zufälligen Teilmengen von {0,…,7}\{0, \dots, 7\}{0,…,7} geprüft: Die drei Aussagen sind stets gleichzeitig wahr oder gleichzeitig falsch.

Hilfreiches

Teilmenge und Mengengleichheit

A⊆B:  ⟺  ∀x:(x∈A⇒x∈B)A \subseteq B :\iff \forall x: (x \in A \Rightarrow x \in B)A⊆B:⟺∀x:(x∈A⇒x∈B). Es gilt A=B  ⟺  A⊆B∧B⊆AA = B \iff A \subseteq B \land B \subseteq AA=B⟺A⊆B∧B⊆A.

Ringschluss

Um die Äquivalenz von nnn Aussagen zu zeigen, genügt eine geschlossene Kette von nnn Implikationen p1⇒p2⇒⋯⇒pn⇒p1p_1 \Rightarrow p_2 \Rightarrow \dots \Rightarrow p_n \Rightarrow p_1p1​⇒p2​⇒⋯⇒pn​⇒p1​.

Typische Fehler
  • Bei einer Mengengleichheit nur eine Inklusion zeigen.
  • Den Ringschluss nicht schließen (z. B. nur (i) ⇒\Rightarrow⇒ (ii) und (i) ⇒\Rightarrow⇒ (iii)) – dann fehlt die Rückrichtung.
  • Mit einem Venn-Diagramm „beweisen“: Es veranschaulicht, ersetzt aber keinen Beweis.
