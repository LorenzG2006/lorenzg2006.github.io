Angabe Originalseite

Zeigen Sie, dass die Vektoren x1,x2,x3\mathbf{x}_1, \mathbf{x}_2, \mathbf{x}_3x1​,x2​,x3​ eines Vektorraumes genau dann linear unabhängig sind, wenn x1+x2+x3,x2+x3,x3\mathbf{x}_1 + \mathbf{x}_2 + \mathbf{x}_3, \mathbf{x}_2 + \mathbf{x}_3, \mathbf{x}_3x1​+x2​+x3​,x2​+x3​,x3​ linear unabhängig sind.

Lösung verborgen – erst selbst probieren!

Überblick

Wir beweisen beide Richtungen getrennt. Jeweils wird eine Linearkombination gleich o\mathbf{o}o gesetzt und nach den Vektoren umgeordnet, deren Unabhängigkeit vorausgesetzt ist; dann müssen alle Koeffizienten verschwinden. Für die Rückrichtung stellen wir die xi\mathbf{x}_ixi​ als Kombination der neuen Vektoren dar.

Sei VVV ein Vektorraum über KKK und

y1:=x1+x2+x3,y2:=x2+x3,y3:=x3.\mathbf{y}_1 := \mathbf{x}_1 + \mathbf{x}_2 + \mathbf{x}_3,\qquad \mathbf{y}_2 := \mathbf{x}_2 + \mathbf{x}_3,\qquad \mathbf{y}_3 := \mathbf{x}_3 .y1​:=x1​+x2​+x3​,y2​:=x2​+x3​,y3​:=x3​.

Richtung „⇒“

Voraussetzung: x1,x2,x3\mathbf{x}_1, \mathbf{x}_2, \mathbf{x}_3x1​,x2​,x3​ linear unabhängig. Aus λ1y1+λ2y2+λ3y3=o\lambda_1\mathbf{y}_1 + \lambda_2\mathbf{y}_2 + \lambda_3\mathbf{y}_3 = \mathbf{o}λ1​y1​+λ2​y2​+λ3​y3​=o folgt

o=λ1(x1+x2+x3)+λ2(x2+x3)+λ3x3=λ1x1+(λ1+λ2)x2+(λ1+λ2+λ3)x3.(nach xi ordnen)\begin{aligned} \mathbf{o} &= \lambda_1(\mathbf{x}_1 + \mathbf{x}_2 + \mathbf{x}_3) + \lambda_2(\mathbf{x}_2 + \mathbf{x}_3) + \lambda_3\mathbf{x}_3\\ &= \lambda_1\mathbf{x}_1 + (\lambda_1 + \lambda_2)\mathbf{x}_2 + (\lambda_1 + \lambda_2 + \lambda_3)\mathbf{x}_3 . && \text{(nach } \mathbf{x}_i \text{ ordnen)} \end{aligned}o​=λ1​(x1​+x2​+x3​)+λ2​(x2​+x3​)+λ3​x3​=λ1​x1​+(λ1​+λ2​)x2​+(λ1​+λ2​+λ3​)x3​.​​(nach xi​ ordnen)​

Da die xi\mathbf{x}_ixi​ unabhängig sind:

λ1=0,λ1+λ2=0,λ1+λ2+λ3=0.\lambda_1 = 0,\qquad \lambda_1 + \lambda_2 = 0,\qquad \lambda_1 + \lambda_2 + \lambda_3 = 0 .λ1​=0,λ1​+λ2​=0,λ1​+λ2​+λ3​=0.

Daraus nacheinander λ1=0\lambda_1 = 0λ1​=0, λ2=0\lambda_2 = 0λ2​=0, λ3=0\lambda_3 = 0λ3​=0. Also sind die yi\mathbf{y}_iyi​ linear unabhängig.

Richtung „⇐“

Voraussetzung: y1,y2,y3\mathbf{y}_1, \mathbf{y}_2, \mathbf{y}_3y1​,y2​,y3​ linear unabhängig. Rückrechnung:

x3=y3,x2=y2−x3=y2−y3,x1=y1−(x2+x3)=y1−y2.\mathbf{x}_3 = \mathbf{y}_3,\qquad \mathbf{x}_2 = \mathbf{y}_2 - \mathbf{x}_3 = \mathbf{y}_2 - \mathbf{y}_3,\qquad \mathbf{x}_1 = \mathbf{y}_1 - (\mathbf{x}_2 + \mathbf{x}_3) = \mathbf{y}_1 - \mathbf{y}_2 .x3​=y3​,x2​=y2​−x3​=y2​−y3​,x1​=y1​−(x2​+x3​)=y1​−y2​.

Aus μ1x1+μ2x2+μ3x3=o\mu_1\mathbf{x}_1 + \mu_2\mathbf{x}_2 + \mu_3\mathbf{x}_3 = \mathbf{o}μ1​x1​+μ2​x2​+μ3​x3​=o folgt

o=μ1(y1−y2)+μ2(y2−y3)+μ3y3=μ1y1+(μ2−μ1)y2+(μ3−μ2)y3.(nach yi ordnen)\begin{aligned} \mathbf{o} &= \mu_1(\mathbf{y}_1 - \mathbf{y}_2) + \mu_2(\mathbf{y}_2 - \mathbf{y}_3) + \mu_3\mathbf{y}_3\\ &= \mu_1\mathbf{y}_1 + (\mu_2 - \mu_1)\mathbf{y}_2 + (\mu_3 - \mu_2)\mathbf{y}_3 . && \text{(nach } \mathbf{y}_i \text{ ordnen)} \end{aligned}o​=μ1​(y1​−y2​)+μ2​(y2​−y3​)+μ3​y3​=μ1​y1​+(μ2​−μ1​)y2​+(μ3​−μ2​)y3​.​​(nach yi​ ordnen)​

Unabhängigkeit der yi\mathbf{y}_iyi​ liefert μ1=0\mu_1 = 0μ1​=0, μ2−μ1=0\mu_2 - \mu_1 = 0μ2​−μ1​=0, μ3−μ2=0\mu_3 - \mu_2 = 0μ3​−μ2​=0, also μ1=μ2=μ3=0\mu_1 = \mu_2 = \mu_3 = 0μ1​=μ2​=μ3​=0. Die xi\mathbf{x}_ixi​ sind linear unabhängig.

Ergebnis

x1,x2,x3\mathbf{x}_1, \mathbf{x}_2, \mathbf{x}_3x1​,x2​,x3​ linear unabhängig   ⟺  \iff⟺ x1+x2+x3, x2+x3, x3\mathbf{x}_1 + \mathbf{x}_2 + \mathbf{x}_3,\ \mathbf{x}_2 + \mathbf{x}_3,\ \mathbf{x}_3x1​+x2​+x3​, x2​+x3​, x3​ linear unabhängig. ■\blacksquare■

Probe

y1−y2=(x1+x2+x3)−(x2+x3)=x1\mathbf{y}_1 - \mathbf{y}_2 = (\mathbf{x}_1 + \mathbf{x}_2 + \mathbf{x}_3) - (\mathbf{x}_2 + \mathbf{x}_3) = \mathbf{x}_1y1​−y2​=(x1​+x2​+x3​)−(x2​+x3​)=x1​ ✓, y2−y3=x2\mathbf{y}_2 - \mathbf{y}_3 = \mathbf{x}_2y2​−y3​=x2​ ✓.

Matrixsicht

Die Übergangsmatrix (Spalten = Koeffizienten der yj\mathbf{y}_jyj​ bezüglich der xi\mathbf{x}_ixi​) ist T=(100110111)T = \begin{pmatrix} 1 & 0 & 0\\ 1 & 1 & 0\\ 1 & 1 & 1\end{pmatrix}T=​111​011​001​​, eine untere Dreiecksmatrix mit Diagonale 1,1,11,1,11,1,1, also det⁡T=1≠0\det T = 1 \neq 0detT=1=0: invertierbar.

Hilfreiches

Invertierbare Transformation

Ist (y1,…,yn)=(x1,…,xn) T(\mathbf{y}_1,\dots,\mathbf{y}_n) = (\mathbf{x}_1,\dots,\mathbf{x}_n)\,T(y1​,…,yn​)=(x1​,…,xn​)T mit invertierbarer Matrix TTT, so sind die xi\mathbf{x}_ixi​ genau dann linear unabhängig, wenn die yi\mathbf{y}_iyi​ es sind, und beide spannen denselben Unterraum auf.

Typische Fehler
  • Beim Ausmultiplizieren vergessen, dass x3\mathbf{x}_3x3​ in allen drei Vektoren vorkommt (Koeffizient λ1+λ2+λ3\lambda_1 + \lambda_2 + \lambda_3λ1​+λ2​+λ3​).
  • Die Rückrichtung weglassen oder nur mit „analog“ begründen.

Verwandte Beispiele: Bsp. 503, Bsp. 505.
