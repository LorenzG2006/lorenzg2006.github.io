Überblick

Entscheidend ist 10≡−1(mod11)10 \equiv -1 \pmod{11}10≡−1(mod11). Dann ist 10i≡(−1)i10^i \equiv (-1)^i10i≡(−1)i, und die Dezimaldarstellung wird modulo 111111 zur alternierenden Ziffernsumme. Wie in Bsp. 72 folgt aus der Kongruenz x≡A(x)x \equiv A(x)x≡A(x) die Äquivalenz in beiden Richtungen.

Schritt 3: Äquivalenz

Aus x≡A(x)(mod11)x \equiv A(x) \pmod{11}x≡A(x)(mod11) folgt 11∣x−A(x)11 \mid x - A(x)11∣x−A(x). Daher:

  • Ist 11∣x11 \mid x11∣x, so auch 11∣x−(x−A(x))=A(x)11 \mid x - (x - A(x)) = A(x)11∣x−(x−A(x))=A(x).
  • Ist 11∣A(x)11 \mid A(x)11∣A(x), so auch 11∣A(x)+(x−A(x))=x11 \mid A(x) + (x - A(x)) = x11∣A(x)+(x−A(x))=x.

(Die alternierende Summe kann negativ sein; „durch 11 teilbar“ ist für negative Zahlen genauso definiert, z. B. 11∣−1111 \mid -1111∣−11.)

Hilfreiches

Potenzen von Kongruenzen

Aus a≡b(modm)a \equiv b \pmod ma≡b(modm) folgt ai≡bi(modm)a^i \equiv b^i \pmod mai≡bi(modm) für alle i∈Ni \in \Ni∈N.

Allgemeines Prinzip

Ist 10≡r(modm)10 \equiv r \pmod m10≡r(modm), so gilt x≡∑airi(modm)x \equiv \sum a_i r^i \pmod mx≡∑ai​ri(modm). Für m=3,9m = 3, 9m=3,9 ist r=1r = 1r=1 (Ziffernsumme), für m=11m = 11m=11 ist r=−1r = -1r=−1 (alternierende Summe).

Typische Fehler
  • Mit der höchsten Stelle mit +++ beginnen: Das Vorzeichen ändert sich dann höchstens global (±A(x)\pm A(x)±A(x)), was für die Teilbarkeit egal ist – für den Rest modulo 111111 aber nicht.
  • Die Stellen falsch nummerieren: a0a_0a0​ ist die Einerstelle.

Verwandte Beispiele: Bsp. 72, Bsp. 74, Bsp. 70.
