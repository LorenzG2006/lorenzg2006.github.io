4–13) Man beweise mittels vollständiger Induktion:

Ist a0=0a_0 = 0a0​=0 und an+1=an+(n+1)a_{n+1} = a_n + (n+1)an+1​=an​+(n+1) für alle n∈Nn \in \Nn∈N, so gilt an=n(n+1)2a_n = \frac{n(n+1)}{2}an​=2n(n+1)​.

Lösung

Lösung verborgen – erst selbst probieren!

Überblick

Die Folge ist rekursiv gegeben: Jedes Glied entsteht aus dem vorigen. Eine explizite Formel für rekursiv definierte Folgen beweist man typischerweise per Induktion: Den Anfang liefert der Startwert a0a_0a0​, den Schritt die Rekursionsgleichung zusammen mit der IV.

Zur Orientierung die ersten Glieder aus der Rekursion: a0=0a_0 = 0a0​=0, a1=0+1=1a_1 = 0 + 1 = 1a1​=0+1=1, a2=1+2=3a_2 = 1 + 2 = 3a2​=1+2=3, a3=3+3=6a_3 = 3 + 3 = 6a3​=3+3=6, a4=6+4=10a_4 = 6 + 4 = 10a4​=6+4=10. Die Formel liefert 0⋅12=0\frac{0\cdot1}{2} = 020⋅1​=0, 1⋅22=1\frac{1\cdot 2}{2} = 121⋅2​=1, 2⋅32=3\frac{2\cdot3}{2} = 322⋅3​=3, 3⋅42=6\frac{3\cdot4}{2} = 623⋅4​=6, 4⋅52=10\frac{4\cdot5}{2} = 1024⋅5​=10 – passt. (Die ana_nan​ sind die Dreieckszahlen 1+2+⋯+n1 + 2 + \dots + n1+2+⋯+n.)

Induktionsanfang (n=0n = 0n=0): Nach Definition ist a0=0a_0 = 0a0​=0, und 0⋅12=0\frac{0 \cdot 1}{2} = 020⋅1​=0. ✓

Induktionsvoraussetzung (IV): Für ein festes, aber beliebiges n∈Nn \in \Nn∈N gelte an=n(n+1)2a_n = \frac{n(n+1)}{2}an​=2n(n+1)​.

Induktionsbehauptung: an+1=(n+1)(n+2)2a_{n+1} = \frac{(n+1)(n+2)}{2}an+1​=2(n+1)(n+2)​.

Induktionsschritt (n→n+1n \to n+1n→n+1):

an+1=an+(n+1)(Rekursionsgleichung)=IVn(n+1)2+(n+1)(Induktionsvoraussetzung)=n(n+1)+2(n+1)2(gemeinsamer Nenner 2)=(n+1)(n+2)2.((n+1) herausheben)\begin{aligned} a_{n+1} &= a_n + (n+1) && \text{(Rekursionsgleichung)}\\ &\overset{\text{IV}}{=} \frac{n(n+1)}{2} + (n+1) && \text{(Induktionsvoraussetzung)}\\ &= \frac{n(n+1) + 2(n+1)}{2} && \text{(gemeinsamer Nenner 2)}\\ &= \frac{(n+1)(n+2)}{2}. && \text{(}(n+1)\text{ herausheben)} \end{aligned}an+1​​=an​+(n+1)=IV2n(n+1)​+(n+1)=2n(n+1)+2(n+1)​=2(n+1)(n+2)​.​​(Rekursionsgleichung)(Induktionsvoraussetzung)(gemeinsamer Nenner 2)((n+1) herausheben)​

Das ist die Induktionsbehauptung. Also gilt an=n(n+1)2a_n = \frac{n(n+1)}{2}an​=2n(n+1)​ für alle n∈Nn \in \Nn∈N.

Ergebnis

Für die Folge mit a0=0a_0 = 0a0​=0, an+1=an+(n+1)a_{n+1} = a_n + (n+1)an+1​=an​+(n+1) gilt an=n(n+1)2fu¨r alle n∈N.■a_n = \frac{n(n+1)}{2} \qquad \text{für alle } n \in \N. \quad \blacksquarean​=2n(n+1)​fu¨r alle n∈N.■

Hilfreiches

Induktion für rekursiv definierte Folgen

Ist an+1=f(n,an)a_{n+1} = f(n, a_n)an+1​=f(n,an​) und vermutet man an=g(n)a_n = g(n)an​=g(n), so genügt es zu zeigen: an0=g(n0)a_{n_0} = g(n_0)an0​​=g(n0​) und f(n,g(n))=g(n+1)f(n, g(n)) = g(n+1)f(n,g(n))=g(n+1) für alle n≥n0n \ge n_0n≥n0​.

Gaußsche Summenformel

1+2+⋯+n=∑k=1nk=n(n+1)2.1 + 2 + \dots + n = \sum_{k=1}^{n} k = \frac{n(n+1)}{2}.1+2+⋯+n=k=1∑n​k=2n(n+1)​. Die Rekursion beschreibt genau das schrittweise Aufsummieren.

Typische Fehler
  • Im Schritt die explizite Formel für an+1a_{n+1}an+1​ verwenden, statt von der Rekursion auszugehen.
  • Den Induktionsanfang bei n=1n = 1n=1 machen, obwohl die Folge bei a0a_0a0​ startet (das wäre hier zwar auch richtig, lässt aber n=0n = 0n=0 unbewiesen).
